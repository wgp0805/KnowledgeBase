# 什么是 Loop Engineering？

面试题讲解 Loop Engineering：设计 Agent 循环结构的工程实践——单循环、嵌套循环、并行循环。沉默王二分析 Loop Engineering 是 Harness Engineering 的进阶，决定 Agent 如何迭代、何时终止、如何从错误中恢复。
