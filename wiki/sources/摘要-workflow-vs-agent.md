# Workflow 和 Agent 有什么区别

面试题辨析 Workflow 与 Agent 区别：Workflow 是开发者预定义流程，LLM 在节点干活但不决定走向；Agent 是 LLM 自主决定下一步。沉默王二给出判断标准——能画出完整流程图就是 Workflow，画不出就交给 Agent。
