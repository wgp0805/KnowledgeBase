# 摘要：大厂争相开源 Harness 背后的商业阳谋

## 核心主旨
OpenAI（Codex CLI）、DeepSeek（DeepSeek Harness）相继开源 Agent Harness 框架，标志着 AI 竞争从模型层下沉到框架层。Harness 是连接模型与真实环境的执行层，开源 Harness 的本质是用免费框架锁定开发者生态，为未来的模型订阅和云服务铺路。

## 关键论点
1. **Harness 是 Agent 时代的"操作系统"**：模型负责判断下一步，Harness 负责理解环境、调用工具、管理会话与权限。谁掌握 Harness 标准，谁就掌握 Agent 分发入口。
2. **开源是商业策略而非慈善**：大厂开源 Harness 框架，目的是让开发者依赖其工具链，最终将流量导回自家模型 API 和云服务。
3. **竞争重心转移**：从"谁的模型更聪明"转向"谁的 Harness 更好用、生态更完善"。模型能力趋同后，框架体验成为差异化关键。
4. **DeepSeek Harness 的定位**：面向开发者的 Agent 执行框架，支持插件化模型、工具、沙箱，强调本地化与可定制。

## 重要细节
- Harness 的核心组成：模型接口、工具执行、会话管理、沙箱隔离、权限策略
- 开源 Harness 的商业模式：框架免费 → 模型收费 / 云服务收费 / 企业版收费
- 开发者选择 Harness 时的考量：生态、文档、插件丰富度、与现有工具链集成度
