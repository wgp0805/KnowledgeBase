## 核心摘要
本文是一篇面向小白的 Agent 使用入门教程，提出用好 Agent 的四类任务分类法：检查（找出资料中的问题）、梳理（把杂乱信息整理成可用产物）、执行（按流程完成工作）、观察（监测外部变化并行动）。以百度搭子 DuMate 为例演示四类任务的落地，强调每类任务的关键是向 Agent 说清楚"标准/逻辑/目的/条件"，并介绍了长期记忆、技能与套件（插件）、定时自动化任务等功能。
