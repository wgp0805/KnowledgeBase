## 核心摘要
daryl（腾讯技术工程）的工程实践长文，核心论断是 Agent 里很多模型调用不是为了生成答案，而是替代码做一次判断——Jev 把"生成"变"判断"，输出从文本变成可执行的概率判断。文章提出架构分工四层：慢思考层（GPT/Claude 负责规划、解释、生成、复杂推理）、快判断层（Jev 负责路由、筛选、评分、门禁）、确定性层（权限、状态、副作用、回滚由普通代码承担）、兜底层（高风险或低置信度走人工/更强模型）。Jev 不是更便宜的 GPT，而是 Agent 的"反射神经"而非大脑，最适合高频、封闭、可回退、需要概率但不需要生成的小判断。上下文压缩的切口是 fast-jev-compaction：把"判断工具历史还要不要留"作为单一判断（keepCall/keepResult 两个 Noul 问题），而非"总结旧历史"，保留原文精确性，避免摘要改写事实。使用原则是一个判断一个问题，不要把"是否重要"和"是否截断"混进一个 prompt；置信度阈值需先 shadow mode 验证再上线，L3 不可逆操作不让 Jev 单独决定。
