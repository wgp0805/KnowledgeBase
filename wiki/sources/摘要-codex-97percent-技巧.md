## 核心摘要
苏三整理的 Codex 10 条最实用使用技巧，从基础三步到进阶工作流全覆盖。核心观点：Codex 真正好用是因为它把 App、项目上下文、插件、MCP、自动化和 Git 工作流放到了一起，而不仅仅是一个聊天窗口。做好前 3 条（创建项目、写 AGENTS.md、计划模式）就已甩开一大半用户。

## 关键信息

### 基础三步
1. **创建项目工作空间**：把相关文件、资料、截图放同一工作空间，项目边界越清楚 Codex 越不容易跑偏
2. **写 AGENTS.md**：给 Codex 看的项目说明书，四块关键内容：构建/测试命令、编码规范、红线规则（用"禁止/Never"）、代码定位策略
3. **[[计划模式]]必须用**：任务超过两三步就先开计划模式，先讲清目标/范围/风险，确认后再执行

### 扩展能力
4. **连接手机**：轻量操作随时接想法、看进度
5. **用 Skill**：把反复做的流程固定下来（superpowers 管纪律、guizang-ppt-skill 做 PPT、html-anything 做页面），跨平台标准（Codex/Claude Code/Cursor 通用）
6. **装插件**：让 Codex 操作真实工具（Chrome 看网页、Documents 处理 Word/PDF、GitHub 读仓库、Remotion 做视频），按场景装不要全装

### 进阶工作流
7. **MCP 是进阶分水岭**：接 GitHub/Notion/Linear/数据库等外部系统，先稳定跑通一个比堆十个半成品强
8. **[[automations|自动化任务]]**：定时收集信息、定期检查项目、周期性生成报告；注意自动化面板不继承对话模型设置，需手动改
9. **学会看 Git**：至少知道 Codex 改了哪些文件、哪些是新增/删除、能否回退；会看 diff 是区分"用 AI 工具"和"被 AI 工具用"的关键
10. **[[Worktree]] 隔离**：给 Codex 开隔离工作区，不污染主项目；选择标准：小修补 Local、重要构建 Worktree、长时间自动化 Cloud
