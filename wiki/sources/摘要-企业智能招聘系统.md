## 核心摘要
苏三开源的企业级 AI 智能招聘管理平台，微服务+AI 深度融合的实战项目。7 个业务微服务 + 7 个独立 MySQL 库（55 张表）+ 315+ REST 接口，覆盖职位→简历→筛选→面试→Offer→合同→入职全招聘生命周期。AI 层由 11 个 Agent、12 类 AI 能力构成：简历解析（文本 Tika + 图片 qwen-vl-max 视觉模型）、AI 筛选/出题/JD 生成、AgentScope 2.0 多智能体六维面试评估、Offer 接受度/留任预测、AI 人才推荐、数据洞察。技术栈 Spring Boot 4.1 + Java 25 虚拟线程 + Spring Cloud Gateway 5.0 + Nacos + LangChain4j 0.29 + AgentScope 2.0 + Vue 3.5 + Element Plus 2.9 + RustFS。

## 架构亮点
1. **真微服务**：数据库-per-服务，网关 AuthFilter 统一 JWT 鉴权后通过 X-User-Id 等 Header 透传，服务层零感知认证
2. **声明式 HTTP 客户端**：Spring 原生 `@HttpExchange` + `@LoadBalanced` RestClient + Nacos，接口即文档零手写 HTTP
3. **LLM 网关多模型路由**：Qwen/DeepSeek 双厂商主备切换，按 Agent 路由模型（qwen-vl-max 视觉/qwen3-max 文本/deepseek-v4-flash 预测），失败自动降级
4. **AgentScope 多智能体编排**：面试评估由主控调度 4 个子 Agent 通过 `agent_spawn` 协作，同步与 SSE 流式双模式；简历→Offer 五阶段流水线
5. **视觉模型简历解析**：图片/扫描件自动切换 qwen-vl-max，失败标记人工复核
6. **全链路异步化**：AI 任务队列+前端轮询+实时进度，定时预计算+SHA-256 指纹去重+Redis/Caffeine 双级缓存
7. **真实智能体监控**：Agent 任务队列、SSE 事件流、Token 消耗分布、成功率健康度全部来自真实调用
8. **合同电子签章闭环**：手写签名画板→邮件签署链接→双签署→生效
9. **Java 25 虚拟线程**：AI 异步、SSE、邮件等高 IO 场景
10. **LangChain4j→AgentScope 适配**：编排层与模型层解耦，AgentScope 不直连大模型
11. **多级降级链**：面试评估（多Agent→单Agent→LLM直调→启发式）、简历筛选、Offer/留任预测
12. **双级缓存人才推荐**：Redis 15min + Caffeine 5min，支持"换一批"分页

| 简历解析（文本） | Tika + LLM 结构化 |
| 简历解析（图片） | qwen-vl-max 视觉模型 |
| AI 筛选 | LLM 五维加权评分 + 降级启发式 |
| AI 出题/JD 生成 | LLM 异步任务 + 轮询 |

| 数据洞察 | LLM 生成自然语言洞察 |
| 多 Agent 编排 | AgentScope 子 Agent 协作 |
