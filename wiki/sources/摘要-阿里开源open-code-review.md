## 核心摘要
阿里开源 open-code-review，源自内部 AI 代码审查助手，服务数万开发者，识别数百万代码缺陷。核心架构：确定性工程 + LLM Agent 混合模式。工程负责精确文件选择、智能分束、规则匹配、位置定位；Agent 负责动态决策、上下文检索、深度审查。相同模型下精度反超 Claude Code，token 消耗只有约1/9。内置 NPE、SQL注入、XSS、线程安全等规则。Apache-2.0 协议开源。
