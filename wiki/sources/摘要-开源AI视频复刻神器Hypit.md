## 核心摘要
Hypit 是一个开源 Skill 项目，把 Codex、Claude Code 等编码 Agent 变成视频制作工具：给一条参考视频，Agent 会分析原片的文案、镜头、字幕、节奏与动效，照原片结构重新组织画面、台词、字幕和动效，替换成新的人物、产品、语言后生成新视频。项目不到两个月在 GitHub 拿下 1 万多个 Star，闲鱼上已出现 95 元资料、9.9 元远程安装、30–100 元代部署与调试的衍生生意。其工作流分五步：输入素材 → 理解参考视频 → 写成可编辑的视频工程（字幕、图片、动效可绑定到台词中的词，改台词会自动重排时间）→ 调用 Hypit Runtime 执行（可托管付费服务如 Seedance，也可用本地免费工具但效果打折）→ 保存成片与视频工程供下次复用。安装只需 `npx skills add hypit-ai/hypit -g`，本质是 Skill 提供制作知识与导演方法、Agent 负责理解与编写方案、Runtime 负责执行的三层分工，本身并不是视频模型。
