## 核心摘要
本文（逛逛GitHub 公众号，发布于人人都是产品经理）盘点了 2026 年 9 月 GitHub 上新增 Star 最快的 20 个开源项目，头部项目几乎全部围绕 AI Agent 基础设施展开：Archify（把代码仓库画成交互式架构图，月增约 3.34 万 Star）、Ponytail（给 Agent 加"实现前优先复用"的判断顺序，月增约 3.12 万 Star）、God's Eye View（3D 动态地球，3.11 万）、i-have-adhd（Agent 输出先给重点，2.65 万）、Hindsight（Agent 长期记忆，2.28 万）。中腰部则集中在工程配套：阿里 Open Code Review（代码审查，2.18 万）、腾讯 WeKnora（知识库，1.08 万）、NVIDIA SkillSpector（Agent Skill 安全扫描，3500）、Anthropic 的 Financial Services 与 Knowledge Work Plugins、Cua（Agent 桌面操作）、Context Mode（压缩工具输出对上下文的占用）等。整体趋势是 Agent 生态从"能对话"走向记忆、安全、多 Agent 管理、桌面执行与行业插件的全链路配套。
