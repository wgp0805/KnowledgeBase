# 什么是上下文工程（Context Engineering）？

面试题辨析 Context Engineering：管理 LLM 上下文窗口内容的工程实践，决定哪些信息进入上下文、以什么顺序、何时压缩。沉默王二讲解 Context Engineering 与 Prompt Engineering 的区别——前者管「窗口里放什么」，后者管「怎么对模型说话」。
