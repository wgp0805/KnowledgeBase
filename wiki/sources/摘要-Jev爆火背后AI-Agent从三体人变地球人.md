## 核心摘要
本文用《三体》中"思考即表达"的三体人比喻当下大模型：每次任务都重新展开成一次完整思考，而成熟的人类专家会把反复验证过的经验沉淀成直觉。TypeSafe 于 2026-09 发布的 Jev 反着行业潮流走，不追求想得更久、只负责判断，接受状态直接返回结构化概率，定价每百万输入 Token 0.042 美元、输出不收费、端到端延迟 70–500ms，被命名为 System One Model，催生出 Decision per Dollar（每美元可完成的可靠决策数）这一 Agent 时代新指标。作者推演：Memory 只是把经验留在模型外面（基于记忆的适应），Post-training 才把经验压进权重，两者连接后大量重复经验可被压缩成廉价稳定的 Judgment，即"智能压缩"。由此企业能力资产形成 Knowledge（RAG）—Know-how（Skill/SOP）—Experience（执行轨迹）三层，最有价值的数据不是"犯过的错"，而是"错误+纠正+Outcome"构成的 Proprietary Decision Data。作者进一步提出 Experience Compiler（经验编译器）与 Agent Learning Infrastructure（智能体学习基础设施）的构想，以及与 Scaling Intelligence 并行的第二条曲线 Scaling Experience——Agent 真正要从"三体人"变成"地球人"。
