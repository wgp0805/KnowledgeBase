## 核心摘要
本文介绍了 Flowable 开源 Java 工作流引擎，阐述了其从 Activiti 分叉的发展历史、核心优势以及与其他主流工作流引擎（Activiti、Camunda、jBPM）的对比。文章详细说明了 Flowable 与 Java/Spring 生态的深度集成、支持 BPMN/CMMN/DMN 多种标准、性能优化、嵌入式部署灵活性等优势，并提供了 Spring Boot 集成和独立引擎两种入门案例。
