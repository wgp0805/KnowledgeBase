## 核心摘要
冰河实测国产开源 **PI-Desktop**（GitHub `vastsa/PI-Desktop`）：把原来散在几个窗口里的东西（Claude Code 改前端、Codex 跑后端测试、编辑器看 Diff）塞进一个窗口，终端数量从三个减到一个。它不发明新技术、不自带模型，Agent Runtime 来自开源 Pi 项目，桌面层负责会话管理、权限、插件和多 Agent 调度——"它不负责让 AI 变聪明，只负责让 AI 干活的时候你别到处找东西"。定位是解决"工作区秩序"而非"模型能力"。

## 关键信息
- **会话不再一次性**：会话挂到项目下（左侧栏看每个项目最近干了什么、置顶/归档、从旧会话开分支）；一个仓库一个项目、按任务开会话，切项目不用重新解释上下文；任务中想到新要求可**排队**，等手头处理完再接着跑；关应用再开 Session 还在；项目有检查点中断后尽量恢复现场（仍建议重要代码照常 commit）
- **Diff 一屏看**：Agent 改完代码 Diff 在右侧面板，命令输出/文件内容/执行记录放一起；会话留完整工具调用记录、长会话右侧缩略导航、上下文占用与 Token 用量显示
- **三种干活方式**：Agent（需求明确改小问题）、Plan（需求模糊/文件多，先研究仓库给计划确认再动手）、Goal（目标清楚、验收条件写明白、路线自选）；三者都走权限层
- **多 Agent**：Subagent 做并行调查（独立上下文、结论交回主 Agent、模型可不同）；Session Orchestrator 一个主会话带多个 Worker（每个完整会话可单独看可追加任务）；适合工作项彼此独立能同时推进的大仓库改造，小文件拆多会话检查成本>收益
- **插件**：能加面板/右侧视图/悬浮组件/主题，接 Skills/MCP Server/后台服务，插件间传消息；市场可装、`.piplug` 包可导入、有模板；目前数量有限质量参差，权限审批≠沙箱隔离，来源不明不装
- **模型与数据**：不同会话不同模型、同会话可换（换完不用重讲背景）；上下文窗口/最大输出/推理开关/温度单独调；自定义模型 ID 与自建网关 Endpoint；数据默认本机、API 凭据系统钥匙串、无遥测；可源码部署让 AI 审
- **安装**：Releases 安装包即可（macOS Apple Silicon/Intel、Windows x64、Linux x64/ARM64，glibc≥2.35）；Early Preview 接口和行为会变，不适合当唯一生产工具
