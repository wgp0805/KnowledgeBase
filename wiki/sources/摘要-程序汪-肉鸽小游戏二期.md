## 核心摘要

程序汪分享的线上街机内嵌H5肉鸽类小游戏二期项目案例，投入4万元、20天、2人开发。项目在已有街机APP上增加"玩小游戏领好礼"功能，通过H5接入Cocos Creator 3.8 LTS开发的肉鸽小游戏，提升APP可玩性与用户停留时长。文章详细讲解了系统边界（复用一期功能与二期新增模块隔离）、安全免登录接入流程（launch_code一次性令牌+短期访问令牌）、JSBridge最小接口设计（7个版本化方法）、Cocos工程模块划分与性能目标（冷启动p75≤4秒、45FPS以上）、金币账本与APP礼品商城统一方案（游戏服务端调用钱包服务端入账）、服务端结算与回放验证机制、竖屏沉浸式适配等核心技术方案。后端采用Spring Boot + Netty(TCP) + MySQL + Redis + Druid，前端Vue/uni-app H5/APP，游戏使用Cocos Creator 3.x + AI工具Codex辅助。
