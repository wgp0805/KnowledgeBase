## 核心摘要
本文介绍了如何使用 Docker 部署 OmnoBox 爬虫管理工具。通过一条 docker run 命令即可完成部署，映射端口 7023，挂载数据目录。部署后访问 localhost:7023/admin 进入管理界面，可从 GitHub 导入爬虫链接并选择需要的源。
