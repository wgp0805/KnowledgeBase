## 核心摘要
冰河撰写的 AI 大模型系统学习路线，按"五关"递进组织：提示词工程 → RAG → Function Call → Agent → 微调与部署。面向非技术人员（产品/运营/市场）和开发人员提供不同周期路线，强调"动手敲代码"而非纯理论。核心观点：AI 是工具不是人，90% 场景 RAG 比微调更实用。

## 关键信息

### 五关递进路线
1. **提示词工程**：给 AI 身份、明确要求、提供例子（少样本提示）、分步推理（思维链）
2. **RAG**：给 AI"开卷考试"，先检索资料再回答，解决私有知识盲区
3. **Function Call**：让 AI 能调用外部工具（查天气、发邮件、查数据库）
4. **Agent**：给 AI 目标让它自主决策，思考→行动→观察循环
5. **微调与部署**：用专属数据训练通用模型；部署涉及 API 封装、服务化、量化压缩、弹性伸缩

### 学习心态
- 别焦虑：门槛高才值得学
- 别贪多：盯住一个方向先搞透（如先精通 RAG 再扩展）
- 别怕代码：看十遍不如写一遍
- 别闷头学：多交流

### 微调警示
- 需要大量高质量问答对数据
- 需要算力（显卡贵）
- 微调过头会导致"灾难性遗忘"（忘记原有知识）
- 建议：90% 场景用 RAG 替代微调
