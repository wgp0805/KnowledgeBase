# 摘要：宠物照护Agent的记忆设计

## 核心主旨
以宠物照护场景为例，阐述 AI Agent 的分层记忆模型设计。从散落的病例数据到可控的记忆系统，AI PM 需要设计短期、长期和情景记忆的协同机制。

## 关键论点
1. **记忆分层的必要性**：单次对话记忆无法支撑长期宠物照护，需要短期（本次对话）、长期（宠物档案）、情景（特定就诊场景）三层记忆。
2. **记忆的可控性**：记忆不是越多越好，需要设计遗忘机制、更新机制和冲突处理机制。
3. **记忆与推理的关系**：记忆为推理提供上下文，推理结果又回写记忆，形成闭环。
4. **产品设计要点**：
   - 记忆写入需明确触发条件和数据结构
   - 记忆读取需考虑相关性和时效性
   - 记忆更新需处理矛盾信息（如病情变化）
