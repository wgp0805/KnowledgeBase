## 核心摘要
小米 MiMo 团队打开 Xiaomi MiMo Desktop 邀测闸门，同时放出 MiMo-X-Pro-Preview 与 MiMo-X-Flash-Preview 两款预览版模型，几乎不谈跑分，全部话术压在"交付"上，作者据此判断桌面 Agent 的竞争正从"答得对不对"转向"能不能把活干完"。能力上分四层：一是混合素材直投（表格/图片/视频/PDF/录音/压缩包），输出是可继续编辑的文档、表格、PPT、网页、图片、音视频乃至 3D 模型、App 与工程源码，并把 MCP 控制 Figma 写进官方工作流；二是预览非静态截图而是含组件结构、交互逻辑、状态变化与数据可视化的真页面；三是局部编辑——选中文本/图表/表格区域用自然语言描述要改的部分，作用范围被限定，且每次修改留版本记录可横向比方案与回退，作者称这是"玩票"与"真能用"的分水岭；四是 Smart 调度三层——任务评估（办公/编程/研究/设计/混合）、模型路由（标准模型 vs 旗舰模型）、Harness/Agent/Skill 路由（大任务拆给多个 Agent 分别负责调研、规划、执行、复核），并支持多会话协同（各会话独立记忆、工作区与任务状态）。浏览器既是信息入口也是执行环境，可在同一工作流内用浏览器检查关键交互、自动验证成果；英文官网另列"电脑操控"（读屏、跨应用键鼠、Record & Replay）标注为海外版专属。降本三条路径为模型路由、局部编辑与上下文缓存，官方实测同会话缓存命中率最高 99%、跨会话最高 95%。作者三点判断：评分标准变了；邀测本质是"用真实任务换反馈"；真正该盯的是没公布的定价、Mac/Windows 支持范围与长任务失败率，预览阶段别压进核心生产流程。
