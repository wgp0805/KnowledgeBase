## 核心摘要
OpenAI 在 DevDay 2026 一口气发布 20 多项更新，开场公布 ChatGPT 周活跃用户突破 12 亿，核心主线是从"被动答题框"走向 7×24 小时自主协作生态。四大杀招：①**Dots**——由 GPT-6 Astra 驱动的常驻自主智能体，每个 Dot 自带独立云端虚拟沙箱电脑与专属浏览器，常驻 ChatGPT 网页/桌面/手机并进驻 Slack、Teams，支持 Proactive Research 后台只读巡检 4000+ 应用，敏感操作须经 Auto-Review 人工审核，企业版 Specialist Dots 深度整合进微软 Microsoft Agent 365；②**GPT-6.1 Sol**——性能逼近旗舰 Astra，标准价 2/10 美元（Astra 的五分之一），缓存输入低至 0.10 美元/百万 Token（比标准输入降 95%），DeepSWE v1.1 跑分追平 Astra、Terminal-Bench 单任务成本从 23 美元降到 5.47 美元；③**Ultrafast 极速引擎**——Codex 内代码生成最高提速 8 倍（约 300 tokens/s），标准 API 最高 6 倍，配套 Pro 500 订阅档（25 倍 Plus 配额）；④开发者底座——Codex in the Cloud、Codex Security Cloud（内置网络安全模型 Daybreak Blue）、Agents API 注入 Computer use、Decisions API，并与 AWS Bedrock 合作托管 Managed Agents。生态层面推出 Sign in with ChatGPT（Plus/Pro 配额可在 Devin、Notion、Vercel、OpenClaw 等首批 16 家伙伴产品抵扣）、ChatGPT Space/Pages/协同演示文稿、OpenAI Marketplace（32 家伙伴）与 Private Intelligence 零数据留存隐私方案。
