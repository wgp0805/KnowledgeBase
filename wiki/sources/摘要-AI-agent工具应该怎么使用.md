## 核心摘要
以 Codex 实际使用经验为基础，总结 AI 编程 Agent 工具的 9 条最佳实践。核心观点：AI 编程不是"丢需求等结果"，而是要像带实习生一样引导——先建项目说明书（AGENTS.md），再用 Plan 模式出方案，小步拆解任务，多模型交叉验证。人负责架构决策和验收，AI 负责填充实现。

## 关键技巧
1. **先建 AGENTS.md** — 进入项目先 /init，编写项目说明书，控制在 200 行以内，踩坑后动态更新
2. **Plan 模式先行** — 先出执行计划再写代码，审计划比推翻重来高效得多
3. **大需求拆小任务** — 每个原子功能独立对话，"搜索功能"拆成 UI/API/对接/兜底 四步
4. **测试是质量保障** — 用另一个 Agent 交叉验证代码质量，AGENTS.md 规定测试先行
5. **不要手动改 AI 代码** — 手动改会导致 AI 覆盖你的改动，改完必须开新对话
6. **多模型协作** — Codex 写代码 + Claude Code 审查，至少两个 session（审核 role + 执行 role）
7. **Prompt 要精确** — 结构：背景+目标+约束+验收标准，贴代码比说自然语言准确
8. **用官方模型** — 中转站有模型偷换、限流、截断等问题
9. **架构由你，实现交给 AI** — 你负责目录结构/模块边界/数据流向，AI 负责填充实现
