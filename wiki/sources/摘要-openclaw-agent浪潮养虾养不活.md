## 核心摘要
OpenClaw 以 24.8 万星登顶 GitHub 历史第一（2026 年 3 月，奥地利独立开发者 Peter Steinberger 的周末项目，把 Claude Code 接进 WhatsApp），但国内跟进做封装的 C 端产品九个月内集体撤退——腾讯 QClaw 宣布 12 月 24 日停运，从内测排队到关灯不到十个月。作者用五个关键决策拆解失败原因：①价值沉淀在开源层，封装产品只是"流量二道贩子"（模型/框架都不掌握，汉化+预装+补贴算力只构成成本不构成壁垒，Steinberger 本人 2026 年 2 月已加入 OpenAI）；②Agent 成本结构反互联网——每次调用燃烧 Token，用户越活跃亏损越大，有重度用户一天烧 100 万 Token，DAU 从资产变负债，免费模式在边际成本递增行业是自杀；③大厂涌入只是给开源生态做昂贵地推（Gartner：试点 Copilot 企业仅 6% 转向大规模部署）；④用户要"干活的 Agent"而非"聊天的 Agent"，使用成本高于手动成本就没有刚需；⑤从对话到执行的鸿沟在于信任——权限交付需要时间，信任崩塌只需一次事故。结论：企业级/垂直/嵌入式 Agent 可能活得很好，但面向普通消费者的通用 Agent 尚未在成本结构与付费意愿之间找到平衡点。
