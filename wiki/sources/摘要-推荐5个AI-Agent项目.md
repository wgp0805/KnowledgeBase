## 核心摘要
本文推荐了多个 Java 技术栈的 AI Agent 实战项目，由微信公众号「苏三说技术」作者苏三撰写。重点介绍了 5 个 AI Agent 项目：企业智能知识库系统（Spring Cloud 微服务 + RAG + KAG 双引擎）、智能代码审查 AI Agent（LLM + 规则引擎 + RAG 增强）、智能天气播报 AI Agent（Spring AI Alibaba + 通义千问）、智能翻译助手 AI Agent（Spring AI + RAG）和智能商品推荐 AI Agent 系统（RAG + Function Calling + MCP 组合架构）。此外还介绍了短链系统、SaaS 点餐系统、商城微服务系统等实战项目。

> 注：本文为知识星球推广文章，项目信息可用于了解当前 Java AI Agent 项目的技术栈和架构趋势。
