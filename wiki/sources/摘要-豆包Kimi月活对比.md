## 核心摘要
2026 年 8 月 QuestMobile 榜单：豆包月活 3.82 亿断层第一（超第二到第七名总和），Kimi 月活 729 万（不到豆包五十分之一），DeepSeek 1.3 亿月活。三家用学生身份实测一个月，覆盖长文本生成、多轮对话、代码 Debug 三类任务。结论：DeepSeek 推理质量最高且免费，Kimi 长文本仍是独门优势但等待时间长，豆包交互最顺滑但回答偏"讨喜"而非"准确"。商业化上，豆包 3.82 亿月活单日营收不到百万（2026-05 上线最高 5088 元/年订阅），DeepSeek 靠 API 年化 4-5 亿美元营收（8 月涨价），Kimi 被夹在中间。作者判断：下一个赢家的形态现在还不存在，真正围绕学习场景设计工作流的 AI 产品三家都只做了零碎一角。

## 关键信息
- **月活数据**：豆包 3.82 亿、DeepSeek 1.3 亿、Kimi 729 万
- **用户粘性**：Kimi 10 分钟以上用户占比 26.1%，豆包 27.5%，DeepSeek 30.0%（最高）
- **任务实测**：
  - 长文本生成：DeepSeek 39 秒精炼可打印；豆包 1 分 47 秒冗长堆砌；Kimi 4 分 10 秒最详尽但最慢
  - 多轮对话：DeepSeek 指令跟踪最精准；豆包修改保守迭代感弱；Kimi 细节丰富但多指令并行时记忆衰减
  - 代码 Debug：DeepSeek 唯一检出全部 5 处 Bug 且有工程级鲁棒性；豆包未发现除零风险且引入精度丢失；Kimi 修正代码有缩进错误
- **商业化**：豆包单用户日营收 <0.003 元；DeepSeek API 年化 4-5 亿美元；Kimi 月活撑不起 API 生意
- **结论**：按场景切换——查资料/debug 用 DeepSeek，论文长文本用 Kimi，日常琐事用豆包
