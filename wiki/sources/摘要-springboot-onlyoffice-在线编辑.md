## 核心摘要
本文详细介绍了 Spring Boot 集成 OnlyOffice 实现在线 Word 文档编辑、转换和保存功能的完整方案。内容包括 OnlyOffice Document Server 的 Docker 及 Ubuntu 部署方式、前端 Vue 组件集成 OnlyOffice API（文档配置、编辑器初始化、回调设置）、后端 Spring Boot 控制器（文件获取接口、回调处理接口、文件保存逻辑），以及常见问题解决（Token 认证、文档加载失败、后端鉴权冲突等）。
