## 核心摘要
字节正式发布豆包工作，与飞书原生打通，继承文档、数据、权限系统，实现办公 Agent 的丝滑操控。这是飞书+豆包团队整合后首个重要产品，与 WorkBuddy、千问办公形成办公 Agent 御三家。核心亮点是无需飞书 CLI，开箱即用，公司统一支付 AI 额度，员工用脚投票直接迁移。

## 关键洞察
- **产品定位**：豆包内原"工作任务"独立拆出，与飞书原生打通
- **核心优势**：
  - 飞书账号直接登录，继承企业身份、文档、多维表格、知识库、聊天、邮件、权限系统
  - 本地电脑 + 云电脑双模式，长任务可扔云端
  - 企业统一支付 AI 额度，个人无需订阅报销
  - 后台可按人/部门限制月度使用上限
- **功能完整性**：Skill、MCP 连接器齐全，预置工作伙伴（专家/专家团），支持企业微信/钉钉/百度网盘/企查查等
- **组织数据资产观**：Agent 用谁家的在模型差距不大的情况下没那么重要，重要的是数据存在哪、组织上下文在哪
- **飞书 CLI 替代**：无需再维护飞书 CLI 升级，开箱即用
- **竞争格局**：办公 Agent 御三家集结（WorkBuddy、千问办公、豆包工作）
