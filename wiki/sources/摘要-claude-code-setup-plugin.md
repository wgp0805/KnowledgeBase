## 核心摘要
Anthropic 官方开源了名为 **claude-code-setup** 的项目级一键配置插件，用于解决 [[ClaudeCode]] 高级能力（[[MCP]]、[[Skill]]、[[Hooks]]、[[Agent]]、Slash Commands 五大能力）配置门槛高的问题。其背后通过 [[claude-automation-recommender]] Skill 实现，扫描项目代码后给出"按项目类型精准匹配"的自动化推荐清单，全程只读、绝不动文件。安装方式：在 Claude Code 中执行 `/plugin install claude-code-setup@claude-plugins-official`，使用时用自然语言交互（如"帮我 set up claude code"）即可获得分类建议。文章核心观点：Claude Code 真正决定上限的不是模型强弱，而是用户是否充分激活其自动化能力栈，避免把它当成普通聊天机器人使用。
