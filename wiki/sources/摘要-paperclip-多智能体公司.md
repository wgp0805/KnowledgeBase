## 核心摘要

终码一生（2026-10-29）介绍开源多智能体编排项目 **Paperclip**（GitHub 100k+ Star，Node.js + React，MIT 协议，2026 年 3 月开源）。开发者比喻："OpenClaw 是员工，Paperclip 是公司"——它不做代理，做**编排层**，给 Claude Code/Codex/Cursor/Gemini CLI/OpenClaw/bash/HTTP 机器人等各自为战的 AI Agent 安排岗位、划定汇报线、分配预算、跟踪进度。

**关键机制**：
1. **接入即"入职"**：适配器官方写好，填角色/职称/汇报关系/预算即可；"只要能接收心跳，就能入职"（Claude Code 当 CTO、Codex 当工程师、Cursor 当设计师）
2. **任务绑定**：任务与公司目标、项目目标、具体工单绑定，代理清楚"为什么做"而不只是任务标题；上下文从任务上流到项目和公司目标
3. **心跳机制**：按时间表定时唤醒代理、检查状态、结果往上汇报；目标拆到哪一层、谁负责哪一段，面板可追溯
4. **刹车机制**：每月预算花到上限自动停止（防代理陷入循环烧光额度）；雇佣/暂停/终止代理需审批；全部操作留审计日志，配置变更带版本控制可回滚
5. **组织架构**：代理有老板/头衔/职位描述，工单记录每次对话与工具调用，任务间有依赖（阻塞项没解决下游不启动）
6. **多租户**：一个实例可跑多个公司，数据隔离，手机可监控

**安装**：`npx paperclipai onboard --yes` 一行命令（本地回环默认；`--bind lan`/`--bind tailnet` 配局域网/Tailscale；私有 registry 报错可 `--registry https://registry.npmjs.org` 强制公共源；API 3100 端口 + 嵌入式 PostgreSQL 自动创建；前置 Node.js 20+/pnpm 9.15+）。

**现状**：生态仍在生长、社区推插件、Star 还在涨；但开源才半年多，issue 区堆着六千多个未关闭问题，"更适合爱折腾、能接受边用边修的人；想找装上就零维护的团队工具，还得再等等"。

**定位**：与 [[多智能体编排]]（AgentScope 主控-子 Agent 模式）对照，Paperclip 走"公司组织架构"路线——强调角色、汇报线、预算、审批、审计这类**管理性机制**，而非纯任务分解。
