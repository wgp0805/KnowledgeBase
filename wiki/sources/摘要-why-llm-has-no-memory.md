# 为什么说 LLM 本身没有记忆？

面试题讲解 LLM 无状态本质：模型权重训练后固定，每次推理独立无状态。沉默王二分析「记忆」的工程实现——短期记忆靠上下文窗口，长期记忆靠外部存储（文件/数据库/向量库），Agent 框架负责加载和检索。
