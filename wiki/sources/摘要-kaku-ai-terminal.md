## 核心摘要
沉默王二介绍了一款名为 Kaku 的 AI 终端，由 tw93 开发，基于 WezTerm 深度定制，使用 Rust 编写，MIT 协议开源。Kaku 的核心卖点是在一个终端窗口中同时运行 Claude Code 和 Codex 两个 Agent（左右分屏），内置 Lazygit、Yazi 文件管理器、目录跳转、广播输入等开发者工具，并提供 `Cmd+L` 快捷键进入 AI 聊天面板，支持 `@cwd`/`@tab`/`@selection` 上下文附加。文章还展示了 Claude Code vs Codex 的并排对决 case（中国文字珠帘数字文物展览网站），Codex 用时 15 分钟完成。Kaku 目前仅支持 macOS，GitHub 5.6k star。
