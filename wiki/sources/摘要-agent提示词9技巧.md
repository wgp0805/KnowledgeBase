## 核心摘要
不换模型、不换 Harness 提高 Claude Code/Codex 等 Agent 输出质量的 9 个提示词技巧（源自 Anthropic 与 OpenAI 官方指南）：①抽卡——Token 按概率采样，同一提示词重跑可能就得到想要的结果；②少样本提示——附 2-3 个规范输入输出示例，Transformer 的 Induction Heads（归纳头）会照抄前文模式对齐格式与深度；③角色设定——"你是资深后端架构师"让模型在高维概率空间做贝叶斯过滤、激活领域专家；④少用负向提示——"不要废话"反而勾起模型对"废话"的注意力；⑤结构化输出——OpenAI 测试中开启 API 层 Structured Outputs 后格式 100% 合规；⑥提高思考强度——推理拉满可解难题但更耗 Token；⑦专注推理查询 ARQ（Attentive Reasoning Queries）——给模型发"答题卡"逐项确认规则是否适用/是否执行过，利用"离生成位置越近影响越大"的近因特点在输出前重申规则；⑧用指令优先级防提示词注入——系统提示词权重最高、用户提示词次之、工具返回内容最低，配合训练把低等级内容当资料不执行；⑨言语化采样（Verbalized Sampling）——强制模型同时输出多个候选答案及其概率，对抗对齐训练产生的典型性偏差（Typicality Bias，即"AI 味"），论文实测多样性提升 1.6-2.1 倍。
