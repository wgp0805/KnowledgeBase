## 核心摘要

marka.md 是一款基于 Rust + Tauri 构建的轻量级本地 Markdown 编辑器，安装包仅几 MB，专为 AI 场景设计。核心功能是将多个 Markdown 文件通过 Context Tray（上下文托盘）暂存，实时显示 Token 估算，一键打包成 AI 就绪的上下文包，粘贴到任意 AI 对话窗口（Claude/ChatGPT/Gemini/Cursor 等）。采用本地优先架构，无账号、无云同步、无遥测，数据安全可控。技术栈为 Tauri 2.11 + React 19 + CodeMirror 6，支持 Mermaid 图表、14 套主题（含 Claude/Cursor/Gemini 品牌色）、PDF 导出等功能。
