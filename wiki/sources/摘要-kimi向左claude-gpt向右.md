## 核心摘要
9 月 17 日 Kimi Code 正式推出桌面客户端（macOS/Windows），把终端编程 Agent 搬到图形界面，可打开本地项目、修改代码、执行命令、查看文件改动、调用浏览器、通过不同权限模式控制 AI 操作，支持接入第三方模型（Anthropic/OpenAI/Google/DeepSeek/千问）。而 Claude 和 ChatGPT 在做减法：Claude 把独立 Chat 和 Cowork 合并成一个 Claude（9 月 16 日公告），OpenAI 7 月把 Codex App 并入新版 ChatGPT 桌面应用（一个客户端有 Chat/Work/Codex）。核心观察：Claude、ChatGPT 正在做减法，Kimi 却还在做加法。Kimi Code 与 Kimi Work 区别：Work 面向办公和知识工作，Code 围绕软件开发设计（理解代码仓库、修改多文件、运行命令、展示代码差异）。作者判断 Kimi 未来可能整合但未必简单合并，可参考 ChatGPT"客户端统一、专业功能保留"思路。
