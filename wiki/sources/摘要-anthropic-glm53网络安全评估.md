## 核心摘要
Anthropic 发布对智谱 GLM-5.3 的网络安全评估（全文翻译）：五个月前 Anthropic 以限制性开放的 Claude Mythos Preview 首次实现自主开发端到端漏洞利用程序（经 Project Glasswing 让可信防御者发现超 1 万个漏洞），如今同等能力已扩散到 GLM-5.3——它在 ExploitBench 410 次尝试完成 50 次端到端漏洞利用（Mythos Preview 为 56 次），在二进制漏洞基准 4% 完成完整控制流劫持（此前 Claude Opus 4.6 与 GLM-5.2 均为 0）；研究人机协作一天内让它在浏览器 JS 引擎发现多个零日并串联成可用攻击，GLM-5.3-Flash 仅用人类 20 分钟 + 模型 8 小时、成本 20.40 美元就把 CVE-2026-11645 变成绕过 PAC 的 ARM64 漏洞利用链。NIST 下属 CAISI 9-17 独立评估称 GLM-5.3 是"迄今网络安全能力最强的开放权重模型"（综合落后美国前沿模型约 4 个月）。关键风险在护栏：abliteration（拒绝行为移除）花约 2200 GPU 小时/4400 美元即可把拒绝率从 90%+ 降到 3%-12% 且能力基本不掉；不改模型也能绕过——欺骗性提示（自称红队演练）64%、预填思考 token 92%、移除拒绝行为 100% 参与恶意任务，而相同攻击对保留护栏的 Claude 全部无效。Anthropic 据此主张：防御者应获得与攻击者至少同等强的前沿模型，政府应对强能力模型开展独立安全测试。
