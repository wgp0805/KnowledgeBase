## 核心摘要
作者"冰河"从测试同事手敲 SQL 查数据异常的低效场景出发，分享自写数据分析 Skill [[DataInspector]] 的完整方法：核心产物不是代码而是一份纯文本操作手册（SKILL.md），用大白话写清"你是谁、能干什么、不能干什么、按什么顺序干、什么情况必须停下来"。设计要诀是**先写红线再写流程**——绝对禁止写操作、绝对不连生产库、绝对要人工确认才能执行；再配六步流程（复述问题→读真实表结构→写带注释 SQL→安全自检→提交确认→执行并解读）和只读账号 + 库表白名单的运行环境。作者用订单状态分布核对的真实场景验证了全程可复现，并总结三个踩过的坑：AI 编字段名、图省事给写权限、敏感字段直接打印——提炼为 [[Skill安全红线]] 概念。这套"手册 + 只读账号"的最小方案不需要写代码或搭服务，即可把每周重复的 SQL 核对工作安全外包给 AI。
