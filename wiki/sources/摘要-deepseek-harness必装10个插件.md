## 核心摘要
小哈（犬小哈）推荐 DeepSeek Harness（DSH）必装的 10 个插件，覆盖代码质量、文档、测试、安全、可视化等场景。DSH 遵循"一切皆插件"设计，插件生态是其核心扩展机制。10 个插件：(1) **ModLens** — 模型透镜，可视化展示 Token 用量、工具调用次数、上下文占用，帮助优化提示词和上下文布局；(2) **Code Review** — 自动代码审查，提交前检查潜在 Bug、安全漏洞、代码规范；(3) **Test Generator** — 自动生成单元测试，覆盖边界条件；(4) **Doc Generator** — 自动生成 API 文档和代码注释；(5) **Refactor Helper** — 智能重构建议，识别重复代码和坏味道；(6) **Security Scanner** — 安全扫描，检测依赖漏洞和敏感信息泄露；(7) **Performance Profiler** — 性能分析，定位瓶颈；(8) **Git Helper** — Git 操作增强，自动生成 commit message；(9) **API Tester** — API 接口测试，自动生成测试用例；(10) **Visual Debugger** — 可视化调试，图形化展示执行流程。

## 关键信息
- **DSH 插件机制**：一切皆插件，通过插件扩展工具、技能、MCP 支持
- **ModLens 核心价值**：Token 可视化是 Agent 时代的新性能分析维度，帮助理解上下文布局策略
- **插件安装**：通过 DSH 配置文件或命令行安装，支持项目级和全局级
- **插件开发**：遵循 DSH 插件协议，可自定义工具和技能
