## 核心摘要
- 沉默王二体验 EvoMap 团队 2026-08-09 上线的 beta 版 Agent 工具 **EvoX**，核心差异点是「蜂群模式」多 Agent 组织方式 +「联网自进化」学习方式。注册即用、无需邀请码，Mac/Windows 双端。
- **多模型横评配置**：作者在同等 Harness 架构和任务下分别配置 DeepSeek V4 Flash、GLM-5.2、Qwen3.8 Max，并可切换 Opus 4.8、GPT-5.6 Sol 等海外顶级模型；结论是「单挑各有高低，但让用户选最适合场景的模型」这件事 EvoX 做得到位，不同模型擅长的场景不同，搭配灵活度高最高。本篇重点在「多模型可热切 + 蜂群编排」的工程体验，而非任一单模型的发布参数（后者见 [[摘要-deepseek-v4-flash发布]]）。
- **蜂群模式 vs 传统编排**（核心论点）：
  - 单 Agent 单线程：上下文越堆越长，前面推理干扰后面，563 道逻辑/数学/物理题准确率仅 26%。
  - 主 Agent + Sub-agent 编排：Sub-agent 完成后交回主 Agent 二次概括，转述环节丢信息，准确率有提升但仍受限。
  - EvoX 蜂群模式：① 任务拆得更细，每个 Agent 只做一个边界清楚的子问题；② 上下文彼此隔离，不被其他 Agent 中间结果污染；③ **结果确定性汇合**——Agent 只负责推理，最终产出不经二次转述，每个 Agent 原始答案都对程序可见。同模型同题准确率飙到 71%，约 2 倍提升。
  - Token 成本：256 个子任务塞进一个上下文需约 4934 万 token，蜂群分治后约 104 万 token，差约 48 倍。
- **联网自进化机制**：EvoMap 经验网络把经验封装成两种形式——**Gene**（最小经验单元，记录某具体任务的成功执行路径，含工具/踩坑/解法）与 **Capsule**（打包的能力模块，可含多个 Gene，组合成可复用能力包）。新 Agent 第一天即可继承网络上其他 Agent 积累的经验，EvoX 已内置一批优质 Capsule 开箱即用，对应「第一天就很聪明」的宣发点。
- **三大能力分仓**：Chat（问答调研，偏好结构化输出，自动整理成表格图表）、Cowork（办公协作，会议纪要/文档整理/连通海内外 IM/长任务流程自动执行）、Code（开发场景，读工程/改代码/跑测试，支持「拆分并行会话」生成多个蜂群会话）。
- **实测案例**：用 DeepSeek V4 Flash 跑 Chat 模式设计 AI 风格预设、为开源项目 PaiCLI Agent 设计性能基准测试（结构化五面板：指标/场景/流程/评分/交付清单）；Code 模式对 PaiCLI 做 4 维并行代码健康度审查（安全审计/性能热点/代码架构/依赖健康），生成 5 个蜂群会话。
- **作者定性**：EvoX 是通用 Agent 赛道大厂生态位之外，创业公司中的潜在黑马；Agent 下一步进化很可能发生在「组织方式」上——让一群 AI 会分工、会继承经验、会一起把复杂任务做完。承认 beta 版交互细节仍有提升空间。
- 蜂群模式适配场景：并行调研、多视角评审、方案竞争、交叉验证。
