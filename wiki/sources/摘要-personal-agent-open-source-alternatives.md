## 核心摘要
文章盘点了三款近期爆火的 Personal Agent 的 GitHub 开源平替：**Rakazo**（对标 Grok Bot，可搭建多 Bot 分工、各自拥有对话/记忆/例行任务的持续运行 AI Bot，模型与电脑环境自选，本地或服务器常驻）、**OpenMuse**（对标 Meta Muse，CopilotKit 出品，iOS/Android/Web 三端，持久化浏览器可人工接管、可选 Linux 工作区、定期监控公开页面并在价格/状态变化时提醒，Alpha 阶段需自行部署）、**OpenDots**（对标 OpenAI Dots，多专业助手 AI 工作台，每个 Dot 有独立角色与工具权限，成果落入 Space/Page 工作空间，支持周期任务、语音与 Slack 接入）。三者共同反映的赛道趋势是：Personal Agent 的开源替代品已从"聊天框"走向"带电脑环境、记忆与后台常驻执行"的完整执行体，用户可以自托管、自选模型来摆脱对闭源产品的依赖。
