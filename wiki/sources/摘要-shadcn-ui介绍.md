## 核心摘要

shadcn/ui 不是传统的 npm 组件库，而是一套将组件源码直接复制到项目中的工具和方法。核心理念是"开放代码"——组件源码在项目中，开发者完全掌控，可自由修改。这种方式相比传统 UI 库（如 Ant Design、Material UI）具有看得见、改得动、好维护、AI 友好等优势。

技术栈基于 React + Tailwind CSS + Radix UI + TypeScript，通过 CLI 命令将组件源码复制到 components/ui/ 目录。适用于后台系统、官网、SaaS 产品等场景，已获得 11 万+ Star。
