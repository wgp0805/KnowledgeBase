## 核心摘要
冰河介绍 open-system 项目：一个基于 Spring Boot + Dubbo + Nacos + MyBatis Plus 的企业级微服务开放平台，作为统一服务接入层为多个业务系统提供标准化 RESTful API。核心解决集成爆炸、安全鉴权缺失、幂等性、日志分散和扩展性五大痛点。采用四层架构模型与 Maven 多模块分离（server / interface / resource / client），支持同步与异步两种调用模式，幂等性基于 transId + serviceCode 历史记录实现，安全机制用 RSA + AES 混合加密与系统标识白名单。
