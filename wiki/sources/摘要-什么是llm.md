## 核心摘要

沉默王二（2026-11-02）LLM 基础科普（Vibe 知识大赏系列），用"词语接龙"类比讲清大语言模型的工作原理，适合零基础入门。

**LLM 是什么**：既不是数据库也不是搜索引擎，而是基于 Transformer 架构、按概率逐个预测下一个 Token 的神经网络。

**五个核心问题**：
1. **怎么输出**：分词器把文本切成 Token（词元）→ 转数字编号（DeepSeek 估算 1 中文字符≈0.6 Token、1 英文字符≈0.3 Token）→ **自回归**逐 Token 预测：如"床前明月"后词表十几万候选各算概率，"光"95% 最高就输出"光"，再拼回输入继续预测下一个——"打字机效果"是底层本来就逐 Token 输出
2. **"大"指什么**：7B/70B/671B 的 B=Billion（十亿）指**参数数量**（权重）；旧模型（LSTM/BERT）参数几百万到几亿且一模型一任务，主流 LLM 用 Transformer Decoder-only + 自注意力；**缩放定律（Scaling Law）**：参数+数据+算力一起加效果稳定变好；语料达十几万亿 Token、参数过百亿/千亿时出现**涌现能力**
3. **怎么听懂指令**：两步训练——**预训练**（读遍互联网书籍/网页/代码，把通用知识压缩进参数）+ **后训练**（先 SFT 监督微调学问答格式，再 RL 强化学习对齐人类偏好、在数学/代码任务中练出思维链）。预训练决定"肚子里有多少墨水"，后训练决定"能不能用对地方"
4. **为什么胡说八道**：生成靠概率采样，**温度（Temperature）**控制随机性——写代码调低（0.1）选最高概率，写文案调高（0.8）给次选机会；更深层：参数是海量语料的有损压缩（记的是统计规律不是原文），遇训练截止后新闻或没记准的细节不会说"不知道"而照样挑通顺路径接完 → **幻觉**
5. **工程怎么补**：模型权重固定不会自学、不记上次对话、不能自己查资料执行命令——所以用 RAG 补真实资料、用 Harness 管记忆与工具调用
