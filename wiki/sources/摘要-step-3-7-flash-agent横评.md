## 核心摘要
这篇资料用 Claude Code、Google Antigravity 等工具，对 Step 3.7 Flash、DeepSeek V4 Flash、Gemini 3.5 Flash、Qwen3.6 Flash 在真实 Agent 任务中的表现进行横向体验。测试任务包括从零搭建开发者日志站、生成 GitHub 项目雷达、分析开源项目源码并生成架构 HTML 报告。文章认为 Flash 模型不应只看单次 benchmark 或 token 单价，而要看工具调用稳定性、错误自修复能力、返工成本和最终交付物质量；Step 3.7 Flash 在工具调用稳定性、前端交付观感和综合执行成本上表现较稳，但 256K 上下文是明显短板。
