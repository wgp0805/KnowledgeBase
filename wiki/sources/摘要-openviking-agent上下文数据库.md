## 核心摘要
火山引擎开源 OpenViking，以虚拟文件系统统一知识库、记忆与技能，通过 L0/L1/L2 分层加载优化 Agent 上下文检索。三类内容统一：Resources（知识资料）、Memories（用户记忆）、Skills（技能工作流）。相比传统 RAG 的优势：保留结构、可观察检索、减少无关内容进入上下文、多 Agent 共享记忆。支持 Claude Code、Codex、Cursor 等多种 Agent 接入。
