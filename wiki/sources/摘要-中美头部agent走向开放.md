## 核心摘要
Agent 竞争白热化之际，OpenAI、Anthropic 和腾讯纷纷开放自家 Agent 底座。9 月 10 日 OpenAI 将 Codex 背后的 Harness 做成托管服务开放公测（一个月前已开源核心代码）；9 月 2 日腾讯开放 WorkBuddy 基座（首批伙伴超百家，可放进眼镜/手表/录音设备）；Anthropic 去年 9 月将 Claude Code SDK 扩展为通用 Agent SDK，今年补上企业插件生态和 Managed Agents。三家公司开放方向一致：把原本只供自家产品使用的系统变成别人开发 Agent 的起点。核心逻辑：Agent 从 coding 走向办公再走向通用平台，竞争越来越多落到 Context 上。两条开放路径：把底座交出去让 Agent 遍地开花、把长在底座上的能力和 Agent 连接成网络。Anthropic 走"模型往外长"（Product Overhang），OpenAI 走"模型+Harness+托管运行连成一体"（Agent 的 AWS 时刻），腾讯走"整机开放"（Agent 时代的操作系统）。《财经》调查：37.6% 选 Codex、25.7% 选 Claude Code、15.3% 选 WorkBuddy。
