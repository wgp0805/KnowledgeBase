## 核心摘要

苏三（2026-11-05）系统介绍自研项目**云梯智能客服系统**——覆盖企业客户服务全生命周期的多租户 SaaS 平台。规模：7 个 Java 服务 + 1 个 Python AI 服务 + Vue 管理端 + 访客端 + 官网 + 六套渠道接入示例，6 个独立数据库 87 张表。

**技术栈**：Java 25（`ScopedValue` 请求上下文）+ Spring Boot 4.0.3 + Spring Cloud 2025.1.2 + MyBatis-Plus 3.5.17；PostgreSQL 17 + pgvector 1024 维 HNSW + RustFS 对象存储；Python FastAPI + Pydantic v2 + LangGraph + LlamaIndex + 千问/DeepSeek/qwen-vl/阿里云 NLS；Vue 3.5 + TS + Vite 5。

**服务拆分三原则**：① 业务事实归业务服务（会话/工单/账单各只有一个主写服务）；② AI 不直接写业务库（模型输出回 Java 由业务规则和权限决定是否执行）；③ 平台治理独立（租户/计费/审计/可观测不混入客服主链路）。

**多租户四层防线**：① 网关从已验签 JWT 取租户（不信任前端请求头，不一致即 403 并记安全事件）+ 租户冻结 + QPS/日额度二维限流；② 应用层所有业务表带 `tenant_code`、关键唯一索引含租户；③ customer_db 的 PostgreSQL **RLS**（连接借出时 `set_config('app.tenant_code', ...)`，忘写租户条件也按租户过滤）；④ 独立 Schema 模式（控制面下发、数据面执行、脚本版本化、每步留痕）。**AI 租户隔离边界**要诚实：ai_db 无 RLS、Python 直连 customer_db 无自动 RLS 上下文，属"应用层隔离 + 显式查询过滤"，非数据库强制隔离。

**实时消息五层可靠机制**：`clientMsgNo` + 唯一索引防重复；服务端按会话分配单调 `seq` 防乱序；客户端持久化发件箱收到 ACK 才移除防丢失；重连带 `lastSeq` 增量补拉防漏；WebSocket 心跳 + HTTP 状态对账防在线状态失真。原则："先落库，再推送；断线后能补，重发不重复"。

**受控 AI 架构**：① **两套 LangGraph 状态机**——客服大脑（意图→情绪→转人工判断→知识召回→回答→状态持久化）、Agentic RAG（检索→召回判分→需要时改写→二次检索→生成→引用校验），环境无 LangGraph 时退化为线性实现；② **规则/训练向量/大模型混合识别**——先跑低成本规则和版本向量，置信度 ≥0.6、情绪强度 <20、未命中转人工关键词时跳过模型分析（省一次调用和 1~2 秒）；模型意图必须落在租户配置清单内，情绪取规则与模型更严重一档；③ **意图训练中心**——训练的是租户意图样本向量索引（非大模型权重）：人工语料 + 高置信度历史问法 → 1024 维向量化 → 留一法评估 → 版本/灰度（20%，按租户+会话稳定哈希）/回滚；④ **多轮槽位**——规则抽取优先，大模型只补空缺槽位，不能覆盖正则确认的订单号；⑤ **Agentic RAG**——向量分与关键词分量纲不同阈值分别配置、资料不足规则改写最多重检一次、回答带 [1][2] 引用并剔除越界引用、无向量密钥退回关键词检索不假装语义检索正常；⑥ **多模态**——图片 OCR/截图判读/订单号金额抽取进业务链路，ASR 转写供质检、TTS 做 IVR；⑦ **租户级模型路由**——模型名优先判厂商、租户配置优先平台默认、缺密钥显式切厂商、最终生效模型可体检；⑧ **AI 成本治理**——业务 AI 配额（调用次数）与 AI 真实成本（Token/成本）分开计量，预算达阈值可仅告警/降级跳过模型/暂停转人工，预算查询缓存 60 秒，ops 不可用时正常放行避免成本系统扩大成 AI 全站故障。

**双速质检**：实时质检（消息落库后，敏感词/绝对化承诺/情绪未安抚/响应超时，不调大模型保证秒级与模型故障可用）+ 全量质检（会话结束后规则命中 + 模型评分 + 评语 + 风险等级，再人工复核）。

**工程质量**：金额用 NUMERIC 避免浮点误差；业务 ID 用雪花算法；审计时间为服务端时间；状态/类型用 SMALLINT + CHECK；逻辑删除；大量离线/在线自检脚本；数据库"基线 + 增量脚本"可一键初始化与增量迁移。

**适合学习**：Java 后端（ScopedValue 替代 ThreadLocal、多库微服务、唯一索引/条件更新/UPSERT/原子序号解决并发、RLS 安全链路、WebSocket 可靠性）、前端（Vue3.5 大型后台、三栏工作台、乐观 UI + 发件箱 + 补拉）、AI 工程（LangGraph 状态机、规则+向量+LLM 协同、意图训练中心、pgvector RAG、多模态进主链路、Token 成本治理）、架构（SaaS 域拆分为用户/租户/客服/计费/运营/实时）。
