## 核心摘要
这篇资料把 [[ClaudeCode]] 学习路线分成“青铜级、白银级、王者级”三阶段。青铜级聚焦安装、启动、理解项目、写代码和修 bug；白银级强调通过 `CLAUDE.md`、Thinking Mode、计划模式、提示词四要素和 Skills 让 Claude Code 更符合个人与项目规范；王者级则进一步利用 Subagents、MCP 和自动化流水线，让 AI 参与从需求分析、方案设计、实现、测试、代码审查到部署的完整流程。文章的核心观点是 AI 编程让开发者从“手敲代码”转向“描述目标、拆分任务、审查验证和指挥 Agent”。
