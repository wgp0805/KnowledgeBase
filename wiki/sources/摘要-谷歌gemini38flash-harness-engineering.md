## 核心摘要
Google 发布 Gemini 3.8 Flash 的同时深入探讨 Harness Engineering，对比 OpenAI、DeepSeek、Google 三大厂商的 Harness 路线。文章核心观点：模型决定 Agent 有多聪明，Harness 决定这份智能能不能持续、稳定、安全地完成工作。Google ADK 2.0 引入 Graph Workflow，将 Agent、Tool 和函数统一为 Workflow Graph 节点；NVIDIA AVO 实验证明评估 Agent 不能只测底层模型。最值得实践的四件事：权限边界代码化、测试融入 Workflow、设置预算与 Kill Switch、优化 Agent Legibility。
