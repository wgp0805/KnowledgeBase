## 核心摘要
腾讯内部孵化的 WorkBuddy（从 CodeBuddy 演化而来）上线三个月迭代 40+ 版本，月活突破 1000 万，成为 AI 办公领域王牌产品。文章核心观点：AI 时代的工作流范式转变为"先做再说，先体验再迭代"，即行动→语言→思想。作者沉默王二分享了 10 道硬核 Agent 面试题，涵盖工具调用失败恢复机制、故障根因重新诊断、ReAct Agent 同步/异步工具调用、多模态 RAG 设计、RAG 召回率计算与测试集构建、LoRA/DPO 微调流程、向量数据库 IVF 索引原理与 nprobe 参数、游戏 NPC 智能交互落地、AI Coding 工具选型与国产替代等核心工程问题。
