## 核心摘要
小哈学Java 盘点 30 款 IDEA 好用插件，分三类：**强烈推荐**（Presentation Assistant 快捷键展示、Codota 代码智能提示+搜索示例、Alibaba Java Code Guidelines 阿里巴巴代码规范中英文切换、Translation 翻译、SequenceDiagram 自动生成时序图、Rainbow Brackets 彩虹括号、HighlightBracketPair 括号高亮、Grep Console 控制台日志高亮、google-java-format 自动格式化、Key Promoter X 快捷键提示、CodeGlance 缩略图、Leetcode Editor 在线刷题）、**装饰类**（Material Theme UI 主题、Power Mode II 打字效果、Background Image Plus+ 换背景）、**较便利**（RoboPOJOGenerator 生成 POJO、Statistic 项目统计、CamelCase 命名格式切换、jclasslib bytecode viewer 看字节码、Auto filling Java call arguments 自动补全参数、GenerateO2O 自动填充参数值、GenerateAllSetter 自动调用所有 Setter、Maven Helper 解决 jar 冲突、FindBugs 查代码隐患、Stack trace to UML 异常堆栈画 UML、Java Stream Debugger Stream 可视化、RestfulToolkit 跳转 Action、Jrebel 代码改后立即生效、String Manipulation 字符串处理、Free Mybatis Plugin mapper 跳转、IDEA QAPlug 提前发现潜在 bug）。

## 关键信息
- **强烈推荐**：Presentation Assistant（录屏共享效果极佳）；Codota（智能提示 + 可搜相关代码示例 + 官网 codota.com/code）；Alibaba Java Code Guidelines（可切换中英文，不符合开发手册都显示）；Translation（command+ctrl+i mac / ctrl+shift+o win）；SequenceDiagram（右键调出，双击类名/函数名跳源码）；Rainbow Brackets / HighlightBracketPair（防错乱括号）；Grep Console（日志高亮）；google-java-format（无需手动快捷键格式化）；Key Promoter X（操作快捷键右下角告知）；CodeGlance（缩略图快速定位）；Leetcode Editor（IDE 内刷题，上班摸鱼）
- **装饰类**：Material Theme UI（主题）、Power Mode II（打字效果）、Background Image Plus+（换背景）
- **较便利**：RoboPOJOGenerator（JSON 生成 POJO，GsonFormat 太久没更新）；Statistic（文件类型统计）；CamelCase（命名格式切换，Edit 菜单找快捷键）；jclasslib（Show Bytecode With jclasslib 看字节码）；Auto filling Java call arguments（Alt+Enter 自动填参数名）；GenerateO2O（自动填参数值）；GenerateAllSetter（自动调用所有 Setter，可填默认值）；Maven Helper（解决 jar 冲突）；FindBugs（空指针/资源未关闭/==比较字符串）；Stack trace to UML（异常堆栈画 UML 时序+通信图）；Java Stream Debugger（Stream 操作可视化）；RestfulToolkit（跳转 Action 方法）；Jrebel（代码改后立即生效，仍需按快捷键）；String Manipulation（Alt+M 弹功能列表）；Free Mybatis Plugin（mapper 接口跳 mapper.xml）；IDEA QAPlug（提前发现潜在问题 bug）
