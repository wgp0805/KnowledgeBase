## 核心摘要

[[苏三]]（2026-09-29）按十大类整理 IDEA 2026.2 必装的 100 款插件：AI 辅助开发 12、代码质量 10、开发效率 15、框架增强 15、数据库 8、UI 美化 10、版本控制 8、测试调试 10、DevOps 7、实用工具 5。文章重点不是"全装"，而是给出选型与内置替代指南——2026.2 的三大趋势是 **AI 原生化 + MCP 标准化 + LSP 开源化**：GitHub Copilot 从插件变为原生内置，MCP 升格为一等公民（主工具栏 MCP Server Widget、自动检测 Claude/Codex TUI、项目级工具集），LSP Client API 全面开源。同时 2026.2 用内置功能替代了大量旧插件（Logpoints 替代手动 println 调试、终端拖拽路径、Resolve All Simple Conflicts 一键解冲突等）。

**2026.2 重大更新速览**：
- GitHub Copilot 原生内置，无需安装插件；Junie 支持 MCP 自动配置
- AI Agent Skills Manager 统一管理 AI 代理技能
- Logpoints 日志断点：非侵入式调试，无需改代码、无需暂停程序
- 多文件 AI 辅助 J2K（Java→Kotlin）转换 + LLM 校验
- Java 27 首发、Kotlin 2.4 稳定、Gradle 10 早期支持、TypeScript 7.0
- 后台异步文件保存、紧凑对象头默认开启、140 个冻结修复

**安装顺序建议**：基础必装（Lombok + Maven Helper + GitToolBox + Rainbow Brackets）→ AI 助手 → 框架增强 → 效率工具 → 按需补充。核心原则：解决实际痛点的插件才值得安装，先装 5-8 款高频插件试用。

**插件市场趋势（2026）**：84% 开发者使用或计划使用 AI 编码工具；MCP 扩展达 4148 个；开源反击（Cline 3.9M、Roo Code 1.6M、Continue 2.9M）；国产崛起（通义灵码 2.5M 安装、CodeGeeX 评分 4.2/5、TRAE AI 完全免费）。
