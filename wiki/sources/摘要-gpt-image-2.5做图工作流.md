# 摘要：从"生图"到"做图"——GPT Image 2.5 工作流体验

## 核心摘要
OpenAI推出的GPT Image 2.5带来Sketch手绘分镜、图片标注修改和多轮局部编辑能力，让AI图片从一次性"生图"变成可反复迭代的"做图"流程。作者通过手绘分镜生成电影镜头、公众号封面多轮修改两个真实场景测试，验证了AI生图正从"抽卡式生成"进入"先有第一版再继续工作"的可控生产力阶段。

## 关键要点
- GPT Image 2.5核心变化：从"生图"（一次性生成）到"做图"（可反复迭代）
- 新增功能：Sketch手绘分镜、Templates模板、图片标注修改、多轮局部编辑
- Sketch功能：手绘火柴人+方框表达空间关系，AI直接生成电影感镜头，省去文字描述
- 多轮编辑稳定性提升：移动人物不换人、去Logo不变背景，理解"只改这个地方"
- 图片标注修改：直接在图片上画区域+备注，指哪改哪
- 工作流变化：从"写Prompt→生成→不满意→再生成"变为"想法→草图→第一版→修改→局部调整→成品"
- 越来越不需要成为"提示词专家"——说不清就画，不满意就指出来
- 第一张图不再是终点，而是创作的开始——AI图片进入生产力阶段的标志

## 详细内容

### 核心转变：生图 → 做图
以前用AI做图更像"生图"——写Prompt生成，不满意就重新生成（抽卡式）。
GPT Image 2.5让它开始像真正"做图"——先有第一版，再在第一版上继续工作（设计式）。

### 场景一：Sketch手绘分镜生成电影镜头
**痛点：** 脑中有画面但难用文字准确描述人物位置、大小、广告牌位置、地平线高度、镜头空间分配。写两百字不如画五秒。

**测试：** 随手画火柴人+方框+广告牌（极其潦草），配合文字Prompt描述场景氛围。

**结果：** AI严格参考草图的人物位置、主体大小、建筑分布和空间关系，生成电影感镜头，不保留手绘线条。

**意义：** 省去"视觉信息→文字→视觉"的翻译损耗。位置/大小/镜头关系说不清就直接画。AI视频创作流程可能变为：剧本→手绘分镜→AI生成关键帧→视频模型生成镜头。从"用文字描述镜头"到"直接设计镜头"。

### 场景二：公众号封面多轮修改
**痛点：** 过去AI生图最头疼——第一张满意后，"把人物往右移"结果换了个人，"去掉Logo"结果背景五官构图全变。

**测试流程：**
1. 上传照片+简单需求 → 生成第一版（已可用）
2. "只把人物向右移动，不重新设计画面" → 人物移动，其余不变
3. "只删除衣服Logo，保持衣服颜色材质褶皱" → Logo去除，其余不变
4. 图片标注：直接在图上画区域+备注 → 精准修改

**关键能力：** 开始能理解"我只让你改这个地方"。改变场景/风格/构图时，尽可能保留原图其他信息。

### 新工作流
```
旧：写Prompt → 生成 → 不满意 → 再生成（抽卡）
新：想法 → 草图 → 第一版 → 修改 → 局部调整 → 最终成品（设计）
```

Sketch（画构图）+ Templates（跳过从零开始）+ 图片标注（指出问题）+ 精准局部编辑 + 多轮一致性 = 一套完整工作流。

### 结论
GPT Image 2.5真正做成的一件事：把"生图"变成了"做图"。第一张图不再是终点，而是创作的开始。这可能是AI图片真正进入生产力阶段的标志。
