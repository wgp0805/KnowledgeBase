## 核心摘要
花叔（前某团新用户运营负责人）开源 huashu-excel skill（MIT 协议，github.com/alchaincyf/huashu-excel），定位「最好用的 Excel 数据处理和分析 skill」。丢一份 Excel/CSV 给它说人话即可：分析销售表、对账、洗数据、口径回溯。核心工作流八步：体检→清洗→对齐→分析→对账→交付→验图→质控。设计哲学是「一套体系化策略，激发大模型能力同时避开其数据处理缺陷」——AI 算错时不会报错，所以用对账、验图、独立质控给不存在的报错机制补位。用十份真实公开业务数据（106 万行电商交易、21 万行纽约市政预算等）压测，独立 agent 实跑全流程。报告支持 HTML/Excel/Word/PPT 四种格式，HTML 报告自包含不联网、图表用内联 SVG 手画。

## 关键信息
- **八步工作流**：体检→清洗→对齐→分析→对账→交付→验图→质控（按需走，查一个数直接查，要报告才全走）
- **体检（第一步）**：用 openpyxl 读原始单元格，识别合并单元格/单元格格式/原始类型；实测中国式销售表用「找表头+清千分位」算月度总额比真值高 161% 零报错
- **对账（第五步）**：拿清洗后明细求和，对表里自带合计行（免费校验和）；揪出过差 10 块钱的错（相对误差 0.00% 肉眼发现不了）
- **质控（第八步）**：另派没参与创作的 agent 从原始数据重算拆台（时间段是不是挑出来的？外部基准分母对得上吗？「已剔除偏差」代码里真做到了吗？）
- **核心缺陷认知**：AI 算错时不会报错，错误数字和正确数字交付时长得完全一样
- **能力激发**：参考 Anthropic AI 心理学研究，用词汇激发让 agent 进入「百万美元项目组」角色状态（领域专家+数据分析师+战略顾问+视觉设计师+前端工程师+质控）
- **test-time scaling**：八步流程强制 agent 多想，每跑完脚本要回答「看到了什么、意味着什么、下一步查什么」
- **抗差统计**：默认给中位数和五数概括，均值只当陪衬（业务数据右偏，少数大客户拉走均值，Tukey 那套）
- **图表规则**：类别超 3 个拒绝饼图（人眼读角度/面积精度低于读长度）；柱形图数值轴强制从 0 开始；双轴图禁用；不完整周期画虚线
- **图表类型**：洛伦兹曲线、双峰分布、事件研究图、价量分解、哑铃图、小倍数图（全用内联 SVG 手画，无图表库）
- **Twyman's Law**：看起来异常的数字通常是错的，先当 bug 查，排除了才当发现
- **报告格式**：HTML（自包含/内联 SVG/发微信当附件能开）、Excel（原生图表引用数据 sheet）、Word（Amazon six-pager 叙述体）、PPT（转交 huashu-design skill）
- **环境适配**：能跑 Python 跑脚本，能派子任务并行，连脚本都跑不了就告诉你在 Excel 里怎么点；核心依赖仅 openpyxl，CSV 纯标准库
- **安装**：`npx skills add alchaincyf/huashu-excel` 或 clone 或直接丢仓库链接给 agent 说「读一下这个仓库的 SKILL.md」
