## 核心主旨

记录一款面向留学生的旅行 Agent 产品构思全过程：从"找到搭子"（匹配同行人）到"按约成行"（将模糊意向转化为可执行旅行计划），核心难点在于陌生人协作意向的转化。

## 关键信息

### 产品定位
- 目标用户：留学生群体（有旅行需求、缺本地社交圈、预算敏感）
- 核心价值：把"想找个搭子一起玩"的模糊意向，转化为"已订好机票酒店、有明确行程"的可执行计划

### 设计思路
1. **意向采集** — 用户表达"想去某地/某时间/某玩法"的模糊意向
2. **搭子匹配** — 基于目的地、时间、预算、兴趣匹配同行人
3. **意向转化** — Agent 主动推进：从"聊聊"到"定下来"的关键转化
4. **计划生成** — 生成可执行的行程、预订、分工方案
5. **按约成行** — 行前提醒、行中协调、行后复盘

### 核心难点
- 陌生人协作的信任建立（身份验证、信用机制）
- 意向到行动的转化率（多数人停留在"聊聊"阶段）
- Agent 在多方协调中的角色边界（撮合者 vs 决策者）
