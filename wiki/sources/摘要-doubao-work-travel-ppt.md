## 核心摘要
作者用一份两人同行、六天五晚的北京旅行方案实测「豆包工作」，验证旅行已成为个人 Agent 检验执行能力的高频场景：先用「浏览器录制与回放」Skill 把查景点、查酒店的方法录成可复用流程（结果导入飞书多维表格），再用"操作电脑" Skill 与**三个 Agent 并行研究**行前准备、景点购票、展览信息（本地电脑与云电脑两种执行环境参与同一任务），最后让 Agent 综合时间/预算/偏好收敛方案，产出可继续修改的行程文档与 20 页 PPT（两人预算约 6310 元，不含大交通）。文章引用 klook 调查（10 个市场 2725 名旅行者，超七成规划者花 10 小时以上）与 Meta Muse 把预订旅行列为代表用途、Instinct 创始人 Noah Shinn 称旅行约占平台交易额一半，说明行业都在把产品从"一次问答"推向"接着处理具体事务"。核心产品判断：把用户查资料的方法沉淀成 Skill、把重复执行交给多 Agent 并行，人只负责提出条件与做出取舍，是个人 Agent 接住一整段任务的关键。
