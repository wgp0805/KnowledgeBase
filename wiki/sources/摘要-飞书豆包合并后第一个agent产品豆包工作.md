## 核心摘要

字节跳动于 7 月 30 日整合飞书产品团队与豆包产品团队后，推出首款重要产品——**豆包工作（Doubao Work）**，直接与飞书原生打通，继承飞书的文档、多维表格、知识库、聊天、邮件及完整权限系统。产品提供本地电脑与云端电脑两种执行模式，支持 Skill、连接器（MCP）和工作伙伴等功能，覆盖企业微信、钉钉、百度网盘、企查查、同花顺等常用集成。

作者的核心判断是：**Agent 用谁家的在模型差距不大的当下可能不重要；真正重要的是企业的数据沉淀在哪**。飞书作为组织数据资产的载体，其积累的文档、会议语料、业务数据和精细化权限管控，才是 Agent 能真正发挥价值的基石。对于已经在用飞书的企业，豆包工作配合飞书，是"最好的 Agent 起手式"。

## 关键信息

- **产品形态**：从豆包原"工作任务"拆出的独立办公 Agent，支持飞书账号直接登录。
- **核心亮点**：完全继承飞书的文档、数据、权限；支持本地与云端双模式执行；企业可统一管控 AI 额度并按部门/个人分配上限。
- **典型用例**：用户用大白话指令让 Agent 操控桌面打开应用、爬取数据写入飞书多维表格、封装为可复用 Skill、读取分析表格数据并生成飞书消息卡片发给同事。
- **组织视角**：过去依赖飞书是因为协同机制和云文档体系；现在依赖飞书是因为"数据 + 关系 + 组织上下文"沉淀其中。
- **行业定位**：今年继 WorkBuddy、千问办公之后，办公 Agent 领域到来的第三个巨头玩家，御三家在办公领域再次集结。
