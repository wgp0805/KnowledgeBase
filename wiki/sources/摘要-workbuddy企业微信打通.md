## 核心摘要

怪哥体验 2026-10-14 升级后的 WorkBuddy 与企业微信深度打通：用企微账号登录 WorkBuddy 企业版（5.8.0+），在授权范围内调用企微消息/文档/日程，成果反向推送回企微。一句话指令（不给群名、不给文档链接）即可完成"检索项目群讨论 → 区分讨论建议与最终结论 → 更新 PRD 到 V0.2 → 关联调整埋点文档 → 变更要点同步回群"的完整闭环。核心判断：Agent 正从**外部顾问**进化为**驻场顾问**——过去是人把工作现场的信息搬给 AI，现在 AI 真正走进工作现场。

## 关键信息

### 背景
- 2026-10-14 WorkBuddy 升级与企业微信深度打通：一边是连接 1400 万机构组织的企微，一边是沙利文报告中国个人端与企业级桌面智能体双榜第一的 WorkBuddy（[[摘要-workbuddy-一句话需求实测]]）
- 对照：微软、Google 在把 Agent 往邮件/文档/日历里塞，腾讯把 WorkBuddy 和企微放到同一张工作桌
- 痛点：打通前 AI 像"能力很强的外部顾问"——专业没问题，但干活前人得先翻聊天记录把最新结论整理交代一遍

### 三步闭环实测（需求："数据导出权限优化"）
1. **理解任务意图**：只发一句话，未给群名/文档链接/改动清单；WorkBuddy 先弹**授权窗口**（列清哪些信息可读、哪些操作需授权），授权后从海量企微消息中准确找到对应项目群与历史文档——光接入信息不够，Agent 还得从海量上下文中理解意图、找到真正需要的信息
2. **上下文驱动执行**：群讨论零散且分阶段（研发建议/设计疑问/最终结论），它准确采用最终确认方案（本期只允许管理员导出、移除自定义角色配置入口、连设计曾提的置灰方案也没保留），更新 PRD 至 V0.2 并保留版本号与文档结构样式；**识别两份文档的关联影响**——自定义角色延期后，`export_perm_view`、`export_perm_save` 埋点事件与"配置启用次数"指标同步从埋点文档本期范围移除（群一句"这期先不做"，落实到功能范围/权限矩阵/页面交互/数据埋点多处调整）
3. **衔接团队协作**：变更要点同步回企微前**再次弹操作确认窗口**，确认后由"智能助理"身份发回项目群，相关同事直接查看继续评审——讨论产生、AI 整理、又回到原群，人不再来回搬运信息

### 核心判断：外部顾问 → 驻场顾问
- 驻场顾问更了解团队在做什么：接到任务自己查阅资料、了解讨论和项目状态；需要拍板的（读资料、发通知）跟人确认——**能主动了解和处理工作，关键操作上又保留人的控制权**
- 企业上下文的真正价值：群里的原始讨论直接成为 WorkBuddy 判断和执行任务的依据，原本"人工整理结论→分析影响范围→逐项交代"的工作被压缩进一次任务
- 方向判断：从外部顾问到驻场顾问，是企业级办公 Agent 接下来值得关注的方向
- 体验入口：企微账号登录授权 WorkBuddy 企业版（5.8.0 及以上）
