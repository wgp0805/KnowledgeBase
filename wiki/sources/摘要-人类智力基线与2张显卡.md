## 核心摘要
抖音视频整理：**2× RTX 5090 + Qwen3.8-27B + DeepSeek Harness = 一台完全本地、完全私有、完全免费的 AI Agent 工作站**。视频主张"人类智力基线站在了新台阶上，门槛是 2 张显卡"——过去跑 Agent 级 AI 要么调云端 API 按 token 付费，要么需要企业级 GPU 集群；如今两张消费级显卡（2× RTX 5090 = 64GB 总显存）就能在本地跑满 Qwen3.8-27B 的 256K 上下文，配合开源的 DSH 框架和 llama.cpp 推理引擎，构成完整 Agent 工作流。实测从零交付一个 3D 体素版"我的世界"网页游戏：38 步、23 分钟、66 tokens/sec、缓存命中 98%，双击 index.html 即可玩，不联网不装依赖。

## 三大核心组件
1. **[[Qwen3.8-27B]]**：阿里通义千问 27B 稠密模型，256K 上下文，混合注意力架构（64 层中 48 层线性注意力 Gated DeltaNet + 16 层全注意力），Q4 GGUF 约 16.69GB，Apache 2.0
2. **[[DeepSeekHarness]]**：DeepSeek 2026-08-13 开源的 Agent 框架，MIT 协议，TypeScript，基于 Cordis 插件内核，"一切皆插件"设计，GitHub 史上涨星最快项目（42 小时约 10 万 Star）
3. **[[RTX5090]]**：NVIDIA 消费级 AI 显卡新标杆，32GB GDDR7、1,792 GB/s 带宽、Blackwell 架构，不支持 NVLink，双卡走 PCIe 通信

## 技术架构
```
DSH (Agent 框架) ──OpenAI 兼容 API──> llama-server (llama.cpp) ──tensor-split 1,1──> 2× RTX 5090
```
- DSH 认 OpenAI 兼容端点，不绑定 DeepSeek API，把 base URL 指向本地 llama-server 即可
- llama-server 启动关键参数：`-c 262144`（256K 上下文）、`--tensor-split 1,1`（两卡对半分摊）、`--cache-type-k/v q8_0`（KV cache 量化减半）、`--spec-type draft-mtp`（MTP 投机解码，无需草稿模型）、`--fit off`（装不下直接报错不静默降级）、`--jinja`（用模型内置聊天模板，Agent 必开）

## 核心意义
1. **能力跃升**：27B + Agent 框架从"尝鲜"变"日常可用"，实测能交付完整 3D 游戏
2. **门槛降低**：从企业级 GPU 集群降到 2 张消费级显卡（约 3-4 万元一次性投入）
3. **完全私有**：数据不出本机，企业 IT 可上 Agent 工作流而不出内网
4. **生态爆发**：DSH 上线 5 天社区插件已超 1400 个
5. **架构解耦**：框架不挑模型（OpenAI 兼容端点），未来模型升级硬件配置不用换
