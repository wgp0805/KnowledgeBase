## 核心摘要
本文复盘 Manus 2.0 如何把"General Agent"从定位做成体验。2025 年 3 月 Manus 上线时能力全面（查资料、整理文件、写代码、做网页、操作浏览器）但"样样通样样松"，通用型 vs 垂直深耕之争激烈；2025 年 12 月 29 日 Manus 加入 Meta，2026 年 9 月 1 日恢复独立运营后 27 天即发布 2.0。2.0 的四个重点：①Studio 新增视频编辑与游戏开发专属环境，网站/应用/文档/幻灯片功能全部整合进同一工作区（此前分散在各入口的 Skills、Project Skills、Connector、Scheduled Tasks 等底层模块早已陆续搭建好）；②Video Editor 的 Alchemy mode 结合视频生成与代码生成组织画面，定位是"给通用 Agent 补一个专业工作间"——不比拼单点视频生成效果，而是解决"做落地页时顺带要几十秒短片+主视觉+动画"的任务间场景，产出素材进入时间线可人改可继续交给 Agent；③Game Dev 专门的游戏开发环境，代码/素材/运行结果留在同一项目，多人游戏可配持续运行的云电脑（Cloud Computer 串联，核心是拿到稳定长时运行环境）；Computer Use 进一步接入本机文件、浏览器和应用，手机可远程发指令找文件；④Cue 独立成新应用，每个 Agent 拥有专属邮箱、手机号、钱包和电脑环境，可在用户预算内支付、接电话留摘要，多 Agent 可拉进同一群聊分工（一个找场地、一个筛选、一个整理成 Deck），接近 Personal Agent 方向。文章判断：通用更像一套调度方式，重点是用户不必自己决定下一步打开哪个 AI 产品；Manus 换上新 Agent Harness（平时轻量、按需引入专业模块）并由 Cascade 服务调度；垂直产品继续比拼单点深度，通用 Agent 要拿的是入口和调度能力，但链条越长任务稳定性越难保证——通用 Agent 需要证明的不是每个单项都赢，价值发生在任务之间。
