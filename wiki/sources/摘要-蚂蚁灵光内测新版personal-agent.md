## 核心摘要
特工宇宙内测体验蚂蚁灵光新版本：灵光正式从"生成个人应用"升级为带长期记忆、可主动推进长程任务的 Personal Agent，给每个用户分配一台 24 小时运行的独立 Linux 云电脑（自带浏览器），支持接入 MCP/CLI/Skill 与第三方工具 Harness。实测可让它接管钉钉长任务、一句话把电脑文件发回来、一句话调用电脑上的各种 Agent，甚至在云电脑里装 Claude Code 当子代理。作者提出 Personal Agent = Agent Harness 框架 + 全新 Agent 基础设施 + 垂直领域专业工具，并判断随着模型能力溢出、Flash 模型极致性价比、Agent 生态进入物理世界三要素成熟，Personal Agent 正从 Gartner 曲线的期望膨胀期迈入稳步爬升期。

## 关键信息

### 新版灵光的转向
- 从"生成个人应用为主的 Personal Agent"升级为"带长期记忆、可主动推进长程任务的全新 Personal Agent"：长程任务主动托管，自带长期上下文记忆，关键节点先于用户主动提醒
- 给每个用户分配独立 Linux 云电脑，24 小时云端运行，有自己的浏览器；可接入 MCP、CLI、各种 Skill，支持第三方工具的 Harness 能力
- 典型玩法：接入钉钉 CLI 接管钉钉长任务；自动回复不紧急消息、自动抓数据写周报、处理家校群打卡待办；通过 CLI/MCP 连接特斯拉、Mac Mini、3D 打印机；直接接管用户已有的 Agent
- 定位为"所有生活场景的 AI 智能中枢"

### 实测：让灵光接管我的 Agent
- 接入路径：给自己的服务做页面+后端+网页输入框（不会代码可丢给千问办公）→ 通过 Claude Code 访问服务 → 灵光用云电脑浏览器打开网页发指令连接自己的电脑
- 实测体验：个人助理中速度体验最快（任务三分钟跑完，比桌面 Work Agent 快）；一句话把电脑文件发到手机；一句话调用电脑上的 Agent
- 进阶玩法：让灵光操作云电脑，在云电脑里下载 Claude Code 作为执行子代理——顺手写了个计算器小程序，打开即用，全程无卡点
- 交互亮点：Agent 执行时用户可清楚看到当前在做什么操作

### Agent 时代核心逻辑
- **把自己的一切数据变成 Agent 的上下文，把自己的一切能力变成 Agent 可以调用的 Skill**
- 作者过去把常用数据/工具封装成独立知识库服务和 Agent，但分散各处管理成本高，灵光接管解决了管理成本问题

### Personal Agent 新阶段判断
- **定义**：Personal Agent = 龙虾（或任意 Agent Harness 框架）+ 各种全新的 Agent 基础设施（浏览器、电脑、邮箱、飞书等）+ 各种垂直领域的专业工具（如 Blender）
- Gartner 曲线对应：龙虾阶段处于萌芽期与期望膨胀期（人们希望有无所不能的 AI 管家，但生态和工具不匹配野心），最大价值是教育市场、培养核心开发团队和工具生态
- 三要素同步成熟才进入新阶段：① 模型能力溢出（Coding/视觉理解/浏览器控制/3D 生成普遍增强，Kimi 和 Qwen 3.8 跻身全球第一梯队，可接管日常 99% 任务）② Flash 模型极致性价比（能力比半年前强两个数量级、成本降两个数量级——过去 Opus 4.6 控制龙虾排版一次几十元，现在 Flash 几毛钱且完成得更好）③ Agent 生态进入物理世界（AI 浏览器 → MCP/Skill/CLI 连接桌面工具与企业 SaaS；传统 SaaS 厂商主动适配 Agent，否则 Agent 可逆向一键复刻）
- 结论：Personal Agent 不会像龙虾一样销声匿迹，正式迈入"稳步爬升期"
- 赛道判断：Personal Agent 大概率是大厂才能跑通的赛道（需要底层模型、云端算力、工具生态、数据安全、与主流办公/通讯工具深度整合）；灵光历史增长纪录——头 4 天 100 万下载、6 天超 200 万，曾击败 ChatGPT 和 Sora 达百万下载速度纪录
- 背景事件：半年前龙虾热潮后关注度消散，几个大厂宣布停止运营龙虾标志"龙虾时代"结束；国庆前 Meta Muse 拉高期待值；钉钉 CEO 陈宇森在朋友圈肯定蚂蚁灵光的效果和方向
