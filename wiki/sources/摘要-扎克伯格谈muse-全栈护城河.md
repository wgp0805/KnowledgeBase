## 核心摘要

本文编译扎克伯格与科技记者 Alex Heath 的访谈：Muse 上线不到两周下载超 250 万，扎克伯格的核心主张是"个人 Agent 必须从预训练开始设计"——理解用户的长期目标、判断私人信息的使用边界，不能只靠通用模型的后训练补一个产品界面。他拆解了 Muse 的全栈能力栈：云端虚拟机让 Agent 持续行动、记忆让 Agent 从单次工具变成长期服务、逐项授权的最小权限系统与独立凭据存储决定用户敢把多少事交给 AI、机密虚拟机（由 Signal 创始人 Moxie Marlinspike 负责）承诺连 Meta 自己也读不到用户内容，另有监控 Agent 识别提示词注入。商业上以每周 1 亿 token + 一台虚拟机的免费额度起量，与 Stripe 合作接入支付，计划从交易抽成。战略层他反思 Llama 4 偏离预期后改用更小核心团队 + 更大算力重建研究（Prometheus 集群、Watermelon 模型、Muse Spark 1.3），并坚持"技术扩散 + 权力制衡"的安全观。
