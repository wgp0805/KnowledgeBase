## 核心摘要
ECC（Everything Claude Code）v1.10.0+ 完整使用教程，覆盖 Claude Code 和 OpenCode 两大平台。ECC 是 AI 编码助手的"外挂系统"，提供六层架构（Rules→Skills→Agents→Hooks→MCPs→Continuous Learning），47+ 专业化 Agent，以及 AgentShield 安全扫描。核心命令包括 /plan（实施规划）、/tdd（测试先行）、/code-review（代码审查）、/orchestrate（多代理编排）。OpenCode 版本比 Claude Code 拥有更丰富的事件类型和原生自定义工具。
