## 核心摘要
文章以 [[WeKnora]] 与 [[Molio]] 对比，提出 Agent 平台存在两种哲学：一种是组织治理型 AI 平台，平台定义能力、统一权限、审计、知识、Agent 与 MCP，让员工在边界内使用；另一种是个人智能体平台，让用户自己选择 Agent、组织知识、配置 Skill 并管理记忆，形成属于自己的 AI 工作环境。Molio 把 Agent 理解为「能做什么」、Wiki 理解为「知道什么」、Skill 理解为「怎么做」、Memory 理解为「记得什么」，强调用户控制而不是平台代管。作者认为企业平台横向扩张组织能力，个人平台纵向深入本地运行环境，但两条路线最终都会走向 Agent + Knowledge + Skill + Memory 的长期工作底座。
