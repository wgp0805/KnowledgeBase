## 核心摘要
一位前端开发者通过 36 行规则文件让 AI 按照规范化流程工作，成功交付 Java 后端模块。核心四步流程（SuperProgramming）：**Brainstorming**（动手前澄清需求、探查现有代码、给出设计大纲）、**Writing Plans**（拆小步、列文件清单、找可复用方法）、**Implementing**（先测试后实现、编译验证）、**Closing the Loop**（改动清单 + 风险 + 待验证项 + 可复用经验）。实战覆盖 Excel 导入（需先探查现有代码避免重复造轮）、详情接口多表聚合、upsert 保存（AI 主动询问是 insert 还是 upsert）、Long 精度丢失等场景。关键教训：规则约束的其实是开发者自己，让每次协作从设计共识开始。
