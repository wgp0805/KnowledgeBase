# 摘要-python-day02-开发环境搭建

## 核心摘要
这是「小嘉 Python 程序设计」系列课程阶段一·核心基础的 Day02 教程，技术基准为 Python 3.15.0。内容覆盖：官网下载安装 Python（重点讲 Windows 勾选 "Add to PATH"）、用 `python --version` 与 [[PyLauncher|py launcher]] 验证安装、REPL 交互模式、官方编辑器 [[IDLE]] 的使用、[[PyCharm]] 专业 IDE 的项目/调试/解释器/带参运行流程、[[Anaconda]] 数据科学发行版的定位、命令行运行脚本，以及 [[Venv虚拟环境]] 入门（创建、激活、验证隔离、退出）。文末附常见问题排查表（PATH 未配置、商店版命令别名占用、多版本、中文乱码）和 6 道练习题，并预告 Day03 系统学习 venv + pip + requirements.txt。
