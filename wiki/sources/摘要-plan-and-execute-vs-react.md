# 什么是 Plan-and-Execute？它和 ReAct 怎么选？

面试题对比 Plan-and-Execute 与 ReAct 两种 Agent 模式：ReAct 边想边做、每步推理；Plan-and-Execute 先规划完整计划再逐步执行。沉默王二给出选型建议——简单任务用 ReAct，复杂多步任务用 Plan-and-Execute。
