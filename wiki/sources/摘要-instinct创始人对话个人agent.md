## 核心摘要
个人 Agent 公司 Instinct 创始人 Noah Shinn 在 Patrick O'Shaughnessy 的访谈中系统阐述了公司路线：Instinst 成立约一年，2026-09-28 完成 10 亿美元 C 轮融资，估值一个月内从 25 亿涨到 100 亿美元，用户日增 10%-11%、年化 GMV 超 10 亿美元（约一半来自旅游交易），零公关预算靠邀请码口碑传播。产品不做独立 App，而是给 Agent 配电话号码、邮箱和云端电脑，走"无界面"路线；为支撑免费模式，必须自研混合推理与分发管线（批处理异步任务 + 蒸馏剪枝），把单用户全天推理成本压到远低于前沿 API 的水平。商业模式对标 Apple Pay / 美国运通——从真实交易网络向 B 端收 Take rate（精品酒店佣金可达 20%-30%），坚决不做广告变现；信任防火墙与独立守门系统是安全底座，用户绑定至少一项敏感资产后留存率约 80%。Noah 判断主动式 Agent 将使 90% 以上 Token 消耗发生在后台，算力需求比被动式 AI 高两到三个数量级。
