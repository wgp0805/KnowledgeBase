## 核心摘要
文章用五个维度（入口、上下文、权限、执行、信任）拆解 Personal Agent 赛道的六条海外路线，认为横向功能排名容易失真，真正的胜负手是争夺用户的"默认委托权"：OpenAI dots 要成为跨渠道保留你目标与标准的"第二身份"（云端电脑 + 4000 插件，主动研究只读）；Meta Muse 从生活事务与交易切入（Muse Secure VM、Stripe Link 一次性卡、邮件只读/代发分级授权）；Gemini Spark 借 Gmail/Docs/Calendar 数据做数字生活调度；Instinct 走"没有新界面"路线，成为联系人本身（接邮件、屏幕、音频、位置，可主动来电发消息）；xAI Grok Bot 把助手扩成多角色数字员工队伍（多 Bot 共用一台云端电脑，含在付费 Cursor 计划中）；OpenClaw 把所有权交给用户（local-first、模型无关、自托管）。另指出 Siri AI（系统级入口）与 Alexa+（家庭声音入口）随时可能改写竞争，产品终局很可能是"一个总入口 + 多个专业 Agent"。
