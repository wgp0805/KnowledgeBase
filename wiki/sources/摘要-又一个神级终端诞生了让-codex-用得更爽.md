## 核心摘要
本文介绍了一款名为 Kaku 的 AI 终端工具，它基于 WezTerm 深度定制，用 Rust 编写，启动快速且完全免费（MIT 协议）。Kaku 的核心特色是内置了 Claude Code 和 Codex 支持，通过 `command + L` 快捷键可快速进入 AI 模式，支持 `@cwd`、`@tab`、`@selection` 等上下文附加功能。文章详细介绍了安装方式（Homebrew 或 DMG 下载）、配置流程、内置工具（Lazygit、Yazi 文件管理器、目录跳转、广播输入等），并通过一个"中国文字珠帘数字文物展览"的案例展示了 Claude Code 和 Codex 在同一终端中同时工作的效果。作者认为终端正在成为替代 IDE 的编程工具，Kaku 提供了开箱即用的极客风体验。
