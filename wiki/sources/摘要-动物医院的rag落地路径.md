# 摘要：动物医院的RAG落地路径

## 核心主旨
以一次危重猫接诊为例，阐述 RAG 在动物医院的落地路径。核心观点：垂直场景的 RAG 不是技术问题，而是知识工程问题——如何将散落的病例、指南、药品信息结构化为可检索的知识。

## 关键论点
1. **场景痛点**：兽医接诊时需要快速查阅病例、用药指南、检验参考值，传统方式效率低。
2. **RAG 的价值**：将医院历史病例、兽医指南、药品说明书等构建为知识库，辅助接诊决策。
3. **落地挑战**：
   - 知识来源分散且非结构化（手写病例、PDF指南、口头经验）
   - 知识时效性（药品更新、指南修订）
   - 准确性要求高（误诊可能致命）
4. **实施路径**：先结构化核心指南 → 再接入历史病例 → 最后加入实时检验数据
