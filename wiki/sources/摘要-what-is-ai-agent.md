# 什么是 AI Agent？与直接调用大模型 API 有什么区别？

面试题辨析：直接调用大模型 API 只是 ChatBot，不是 Agent。Agent 的核心在于自主决策循环——感知、规划、行动、反馈。沉默王二拆解 Agent 与 ChatBot 的本质区别：Agent 有循环（Loop）、有工具（Tool）、有记忆（Memory）、有终止条件。
