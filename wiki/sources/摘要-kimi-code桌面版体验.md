## 核心摘要
作者沉默王二第一时间体验 Kimi Code 桌面版，整体干活能力认可，感觉和网页版完全不一样。设计极简，打开就是对话框，选好模型输入需求，权限模式可设「完全自动」，Kimi 自己规划任务、执行代码、启动预览服务、截图自检。可选模型 K3 High（主力，质量高速度慢）、K2.7 Code Highspeed（高速版，快但粗糙）。实测赛博朋克像素街区（Vite + Three.js，Canvas 2D 分层合成，程序化生成贴图，从输入到交付约 40 多分钟）和鹈鹕骑自行车动画（K2.7 vs K3 对比，K3 质量明显更好，单一时钟源+两段式逆运动学保证动作同步）。支持自定义供应商（内置主流供应商 API 地址，导入 DeepSeek 等）。作者观点：Harness 成了今年下半年主角，Kimi 在前端能力上有一手，但慢、贵。
