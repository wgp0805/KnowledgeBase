## 核心摘要
DeepSeek Harness 官方发布「创造模式」（Creator Mode）玩法指南：用户只需输入一句自然语言，Agent 就能自己读文档、写代码、造插件，甚至把新功能直接装进自己的工作界面（"想给 AI 增加什么新功能，直接在聊天框里提需求"）。官方免费公开 7 套示例 Prompt，覆盖 3D 建模、交互式 3D 游戏、视频剪辑工作台、海报设计工作台、AI 论文阅读器、整 App 换肤、Token 计费板。上手三步：新建会话选「创造模式」→ 粘贴 Prompt 让 Agent 读文档写插件并试运行 → 检查生成结果与安装权限按需修改。

## 关键信息
- **核心玩法**：一句话造插件——3D 建模（埃菲尔铁塔/长城/故宫侧边栏插件）、Transformer 计算过程 3D 交互游戏、视频剪辑工作台（自然语言指挥剪辑）、海报设计工作台（官网 shader 背景+英文字体）、AI 论文阅读器（右侧边栏、保留原文排版、划选文字高亮/笔记/提问）、整个 Harness 应用换肤（5 种风格含像素化）、Token 计费板（Token 用量/对话次数/预估费用/CPU 占用率）
- **三步上手**：① 新建会话选「创造模式」；② 粘贴 Prompt 让 Agent 读取开发文档、编写插件并尝试运行；③ 检查生成结果和安装权限，按需继续提修改要求
- **官方提示**：部分演示插件经过多轮对话修改完善，单凭一条 Prompt 未必能完全复现视频效果
- **设计取向**："真·手搓万物、自己动手、丰衣足食、所想即所得"，进一步坐实 **Everything is a Plugin**
