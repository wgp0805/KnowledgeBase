## 核心摘要
AI Agents Terminal 是一个 VS Code 扩展，把本机装好的 AI CLI 编程助手（Claude Code / Codex / Cursor 等）收进状态栏的一个按钮里。核心特性：只显示已安装的 agent、YOLO 模式（自动放行）、Resume 模式（续上会话）、17个内置 agent 开箱即用。解决多 agent 之间反复横跳的摩擦问题，每个 agent 各自配置 flag，不用全局一刀切。
