## 核心摘要

卡尔的 AI 沃茨（与 yc 星辰合著）两周花 300 多刀订阅费（Muse 100 刀/月、ChatGPT Pro 200 刀、Manus 40 刀、Grok 100 刀）实测 **Google Muse、Grok Bot、OpenAI Dots、Manus Cue** 四款 Personal Agent，覆盖 12 个自媒体平台后台，**可委托率只有 33%**（两个月前是 0%）。结论：现阶段 Personal Agent 是本地 Agent 的补充，"有台云电脑就能躺平"会撞上不可能三角（除非它记住你所有账号密码 API）。作者给出 **3 个可复制提示语**（多任务进度条 / Computer Use 六道门 / 融合日报），配"云端 Personal Agent + 本机 Codex"跑通采集与日报。

## 关键信息

### 四款产品实测结论
- **Google Muse**：第一个被淘汰——莫名被封，用 Gemini Spark 开通后后续使用仍卡；判断"Google 的东西不太适合采集国内平台信息"（**注意**：原文写作"Google Muse"，与本库 [[MetaMuse]]（Meta 的 Muse）是否同一产品存疑，原文语境倾向 Google 系，暂按原文记录、标注待查）
- **Grok Bot**：无本地 Computer Use 能力，用的是命令行交互，Computer Use 压根不生效；但可分多个 agent 共享一台电脑
- **Manus Cue**：同样没有控制本地的 Computer Use 能力
- **Dots**：唯一答案但问题一堆——①所有对话挤在一个对话框、不能像 Grok Bot 那样多 agent 分任务；②"最终活动面板"不记录执行结果，任务状态只能一个个点开看；③一次只能连一台电脑（50 台也只能绑一台，只能互相切换不能同时连）；④**无法复用本机登录状态**，异地登录/登录态失效是死结
- 不可能三角：云端 Personal Agent 想完全替代本机，除非把所有服务的账号密码 API 全记住，还要关掉部分安全设置（否则异地掉线）

### 三个提示语（核心交付）
1. **多任务进度条**：每次回复末尾附固定格式进度表 `| 任务 | 执行端 | 状态 | 证据 | 下一步 |`；执行端写清云端/本机/哪个 Agent；状态六选一（待开始/执行中/等待外部/需我确认/阻塞/已完成）；**没有实际执行记录不许写"执行中"**，口头答应不算；接新任务不能默默丢旧任务；定时任务只在授权后创建并读回任务 ID 和下次运行时间
2. **Computer Use 六道门验证**：按平台清单逐个采集，每平台必过六关——①截图非空 ②页面标题含平台名 ③关键数字已提取 ④数字格式合理（粉丝数≥0、日期 7 天内）⑤无登录弹窗遮挡 ⑥截图时间戳与当前日期一致；任一未过标 FAILED 记原因、**不编造数据**，全过输出 JSON 汇总；硬约束：只读，不点发布/删除/设置，遇二次验证或 CAPTCHA 立即停该平台标 BLOCKED
3. **融合日报**：每天定时跑，信息源（AI News Radar RSS / AIHOT / Hacker News 前 30 / GitHub Trending / Polymarket / XHunt）→ 五段结构（异常与告警 / 邮件摘要与待回复草稿 / AI 新闻按公司维度归类不按热度 / 去重完整链接 / 与当前项目相关的选题建议）→ 输出飞书文档 + 邮件通知（标题含日期）；写作参考 ASD-STE100 简化短句、Anatomy 信息组织（主体→事件→证据→影响→行动），不用"值得关注""引发热议"这类空话

### 两个真香发现
- **邮件是最大惊喜**：所有 Personal Agent 都支持且体验一致最好——建议把所有获取信息的服务都给 Gmail 发一份；agent 读邮件生成草稿+链接，本机 Codex 里下发回复指令排队执行
- **飞书文档做中转**：Dots 存日报到飞书 → 邮箱通知 → 本机 Codex 直接读取持续更新的文档（含图片视频）；"让 Dots 控制本地 Codex 再连远程 CLI"的左脚踩右脚方案完全行不通

### 组合与判断
- 最终架构（作者自嘲鲁布·戈德堡机器）：Dots 采集存飞书 → 飞书通知发邮箱 → 邮箱触发 Codex 读取 → Codex 调本机 Computer Use 跑另一轮采集；日报开头先说今天哪个环节出了问题，并复盘前一天各 Agent 任务完成情况
- 判断：Personal Agent 现阶段更多是本地 Agent 的补充，不是有云电脑就能全交出去；33% 是开始，作者希望半年后到 99%
