# Multi-Agent 协作是怎么实现的

面试题讲解 Multi-Agent 协作实现：主流架构是编排器（Orchestrator）模式，主 Agent 拆任务、派活、收结果，子 Agent 各干各的。沉默王二分析协作的四步流程，以及何时该用 Multi-Agent、何时单 Agent 就够。
