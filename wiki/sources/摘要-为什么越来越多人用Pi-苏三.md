## 核心摘要
苏三（博客园转载版）解析 Pi 为何越来越多人用，内容与追风版高度重合但更精简。Pi 由 libGDX 创始人 Mario Zechner 创建，系统提示词仅 200 Token，核心工具 4 个（read/write/edit/bash），GitHub 8.6 万 Star，被评为"目前唯一能真正平替 Claude Code 的 Agent 架构"。四大原因：便宜（99.93% 缓存命中率，0.028 美元/任务是 Claude Code 七分之一）、不锁模型（15+ 供应商）、兼容已有积累（自动读 `~/.agents/skills` 和 `AGENTS.md`）、可扩展（Extensions/Skills/Packages）。设计哲学："对 Agent 来说，你刻意不做什么，比你做什么更重要"；"Claude Code 是给你一个 AI 助手，Pi 是给你造 AI 助手的工厂"。
