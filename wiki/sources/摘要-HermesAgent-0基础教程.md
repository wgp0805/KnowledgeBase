## 核心摘要
秋芝2046 撰写的 Hermes Agent 零基础新手教程。涵盖下载安装、模型配置（主模型 + 本地辅助模型）、Ollama 集成（以 Qwen3.5 为例）、多 Agent 多模型配置实践。教程以打造一个"赛博导师 Agent"为场景，展示如何通过需求文档让 Agent 自行搭建完整的学习系统（含学习计划、每日推送、错题本、进度网站）。核心亮点：Hermes Agent 的 self-improving 能力——当教学效果不符合预期时，可直接反馈让 Agent 更新自己的 Skill，实现教法进化。
