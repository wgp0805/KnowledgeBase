## 核心摘要
Dataway 是基于 DataQL 的接口配置工具，允许开发者在 Spring Boot 项目中通过 UI 界面直接配置和发布 API 接口，无需编写 Controller、Service、DAO、Mapper 等任何后端代码。它以 Jar 包内嵌方式集成，与应用共享 HTTP 端口，支持接口的配置、测试、冒烟、发布一站式管理，极大提升研发效率。
