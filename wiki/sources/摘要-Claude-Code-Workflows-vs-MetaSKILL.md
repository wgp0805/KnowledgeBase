## 核心摘要
张善友撰写的深度对比文章，系统比较了 Claude Code Dynamic Workflows（JavaScript 可执行脚本编排）与 OpenClaw.NET MetaSKILL（YAML 声明式 DAG 编排）两种 AI Agent 工作流编排范式。文章从编排模型、核心差异矩阵、编排原语、设计哲学、适用场景五个维度展开分析。Claude Code Workflows 采用"代码即编排"范式，图灵完备、灵活度高，适合探索性工作；MetaSKILL 采用"声明即编排"范式，安全门禁完善、审计持久化，适合生产级工作流。两者互补而非竞争，理想组合是用 Workflows 做原型探索，用 MetaSKILL 模板固化。
