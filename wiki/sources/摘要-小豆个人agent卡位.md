## 核心摘要
字节即将推出独立个人助理应用，内部可能定名**「小豆」**，由豆包 Chat 与搜索产品负责人**李福祥**主导（其早期历经 AI Lab 与硬件团队 Ocean，模型策略团队已收归其麾下），此前 Ocean 团队孵化的 **Spell 作为端侧与底层能力供给方**深度配合；另一条线由**童遥**掌舵办公生产力与跨端生态（前豆包 PC 端负责人齐俊元的后任，齐俊元创办的 Today AI 已推出国内首款个人 Agent 与老东家正面交锋）。字节不把 Agent 塞进主端"豆包"而另起炉灶，是因为主端考核确定性交互效率与停留时长，Agent 面对的是长链路不确定任务，两者数据飞轮与评测指标难以共存。腾讯三路并进：微信原生助理**「小微」**（通讯录/支付/小程序特权，但微信克制哲学与 Agent 主动刺探逻辑冲突）、腾讯云**「LightVela」**（个人云端持续在线专属虚拟空间，门槛偏高）、独立 App**「Handy Bot」**（形态最接近 Muse）。文章判断：个人 Agent 争夺的是对数字世界的代理权而非屏幕时长；技术路线分化为 Meta 全栈重做底座 vs Instinct 死磕推理管线控成本；国内超级 App 高墙下个人 Agent 可能异化为"平台 Agent"，引发"代表用户还是代表平台"的信任悖论；终局必然走向随身硬件与终端操作系统。
