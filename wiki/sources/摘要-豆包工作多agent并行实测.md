## 核心摘要

杜小虎（人人都是产品经理）实测豆包工作的三大产品经理场景。①**竞品追踪**：用「多 Agents 并行任务」（指令里说"帮我用多个agent"触发），一个主 Organizer 负责分配、5 个子 Agent 各盯一个竞品（实测 Notion/Asana/ClickUp/Trello/Linear），并行查看 3 个月版本更新，最终核验 35 条官方更新，交付对比表 + 功能重叠统计 + 3 句总结；任务可切小窗后台跑、中途随时插话补充。②**写 PRD**：跨对话协作把散在多个对话里的用户反馈/方案讨论/数据测算（分享链接或摘要）汇入同一个工作任务，@ 上传公司 PPT 模板，一次产出 10 节 PRD 初稿 + 8 页内评审 PPT（套用原有配色版式，每页标题写成结论句）。③**数据周报自动化**：浏览器录屏&回放 Skill 录制一次数据后台导出操作（识别→代码化→批量复现），配「定时任务」每周一 9:00 自动跑：导出上周数据 → 本地"周数据.xlsx"新增工作表算周环比生成图表 → 按上周周报格式产出新周报（开头三条结论、异常波动单独列出）；本地电脑/云电脑可自由切换，结果可同步到飞书。核心主张：把步骤固定却耗时的活交给 Agent，把时间留给判断。
