## 定义

开源的**提示语路由 Skill**，仓库地址 `LearnPrompt/laoyeye`，昵称「**老爷爷**」。由卡尔的AI沃茨与 yc 星辰基于 Matt Pocock 的 `ask-matt` 路由形态打造，把 25 个思考类提示语熔炼进一个路由里，让 Agent 按场景自动挑选。

## 关键信息

### 安装与使用
```bash
npx skills@latest add LearnPrompt/laoyeye
```
或直接对 Agent 说：「帮我用上 laoyeye，github.com/LearnPrompt/laoyeye」。

触发方式：在任何地方敲「laoyeye 帮我」，老爷爷会读取上下文简单提问了解你的处境，给出你最合适的「功法」（即提示语）。切换成语音输入后原地大喊效果更好。

### 命名梗
取自小说里那个经典设定——主角戴着的戒指里住着一缕残魂，本身打不了任何架，但阅历深，能在关键时刻指一条路。**它非必要不替主角打，只在主角进入秘境的时候说一句「小子，你该往那边走」。**

### 收录内容
25 条思考类提示语，分**六个场景**：问清问题、学习理解、解决问题、决策类、计划类、自我认识类。

包括苏格拉底式提问、第一性原理、对抗性审查（双向钢人论证）、乔哈里视窗、逆向法等。

### 工程纪律
- **原提示语一个字不改**——不做「拆散 + 改写成 Agent 风格流程步骤 + 加分支判断和检查清单」的 skill 化改写
- **加来源前缀**：收录上游提示语时统一加 `matt-grilling`、`kaz-leader`、`carl-idea-king` 等前缀，25 个名字与上游发布的名字**零重合**，不会覆盖已装的任何 skill
- **作用于整个对话生命周期**，不是一次性的

### 与 ask-matt 的对照
`ask-matt` 的价值是：你不需要知道仓库里有多少个 skill、也不需要记住哪个叫什么名字，只要说「我现在遇到了什么情况」，它就会挑出合适的 skill——**不光告诉你用哪个，还告诉你为什么不是另一个，以及跑完之后接哪个**。老爷爷复刻了这一形态。
