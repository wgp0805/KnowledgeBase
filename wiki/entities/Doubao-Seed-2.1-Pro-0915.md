## 定义
Doubao-Seed-2.1-pro-0915 是 [[VolcEngine|火山方舟]] 推出的 Seed 系列模型升级版本，顶到 **1M 上下文 + 256k 深度思考**，主打 Agent 长时间执行任务防中途摆烂，降低工具幻觉，可用视觉理解做前端 Coding。属 [[豆包]]/[[Doubao]] 模型家族的旗舰升级版。

## 关键信息

### 核心升级
- **1M 上下文 + 256k 深度思考**：Agent 长时间执行任务防摆烂
- **降低工具幻觉**：减少调用不存在或错误的工具
- **视觉理解做前端 Coding**：视觉能力辅助前端代码生成
- **与 [[Seedance2.5|Seedance 2.5]] 工作流丝滑**：Seed-2.1-pro 做 3D 白模搭建 → Seedance 2.5 生成 AI 视频，一个豆包里全干完

### 五个实测案例（2026-09-16，[[卡尔的AI沃茨]]）
1. **Three.js 体素樱花岛**（27 分钟）：单一 HTML 完整复现 3D 体素浮空樱花岛，InstancedMesh 实例化渲染，程序化生成纹理与噪声
2. **The Dumpling Club 3D 互动网页**（2 小时+）：只给 prompt 无参考图几乎一比一复刻原版；每只包子起名+性格+微表情；内置录制功能导出 MP4/WebM 视频
3. **五份洗衣机文档 → Excel 选货汇总表**：自动提取参数、抠展示图（需完全看懂图）、输出产品摘要
4. **60 子表 Excel 含钢量计算**：一次过，60 行汇总干净交付；陷阱处理：中间独缺 Sheet11 没自作主张补一个
5. **加拿大三城办公室选址调研**：所有重要数字可追溯具体来源（31 条来源附录），最终建议多伦多

### 与早期版本关系
- 早期版本（2026-06，[[摘要-doubao-seed2-1-pro-douyin]]）：办公 Agent 任务/前端 PRD/视频转文字+飞书文档/白板看板
- 0915 升级版：1M 上下文 + 256k 深度思考，长时间 Agent 任务和审美都追上第一档

### 作者定位
"成为我日常批量跑的模型之一，跟 [[DeepSeek]]、[[GLM]] 排排队一起干活"

### 升级实测（2026-09-19，摸鱼小李，详见 [[摘要-seed-2-1-pro升级实测]]）
- 三款小游戏交给 Claude Code 接 Seed-2.1-pro：一句话出 Flappy Bird（约 16 分钟交付 55KB HTML）、照着截图补完八关的黄油猫、地下通道找异常（13 种异常其中 8 种细微）
- 用参考图建模 RTS 单位（磁暴线圈/天启坦克/光棱塔/磁暴步兵等，还原七八成）
- 办公题放进豆包工作：上传立讯年报截图整理产业链报告（四张交互图表+产业链全景图）、小米发布会价格页做成可编辑 PPT
- 背景：今年 6 月字节发布 Seed 2.1 同期推出 [[Seed-Evolving]]（"一次发布，无限进步"），0915 固定近期最好版本
