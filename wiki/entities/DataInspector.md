## 定义
data-inspector 是作者冰河自写的只读数据核对 Skill：接收自然语言数据问题，按固定流程生成 SQL、经人工确认后在只读账号下执行并解读结果。不执行任何写操作、不连生产库，用于核对测试数据、定位异常记录。

## 关键信息
- **交付形态**：一份纯文本 SKILL.md（含 frontmatter name/description），不需要写代码或搭服务
- **结构**：绝对红线（优先级最高）→ 六步工作流程 → 输出格式 → 特殊情况处理
- **绝对红线**：① 禁止任何写操作（insert/update/delete/drop/truncate/alter 立即终止）② 禁止连接白名单外的库表 ③ 禁止跳过用户确认执行 SQL ④ 手机号/身份证/银行卡等字段必须脱敏或排除
- **六步流程**：确认问题（复述需求）→ 读取真实表结构（不凭记忆写字段）→ 编写带注释、中文别名的 SELECT → 安全自检 → 提交确认（不确认不执行）→ 只读执行并解读（表格 + 异常值提示）
- **配套环境**：DBA 申请的只读账号（仅 SELECT、仅测试库/影子库）+ 库表白名单配置 + SQL 关键字审核层；核心原则是"AI 写的 SQL 必须经人确认才执行"
- **实测场景**：回归测试后核对 orders 表各状态数量占比，发现"已取消占比 42%（上一版 18%）"并给出排查方向，全程可复现
- **三个坑**：AI 凭印象编字段名 → 强制先读表结构；图省事给写权限 → 差点混进 UPDATE，改为只读账号；敏感字段直接打印 → 脱敏规则写进红线
