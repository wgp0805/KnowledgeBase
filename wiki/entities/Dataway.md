## 定义
Dataway 是 Hasor 生态下的接口配置工具，基于 DataQL 脚本引擎，允许开发者在 Spring Boot 项目中通过 UI 界面一站式完成接口配置、测试、冒烟和发布，无需编写 Controller、Service、DAO、Mapper 等后端代码。

## 关键信息
- **定位**：零代码 API 接口配置工具
- **集成方式**：以 Jar 包内嵌到应用中，共享同一 HTTP 端口
- **核心能力**：UI 界面配置接口、在线测试、冒烟测试、接口发布
- **脚本引擎**：基于 DataQL 查询语言
- **生态关系**：属于 Hasor 框架生态，通过 Hasor-Spring Bridge 与 Spring Boot 集成
- **优势**：减少大量 CRUD 模板代码，降低开发成本
