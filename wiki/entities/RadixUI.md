## 定义

Radix UI 是一套无样式的 React 无障碍组件原语（Primitives），提供可访问、可定制的底层 UI 组件，是 shadcn/ui 的构建基础。

## 关键信息

- **定位**：无样式组件原语，不带任何视觉样式，只提供行为和无障碍支持
- **核心价值**：ARIA 规范完整实现、键盘导航、焦点管理、屏幕阅读器支持
- **技术栈**：React + TypeScript
- **与 shadcn/ui 关系**：shadcn/ui 使用 Radix UI 作为底层组件原语，添加 Tailwind CSS 样式
- **组件类型**：Dialog、Dropdown Menu、Tabs、Accordion、Tooltip 等
