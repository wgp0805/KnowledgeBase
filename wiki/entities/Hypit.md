## 定义
Hypit 是开源的视频复刻 Skill 项目（github.com/hypit-ai/hypit），让 Codex、Claude Code 等 Agent 读取参考视频并按原片结构重组画面、台词、字幕与动效，生成可继续编辑、可复用的视频工程。它本身不是视频模型，而是"制作知识 + 方案编写 + Runtime 执行"的三层结构。

## 关键信息
- **热度**：开源不到两个月 GitHub 1 万+ Star
- **形态**：Agent Skill（提供制作知识与导演方法）+ Hypit Runtime（执行图片生成、视频生成、配音、语音转写、本地渲染）
- **五步工作流**：输入素材 → 理解参考视频（分析文案/镜头/字幕/节奏/动效）→ 写成视频工程 → Runtime 调用服务执行 → 保存成片与工程供复用
- **工程复用特性**：字幕、图片、动效可绑定到台词中的词；改台词时相关画面自动重排时间；换人物/产品/语言时只改变化部分
- **执行模式**：托管服务（效果好、需付费，Seedance 等模型成本高）或本地免费工具链（成本低但效果差）；付费生成前列出将使用的服务与预计费用
- **安装**：`npx skills add hypit-ai/hypit -g`，或把项目链接丢给 AI 安装，安装后用 `/hypit` 触发
- **衍生生态**：闲鱼已出现 95 元项目资料、9.9 元远程安装、30/100 元代部署与配置调试服务
- **典型玩法**：保留排行榜形式换盘点主题、替换视频主角、复用播客双人对话版式植入推广、中文视频转多语言版本
