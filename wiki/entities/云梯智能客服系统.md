## 定义

云梯智能客服系统是苏三开发的**多租户 SaaS 智能客服平台**，围绕企业客户服务全生命周期建设，把六类客户入口、实时会话、智能路由、AI 客服、企业知识库、工单与 SLA、客户 360、质检、套餐计费、安全审计和平台运营串成完整链路。

一句话定位：一套覆盖"渠道接入、智能接待、人工协同、工单闭环、客户经营、质量治理、计费控本、平台运营"的企业级 SaaS 智能客服系统。

### 核心亮点

- **多租户隔离四层防线**：网关 JWT 认租户 → 应用层 tenant_code → PostgreSQL RLS → 独立 Schema（详见 [[多租户隔离]]、[[RLS]]）
- **实时消息五层可靠性**：clientMsgNo 幂等、服务端 seq、ACK、持久化发件箱、断线增量补拉（"先落库再推送，断线能补，重发不重复"）
- **受控 AI Agent**：LangGraph 双状态机（客服大脑 + Agentic RAG）、规则/训练向量/大模型混合决策、业务规则掌握最终动作（详见 [[智能客服Agent设计]]）
- **意图训练中心**：1024 维向量 + 留一法评估 + 版本/灰度/回滚（训练的是样本向量索引，不是大模型权重）
- **Agentic RAG**：pgvector 召回 + 阈值判分 + 规则改写 + 二次检索 + 引用范围校验
- **多模态客服**：图片 OCR、截图结构化、语音 ASR/TTS 进入客服与质检链路
- **AI 成本治理**：真实模型调用计量、Token 成本、预算告警、跳过模型和转人工
- **智能路由**：技能组匹配 → 坐席在线 → 长连接在线 → 接待量 < 上限 → 负载最低 → 同类优先最久未切换 → 排队 → 超时跨技能组溢出
- **SLA 闭环**：建单快照截止时间、每 30 秒扫描、预警/升级/解决/回访/满意度，改优先级不偷偷重算已承诺 SLA
- **客户 360**：标签规则引擎（指标+比较符+阈值+统计窗口）、合并重复客户、字段级权限、匿名化
- **[[双速质检]]**：实时规则预警（不调模型）+ 会话结束后 AI 全量质检 + 人工复核
- **计费体系**：套餐/配额/五类用量/账期账单/超量费/收款流水；业务用量 LongAdder 自增 + 每分钟批量上报
- **安全审计**：双因素、失败锁定、API Key 哈希、导出审批、追加式审计（写审计失败不回滚主业务）
- **可观测**：TraceId 全链路贯穿 Java 与 AI 计量，AI 调用可按调用链号反查模型/Token/成本/耗时

### Java 25 ScopedValue 实践

用 `ScopedValue` 替代 `ThreadLocal` 管理登录态与租户上下文：

```java
ScopedValue.Carrier carrier = ScopedValue.where(CURRENT, state);
if (tenant != null && !tenant.isBlank()) {
    carrier = carrier.where(TenantContext.CURRENT, tenant);
}
return carrier.call(action);
```

请求结束后作用域自动失效，不需要 `ThreadLocal.remove()`——比"每个地方手写清理"更能保证线程池复用时**不串用户、不串租户**（详见 [[ScopedValue]]）。
