石人闯，网名"程序员追风"，AgentBro 开源项目作者，微信公众号作者。长期从事 AI 编程工作流与开源工具实战分享，每日自用 AgentBro 管理多 Agent 环境下的 Skill 治理。

**核心观点与实践：**
- "收藏了多少 Skill，和当前应该生效多少 Skill，是两回事" — 强调库存与生效分离
- "一个 Skill 有没有被管住，我现在只看几件事：真实源码在哪里，中心库认的是哪一份，它属于哪些技能包，以及此刻在哪些 Agent 上生效" — Skill 治理的四要素
- 推行"中心库唯一事实源 + 软链接分发 + 技能包开关"的治理范式
- 实战积累：中心库 213 个 Skill，各 Agent 累计 244 份安装；一次扫描发现 86 个可接管 + 19 个同名冲突

**技术栈偏好：**
- macOS 原生开发（菜单栏入口、灵动岛集成）
- SSH 隧道远程管理
- 多 Agent 兼容：Claude Code、Codex、ZCode、Trae、Qoder、豆包等
