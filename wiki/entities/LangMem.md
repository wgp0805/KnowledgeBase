## 定义
LangMem 是 [[LangChain]] 官方推出的长期记忆 SDK，为 AI Agent 提供跨会话记忆能力，本质是"自动收口 + 按需检索"。

## 关键信息
- 出处：LangChain. (2025). LangMem (Version 0.x)，GitHub: github.com/langchain-ai/langmem
- 与 [[Mem0]]、[[Zep]] 同属 Agent Memory / Long-term Memory Layer 框架
- 由 [[LangChain]] 生态提供，可作为该生态内 Agent 的记忆层方案
