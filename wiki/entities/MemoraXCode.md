## 定义
MemoraX Code 是开源的**面向代码智能体的长期记忆系统**（github.com/memorax-ai/memorax-code，官网 code.memorax.net / 记忆平台 platform.memorax.net），给 Coding Agent 加一层跨会话、跨 Agent 的项目记忆——新开对话不用从头交代项目背景，切 Agent 之后沉淀的项目认知依然生效。定位痛点：模型单次任务能力已经很强，但"只要新开一个对话，之前所有项目层面的默契全部归零"；单纯拉大上下文窗口解决不了，因为窗口分不清调试时的废话和决定后续重构的硬约束。

## 关键信息

### 记忆两层架构
- **本地记忆**：盯代码仓库——代码结构、关键入口、Issue 历史、项目演进信息
- **云端记忆**：跨任务、跨对话、跨 Agent 的项目经验、开发偏好、失败方案，支持团队间共享
- **召回策略**：新任务进来不一股脑塞全部历史，而是**按当前任务意图检索**，只喂真正相关的记忆（在 Codex 里做完一段任务，切到 Claude Code 继续干，认知延续）

### 可学习的记忆框架（核心差异化）
市面多数记忆系统走人工写提示词/硬编码规则路线——能用但维护成本高，规则一多互相打架。MemoraX Code 改为：构造专门的代码训练数据集 + 设计记忆评估和奖励信号，**让记忆模型自己学**"什么信息值得留、什么内容已过时、什么时机该召回"；训练体系与用户私有记忆数据隔离，模型能力迭代后再服务线上任务。核心认知：记忆系统的难点从来不是"存不存得下"，而是"**该不该在此时此刻想起这件事**"。

### Procedure Memory（过程记忆）
从历史开发轨迹自动提取有复用价值的分析/执行/验证步骤，提炼成结构化工程经验供同类任务复用——不是记录"上次发生了什么"，而是总结"遇到这类工程问题，哪些路径/步骤/手段是有效的"（详见 [[ProcedureMemory]]）。官方数据：123 个历史任务片段自动提炼 15 条工程经验、归纳 4 类；3 小时复杂长程任务对比——不开记忆综合得分 11.71（关键检查项 2/13），开启后 70.30（10/13），调用成本降约 22.6%（省的是重复摸索已踩坑的 token）。

### 克制性与评测
- 内部测试：85.5% 的记忆触发行为与人的判断一致、81.2% 的记忆内容拿到正向反馈——"该不该想起"已做得较克制
- **AML（Agent Memory Leaderboard）Coding Track 62 分第一**，对比 Claude Mem 解题率提升 10%（详见 [[AgentEval]]）
- 原生支持 [[Codex]]、[[ClaudeCode]]、[[DeepSeekHarness]]、[[OpenCode]] 四款主流 Coding Agent，其他平台适配中
- 记忆可在官方平台查看/编辑/删除——**不可编辑的记忆系统用久了会变黑箱**

### 方法论判断（冰河总结）
现在比拼 Coding Agent 多是单次任务能力；但真实软件工程是同一仓库反复迭代、同类问题反复出现、多 Agent 来回切换——**模型能力决定一次任务能走多远，记忆系统决定下一次任务从哪里开始**。代码本身不会记录团队踩过的坑、被否决的方案、版本兼容的隐性约束，这些隐性工程知识才是长期项目最值钱的东西。
