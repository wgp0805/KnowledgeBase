## 定义

JxBrowser 是一个 Java 库，提供基于 Chromium 内核的 Web 视图组件，用于在 Java 桌面应用中嵌入现代 Web 内容。

## 关键信息

- **核心能力**：在 Swing/JavaFX 应用中嵌入 Chromium 浏览器
- **协议支持**：支持自定义 `jxb://` 协议，从 classpath 加载 Web 资源
- **应用场景**：构建 Web UI 风格的 Java 桌面应用
- **优势**：完整的现代 Web 标准支持，比 Java 内置 WebView 更强大
