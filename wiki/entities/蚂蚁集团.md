## 定义
蚂蚁集团（Ant Group）是一家中国金融科技公司，旗下拥有支付宝等产品，同时也是 Java 开源生态的重要贡献者，开源了 Jeandle（基于 LLVM 的 JVM JIT 编译器）、AntV、Ant Design 等多个顶级项目。

## 关键信息
- **旗下产品**：支付宝（Alipay）
- **开源贡献**：
  - Jeandle：基于 LLVM 的 JVM JIT 编译器
  - AntV：数据可视化解决方案
  - Ant Design：企业级 UI 设计语言
  - Spring Cloud Alibaba：微服务解决方案
  - SOFABoot：金融级 Java 应用框架
  - Seata：分布式事务框架
