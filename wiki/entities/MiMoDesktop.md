## 定义
Xiaomi MiMo Desktop，小米 MiMo 团队 2026-09-08 开放邀测的桌面端 AI Agent 应用，同期放出 MiMo-X-Pro-Preview 与 MiMo-X-Flash-Preview 两款预览版模型。几乎不谈跑分，全部话术压在"交付"上。

## 关键信息

### 混合素材直投与可编辑交付
- 输入：表格、图片、视频、PDF、录音乃至未解压的压缩包，直接扔进去，不用先整理、不用转格式
- 输出：可继续编辑的文档、表格、PPT、网页、图片、音频、视频，甚至 3D 模型、App 与软件工程项目
- 官方 PPT 工作流：混合素材输入 → 事实与数据梳理 → 叙事结构设计 → 图表与版式生成 → 交付可继续修改的 PPT

### 预览是真页面而非截图
成果预览包含组件结构、交互逻辑、状态变化和数据可视化，直接在会话里展示。官方 demo：单 HTML 的 3D 场景（城堡/摩天轮/旋转木马/极光，城堡可灯光秀）、three.js 的 SnowRunner 风格足球游戏、意大利主题 PPT、徽派建筑深度调研报告。做原型、数据网页、Office 文件与交互 Demo 时可直接预览、提问、继续迭代，不必先搭本地前端环境。

### 局部编辑
选中会话或产物里的任意元素、文本段落、图表、表格区域，用自然语言描述要改什么，选区限定作用范围，只处理要改的那部分，不用重做整份成果、不用重复交代背景。每次修改留版本记录，可横向比方案、随时回退。作者称这是"玩票"与"真能用"的分水岭——生成一次惊艳不难，难的是第九次微调还愿意用它。

### Smart 调度（三层）
1. **任务评估**：识别办公/编程/研究/设计/混合场景，判断推理深度、工具范围、交付标准
2. **模型路由**：日常任务走标准模型（快、便宜），复杂推理、长链路执行、高质量交付走旗舰模型
3. **Harness / Agent / Skill 路由**：按任务类型选办公、代码或研究 Harness/Agent；大任务拆给多个 Agent 分别负责调研、规划、执行、复核，过程中自动调用不同 Skill

此外支持多会话协同：按需组成多角色会话团队，会话间自动通信协作，每个会话有独立的记忆、工作区和任务状态。

### 浏览器既是入口也是执行环境
可自主控制电脑浏览器：打开网页、检索信息、填写表单、提取素材，取到的信息直接进当前任务。生成网页类成果时可在同一条工作流里用浏览器检查关键交互、自动验证成果——相当于给交付物加一轮自动化验收。英文官网另列"电脑操控"能力（读屏、跨应用操作键鼠、Record & Replay 一键复用工作流），标注为海外版专属。

### 三条降本路径与缓存数据
模型路由（不拿旗舰模型干杂活）、局部编辑（改一页不重做整份）、上下文缓存（重复上下文不重复算）。官方实测同会话缓存命中率最高 99%，跨会话最高 95%。

### 定位与风险
- MCP 已被写进官方工作流（自然语言输入 → 理解任务 → 规划工作流 → 调用 MCP 控制 [[Figma]] → 实时生成设计元素 → 交付成果），说明 MCP 正在成为桌面 Agent 接第三方工具的通用插头
- 作者判断：桌面 Agent 评分标准变了，从比谁答得漂亮变为比谁能交出可编辑、可局部修改、可回退的成果
- 邀测本质是"用真实任务换反馈"——限时限量免费，优先开放给 MiMo 开放平台老用户
- 未公布的关键项：定价、Mac/Windows 支持范围、长任务失败率与稳定性。MiMo-X 仍处预览阶段，现阶段不宜压进核心生产流程
- 申请入口：国内 https://mimo.xiaomimimo.com/desktop/invite/ ；海外 https://mimo-ai.xiaomimimo.com/desktop/invite/
