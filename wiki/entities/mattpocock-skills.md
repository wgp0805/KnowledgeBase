## 定义
mattpocock/skills 是 JavaScript/TypeScript 圈著名前端工程师 Matt Pocock 创建的 Agent Skills 仓库，单月增星 50,486。本质是把十几年生产环境踩过的坑，打包成 Claude/Gemini/Codex 通用的「代码自检技能包」。

## 关键信息
- **Star 数据**：单月增星 50,486（2026 年 8 月）
- **作者**：Matt Pocock，JavaScript/TypeScript 圈熟脸，著名前端工程师
- **本质**：十几年生产环境踩坑打包成通用代码自检技能包
- **使用方式**：用 JavaScript 给 Claude Code 装一个；切 Python 装另一个；做 React 装第三个
- **设计哲学**：把 skill 当纪律，不当框架（参见 [[mattpocock-skills]] 概念页）
- **经济学意义**：模型能力是租的（按 token 付费），技能是自己的（一次编写处处复用）
- **定位**：不是 model 在变强，是工具箱在变厚
