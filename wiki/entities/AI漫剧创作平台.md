## 定义
AI 漫剧创作平台是程序汪私活小团队 30 天交付的 SaaS 产品，定位"**编剧的 AI 制片助手**"：用户输入一个故事主题，系统通过**九阶段流水线**自动生成从意图、大纲、小说、剧本、资产、分镜到视频的完整漫剧内容，并配套无限画布节点编排、资产库、多模型统一网关、代理分销与充值计费商业闭环。技术栈为 Python FastAPI（模块化单体）+ Vue 3/Vite/TS + PostgreSQL + Redis + Celery。

## 关键信息
- **开发**：5 万整体费用 / 2 人 / 30 天 / 云服务器 2 台 / 维护费 5000/年；月成本约 ¥1000（不含模型 API 费）
- **AI 工具**：Codex 出方案、TRAE（deepseek/kimi 等）写代码；7 个开发 Skill 驱动（后端架构/数据库建模/任务队列/第三方模型接入/API 测试/安全权限/前端设计）
- **九阶段生成流水线**：0 输入→1 意图→2 方向→3 大纲→4 小说→5 剧本→6 资产→7 分镜→8 视频；每阶段独立可编辑、可重生成、草稿自动保存；文本模型（通义/DeepSeek）、生图（即梦/通义万相）、生视频（可灵）统一网关按类别路由、失败自动重试、统一计量 token 成本
- **无限画布**：基于 Vue Flow，四类节点（角色/场景/道具/剧情）、拖拽/Shift 多选/框选/连线/缩放/平移/删除、JSON 存库保存恢复
- **原子扣费 + 异步任务**：生成任务先原子扣减余额（数据库行锁防超扣），再丢 Celery 队列异步执行，失败自动退款；前端轮询任务状态
- **代理分销**：用户申请代理→管理员审核→专属邀请码→邀请新用户消费按比例分润，自增长分销网络
- **JSONB 混合存储**：projects.contents 存九阶段草稿（key 为阶段序号）、canvases.body 存节点连线 {nodes,edges}，不改表结构还能建索引；单机 2C4G 跑通 MVP
- **安全合规**：全站 HTTPS、JWT 2 小时+刷新、Redis 令牌桶限流 60 次/分、手机号加密、余额原子扣减、支付验签+order_no 幂等+日终对账+失败自动退款、API 密钥只存后端；域名 ICP 备案、AI 生成内容标注、广电总局短剧审核要求、代理分润需法务审核
