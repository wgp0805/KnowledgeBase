## 定义
阿里云的通义大模型 API 平台（DashScope API），为 Spring AI Alibaba 和 AgentScope-Java 等框架提供底层模型调用能力。

## 关键信息
- 提供通义系列模型的 API 调用接口
- Spring AI Alibaba 通过 DashScopeApi 构建 ChatModel
- 支持文本生成、图像生成、语音合成等多种模型能力
- 需申请阿里云百炼 API Key 使用
