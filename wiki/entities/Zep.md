## 定义
Zep 是一个基于时间知识图谱（Temporal Knowledge Graph）架构的 Agent 记忆系统，为 AI Agent 提供跨会话的长期记忆能力。

## 关键信息
- 出处：Rasmussen et al. 2025《Zep: A temporal knowledge graph architecture for agent memory》(arXiv:2501.13956)
- 与 [[Mem0]]、[[LangMem]] 同属 Agent Memory / Long-term Memory Layer 框架
- 核心思路：用时间知识图谱组织记忆，本质也是"自动收口 + 按需检索"
