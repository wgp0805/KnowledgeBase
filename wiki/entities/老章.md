## 定义
老章（公众号：Ai 学习的老章）是 AI 编程方向自媒体作者，擅长 Harness 横评与模型实测。代表作《DeepSeek-V4.1-Flash 的最佳 Harness 搭档，我觉得可能是 Claude Code》横评 [[DeepSeek-V4.1-Flash]] 在四种 Harness 下的表现。

## 关键信息
- **公众号**：Ai 学习的老章
- **测评风格**：用同一任务横评多个 Harness，关注 Token 消耗、缓存命中、TPS、耗时等量化指标
- **核心贡献**：用 [[SimonWillison|Simon Willison]] 的 Space Invaders 原题横评 Pi Agent / Claude Code / DSH 标准 / DSH 极简四种 Harness
- **核心结论**：
  - 综合排名：① Claude Code 9.2 分 ② Pi Agent 8.9 分 ③ DSH 标准 8.7 分 ④ DSH 极简 7.2 分
  - Claude Code 仅用 Pi Agent 约 1/3 的 Token 和 1/4 的耗时拿到全场最优效果，是生产级工业落地 ROI 最高标杆
  - DSH 极简省 84.5% Token 但缺乏全局视野，40 分钟全场最慢且最终失败
- **关键启示**：如果你觉得某个模型不太好，或许可以换一个 Harness
