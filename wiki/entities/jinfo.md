## 定义
jinfo 是 JDK 自带的 Java 诊断工具，用于查看和修改 JVM 参数，支持线上动态调整参数。

## 关键信息
- **定位**：查看/修改 JVM 参数
- **典型场景**：线上动态调整参数
- **属于**：JDK 自带 Java 诊断工具集
