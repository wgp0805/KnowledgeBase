## 定义

微信公众号「我是程序汪」作者，背后运营私活小团队，持续分享真实私活项目和商业案例，涵盖软硬件对接、项目估价、技术方案设计等内容。

## 关键信息

- **内容定位**：真实私活项目复盘，展示软件硬件对接、商业项目估价、技术方案全貌
- **团队模式**：私活小团队接单开发，1 人开发为主，复用已有项目代码
- **技术栈**：Java 后端（SpringBoot + MyBatisPlus + MySQL + Redis）、Vue + UniApp 前端、IoT 硬件对接
- **AI 工具应用**：用 Codex 整理需求、Figma 生成 UI 原型、Codex 开发业务代码，AI 辅助生成 80% 需求文档和设计稿；也分享 Agent Skill 项目实测（如 [[QianWen-AI]] 多模态技能包）
- **代表项目**：无人图书柜（6 万/30 天/RFID+MQTT）、街机H5肉鸽小游戏（4 万/20 天/Cocos Creator）、快递柜系统（功能复用基础）
- **项目估价参考**：研发费按人月估算（2 人 20 天 4 万），维护费按年收取（如 4000-6000/年），走正规合同
- **GitHub 开源项目盘点（2026-10-16，详见 [[摘要-github三个开源项目-text-to-cad]]）**：text-to-cad（给 Agent 加 CAD 建模能力的插件+Skill）、pdoom-video（音乐 MV 制作全开源，Claude Code 对话协作完成）、Jev 聊天助手（安卓聊天回复建议悬浮卡片）
- **技术科普**：Tomcat 11 新特性全景（2026-10-25，详见 [[摘要-tomcat-11-new-features]]）——虚拟线程、Servlet 6.1、EL 6.0、FFM OpenSSL，JDK 25 + Tomcat 11.0.27 实测
