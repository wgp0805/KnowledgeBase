## 定义
Felix Rieseberg 是 Anthropic 工程主管，负责 Claude AI、Cowork、Claude Code Desktop 等核心产品工程；此前是 [[Electron]] 的长期核心维护者，任职过 Notion、Stripe、Slack、微软。2026-10 因一篇呼吁"使用模型必须更有野心（Be More Ambitious）"的万字长文在技术社区刷屏。

## 关键信息
- **核心论点**：多数人只拿顶级模型改邮件、查资料，等于"开着歼-20 送外卖"；"速度"（同样的事更快）人尽皆知拉不开代差，真正的野心在**高度、深度、广度**三个维度
- **高度代表作**：把"修一个又一个崩溃"升级为给 Claude 崩溃报告权限 + 版本映射 Git commit + 三套系统测试环境，实现"客户端持续零崩溃"的全自动工作流；QBR 三步升维（填模板→喂数据问决策→重构季度回顾机制本身）
- **深度主张**：不要让模型只"扮演专家"（只会换黑话），要逼它使用行业顶尖专家的真实工具、原始素材与框架，并**必须引入能跑代码/单元测试/基准的外部裁判，绝不让模型自己评判自己**
- **广度技巧**：名词换动词（IDEO《创新艺术》）、组建跨界特遣队与红队审查；反对劣质角色扮演——要调用的是方法和审计步骤，不是"你是做空机构经理"的帽子
- **配套心理学**：用"自我效能感"（丹齐格解未解难题、班尼斯特破 4 分钟一英里后 46 天被追平、林纳斯卸下包袱写 Linux）解释为什么人们不敢放手想象
- **承认的代价**：抽象层级拉高使人类审查成本指数级上升、长程任务错误滚雪球——野心必须配自动化测试与外部校验沙盒
- **轶事**：levelsio 爆料他常在骑自行车时用手机语音给 Claude 下宏观指令，搭出 3D 个人主页
