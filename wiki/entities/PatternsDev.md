## 定义
Patterns.dev 团队维护了目前最大的前端 Skills 合集，包含 58 个覆盖 JavaScript、React、Vue 三大技术栈的设计模式 Skills，全部开源在 GitHub。

## 关键信息

### 规模与覆盖
- **58 个专业 Skills**，全部可独立安装
- 支持平台：Claude Code、Cursor、Codex、Gemini CLI、Antigravity、OpenCode

### React Skills（18 个）
- **模式类**：hooks-pattern、hoc-pattern、compound-pattern、render-props-pattern、presentational-container-pattern、ai-ui-patterns
- **现代化**：react-2026（Vitest、Vite SSR、React Compiler）、react-composition-2026（React 19 Slots、动态组合）
- **渲染类**：client-side-rendering、server-side-rendering、static-rendering、incremental-static-rendering（ISR）、streaming-ssr、progressive-hydration、react-server-components、react-selective-hydration
- **性能类**：react-render-optimization、react-data-fetching（TanStack Query、Suspense、React.cache）

### Vue Skills（3 个）
- vue-composition-api、vue-performance、vue-ssr

### JavaScript Skills（29 个）
- 涵盖 js-performance-patterns、vite-bundle-optimization、design-patterns、islands-architecture、view-transitions 等

### 安装方式
```bash
npx skills add PatternsDev/skills --skill <skill-name>
```

### 仓库地址
- GitHub: https://github.com/PatternsDev/skills
