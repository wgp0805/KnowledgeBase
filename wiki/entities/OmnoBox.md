## 定义
OmnoBox 是一款开源的爬虫管理工具，支持通过 Docker 快速部署，提供 Web 管理界面，可从 GitHub 导入爬虫链接并管理多个数据源。

## 关键信息
- **部署方式**：Docker 一键部署
- **默认端口**：7023
- **管理界面**：localhost:7023/admin
- **数据源**：支持从 GitHub 导入爬虫链接
- **GitHub 仓库**：https://github.com/Silent1566/OmniBox-Spider
