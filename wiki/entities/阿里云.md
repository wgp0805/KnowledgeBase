## 定义
阿里巴巴的云计算业务，提供通义千问、ModelScope、DashScope API 与算力，是国产大模型的主要云底座。

## 关键信息
- **2026 年 AI Agent 开发者调研报告**（2026-09 发布，数据源自 GitHub 仓库 aliyun/ai-agent-handbook 根目录 `2026-agent-survey-report.md`，配套《AI Agent Handbook 精读》系列）：
  - 北京、深圳、广州、上海、杭州多场线下开发者沙龙，**有效问卷 1906 份**，受访者以企业技术决策者、架构师、一线工程师与产品经理为主
  - 核心结论：开发率 46%（去年 36%）但**上线率仅 18%**、持续迭代不到 10%；卡点不在意愿也不在模型，而在**能优化 Harness 层、开箱即用的工程配套**（详见 [[企业Agent落地]]）
  - 架构：单 Agent 40% / 多 Agent 42% / Human-in-the-Loop 作主要架构原则 15%，混合形态长期存在
  - 痛点：多 Agent 状态与上下文衰减 60%；上下文检索不准 54%、记忆更新遗忘机制缺失 48%（窗口限制仅第三）
  - 评估：人工抽查 55.5% 居首、轨迹自动评估仅 6.7%，16% 从未量化成功率（详见 [[AgentEval]]）
