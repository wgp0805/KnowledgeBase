## 定义
Manus 是定位 General Agent（通用 Agent）的 AI 产品，2025 年 3 月上线即以"一个聊天框搞定查资料、整理文件、写代码、做网页、操作浏览器"出圈。经历与 Meta 的收购/独立波折后，2026 年 9 月 1 日恢复独立运营，27 天后（9 月 28 日）发布 2.0，把"通用"从定位做成体验，并推出个人 Agent 应用 Cue 与 Meta Muse 正面竞争。

## 关键信息
- **2.0 本体**：底层换成自研 Agent 框架 Cascade，官方单测数据 Token 消耗减少 23.2%、任务耗时缩短 28.2%、运行成本降低 32%（发布会将"成本降低 32%"放在最显眼位置）
- **Manus Studio**：桌面端定位"人和 AI 共享的工作空间"，新增视频编辑（Alchemy mode 结合视频生成与代码生成组织画面）与游戏开发专属环境，网站/应用/文档/幻灯片与分散数月陆续上线的 Skills、Project Skills、Connector、Scheduled Tasks 全部整合进同一工作区；此前能力越拆越细，2.0 是"收纳袋式"重新整合
- **云电脑**：Cloud Computer（4 月发布）为项目提供持续运行环境，多人游戏等长任务天然需要；Computer Use 进一步接入本机文件、浏览器和应用，手机可远程发指令
- **Cue**（独立个人 Agent App，邀请制）：给每个 Agent 配独立邮箱、电话号码、钱包和电脑，可在用户设定预算内付款、接电话留摘要；多个 Agent 可拉进同一群聊分工（一个查场地、一个筛选、一个写方案成 Deck）
- **调度哲学**：通用更像一套调度方式——用户不必自己决定下一步打开哪个 AI 产品；新 Agent Harness 平时轻量、按需引入专业模块，由 Cascade 服务调度。垂直产品比拼单点深度，Manus 要拿的是入口和调度能力；风险是链条越长、任一环节偏差越影响最终结果
- **定位演进**：早期"能力覆盖面广的执行助手"→ 2.0 证明"任务之间的价值"，不追求每个单项都赢
- **国内动向**：面向国内市场的产品在筹备、团队正在组建，与国产模型厂商合作推进；没有自家"围城"的独立玩家反而敢做真正的"连接者"
