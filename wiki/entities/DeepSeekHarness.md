## 定义
DeepSeek Harness 是 DeepSeek 自研的 Agent 评测框架，为模型提供终端操作、代码编辑、工具调用和任务验证环境。2026-07-31 随 V4-Flash 正式版发布首次亮相（官方标注为「极简模式」，max 档位，topp=0.95，temperature=1.0）。

## 关键信息
- **作用**：V4-Flash 正式版公开基准测试中的 Code Agent 任务均使用该框架测试
- **团队背景**：DeepSeek Agent Harness 团队成立于 2026 年 3 月；负责人崔添翼（90 后浙大计算机出身，6 枚 ACM 亚洲区域赛金牌，曾任 Jane Street 量化机构九年，2026 年 3 月加入 DeepSeek）
- **意义**：自研 Agent 评测框架暗示 DeepSeek 在 Agent 能力上还有后手；相关基准成绩为官方自测，截至 7 月 31 日尚无第三方独立复现
