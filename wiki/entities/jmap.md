## 定义
jmap 是 JDK 自带的 Java 诊断工具，用于打印内存快照，是 OOM 分析、内存泄漏排查的核心工具。

## 关键信息
- **定位**：打印内存快照
- **典型场景**：OOM 分析、内存泄漏
- **配合**：jhat 分析 heap dump
- **属于**：JDK 自带 Java 诊断工具集
