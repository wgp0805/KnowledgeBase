## 定义
Hasor 是一个 Java 框架生态，旗下包含 Dataway（接口配置工具）和 DataQL（查询语言）等子项目，通过 Hasor-Spring Bridge 与 Spring Boot 打通整合。

## 关键信息
- **生态组成**：Dataway（接口配置工具）、DataQL（查询语言）等
- **集成方式**：提供 Hasor-Spring Bridge 与 Spring Boot 生态打通
- **定位**：Java 框架生态，提供从数据查询到接口发布的完整链路
