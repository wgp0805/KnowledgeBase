## 定义
中国大模型公司，开发了Kimi系列大语言模型，是首批入驻淘宝AI空间站的厂商之一。

## 关键信息
- **产品定位**：面向大众用户的大语言模型
- **入驻平台**：淘宝AI空间站
- **服务类型**：提供Token套餐订阅服务
- **竞争表现**：在游戏生成等任务中与Fable 5.1竞争，成本更低

### Kimi Code 桌面客户端（2026-09-17）
Kimi 正式推出 [[KimiCode]] 桌面客户端（macOS/Windows），把终端编程 Agent 搬到图形界面，支持接入第三方模型。产品路线在做加法（独立 Code 客户端），与 [[Claude]]、[[ChatGPT]] 的合并减法路线形成对比。详见 [[摘要-kimi向左claude-gpt向右]] 与 [[摘要-kimi-code桌面版体验]]。

### 金融行业 AI 解决方案（2026-09-17）
Kimi 推出金融行业 AI 解决方案，是 [[Qovest]]（阿里金融投研 Agent）的竞品之一。详见 [[摘要-阿里qovest金融投研agent]]。
