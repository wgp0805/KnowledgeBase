## 定义
Apifox 是国产一体化 API 协作与调试平台，集 API 文档、调试、Mock、自动化测试于一体，定位类似 Postman + Swagger + JMeter 的组合。

## 关键信息
- 在 [[摘要-springboot-minio文件存储]] 中被用作验证 Spring Boot + MinIO 三个文件接口（图片上传/下载/删除）的测试工具
