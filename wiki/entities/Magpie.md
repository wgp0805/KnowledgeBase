## 定义

magpie 是一个本地运行的开源 AI 网关工具（GitHub 20K Star），把多家供应商的账号/Key/模型集中到本机网关统一调度，被程序汪作为 CC Switch 的替代品使用。

## 关键信息

- **本机网关**：装完后多一个网关地址 `127.0.0.1:3425`，在 OpenAI Chat Completions/Responses、Anthropic Messages、Google Gemini 三类 API 格式之间互转；供应商接入支持内置预设/自定义，需要额外登录或请求逻辑的供应商可用插件（npm 包/git 仓库/本地文件夹）实现浏览器授权、设备码登录、定期刷新 token 等场景
- **模型列表聚合**：各家供应商的模型摆在一个列表里直接在 Claude Code 里选；给 opus/sonnet/haiku/fable 四档各留下拉框，可四档指同一模型，也可 opus 挑贵的、haiku 挑快的，还能单独给子 Agent 指模型
- **自动路由组**：开"自动创建路由组"后多家供应商的同名模型自动成组（文档格式 `auto/<模型ID>`，旧 `group/auto-…` 兼容）；也有"难题给强模型/便宜优先/永不卡住"三个一键模板和命令行建组
- **额度与账号调度**：默认智能策略在还有额度的账号里挑重置时间最早者（快到期的额度不用就浪费；仅 5 小时窗的 Claude 企业版按 5 小时算排在周窗更晚重置者前面；已用 90%+ 的账号靠后）+ 按顺序/轮流/最少使用/重置前用完四策略；被限流选保持原位或排到最后；欠费歇半小时、厂商限流按 Retry-After 跳过、报错账号指数退避。与 CC Switch failover（每工具一条供应商队列、不可用才跳下家）相比，magpie 会**在请求开始前**根据额度和重置时间安排这轮先交给谁
- **会话保持**：自动/整个会话/一轮之内/关闭四档，见 [[会话保持]]
- **按请求分流**：路由组规则可看 token 长度、有没有带图、要不要 reasoning、来自哪个 Agent、是否在压缩上下文、意图、时段/星期/文件夹（可排除）。不能识图的模型可让识图模型代描述图片；不能联网的可指定搜索 API 或模型代搜；检测到死循环（思考/正文反复绕同样几句）就把这条回复结束并交回可重试错误
- **意图路由**：见 [[意图路由]]（magpie 实现：判断模型看最新用户消息+截断的上一轮，8 秒默认等待，失败沿用上轮意图，可用本地模型）
- **可观测**：用量页按模型/账号统计 token、缓存命中率与折算费用（含尝试/应答/失败/已用额度/重置时间）；路由页顶部一条实时请求流水——由谁应答、为何选它、每次尝试；网关页可看最近调用原始消息的结构化展示
- **参数细调**：供应商详情参数可按模型覆盖（上下文窗口/单次最大输出/压缩阈值，可写 `deepseek-v4-flash=272k` 分模型指定）；留空按厂商和 models.dev 数据补全；每账号可单独配网络连接方式与并发上限
- **写入安全与可还原**：写 Agent 配置前先读原文件，只更新接入所需字段，注释/键序/缩进保留，原子落盘；Claude Code 只改 `~/.claude/settings.json` 的 env 段（`ANTHROPIC_BASE_URL` 指向 `127.0.0.1:3425`、`ANTHROPIC_AUTH_TOKEN=magpie`+四档模型变量），Codex 在 `~/.codex/config.toml` 加 `[model_providers.magpie]` 表（不碰 ChatGPT 登录状态）；`applied.json` 记录最近应用了哪些字段，`stash.json` 保留接入前原值，界面"断开并还原"或 `magpie <agent> default` 撤销。例外：为 Claude Desktop 接第三方供应商会新建 `Claude-3p` 配置目录
- **细节**：托盘单图标订阅剩余额度悬停可看；支持重置卡的订阅可开自动使用重置卡；按首次请求启动 5 小时窗的订阅有"窗口重置时预热"与"每日定时预热"两项提前计时；隐私页有脱敏掩码设置；CLI 版 `magpie tui` 给不开桌面窗口的人
