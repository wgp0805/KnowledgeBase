## 定义
Qoder Sites 是 Qoder 的发布能力，把本地原型变成可管理、可继续发布的在线站点，支持同链接重新发布和反馈数据持久化。

## 关键信息
1. **核心功能**：
   - 构建-发布-生成可访问链接
   - 同链接重新发布：版本变化由发布流程承接，不需要重新导出
   - 反馈数据持久化：表单提交逻辑有效，浏览器刷新不会丢数据
2. **技术栈**：Vite + React + Tailwind
3. **使用流程**：
   - 上传线框图 → 输入需求 → 自动构建 → 本地预览 → 发布到Sites → 生成固定域名
   - 修改需求 → 重新发布 → 同链接更新
4. **应用场景**：
   - 原型设计：从线框图到可点击原型
   - 可用性测试：收集用户反馈
   - 研究报告：生成精美排版的可访问链接
5. **限制**：后端、数据库和 Cloud Agent 受账户套餐与配额约束
