## 定义

Tailwind CSS 是一个实用优先（Utility-First）的 CSS 框架，提供大量原子化 CSS 类名，直接在 HTML 中组合类名完成样式编写，无需编写自定义 CSS。

## 关键信息

- **核心理念**：Utility-First，每个类名只做一件事（如 `flex`、`text-center`、`bg-blue-500`）
- **工作原理**：构建时扫描源码，只生成实际使用的 CSS，体积极小
- **配置系统**：`tailwind.config.js` 定义主题、插件、自定义类
- **生态**：shadcn/ui、Flowbite、DaisyUI 等基于 Tailwind 构建
- **与传统 CSS 对比**：无需命名类名、无需切换文件、样式即代码
