## 定义
Cue 是 [[Manus]] 推出的 Personal Agent 产品：给每个 Agent 配置**真实世界里的执行身份**——电话、邮箱、钱包和电脑。Cue 不只做研究和整理，还能持续对外联系、接收回复、在预算内付款，把任务推进到原本必须用户亲自接手的动作（联系商家、确认需求、下单付款）。

## 关键信息
- **能力组合**：电话可接听并留摘要；邮箱可持续询价与确认；钱包可在用户预算内付款；电脑执行常规任务
- **风险位阶最高**：因为 Agent 变成"对外代表用户"的主体，需要远比聊天更严格的资金授权模型
- **四层控制设计（易安说AI）**：
  - **金额分级**：低于小额阈值自动执行，超过必须确认
  - **收件人校验**：首次联系、外部域名、敏感地址必须显示预览等待批准
  - **支付白名单**：只允许向已验证商家、已绑定服务、限定类别付款
  - **行动回执**：电话/邮件/订单/支付全程可审计日志、撤销窗口与异常告警
- **"预算内付款"不是文案**：预算必须配合支付范围、次数上限、收款方约束、不可逆操作二次确认才真正控制风险
- **赛道对标**：与 [[MetaMuse]]（生活与交易管家）、[[GrokBot]]（多 Bot 分工）、[[Dots]]（跨时间持续任务）构成四种权限切入
- **实测遗留判断（卡尔的AI沃茨，2026-10-16）**：Cue 无本地 Computer Use 能力，无法抓取需要本机登录态的国内平台数据
