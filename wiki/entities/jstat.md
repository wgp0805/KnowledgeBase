## 定义
jstat 是 JDK 自带的 Java 诊断工具，用于查看 GC 情况，监控 GC 频率。

## 关键信息
- **定位**：查看 GC 情况
- **典型场景**：监控 GC 频率
- **属于**：JDK 自带 Java 诊断工具集
