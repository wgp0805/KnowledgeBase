## 定义
Kimi Code 是月之暗面（Kimi）推出的桌面编程 Agent 客户端（macOS/Windows），把终端编程 Agent 搬到图形界面，可打开本地项目、修改代码、执行命令、查看文件改动、调用浏览器、通过不同权限模式控制 AI 操作，支持接入第三方模型。9 月 17 日正式推出桌面客户端。

## 关键信息
- **与 Kimi Work 区别**：Work 面向办公和知识工作，Code 围绕软件开发设计（理解代码仓库、修改多文件、运行命令、展示代码差异）
- **权限模式**：可设「完全自动」，Kimi 自己规划任务、执行代码、启动预览服务、截图自检
- **可选模型**：K3 High（主力，质量高速度慢）、K2.7 Code Highspeed（高速版，快但粗糙）
- **第三方模型**：支持自定义供应商（内置主流供应商 API 地址，导入 DeepSeek 等）
- **实测**：赛博朋克像素街区（Vite + Three.js，Canvas 2D 分层合成，程序化生成贴图，约 40 多分钟交付）；鹈鹕骑自行车动画（K3 质量明显更好，单一时钟源+两段式逆运动学保证动作同步）
- **产品路线**：Claude、ChatGPT 在做减法（合并客户端），Kimi 还在做加法（独立 Code 客户端），作者判断 Kimi 未来可能整合但未必简单合并

### K3.1 Pro 上线与游戏开发实测（2026-10-24）
2026-10 实测时模型下拉已上线 [[K3.1Pro]]，支持思考强度三档 Low/High/Max（实测用 High，见 [[思考强度]]），主力模型由 K3 High 换代为 K3.1 Pro。实测展现的工作方式（详见 [[Agent交付前自测]]）：先思考规划（跳一跳案例思考 16 秒）再写文件；写完不直接交卷，用本地预览实际运行验证（跳一跳真跑几局检查连击/掉落结算/重开，植物大战僵尸点击 3 次+截图 3 次确认种植/冷却/僵尸生成/阳光掉落）；遇环境故障自愈（预览端口被占用自动换端口继续）；有自我审美修正（嫌光照偏亮，主动压低曝光、减轻地面阴影后复验）；交付后主动适配移动端。两个游戏案例（3D 跳一跳、植物大战僵尸）各约 10 分钟、一次成型零返工，比 GPT-6 Astra 慢 3~5 倍但交付经过更仔细的验证。详见 [[摘要-kimi-k31-pro-首测]]。
