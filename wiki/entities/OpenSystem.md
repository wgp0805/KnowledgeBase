## 定义
OpenSystem（open-system）是 [[冰河]] 主导手写的企业级微服务开放平台，作为统一服务接入层为多个业务系统提供标准化 RESTful API，解决点对点集成爆炸、安全鉴权缺失、幂等性与日志分散问题。

## 关键信息
- 技术栈：Spring Boot 2.3.3 + Apache Dubbo 2.7.18 + Nacos 1.x + MyBatis Plus 3.0.1 + MySQL 5.7+ + Druid 连接池
- 架构：四层架构模型，Maven 多模块分离（server / interface / resource / client），模块间通过 Dubbo RPC 调用
- 幂等性：基于 `transId`（事务ID）+ `serviceCode`（服务编码）的历史记录机制，相同请求多次提交直接返回历史结果
- 调用模式：同步（实时结果返回）与异步（HTTP 回调推送）两种
- 安全：RSA + AES 混合加密，系统标识白名单验证，防非法调用
- 设计模式：策略模式（服务编码路由）、工厂模式（根据编码选服务）、回调模式（异步结果推送）
- 适用场景：企业级 API 网关参考实现、微服务系统集成平台、多系统对接统一服务层、需要幂等性的支付/订单/数据同步接口
