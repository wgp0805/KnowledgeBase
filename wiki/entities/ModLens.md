## 定义
ModLens（模型透镜）是 [[DeepSeekHarness]] 推荐必装插件之首，提供 Token 用量、工具调用次数、上下文占用的可视化展示。在 Agent 时代，Token 可视化是新的性能分析维度，帮助开发者理解上下文布局策略、优化提示词、诊断 Agent 行为。

## 关键信息
- **功能**：可视化展示 Token 用量、工具调用次数、上下文占用
- **价值**：Token 可视化是 Agent 时代的新性能分析维度
- **用途**：优化提示词、理解上下文布局策略、诊断 Agent 行为
- **归属**：[[DeepSeekHarness]] 插件生态
