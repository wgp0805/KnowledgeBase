## 定义
Instinct 是 Noah Shinn 于约 2025 年创立的个人 Agent 公司，产品形态激进地"没有界面"：不开发独立 App，而是给 Agent 配专属电话号码、邮箱和云端电脑，用户像联系真人助理一样发短信、打电话或转发邮件，让它订机票酒店、取消订阅、协调会议、完成购买，甚至围绕持续数月的长期目标主动推进任务。

## 关键信息
- **增长与资本**：2026-09-28 完成 10 亿美元 C 轮融资（红杉、Benchmark、Coatue 领投），估值 100 亿美元，一个月前上一轮估值仅 25 亿；成立仅约一年，仍需邀请码，有用户在 eBay 把邀请码炒到 300 美元
- **产品数据**：用户日增 10%-11%（超过 Claude Code、Codex 等此前最快产品），零公关预算纯口碑；年化 GMV 超 10 亿美元，约一半来自旅游出行交易
- **无界面路线**：绑定手机侧边 Action Button 语音唤起、AirPods 耳边轻交互；复杂信息临时生成网页或 Mini App；超过 50% 核心流量不在 iMessage 上
- **自研推理管线（免费模式的底气）**：混合推理 + 模型分发 + 后台任务批处理（异步离线跑，不需 200ms 同步返回），批处理与调度优化使单点吞吐提升 3-8 倍，再配合端到端蒸馏剪枝各环节抠 30%-50% 冗余，综合效能逼近 Opus 5 级而成本远低于直接调用前沿 API
- **商业模式**：对标 Apple Pay / 美国运通，从交易网络向 B 端商户收 Take rate，C 端保持免费无广告；拒绝广告竞价推荐（防止 Agent 变成"受广告主驱动的说服机器"）；参照系：Shopify 变现率 2.5%-3%、Amazon 抽成 10%+、App Store 30%，精品酒店佣金可达 20%-30%
- **信任与留存**：普通用户需 2-3 周才开放银行卡/邮箱/日历等核心权限，约 40% 用户三周内绑定主信用卡；一旦绑定至少一项敏感资产并体验到价值，长效留存率约 80%
- **安全架构**：外部输入（邮件/网页）过独立"安全防火墙"阻断 Prompt 注入，所有行动意图经独立于主决策链路的"守门人系统"毫秒级审计（一票否决权），配 24 小时红蓝对抗战队
- **算力判断**：主动式 Agent 90% 以上 Token 消耗发生在用户看不见的后台，整体算力需求比被动式 AI 高两到三个数量级；算力集群交付周期长达数月，供需误判会造成 3-4 倍惩罚，创始人 40% 精力在防算力风险
- **Agent 可信网络**：两个用户的 Agent 可直接拉通协调日程、联合策划活动（六人朋友圈每周自动协同策划周末聚会），按夫妻/朋友/同事关系设置细粒度可撤销的访问权限
- **与 Muse 的路线分歧**：Muse 是功能丰富的 AI 原生独立 App，Instinct 追求 App 本身消失；Noah 认为个人 Agent 市场仍在非常早期，无需焦虑竞争
- **五维度框架下的定位（2026-10-01）**：官网第一句即"没有新的界面"——连接邮件、消息、屏幕、音频与位置，经训练会用手机和电脑，用户直接给它发消息或打电话；把 Agent 从"需要主动打开的目的地"变成日常沟通关系中的一个联系人，入口一旦消失就不再和其他 App 争夺打开频次；产品魅力与风险同源——屏幕/音频/位置是最敏感权限，主动来电可能变成高成本打扰，误操作撤回需要比"聊天记录可删除"更细的机制；截至该文截稿官网未清晰列出完整地区、订阅层级与开放状态（详见 [[摘要-personal-agent六条海外路线]]）
- **命名歧义（2026-10-08 标注）**：ZooWork 的客服**决策模型**也叫 Instinct（[[Instinct决策模型]]），与本页的个人 Agent 公司同名不同物，引用时须区分
