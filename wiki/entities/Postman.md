## 定义
Postman 是流行的 API 调试与测试工具，支持构造 HTTP 请求、抓包重放、批量脚本化调用。在秒杀防刷语境中，它是散户黄牛脚本最常用的工具——抓包后写 for 循环重放请求。

## 关键信息
- 类型：API 调试 / HTTP 客户端
- 在防刷语境中的角色：散户黄牛的典型工具
- 散户脚本特征：拿 Postman 抓个包、写个 for 循环重放，**不看前端**，直接照着抓到的请求怼
- [[前端校验串]] 一上，这类散户脚本全军覆没——因为他们不执行前端算法
