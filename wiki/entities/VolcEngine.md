## 定义
火山引擎是字节跳动推出的云服务平台，提供大模型 API、对象存储等能力，是豆包生态的云服务底座。

## 关键信息
- **API 开通**：控制台开通 API 流程复杂，一般人像走迷宫，豆包工作可操作浏览器代为完成
- **与豆包工作的关系**：豆包工作可调用【操作浏览器】技能，代用户完成火山引擎 API 开通流程
- **模型服务**：Seedream 5.0 Pro、Seedance 2.5 等模型通过火山引擎提供
- **ADrive 智能网盘**（2026-09 发布）：由火山引擎打造的全新独立智能网盘产品，Slogan「连接你的 AI 应用，让文件与产物持续可用」，面向 AI 智能体与人类用户协同办公的企业级智能网盘。将 OpenClaw、Trae 等主流 AI 智能体的工作目录映射至云端，实现 AI 工作数据的沉淀与复用。详见 [[ADrive]]

## 模型升级（2026-09-17，详见 [[摘要-doubao-seed-2-1-pro-0915实测]]）
火山方舟将 Seed 模型升级到 **[[Doubao-Seed-2.1-Pro-0915]]**，顶到 1M 上下文 + 256k 深度思考，主打 Agent 长时间执行任务防摆烂、降低工具幻觉、视觉理解做前端 Coding。[[卡尔的AI沃茨]] 五个真实任务连测：审美和长时间 Agent 任务都追上第一档。

## 豆包座舱助手（2026-09-19）
火山引擎与 [[豆包]] 正式发布 [[豆包座舱助手]]，参与汽车"感知—决策—执行"，实时感知数百种车辆信号，调用车控、导航、辅助驾驶、车载娱乐等数千个整车原子能力。首款搭载车型是上汽荣威家越07。火山引擎 4 月数据显示搭载豆包大模型的智能汽车超 700 万辆、覆盖 50 多品牌 145 车型。详见 [[摘要-豆包座舱助手]]。
