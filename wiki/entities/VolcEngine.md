## 定义
火山引擎是字节跳动推出的云服务平台，提供大模型 API、对象存储等能力，是豆包生态的云服务底座。

## 关键信息
- **API 开通**：控制台开通 API 流程复杂，一般人像走迷宫，豆包工作可操作浏览器代为完成
- **与豆包工作的关系**：豆包工作可调用【操作浏览器】技能，代用户完成火山引擎 API 开通流程
- **模型服务**：Seedream 5.0 Pro、Seedance 2.5 等模型通过火山引擎提供
