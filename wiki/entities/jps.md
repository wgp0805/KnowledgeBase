## 定义
jps 是 JDK 自带的 Java 诊断工具，专门列出 Java 进程，类似 ps 但只看 Java。

## 关键信息
- **定位**：列出 Java 进程
- **优势**：类似 ps 但只看 Java，更精准
- **属于**：JDK 自带 Java 诊断工具集
