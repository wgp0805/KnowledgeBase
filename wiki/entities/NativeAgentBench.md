## 定义
自建的 Agent 自动化评测集，覆盖**代码定位、缺陷修复、终端操作、MCP 工具编排和长上下文压缩**等场景。在 [[PaiCLI]] 项目中配套 28 题自动化评测体系。

## 关键信息

### 防作弊的沙箱设计
- 候选 Agent 被放进**断网且根文件系统只读**的 Docker 容器里独立执行
- **API 密钥留在宿主机侧**——防止 Agent 联网搜答案或者读取测试脚本作弊
- Agent 结束任务后，宿主机的验证器把**预设的隐藏单元测试**拷进隔离目录
- **不经过任何 Shell 字符串拼接**，直接用**进程参数数组**执行编译和单元测试

### 判定流程示例（区间边界修复）
验证脚本先调用 Java 编译器编译被修改的源码，**编译失败直接判为未通过**；编译成功后立即生成并执行隐藏边界测试类，专门判断边界重合、空区间等极端情况。

### 除通过率外的过程指标
从工具调用监听器里采集：
- 完成步数
- 输入输出 Token 消耗
- 工具调用失败率
- 是否触发了危险命令拦截

### 软性指标
代码可读性、异常处理规范、有没有冗余改动这些**单元测试测不出来**的指标，交给 [[LLM-as-Judge]] 按预先定义的评分表打分（需配合 [[位置偏见]] 消除与人工盲评校准）。
