## 定义

Ascend C 是**华为昇腾平台上用于编写更底层的自定义算子**的编程语言，其形态是**在 C 和 C++ 基础上做裁剪扩展**得到的领域语言。

## 关键信息

- **适用场景**：昇腾走的是"兼容适配 [[Triton]]"的路线（`triton-ascend` 已迁至 triton-lang 官方组织，2025 年 5 月开源、2026 年 1 月发 3.2.0 正式版，底层依赖 [[CANN]] 社区版 9.0.0）；**当需要写更底层的自定义算子时，用 Ascend C**。
- **与 [[DSL]] 分层的关系**：与 NVIDIA 侧的 CuTe DSL / ThunderKittens 同处"最贴近硬件、性能上限最高但门槛最高"的那一层，参见 [[DSL]]。
- **对照**：[[寒武纪]] 走的是完全不同的一套体系（BANG / BANG C / CNCC / MLISA / CNAS / BANGPy）。
