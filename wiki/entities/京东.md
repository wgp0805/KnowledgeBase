## 定义
京东（JD.com）是中国领先的自营电商平台，核心护城河为"自营零售数据 + 仓储物流网络 + 供应链履约系统"，正在将这套基础设施演进为能够自主决策、调用工具并完成履约的"供应链智能体"。

## 关键信息
- AI 产品线：基础大模型 JoyAI-LLM Flash、图像模型 JoyAI-Image-Edit、具身大尺寸模型 JoyAI-RA、工业大尺寸模型 JoyIndustrial
- AI 编程工具：JoyCoder（AI Coding 工具）
- AI Agent 平台：京东云 JoyAgent，开源 JoyAgent-JDGenie，支持 ReAct 与 Plan-and-Execute 模式
- Agent 子能力：Report、Search、Code、File 等子 Agent；支持多 Agent 上下文、高并发 DAG、跨任务工作流记忆
- 智能客服采用混合方案：高频标准流程走工作流（查物流、催配送），复杂场景走 Agent（跨订单比价退差价）
- 对比阿里/腾讯/字节，推广力度不大，但 AI 产品线齐全
- 核心价值：AI Agent 让供应链基础设施变成可自主决策的智能体
