## 定义
Lazygit 是一款基于终端的 Git 可视化界面工具，通过简单的快捷键操作实现 Git 的可视化管理，被 Kaku 终端工具内置。

## 关键信息
- **功能**：提供 Git 操作的可视化界面，包括暂存、提交、分支管理、rebase 等
- **快捷键**：在 Kaku 中通过 `Cmd+Shift+G` 一键唤起
- **优势**：无需记忆复杂的 git 命令，通过可视化操作简化 Git 工作流
- **技术栈**：Go 语言编写
- **集成**：被 Kaku 终端工具内置，作为终端老炮的必装工具之一
