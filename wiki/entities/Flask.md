## 定义
Flask 是一个基于 Python 的轻量级 Web 框架，由 Armin Ronacher 创建。仅 5000 行核心代码，通过扩展系统支撑了整个 Python Web 生态。是"微框架"设计哲学的代表作。

## 关键信息
- **核心代码**：约 5000 行，极简但可扩展
- **设计哲学**：简单、优雅、可组合——核心只做路由和请求响应，其余通过扩展实现
- **生态**：Flask-SQLAlchemy、Flask-Login、Flask-WTF 等扩展覆盖全栈需求
- **影响力**：Armin Ronacher 将同样的极简哲学带入了 Pi Agent 的设计——4 个工具、~300 词提示词
