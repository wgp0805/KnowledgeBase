## 定义
Vercel 实验室（Vercel Labs）发布了目前安装量最高的前端开发 Skills，包括 react-best-practices（148,900+ 安装）、web-design-guidelines（112,700+ 安装）等。

## 关键信息

### 主要 Skills
| Skill | 安装量 | 说明 |
| :---: | :---: | :--- |
| react-best-practices | 148,900+ | React Hooks、组件模式、性能优化 |
| web-design-guidelines | 112,700+ | 全面的 Web 设计标准与精致界面 |
| composition-patterns | 48,400+ | 组合模式与可扩展组件模式 |
| next-best-practices | — | Next.js 最佳实践（App Router、Server Components） |
| react-native-skills | 34,300+ | React Native 跨平台移动开发 |

### 安装方式
```bash
npx skills add vercel-labs/agent-skills/<skill-name>
```
