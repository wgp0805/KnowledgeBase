## 定义

odiff 是一个开源、免费、支持命令行的**图像差分（visual diff）工具**（GitHub: `dmtrKovalenko/odiff`）。在 AI 辅助游戏开发的工作流中，它承担"让 Agent 只看到真正变化的像素"这一职责：给它两张图片，它会瞬间计算差异并输出一张高亮标注差异的 Diff 图像。

## 关键信息

- **解决什么问题**：直接把修改前后的两张大图喂给多模态大模型时，模型极难准确识别细微改动，更无法量化评估改动是否逼近目标；高分辨率截图本身构成隐蔽的[[上下文污染]]。odiff 把"全图对比"降维成"只呈现真正的像素差异"。
- **量化反馈**：odiff 能直接向标准输出打印量化的相似度数值（例如 `85% similar`）。LLM 对纯文本数值极其敏感，可以把该百分比当作坚实的**基准评估函数**，在连续 Agent 轮次中自主朝"降低差异/提高相似度"的目标收敛。
- **类比**：如同 Git 对代码做 Diff，图像差分 + 精准局部裁剪让 LLM 能以极高置信度直观看到变化并获得量化指标。
- **配套实践**：建议在引擎中增加 UI 层/玩法层渲染开关，验证 UI 时关掉背景动态 3D 渲染，消除背景动画对视觉评测的干扰。
