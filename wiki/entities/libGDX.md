## 定义
libGDX 是一个基于 Java 的跨平台游戏开发框架，由 Mario Zechner 创建。支持 Windows、Linux、Mac、Android、iOS 和 Web 平台，是 Java 生态中最流行的 2D/3D 游戏引擎之一。

## 关键信息
- **跨平台**：一次编写，六平台运行（桌面三端 + 移动两端 + Web）
- **架构**：核心模块（无依赖）+ 平台后端（LWJGL/Android/RoboVM/GWT）
- **生态**：Box2D 物理引擎集成、Scene2D UI 框架、3D 模型渲染管线
