## 定义
NVIDIA GeForce RTX 5090 是基于 Blackwell 架构的消费级 AI 显卡新标杆，被视作本地 AI Agent 部署的"门槛硬件"。两张 RTX 5090（2× 32GB = 64GB 总显存）即可在本地跑满 Qwen3.8-27B 的 256K 上下文，构成完全本地、完全私有的 AI Agent 工作站。

## 关键信息

### 硬件参数
| 属性 | 详情 |
|------|------|
| 显存 | 32GB GDDR7 |
| 显存带宽 | 1,792 GB/s |
| 架构 | Blackwell（计算能力 12.0） |
| NVLink | 不支持（消费级从 3090/3090Ti 之后取消） |
| 多卡通信 | PCIe（约 32-64 GB/s） |

### 双卡配置能力（2× RTX 5090 = 64GB 总显存）
- 可运行 Qwen3-70B @ Q4_K_M（需约 42GB）
- 可运行 [[Qwen3.8-27B]] @ Q4 + 256K 全上下文
- 可运行 DeepSeek R1 70B @ Q4_K_M
- 70B 模型推理速度约 40-50 tokens/sec
- 整机功耗峰值约 1,150W（仅 GPU）

### 推荐整机配置（双卡方案）
| 组件 | 配置 |
|------|------|
| GPU | 2× RTX 5090 (32GB × 2 = 64GB) |
| CPU | AMD Threadripper 7960X (24C) |
| 主板 | ASUS Pro WS TRX50-SAGE WIFI |
| 内存 | 128GB DDR5-5600 |
| 存储 | 2× Samsung 990 Pro 4TB (RAID-0) |
| 电源 | 1600W Titanium |

### 入门级单卡配置
| 组件 | 配置 |
|------|------|
| GPU | 1× RTX 5090 (32GB) 或 1× RTX 4090 (24GB) |
| CPU | AMD Ryzen 9 9950X |
| 内存 | 64-128GB DDR5 |
| 可跑模型 | Qwen3.8-27B Q4（上下文受限）/ Qwen3-32B Q4 |

### 重要避坑
- **双卡没有 NVLink**：RTX 5090 不支持 NVLink，多卡通信走 PCIe。[[TensorSplit]] 摊开的是权重和 KV cache，解码每步两卡都要同步，**双卡不会让解码速度翻倍**（约 1.6-1.8x）
- 一次性投入约 ¥30,000-40,000，无后续订阅费
