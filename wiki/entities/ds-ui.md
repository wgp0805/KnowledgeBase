## 定义
ds-ui 是一套基于 Canvas 构建的专业 GUI 框架，面向高信息密度、长时间运行、强键盘操作的企业级 Web 应用（ERP、临床信息系统、财务系统等）。核心设计理念是让业务开发人员面对的是业务控件（Button、DataGrid、Tree、Window、Dialog），框架承担控件内部的复杂度。

## 关键信息
- **渲染方式**：基于 Canvas，放弃部分浏览器原生 UI 能力，换取更可控、更统一的专业 GUI 运行时
- **核心模型**：对象式、命令式控件模型（类似 WinForms），控件具有稳定对象身份
- **统一体系**：组件关系、布局、事件、焦点、输入、弹层、页面生命周期、刷新和诊断由同一套运行时管理
- **临时窗口**：按需创建、等待结果、关闭后丢弃，不提升为页面级常驻状态
- **适用场景**：ERP、财务系统、临床信息系统、电子病历编辑器、报表设计器、高密度业务工作台
- **不适用场景**：内容展示、信息浏览、普通表单、面向大众的门户网站（可访问性需额外建设）
