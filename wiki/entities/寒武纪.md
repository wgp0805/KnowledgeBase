## 定义

寒武纪（Cambricon）是中国的 AI 芯片公司，其加速卡是与英伟达、华为[[昇腾]]并列的国产算力选择之一。与昇腾"兼容适配 [[Triton]]"的路线不同，寒武纪走的是**完全自研的一套编译与编程体系**。

## 关键信息

### 自研技术栈
| 组件 | 职责 |
| --- | --- |
| **BANG** | 通用并行编程模型 |
| **BANG C** | 写算子用的语言，在 C 和 C++ 基础上扩展而来 |
| **CNCC** | 自研编译器，把 BANG C 源码编译成寒武纪自己的底层指令集 **MLISA** |
| **CNAS** | 汇编器，把 MLISA 汇编成目标二进制文件 |
| **BANGPy** | 另一套基于 Python 的算子开发接口 |

### 与竞争路线的对照
- 华为昇腾：兼容 Triton（`triton-ascend` 迁入 triton-lang 官方组织）+ [[AscendC]] 写底层算子 + [[CANN]] 软件栈；
- 寒武纪：全自研工具链，不依赖 Triton 生态。

详见 [[DSL]] 与 [[AI编译器]]。
