## 定义
老王霸（公众号「产品经理老王霸」，人人都是产品经理作者，自称"电商产品经理老王霸"）是电商方向产品经理自媒体作者，擅长把大厂交付规范固化成可复用的 [[WorkBuddy]] Skill，代表作为 5 套产品经理核心交付 Skill 系列。

## 关键信息
- **Skill 系列**（GitHub 组织 `pmlaowangba-lab`，安装命令为"帮我把 GitHub 仓库 pmlaowangba-lab/<repo> 安装到 .agents/skills/"）：
  - `laowang-prototype`：业务场景 → 本地可交互自适应 HTML 原型，支持多页面联动
  - `laowang-diagram`：角色/主干步骤/异常 → 泳道逻辑 → draw.io 矢量图（泳道图、框架图）
  - `laowang-prd`：工业级自检递归补全前置/后置条件、字段字典、异常分支、埋点字典
  - `laowang-report`：零散记录 → 四段式汇报（收益/抓手/卡点/里程碑）+ 3 页 PPT 大纲
  - `laowang-pm-deck`：deck-build 六段结构案例卡建库 + 挂载后四维证据链诊断与面试对练
- **方法论**：先建库再使用；案例按背景/角色/决策/推演/结果/方法论六段结构沉淀，每条结论标注证据等级
- **观点**：金九银十求职季，大厂面试考业务闭环、系统推演、业务决策力；机械交付（画原型、抠流程、补 PRD、汇报 PPT）应交给 AI，人聚焦商业洞察与用户同理心
