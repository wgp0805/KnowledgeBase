## 定义
IQuestRT 是至知发布的开源推理引擎，专门优化 **IQuest-Q1** 模型的推理执行过程，直指"用 AI 编程助手总得盯着屏幕等"的痛点：从执行路径入手减少反复出现的等待——推测解码、准备提前开始、用数据本身判断齐没齐、专家预取。面向具备服务器部署条件的开发者和团队，门槛为 8 张 NVIDIA GPU（Blackwell、算力 10.0）+ NVLink 组播 + TP=8 + 权重约 330GB，只支持 IQuest-Q1 一个模型。

## 关键信息
- **模型 vs 引擎**：IQuest-Q1 负责理解/推理/生成，IQuestRT 负责底层计算、显卡通信、数据传输
- **四项优化**：
  1. **推测解码**：候选生成、验证、后续状态处理一体化；按已生成候选在显卡上决策是否继续预测、预测深度随执行情况调整
  2. **准备提前开始**：底层调度让符合条件后续程序提前备输入、与前序计算重叠；相邻操作合并减少中间结果反复读写
  3. **NaN 同步**：缓冲区初始填 NaN，读到无 NaN 即所有卡写完（免标志位免单独同步，靠 NVLink 组播）
  4. **专家预取**：提前预测 MoE 专家权重预热进缓存（活跃验证行 4-5 行有收益、6-8 行不启用）
- **性能（仅官方自测）**：8 卡 TP=8 单请求解码 911 tokens/s vs vLLM 309.83 tokens/s（2.94 倍）；每轮推测解码 3.558ms 输出 3.24 token、每输出 token 1.098ms；测试样本 400 条 Claude Code 轨迹×2 种子=800 次解码/32 万 token
- **功能边界**：支持流式输出、客户端工具调用、接入 Claude Code、Anthropic Messages 接口；不支持图像输入、约束式结构化输出、连续批处理、自定义采样参数（固定温度 1、top-k 20、top-p 0.95）
- **指标口径**：单请求解码速度只测生成（解码）阶段，不含输入处理与模型加载，不代表用户拿成果的全部耗时
