## 定义

React 是 Meta（Facebook）开源的 JavaScript 前端框架，基于组件化架构和虚拟 DOM，通过声明式编程和单向数据流构建用户界面。

## 关键信息

- **核心概念**：组件化、JSX、Virtual DOM、单向数据流
- **生态优势**：npm 生态最丰富、社区最大、就业市场需求最高
- **元框架**：Next.js（SSR/SSG）、Remix、Gatsby
- **Java 生态关联**：JxBrowser + React 构建桌面应用、shadcn/ui 基于 React 构建
- **版本**：React 19（2025）
