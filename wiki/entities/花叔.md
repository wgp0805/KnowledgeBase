## 定义
花叔（GitHub: @alchaincyf），前某团新用户运营负责人，Agent Skill 创作者。基于运营时期的数据处理痛苦经验和对大模型能力的理解，开源 huashu-excel skill（MIT 协议，github.com/alchaincyf/huashu-excel），定位「最好用的 Excel 数据处理和分析 skill」；另有 huashu-design skill 处理 PPT、huashu-report skill 生成报告。

## 关键信息
- **背景**：前某团新用户运营负责人，每天提前 2 小时取数据做分析在早会同步
- **核心作品**：huashu-excel skill（Excel 数据处理和分析）
- **设计哲学**：一套体系化策略，激发大模型能力同时避开其数据处理缺陷
- **核心洞察**：AI 算错时不会报错，错误数字和正确数字交付时长得完全一样
- **能力激发方法**：参考 Anthropic AI 心理学研究，用词汇激发让 agent 进入「百万美元项目组」角色状态
- **test-time scaling 应用**：八步流程强制 agent 多想，每跑完脚本回答「看到了什么、意味着什么、下一步查什么」
- **抗差统计实践**：默认中位数和五数概括，均值只当陪衬（Tukey 那套）
- **图表规则**：类别超 3 个拒绝饼图、柱形图数值轴从 0 开始、双轴图禁用、不完整周期画虚线
- **压测方法**：十份真实公开业务数据（106 万行电商交易、21 万行纽约市政预算等），独立 agent 实跑全流程，另派复核 agent 重算
- **Twyman's Law 实践**：1.02 亿年薪先当 bug 查，排除了才当发现

### huashu-report（2026-09）
花叔的第三个重磅 skill，MIT 协议开源，详见 [[Huashu-Report]]。要点：
- **定位跃迁**：橙皮书只是它能做的六种产物之一（咨询 deck / 研报 / 学术 / 论文 / 调查 / 科普），能产出 22 页投研、39 页 16:9 咨询 deck、56 页竞争格局研究、370 页 29 章的《智能简史》
- **数字溯源机制**：动笔前先建 `数据表.json`，编译器反向检查「正文引了数据表里没有的条目」——模型能编数字，但过不了编译；口径写不出一句完整的话这个数字就不能用
- **强制力原则**：能写成函数或计数的规则一律挪进编译器，只有机器判不了「什么叫具体」的才留在手册——**手册不是强制力**
- **人工逐页复核**：机器查完还得用眼睛逐页看，12 页拼一张检查表扫完全书；自检本身的规矩是**假警报比漏报贵**
- **品位来源**：19 个 agent 扫 74 份 2026 顶级机构 AI 报告（Stanford/BCG/McKinsey/OpenAI/Reuters/RAND/世界银行），实测能下全文 42 份，写成解剖器提取结构指标——报告品位对齐最顶尖公司的选择，不跟着作者个人习惯
- **变现反思**：橙皮书四期结算单从 2.35 万跌到 0.49 万（-79%），所以橙皮书是过去式

### 对 Skill 价值的核心判断
Skill 很有价值的一点是：可以把**没有被 AI 训练过的、藏在人脑中的工作流与品味等知识固定下来**；同时也能通过一些机制去**激发期望 agent 具备的能力，从最好的范本去学习**。
