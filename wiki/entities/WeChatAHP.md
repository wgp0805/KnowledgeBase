## 定义
WeChat AHP 是 formulahendry（韩老师）发布的 VS Code extension，让微信和 VS Code 的 Agent session 双向实时同步，随时随地通过微信远程操控 VS Code Agent，read-write 操作毫秒级实时同步。

## 关键信息
- **AHP（Agent Host Protocol）**：解决多 Client 实时同步 Agent Session 的问题，与 ACP（解决连接任何 Agent Harness 的问题）是强强联合关系
- **作者背景**：此前发布 WeChat ACP（微信连上 Claude/Codex/Copilot/Qwen/Gemini/OpenCode 等各类 Agent），下载量超 14K
- **Agent Rosetta**：作者领导的 AHP x ACP - Universal Agent Host 项目获第一届 CoreAI China hackathon 的 People's Choice Award
- **开源**：代码完全开源，可命令行一键安装
