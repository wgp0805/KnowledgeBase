## 定义
DSH Desktop 是由 BISHENG 团队开发的开源桌面 Agent 基础产品，作为 [[BISHENG]] 平台桌面端的底层改造基础，帮助企业和团队搭建统一的 Agent 平台，管理模型、知识、工具和使用权限。它属于开源 AgentOps 领域，专攻办公效率场景。

## 关键信息
- 截至 2026 年 11 月，DSH Desktop 下载量达 93 万+（两个月内从 23 万+ 快速增长，作者评价"增速离谱"）
- 与 BISHENG 平台关系：DSH Desktop 是桌面 Agent 基础，BISHENG 客户端在其基础上连接企业平台；网页平台负责搭建和管理，桌面端让员工调用平台资源、处理日常工作
- 配置方式：在桌面端「设置 → 模型」中配置大模型（如 DeepSeek），填入自己的 API Key 即可使用
- 个人可直接下载开源 DSH Desktop 个人版客户端，自己配好模型就能用；企业则部署 BISHENG 平台后让员工通过 BISHENG 桌面端登录使用
- 与 [[DeepSeekHarness]] 同属 BISHENG 团队的桌面端 Agent 产品线（苏三此前在 DeepSeek Harness 官方桌面端发布前介绍过第三方客户端 DSH Desktop）
