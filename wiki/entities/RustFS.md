## 定义
RustFS 是一款基于 Rust 编写的高性能分布式对象存储系统，采用 Apache 2.0 开源协议，完全兼容 S3 API，自带 Web 控制台，可作为 MinIO 的国产平替方案。

## 关键信息
- **语言**：Rust
- **开源协议**：Apache 2.0
- **兼容性**：完全兼容 S3 API
- **管理方式**：自带 Web 控制台
- **部署方式**：支持 Docker Compose 一键部署
- **HTTPS 配置**：可通过 Nginx 反向代理 + Let's Encrypt 配置 HTTPS
