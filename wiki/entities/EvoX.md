## 定义
EvoX 是 EvoMap 团队于 2026-08-09 上线 beta 版的通用 Agent 工具（Mac/Windows 双端，注册即用、无需邀请码）。产品定位是大厂生态位之外的创业公司黑马，核心差异在于「蜂群模式」多 Agent 组织方式 +「联网自进化」学习方式，强调让一群 AI 会分工、会继承经验、会一起把复杂任务做完。官网：https://evomap.ai/evox/beta

## 核心能力
- **三大能力分仓**：
  - **Chat**：问答调研，偏好结构化输出，回答自动整理成表格/图表（如五面板：指标/场景/流程/评分/交付清单，评分模型带可调权重计算器）。
  - **Cowork**：办公协作交付，含会议纪要、文档整理、连通海内外 IM 自动汇总、长任务流程自动执行。
  - **Code**：开发场景，读工程/改代码/跑测试，支持「拆分并行会话」生成多个蜂群会话。
- **多模型热切**：内置 DeepSeek V4、Kimi K3（Beta 免费用）；可配自有 API Key 接入 DeepSeek V4 Flash、GLM-5.2、Qwen3.8 Max、本地模型；EvoMap 后台还可选 Opus 4.8、GPT-5.6 Sol 等海外顶级模型。注册用户可领体验金。

## 蜂群模式（Swarm）
与传统多 Agent 编排的根本区别在于「结果确定性汇合」——Agent 只负责推理，最终产出不再经主 Agent 二次转述，每个 Agent 原始答案都对程序可见，避免概括环节丢信息。
- 三件不一样的事：① 任务拆得更细，单 Agent 只做一个边界清楚的子问题；② 上下文彼此隔离，互不污染；③ 结果确定性汇合。
- 同模型 563 道逻辑/数学/物理题：单 Agent 单线程 26% → 主+Sub 编排有提升 → 蜂群模式 71%（约 2 倍）。
- Token 成本：256 子任务单上下文约 4934 万 token，蜂群分治后约 104 万 token，差约 48 倍。
- 适配场景：并行调研、多视角评审、方案竞争、交叉验证。

## 联网自进化
EvoX 背后接 EvoMap 经验网络，把经验封装成两种形式：
- **Gene**：最小经验单元，记录某具体任务的成功执行路径（工具/踩坑/解法）。
- **Capsule**：打包的能力模块，可含多个 Gene，组合成可复用能力包。
- 本地进化：把用过的经验保存在本机，同类任务复用历史经验（格式/表述/数据来源）。
- 联网进化：新 Agent 第一天即可继承网络上其他 Agent 积累的经验，EvoX 已内置一批优质 Capsule 开箱即用（「第一天就很聪明」）。
