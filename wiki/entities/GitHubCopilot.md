## 定义
GitHub 与 OpenAI 合作推出的 AI 编程助手。2026.2 起在 [[IntelliJIDEA]] 中**从插件变为原生内置**，无需安装插件，成为 IDEA 2026.2 "AI 原生化"趋势的标志性变化。

## 关键信息
- **原生内置（IDEA 2026.2）**：Copilot 从需安装的插件升级为 IDE 原生功能，安装 IDEA 即可用
- **同台竞品**：Junie（JetBrains 自家 AI agent，支持 MCP 自动配置）、通义灵码、CodeGeeX、TRAE AI、开源阵营（Cline 3.9M、Roo Code 1.6M、Continue 2.9M）
- **市场背景**：84% 开发者使用或计划使用 AI 编码工具，MCP 扩展达 4148 个
