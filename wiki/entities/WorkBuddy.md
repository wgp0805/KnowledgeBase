## 定义
WorkBuddy 是一款国产桌面 AI 应用，可写 Word、做 PPT、辅助论文、数据分析、设计海报、写代码，生成的文件可直接预览。相比 [[Codex]] 登录/手机号验证/plus 等门槛，WorkBuddy 下载安装登录都很直接，是国产桌面 AI 中最好上手、功能最全的一档。

**最新进展（2026-08-27）**：由腾讯内部孵化，从 [[CodeBuddy]] 演化而来，上线三个月迭代 40+ 版本，月活突破 1000 万，成为 AI 办公领域王牌产品。作者沉默王二表示"Codex 蹬完了就用 WorkBuddy 稳稳接住"，常与 [[Codex]]、[[ClaudeCode]]、[[DeepSeekHarness]] 组合使用。

## 关键信息

### 三大界面区域
- **左侧导航栏**：任务、工作空间、专家、技能、连接器、自动化等入口
- **中间对话区**：提需求、补充材料、回答追问
- **右侧产物区**：生成的 Word/PPT/网页等文件直接预览

### 任务模式
| 模式 | 会做什么 | 适合场景 |
|------|----------|----------|
| Ask | 只问答和看信息，不修改文件 | 了解资料、讨论思路、确认需求 |
| Craft | 直接执行任务 | 生成文档、处理表格、整理文件 |
| Plan | 先拆计划，确认后再执行 | 做 PPT、修论文、改代码等多步任务 |

### 模型选型建议
| 任务 | 可优先尝试 | 感受 |
|------|------------|------|
| 日常问答和写文字 | [[DeepSeek]] V4 Flash | 响应快，成本好控制 |
| 代码和复杂步骤 | [[GLM]] 5.2 | 适合连续执行多个开发步骤 |
| 前端和设计类任务 | [[Kimi]] K3 | 前端和视觉任务表现不错 |
| 图片识别类任务 | 支持图片输入的模型 | 先确认客户端能力标记 |

- 不想研究模型直接保持 **Auto**，让 WorkBuddy 自己分配
- 支持自定义模型：在设置页填写 API Key 和参数

### 权限模型
- **默认权限**：遇到删除重要文件、运行脚本、访问敏感路径时停下来让用户确认
- **完全访问**：减少确认弹窗，执行更顺，风险更高
- 建议：新手保持默认权限；完全访问只在可恢复、可隔离任务里短时开启

### 五类实战场景
1. **写 Word 报告**：选文档处理技能，自动写内容+排版+输出文件，右侧直接预览
2. **做 PPT**：把 Word 资料放工作空间，选幻灯片技能 + Kimi K3，先读 Word 再提取重点设计结构
3. **写论文**：把论文/审稿意见/实验数据/参考资料放同一文件夹整体理解；引用和数据必须回原文核对
4. **开发网站**：项目文件夹设为工作空间，选 GLM，3 分钟出第一版；关键流程上线前必须亲自测
5. **设计海报**：选 Apple 风格，成品能用但效果不如 [[GPT-image-2]]，适合快速出初稿

### 三类进阶能力
- **技能**：一套做事方法（做 PPT、处理表格、生成海报），告诉 WorkBuddy 按什么流程做
- **专家**：角色+经验+方法组合，适合有明确领域的任务；复杂任务可用专家团多角色分工
- **连接器**：接入腾讯文档、邮箱、会议等外部服务，解决去哪里取数据、能调用哪些外部能力

### 其他功能
- **记忆**：默认开启，从对话中整理偏好和近期事项，可查看/修改/删除/关闭，支持导入其他 AI 使用习惯
- **自动化**：按设定时间执行周期任务（每天搜集论文、每周汇总资料），支持手机推送
- **远程**：开启助理后通过微信/企业微信/QQ/钉钉/飞书给电脑上的 WorkBuddy 发任务

### 个人知识库搭建（苏三 2026-09-16 教程）
来自 [[摘要-workbuddy-obsidian-知识库]]。用 WorkBuddy + Obsidian 搭建自生长个人知识库：

**三层极简目录**
- `raw/` 只读原始资料，任何情况下不改动原文
- `wiki/` AI 提炼整理的结构化知识，长期核心资产
- `output/` 临时报告、大纲、阶段性分析

**AGENTS.md 作为宪法**
- 明确规定原文只读、优先增量更新旧页面
- 结论必须溯源（附 raw 路径）
- 不同来源说法不一致时同时保留

**首次入库技巧**
- 只放一篇资料，直观观察 AI 修改了哪些文件
- 验证自生长三问：已有概念做内容融合？核心结论附带两篇原文路径？观点冲突客观保留两方？

**进阶方案**：接入开源 `claude-obsidian` 工具链，命令包括 `init` / `adopt` / `wiki-ingest` / `wiki-query` / `wiki-lint`

**5 条自检标准**：原文与提炼页面隔离 / 关键事实可溯源 / 相同主题合并 / 变更日记清晰 / 索引同步

### 与豆包工作的竞争分析（2026-09-17，怪哥视角，详见 [[摘要-豆包工作vs-workbuddy-竞争分析]]）
**WorkBuddy 领先的两根支柱**：
1. **[[模型超市策略]]**：已接入 DeepSeek/Kimi/GLM/MiniMax 等国内主流模型 + 自家 Hy 系列。用户不用在多厂商间切换，"谁现在最好用我就想用谁"。WorkBuddy 不需要证明 Hy 永远最强，只需保证"中国热门的模型我这里都有"——谁赢它都不输
2. **额度够大（敢用）**：积分多、消耗低、部分模型阶段性免费。中国用户被免费产品教育太久，"敢用"才是 AI Agent 普及最重要的一步

**第三方模型反向带流量**：DeepSeek/Kimi/GLM 每次更新都制造热点和"我想试试"的需求，WorkBuddy 快速接入即可承接——DeepSeek 在帮 WorkBuddy 拉新，Kimi 在帮 WorkBuddy 拉新。长期心智："最近哪个模型更新了？去 WorkBuddy 看看"——从 AI 办公软件升级为**国产大模型分发入口**

**飞轮闭环**：接更多模型 → 承接更多热点 → 获得更多新用户 → 提高留存 → 更有能力补贴模型 → 使用成本更低 → 吸引更多用户

**可复制性**：优势并非无法复制的技术壁垒，[[DoubaoWork|豆包工作]] 接 DeepSeek/Kimi/GLM 没有技术障碍，真正要解决的是战略选择——愿不愿意从"我只推自己的模型"变成"我先抢 AI 办公入口"

### 12 条使用技巧（2026-09-18，叶小钗，详见 [[摘要-workbuddy-12条使用技巧]]）
1. 把任务表达清楚（做什么+有什么+要做到什么程度）
2. 提供样例比说一堆要求更有用
3. 使用提示词增强
4. 执行任务前选对工作模式（Plan/Ask/Agent 三模式，仅问答模式不加载执行工具省上下文）
5. 把复杂任务拆成多步骤
6. 选对任务和空间（任务一次性、空间是长期项目共享文件）
7. 同一会话别频繁切换模型（提示词缓存失效）
8. 对话太长用 /compact 压缩（先整理 handoff 交接文件）
9. 给够权限别让 AI 束手束脚（完全访问 + 沙箱安全）
10. 技能不是越多越好按需开启
11. 理解记忆、个性化和项目规则（记忆自动提取、个性化全局指令、项目规则）
12. 把重复的事情自动化（提示词+执行计划+技能连接器三要素）

### 一句话需求实测与沙利文双榜第一（2026-09-24，详见 [[摘要-workbuddy-一句话需求实测]]）
- 沙利文《2026 年全球桌面 AI 智能体市场研究报告》：WorkBuddy 同时拿下中国**个人端与企业级桌面智能体双榜第一**
- 「MVP 专家开发团」（项目总监/产品经理/工程师/设计师）对一句话需求先发起澄清，产出 PRD、技术方案、设计方案
- 多 Agent 接住需求变更：在 PRD 中选中章节提变更 → 项目总监 Agent 判影响 → 产品经理 Agent 调研 → 结论回写 PRD 并同步研发/设计文档
- 长程记忆让调研新结论回写目标人群与需求优先级；腾讯问卷连接器把待验证问题直接落成问卷，跨工具不再搬运信息
- **应用发布能力**：小程序预览右上角分享 → 创建试用版小程序，得到可访问、可登录、带后端数据逻辑的 MVP，省去部署配置
- 作者判断标准（[[一句话需求]]）：能否理解目标、调度能力、接住变化并持续推进到结果

### 美业行业落地四场景（2026-09-26，马佳彬，详见 [[摘要-workbuddy-美业四场景]]）
1. **活动方案与门店 SOP**：喂历史方案+企业标准当参考上下文，纯提示词即可（价格排期需人工核对）
2. **营销文案批量产出与合规审查**：卖点 → 朋友圈/社群/小红书三版 → 广告法审核员角色自查（详见 [[违禁词审查]]）；推荐 `multi-wordcheck`、`xhs-copywriter`、write 去 AI 味
3. **会员话术库**：四类高频话术（新客接待/复购邀约/沉睡唤醒/客诉应对）→《门店话术手册》→ 提示词做成手机可搜索、带复制按钮的网页查询工具
4. **巡检与合规归档**：五板块检查表 + 零散记录归档成台账 → 直接搓巡检记录网页小系统（含待整改闭环页、月度汇总），3 家店以上连锁比表格好用

### PPT 视觉能力外接（2026-09-27，详见 [[摘要-workbuddy-美图设计室ppt美化]]）
- 局限自省：WorkBuddy 出的 PPT "很 PPT、缺设计感"——因为对话只调了文本大模型，没调出设计能力
- 解法：「专家·技能·连接器」添加「PPT 美化」skill → 召唤带「美图设计室」标识的「PPT 视觉美化师」专家，拖入原稿一句话美化，5 分钟导出可编辑 pptx（详见 [[美图设计室]]）
- 判断标准：[[PPT成品感五要素]]（标题层级、重点数据、字体、配色、页面统一）

## 知识冲突（已解决，2026-08-21）
- 旧定义（2026-06-23，[[摘要-OpenClaw小龙虾教程汇总]]）：WorkBuddy 是 [[OpenClaw]]（小龙虾）的一站式部署平台
- 新定义（2026-08-21，[[摘要-workbuddy保姆级入门教程-苏三]]）：WorkBuddy 是国产桌面 AI 应用
- **处理结果**：2026-08-21 经用户确认，用新知识覆盖旧知识。两者明显不是同一个产品，旧定义可能是早期信息错配或同名不同物。旧定义关联的 [[OpenClaw]]、[[QoderWork]] 已解绑
