# ChatGPT

ChatGPT 是 OpenAI 的对话产品，与 Codex 配合可在移动端使用。青少年版面临年龄验证等产品难题。

## 产品合并路线（2026-09-16）

OpenAI 7 月把 Codex App 并入新版 ChatGPT 桌面应用，一个客户端有 Chat/Work/Codex，在做减法。与 [[Claude]]（合并独立 Chat 和 Cowork）一致，而 [[KimiCode]] 还在做加法。详见 [[摘要-kimi向左claude-gpt向右]]。

## Intelligent UI（2026-10-07）
[[OpenAI]] 把 [[IntelligentUI]] 与 GPT-6 带入更广泛的 ChatGPT 日常聊天（10 月 7 日起向付费用户开放，免费与 Go 用户次日跟进）：用户提问除文字回答外，还能直接看到可点击的图表、表单和交互式小工具，模型根据问题自动选择回答形式。定位变化：**模型从信息提供者变为任务交互入口**。详见 [[摘要-intelligent-ui模型交互界面]]。
