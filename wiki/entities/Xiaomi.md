## 定义
小米集团（Xiaomi），中国知名消费电子与科技公司。在 AI 编程工具领域，通过小米 MiMo 平台发布了基于 OpenCode 构建的 MiMo Code 0.1，采用 MIT 开源协议。

## 关键信息
- MiMo 平台提供 MiMo Auto（限时免费）服务
- MiMo Code 支持小米 MiMo 平台 OAuth 登录
- 以开源方式推动 AI 编程工具生态

### MiMo 平台产品线（2026-09 更新）
2026-09-08 小米 MiMo 团队打开 [[MiMoDesktop]] 邀测闸门，同时放出 [[MiMo-X]] 系列的 MiMo-X-Pro-Preview 与 MiMo-X-Flash-Preview 两款预览版模型。与 MiMo Code 相比，MiMo Desktop 面向办公与设计场景，输出可直接编辑的文档、表格、PPT、网页、图片、音视频乃至 3D 模型与工程源码，并通过 [[Smart调度]] 把模型选择从用户手里拿走。作者评价"这次小米几乎没谈跑分，所有话术都压在'交付'两个字上"，据此判断桌面 Agent 竞争正从"答得对不对"转向"能不能把活干完"，且腾讯、阿里、字节"又多了一个对手"。详见 [[摘要-小米mimo-desktop邀测]]。
