## 简介

**敲代码的小虾米**（XiaoXiaMi）是抖音上专注于 Vibe Coding 实战教学的创作者，粉丝 1.0 万，获赞 5.5 万。其视频系列系统性地覆盖了 Vibe Coding 从立项、技术选型、架构搭建、Agent 宪法编写到 Git 版本控制、部署上线的完整开发流程。

## 代表作品

- **Vibe Coding 实战篇总结：开发全流程（上）** — 立项、功能清单、选技术栈、搭项目架构、写 Agent 宪法
- **Vibe Coding 实战篇总结：开发全流程（下）** — 立真源，落文档，敲代码
- **Vibe Coding 梭哈全流程：一个视频让 AI 使用好 GIT** — Git 在 Vibe Coding 中的安全防线作用
- **Vibe Coding 梭哈部署篇：认识几个网络** — 网络基础概念
- **Vibe Coding 梭哈部署篇：认识服务器** — 服务器选型与部署

## 核心理念

强调在让 AI 写代码之前，必须先"立好地基和规矩"——即完成需求定义、技术选型、架构设计和 Agent 行为准则的制定。认为 Vibe Coding 不是无脑让 AI 写代码，而是有纪律、有流程地调度 AI。
