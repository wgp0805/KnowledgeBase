## 定义
国产 AI 公司 MiniMax 推出的大语言模型系列与 Agent 平台，以超长上下文（1M）、严谨工程实现著称。

## 关键信息

### 主力模型
- **MiniMax M3**（2026 年）：最新主力模型，配备 1M 上下文（默认 512K，需手动切换）

### M3 长上下文使用注意
- 主要用于**项目级代码理解和重构、长文档全文处理**
- **不适合**：短问答/单轮对话、无上下文依赖的轻量创作
- Agent 中默认 512K，需 1M 时手动切换
- Prompt 结构建议：**固定内容前置**（系统提示、参考文档、代码库），**变化内容后置**（当前查询）——可提升 cache 命中率
- 官方在小红书有详细使用指南

### 实战表现（liuxin 2026-06 横评，详见 [[摘要-国产大模型实战横评]]）

| 场景 | 表现 |
|------|------|
| **Django 大型代码库 Bug 修复** | ⭐ **精准定位** `removeprefix` 不尊重路径段边界的真因，正确指向 ASGI 模块，并对比 WSGI 的 `SCRIPT_NAME`/`PATH_INFO` 处理差异（"老程序员的样子"） |
| **3D 城市躲避游戏（Three.js）** | 速度最慢但**主动写完测试**；地图大显得空旷；光影效果不错；角色戴小红帽；**双向两车道无穿模** |
| **英伟达年报 PDF 问答** | ⭐ 表格定位最准、数据最精确（Data Center vs Gaming 倍数）；多步计算（CAGR）回答与对手一致；分析师级问题回答最详细最清晰 |

### MiniMax Agent
官方提供 Agent 网页端（https://agent.minimaxi.com），2026 年新上线**金融场景模块**，链接金融数据库覆盖 A/H/美股、基金、期货、固收、宏观数据问答。

### 综合定位
**长上下文、逻辑严谨、办公场景表现领先**。在 3D 游戏视觉效果上略逊于 DeepSeek V4 Pro，但工程严谨度（主动测试、避免穿模）更胜。
