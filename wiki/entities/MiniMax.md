## 定义
中国大模型公司，开发了MiniMax系列大语言模型，是首批入驻淘宝AI空间站的厂商之一。

## 关键信息
- **商业表现**：2026年上半年开放平台及企业服务收入占比从30.3%跃升到63.4%
- **收入结构**：从"卖模型"转向"卖调用量"，从项目制转向订阅制
- **入驻平台**：淘宝AI空间站
- **服务类型**：提供Token套餐订阅服务

### 开源 Code CLI（2026-09-19）
- 把 [[MiniMaxCode]]（Code CLI v0.4.12，MIT 协议）开源，在 FrontierHarness Eval 上拿到 SOTA 通过率、最快完成时间、第二低 token 消耗
- 架构基于 [[Pi]] 开源编码 Agent 框架，详见 [[MiniMaxCode]]

### 国庆签到积分翻倍（2026-10-01，详见 [[摘要-9家ai大厂token福利]]）
- 9 月 28 日—10 月 7 日，MiniMax Code 每日签到积分直接翻倍，新老用户均可参加，活动 10 月 7 日结束

### 视频链路全链路布局（2026-07~08，详见 [[视频模型全链路布局]]）
- 7 月 31 日发布新一代多模态视频模型 [[H3]]；不到三周后的 8 月 20 日上线创作 Agent 工作台 [[MiniMaxDesign]]，由主 Agent 拆解需求、调度多智能体并行完成从脚本到成片的全流程，作为应对 [[Claude]]/[[Astra|GPT-6]] 跨界做视频的护城河策略
