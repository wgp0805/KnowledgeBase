## 定义
Node.js 是基于 V8 引擎的 JavaScript 服务器端运行时，采用事件驱动、非阻塞 I/O 模型，让 JavaScript 脱离浏览器运行于服务端，是前端工程化工具（npm/npx）与众多 AI 编码工具（Claude Code、Codex 等）的运行基础。

## 关键信息
- **生态核心**：npm/npx 包管理器，支撑 Claude Code、Codex、GSDCore、Ponytail 等工具的安装与运行
- **版本要求**：Claude Code、Codex 等通常要求 Node.js ≥ 18 或更高
- **特点**：事件循环、非阻塞 I/O、单线程 + Worker 线程、包管理成熟
- **常见应用**：前端工程化脚本、AI Agent CLI 运行时、HTTP 服务
