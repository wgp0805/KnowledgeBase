## 定义
Coze（扣子）是字节跳动推出的零代码 AI Agent 搭建平台，支持通过拖拽方式创建 Bot、配置插件、接入对话记忆并发布，面向非技术人员快速构建智能体。

## 关键信息
- 搭建流程：新建 Bot → 写提示词 → 配插件（航班/酒店/天气）→ 开启对话记忆 → 发布
- 适用人群：产品经理、运营等非技术人员
- 支持多插件接入，可快速实现订机票、查酒店、查天气等场景化 Agent
- 与 [[Dify]] 同为推荐的入门级 Agent 搭建工具

### 工作流能力（核心卖点之一）
- **AI 自动生成工作流（Text-to-Workflow）**：输入一句话（如"帮我做一个文本摘要工作流"），AI 自动拆解语义、匹配节点、规划连接与条件分支，生成后可手动微调，非黑盒
- **工作流核心要素**：触发器（何时启动）、节点（大模型/HTTP/发邮件等）、数据流（变量传递）、条件分支（选择器）、变量聚合（多分支汇合）
- **手动搭建关键经验**：选择器所有出口（含 else/false 默认分支）都必须连接，否则报错；多分支输出必须经「变量聚合」节点合并后才能被结束节点统一引用
- **设计哲学洞察**：人倾向合并步骤以简化，AI 倾向拆分步骤以提升精度——拆分让每个节点专注单一任务，在注意力分配/Prompt 难度/可调试性/可复用性/Token 效率五维更优
- **学习路线**：Coze → [[Dify]]（RAG 知识库）→ n8n（系统集成）→ 综合实战
