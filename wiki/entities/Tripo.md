## 定义
Tripo 是 3D 基座模型，可直接把文字或图片变成生产级的 3D 资产，用来生成游戏场景中的角色、怪物、道具。在第三方独立机构盲评榜单（超 20 万用户投票）上，游戏领域低多边形 3D 模型排名前二全是 Tripo 的模型。

## 关键信息
- **P2.0 模型**：秒级完成一个人物建模，生成的网格模型看起来像出自专业 3D 艺术家之手
- **调用方式**：Tripo Studio 工作台直接生成、API 接口（官方最推荐）、CLI 调用、Codex 插件（走 API 接口）
- **核心能力**：一键绑骨（给人物架骨骼产生动作）、预置 idle 待机动画库、动画重定向（把动作迁移到其他人物模型）、自动分件（3D 打印手办必需）
- **实测**：Codex 里一句指令"使用 Tripo API 生成3D模型，最高质量，调用P2.0模型"，8 分钟消耗 130 积分交付 56741 三角面 GLB 模型
- **工作流**：GPT-6 Astra 总指挥 + Tripo 生成 GLB 资产 + Three.js 搭场景
- **量产技巧**：把人物生成过程打包成 Skill 作为 3D 配方复用、动画重定向迁移动作、拆解成 5 个并行进程分批验收
