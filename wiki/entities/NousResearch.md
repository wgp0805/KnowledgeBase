## 定义
Nous Research 是 [[HermesAgent]] 的缔造者，也是 Hermes 系列模型（Hermes 3、Hermes 4）的创造团队。该团队对模型训练和推理优化有第一手积累，既是模型训练方也是 Agent 框架开发者。

## 关键信息
- **主要产品**: Hermes Agent、Hermes 系列模型、Nous Portal（统一订阅网关）
- **开源项目**: hermes-agent（186K+ GitHub Stars，MIT 协议）
- **生态建设**: 运营 Skills Hub（agentskills.io）技能市场，166+ 已追踪技能；提供 Nous-Approved 目录管理审核通过的 MCP 服务器
- **特点**: 打通从模型训练到 Agent 部署的全链路
