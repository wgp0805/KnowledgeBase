## 定义
Arthas 是阿里巴巴开源的 Java 诊断工具，被推荐为线上排查神器，在面试中提及可加分。

## 关键信息
- **定位**：线上排查神器，Java 诊断工具
- **来源**：阿里巴巴开源
- **面试价值**：在 Linux 常用命令面试中提及可加分，体现现代化诊断工具使用能力
- **对比**：与 JDK 自带的 jps/jstack/jmap/jstat/jinfo/jhat 同属 Java 诊断工具，但更强大
