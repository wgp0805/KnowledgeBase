## 定义

shadcn/ui 不是传统的 npm 组件库，而是一套将组件源码直接复制到项目中的工具和方法。核心理念是"这不是一个组件库，而是你搭建自己组件库的方式"。

## 关键信息

- **Star 数量**：11 万+
- **核心理念**：开放代码（Open Code）——组件源码在项目中，开发者完全掌控
- **技术栈**：React + Tailwind CSS + Radix UI + TypeScript
- **使用方式**：通过 CLI 命令 `npx shadcn@latest add button` 将组件源码复制到 `components/ui/` 目录
- **优势**：看得见、改得动、好维护、AI 友好
- **设计理念**：可组合（Composition）、可分发（Distribution）、好看又好用（Beautiful Defaults）、为 AI 时代准备（AI-Ready）
- **适用场景**：后台系统、官网、SaaS 产品
