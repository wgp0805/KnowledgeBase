## 定义
雪花算法（Snowflake）是 Twitter 开源的分布式 ID 生成方案：用 64 位 Long 表示 ID（时间戳 + 机器 ID + 序列号），趋势递增且全局唯一，是分库分表场景下自增主键失效后的主流替代。

## 关键信息
- **结构**：64 位 Long，高位时间戳保证趋势递增，中位机器/工作进程 ID 保证分布式唯一，低位序列号保证同毫秒并发唯一
- **优势**：趋势递增（比 [[UUID]] 对 [[聚簇索引]] 友好）、无需中心节点、性能高
- **MySQL 主键测试**：插入效率 `auto_key > random_key（雪花）> uuid`，雪花算法优于 UUID 但仍略逊于自增
- **分库分表场景**：全局唯一 ID 解法对比——雪花算法（64 位 Long 趋势递增）、号段模式（Leaf）、UUID（不推荐做主键）
- **号段模式（Leaf）**：从数据库批量取号段，内存生成，另一种主流方案
