## 定义
多态反序列化（Polymorphic Deserialization）指 JSON 反序列化时根据类型标识字段动态决定目标 Java 类型的能力，是 Jackson 历史上 20+ 个高危 CVE 的核心原因。

## 关键信息
- Jackson 实现：`@JsonTypeInfo` 注解或 `ObjectMapper.enableDefaultTyping()` 启用
- 风险：外部 JSON 可决定 Java 类型，配合特定 gadget 类实现 RCE
- 安全实践：正常使用固定 DTO 不会自动进入危险路径，禁止开启全局多态反序列化
- Jackson 2026 年又披露两项类型校验绕过漏洞，说明即使关闭默认类型，相关路径仍需持续加固
