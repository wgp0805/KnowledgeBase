## 定义
多 Agent 架构是让多个 Agent 分工协作完成复杂任务的模式，每个 Agent 有独立上下文和职责，通过协调机制共同完成任务。

## 关键信息
- **适用场景**：任务能拆分成多个独立子任务，且拆分能多出新信息
- **判断标准**：拆多 Agent 看能不能多出新信息，不能则保持单 Agent
- **优势**：并行处理、职责分离、上下文隔离
- **局限**：协调开销大、信息传递可能丢失、复杂度高
- **与 Workflow 区别**：Workflow 是固定流程，多 Agent 是动态协作
