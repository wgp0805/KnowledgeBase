## 定义
Agent 平台化指头部厂商把自家 Agent 底座（Harness、SDK、基座）开放，让第三方基于其开发 Agent，把原本只供自家产品使用的系统变成别人开发 Agent 的起点。

## 关键信息
- **核心逻辑**：Agent 从 coding 走向办公再走向通用平台，竞争越来越多落到 Context 上
- **两条开放路径**：把底座交出去让 Agent 遍地开花、把长在底座上的能力和 Agent 连接成网络
- **三条路线**：
  - Anthropic：模型往外长（Product Overhang）
  - OpenAI：模型+Harness+托管运行连成一体（Agent 的 AWS 时刻）
  - 腾讯：整机开放（Agent 时代的操作系统）
- **案例**：OpenAI 开放 Codex Harness、Anthropic 扩展 Claude Code SDK、腾讯开放 WorkBuddy 基座
