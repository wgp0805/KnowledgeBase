## 定义
LangGraph 的检查点机制会自动保存每一步执行后的状态。如果 Agent 在执行到第 N 步时崩溃，重启后可从第 N 步继续，而非从头开始，让 Agent 能运行数小时甚至数天不丢失进度。

## 关键信息
- **自动保存**：每步执行后自动 checkpoint
- **故障恢复**：崩溃重启从断点继续
- **长运行支持**：支撑数小时/数天的长流程 Agent
- **实现**：基于 Checkpointer 接口，支持内存、PostgreSQL、SQLite 等后端
- **配合中断模型**：支持 Human-in-the-Loop，暂停等待人工确认后继续
