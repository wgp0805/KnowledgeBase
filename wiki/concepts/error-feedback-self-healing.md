## 定义
工具执行错误回灌自愈是 Agent 工具调用全生命周期管理的核心机制：无论工具执行成功或失败，统一将执行结果（含完整报错信息）回传给模型上下文，**不直接终止循环**，由模型自主识别错误并纠正重试，从而避免单次工具参数或执行失败导致整个 Agent 崩溃。

## 关键信息

### pi-agent 四层可靠管控流程
1. **参数自动校验（双层兜底）**：JSON 格式化修复（转义字符串转标准 JSON 对象）+ Schema 类型强校验（自动修正参数类型不匹配）
2. **调用前安全检查**：复用 [[trace-turn]] 10 大干预节点，校验指令风险，拦截涉密文件/高危系统操作
3. **调用后结果脱敏**：工具返回数据过滤敏感信息（手机号、身份证、业务隐私）
4. **错误回灌自愈（核心）**：执行结果含报错回传模型，不终止循环

### 自愈示例（Data Agent 场景）
1. 模型生成 SQL 使用不存在数据表字段，工具抛出报错
2. 报错信息传入上下文，模型自主识别字段错误
3. 主动调用查表结构工具，重新生成合法 SQL 语句

### 落地建议
- 高频工具：预设标准化报错文案，明确错误类型与修正方向
- 低频未知错误：配置通用报错模板，保障模型纠错能力
