## 定义
Agent Memory 的功能分类，借鉴认知科学记忆概念，回答"Agent 需要记住什么"：**情景记忆**保存发生过什么，**语义记忆**保存什么是事实，**程序记忆**保存应该怎么做。三者不互斥，一个成熟 Agent 可同时利用不同类型。

## 关键信息
| 类型 | 回答的问题 | 典型内容 |
|------|------|------|
| 情景记忆 Episodic | 发生过什么？ | 历史任务、对话记录、工具调用轨迹、执行结果、成功经验与失败教训 |
| 语义记忆 Semantic | 什么是事实？ | 用户偏好、项目配置、领域知识（不依赖具体事件，跨会话有效） |
| 程序记忆 Procedural | 应该怎么做？ | 工作流、操作规范、调试策略（如"读代码→改文件→跑测试→修错误→汇总"） |

- **例**：Agent 排查数据库 Bug 最终发现是连接池耗尽——保存这段经历属情景记忆；下次可参考排查过程
- **交叉示例**："上次测试失败是因为 Redis 没启动，今后测试前应检查 Redis"同时包含情景记忆与程序记忆
- **重要澄清**：保存工作流不等于模型学会了新能力，而是系统通过外部信息帮助 Agent 重复使用既有方法
