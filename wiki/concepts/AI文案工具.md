# AI文案工具

## 核心定义
基于 AI 自动生成营销文案的工具，支持多渠道适配、品牌调性控制，实现快速出稿和效果优化。

## 关键要点
- 架构要点：多渠道适配、品牌调性控制、A/B 测试、30秒出稿
- 核心价值：降低文案生产成本，提升内容产出效率
- 关键挑战：品牌一致性、内容质量稳定性

## 详细说明

### 架构要点
1. **多渠道适配**：同一产品文案需适配微信、抖音、小红书、淘宝等不同平台风格
2. **品牌调性控制**：通过 Prompt 模板和 Few-shot 示例约束生成风格
3. **A/B 测试**：生成多版本文案，通过投放数据反馈优化生成策略
4. **30秒出稿**：快速生成能力是核心卖点，依赖高效 Prompt 和模型推理优化

### 核心价值
- 人工写一篇营销文案需 30-60 分钟，AI 工具可缩短至秒级
- 支持批量生成、快速迭代，满足高频投放需求
- 降低中小商家的专业文案门槛
