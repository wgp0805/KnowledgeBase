## 定义
个人 Skill 定制七步法是秋芝2046 提出的"把一件事做成自己的 Skill"的操作流程：挑高频任务 → 找成熟底子 → 从个人样本提炼标准 → 带真实任务边改边教 → 整理成 Skill → 盲评对比测试 → 使用中迭代。核心主张是**专属 Skill 的价值在"你独有的标准和要求"，而不是规则堆得越多越好**。

## 关键信息

### 为什么值得做（SkillsBench 实证）
- AI 凭空自编的 Skill：用了比不用还差 8~12 个点
- 网上热门 Skill：大半装了跟没装一样
- 人结合自己真实任务磨出来的：平均涨 16.6 个点
- 结论：AI 不懂你的目标和细节标准，Skill 必须由人用自己的样本和真实任务磨出来

### 七步流程
1. **选高频、AI 又做不好的任务**：两条原则——你会反复做、直接让 AI 做它做不好（如 [[去AI味]]）
2. **找 Skill 底子**：先让 Agent 搜现成的（如 [[Humanizer]]），没有就用官方 [[SkillCreator]]；留意更新时间，老模型的写死规矩会束缚新模型
3. **从样本提炼个人标准**：找 10 篇以上自己写的语料（最好没用 AI 之前写的）→ 让 Agent 分析句子长短/标点/口头禅/开头转折并附原文证据 → 人工分成"要留的、要改的、想加的"
4. **边改边教**：拿真事带它做一遍，逐句评论"不像你"的地方并告诉它你会怎么写，反复几轮直到像你，过程本身沉淀出细节标准
5. **整理成 Skill**：用 skill-creator 在底子上生成新 Skill 并起自己的名字、保留原作者署名与协议；**砍掉多余内容**（AI 只增不删，但 Skill 越短越有效）+ **拆分文件**（SKILL.md 只留主流程和目录，清单/样文/统计进 reference/，脚本进 scripts/）
6. **对比测试**：同一提示词同一件活儿，三个子 Agent 分别不用/用原版/用改好的 Skill，三份打乱标 A/B/C 盲评
7. **使用中迭代**：①**用规律替代禁令**——抓到错了先问为什么，找背后的规律和模式，一条规律拦住一类问题（别不停加"不要这样"）；②**把复盘规则写进 SKILL.md** 让 Agent 主动复盘、由人决定是否写入；③定期更新 reference 样例，模型更新后裸跑一次删掉过时规矩

### 与"带实习生"的类比
做 Skill 没有技术，像带实习生一样需要耐心：挑件值得教的事 → 找现成方法当底子 → 把干得好的给它看 → 带它干一遍 → 考考它 → 每纠正一次它就长进一次。
