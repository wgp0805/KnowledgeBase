## 定义
快照回滚是 Agent 运行时的状态恢复机制：每一轮对话开始前，对工作目录执行一次 Git 提交（快照）。当 Agent 修改文件出错时，可精确回滚到任意历史轮次的状态。

## 关键信息
- **保存粒度**：按轮次保存，用户可精确回滚到出问题的那一轮
- **频率与开销**：轮次频率较低，Git 提交开销可控
- **实现方式**：每轮对话前 `git commit -am "snapshot-round-N"`，回滚时 `git reset --hard <commit-hash>`
- **适用场景**：Agent 编写代码、修改配置、重构文件等可撤销操作
- **对比优势**：比数据库状态持久化更轻量，利用 Git 原生版本控制能力
