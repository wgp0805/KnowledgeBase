## 定义
AI 编程指用大语言模型辅助或代理完成软件编写任务的产品与技术类别，涵盖从"对话式问答"到"代理式自主改代码"的不同形态。核心分野在于 AI 对代码的理解深度：停留在文本层面的字符串匹配，还是能理解类型、引用和调试符号的语义级操作。

## 关键信息
- **能力分层**：低层是"读文本→改字符串"（易在重命名、跨文件引用上出错）；高层是接入 [[LSP]]（懂类型/引用/符号）与 [[DAP]]（驱动真实调试器做运行时诊断），达到 IDE 级操作
- **产品形态**：终端 CLI 代理（[[OhMyPi]]、[[Pi]]）、IDE 插件（Cursor、[[Cline]]）、独立桌面应用（[[Codex]]）等；区别在于上下文理解方式、工具能力与模型绑定策略。VS Code 是 LSP/DAP 机制的代表性宿主（无独立页）
- **模型关系**：多数代理不绑定单一厂商，可切换多个 provider；进阶形态可额外配 advisor 模型审查每轮输出
- **评估维度**：代码理解准确性、编辑可靠性（如 hashline 按内容哈希定位锚点减少冲突）、运行时诊断能力、上手成本与 API 成本
