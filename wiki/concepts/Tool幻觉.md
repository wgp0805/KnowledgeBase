## 定义
Tool 幻觉（Tool Hallucination）是 LLM 在 Agent 场景下的一种特定幻觉：模型调用不存在的工具、调用错误的工具、或以错误的参数/错误的顺序调用工具。[[Doubao-Seed-2.1-Pro-0915]] 将"降低工具幻觉"列为核心升级之一。

## 关键信息

### 与一般幻觉的区别
- [[幻觉|一般幻觉]]：编造不存在的 API/论文/史实（事实层面）
- Tool 幻觉：在 Agent 执行任务时，调用不存在的工具或错误调用工具（行动层面），后果更严重——直接导致任务执行失败或副作用

### 典型表现
- 调用不存在的工具（模型"以为"有这个工具但实际没定义）
- 调用错误的工具（任务需要工具 A，模型调用了工具 B）
- 参数错误（工具对了但参数填错）
- 顺序错误（多个工具调用顺序不对导致状态不一致）

### 为什么是 Agent 的关键问题
- Agent = 大模型 + 工具集 + 执行循环
- 工具调用是 Agent 推动任务往完成状态走的核心动作
- Tool 幻觉直接破坏 Agent 的可靠性，长时间任务尤其严重

### 缓解手段
- 模型层面：[[Doubao-Seed-2.1-Pro-0915]] 降低工具幻觉的专项优化
- Harness 层面：[[Harness差异化|不同 Harness 的工具定义/交互协议]] 影响工具调用成功率
- 应用层面：工具调用前的参数校验、调用后的结果验证、关键节点人工确认
