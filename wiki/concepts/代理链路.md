## 定义
代理链路指现代 Web 系统中请求从用户到应用服务器经过的多层中间件路径。典型链路：`用户 → CDN → 负载均衡器 → 网关 → 应用服务器`。每层中间件都会修改请求信息，是 `getRemoteAddr()` 失效的核心原因。

## 链路层级

| 层级 | 角色 | 对 IP 的影响 |
|------|------|-------------|
| CDN | 内容分发网络边缘节点 | 将用户 IP 写入 X-Forwarded-For |
| 负载均衡器 | 流量分发（如 Nginx/SLB） | 追加自身 IP 到 XFF |
| 网关 | API 网关（如 Spring Cloud Gateway） | 继续追加 IP |
| 应用服务器 | 后端服务 | getRemoteAddr() 拿到的是网关 IP |

## 关键问题
- **getRemoteAddr() 失效**：返回的是最后一跳代理 IP，非用户真实 IP
- **IP 头累积**：X-Forwarded-For 中的 IP 从左到右依次为：用户真实 IP → 各级代理 IP
- **内网 IP 混入**：代理链中的负载均衡器、网关通常使用内网 IP，需过滤

## 解决方案
通过解析 [[X-Forwarded-For]] 头并过滤内网 IP 获取真实客户端 IP，详见 [[摘要-springboot获取真实客户端ip]]。
