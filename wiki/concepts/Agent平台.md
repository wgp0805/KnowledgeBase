Agent 平台指承载 Agent 运行、配置与能力组织的平台类产品。来源文章提出 Agent 平台存在两种哲学：WeKnora 代表「组织的 AI 平台」，平台定义能力并约束 Agent 以保护组织；Molio 代表「个人智能体平台」，由用户自己配置 Agent 管理自己的环境。
