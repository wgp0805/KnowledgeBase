## 定义
分布式发号器（Distributed ID Generator）是在分布式环境下生成全局唯一、趋势递增 ID 的组件，解决单机自增 ID 的单点故障与写入性能瓶颈。短链接、订单等高并发场景下作为短码/业务号的唯一性来源。

## 关键信息

### 主流实现方案
1. **数据库号段模式（推荐）**
   - 数据库维护一张号段表
   - 应用一次性批量申请一大段 ID（如 1~10000），放内存用 AtomicLong 发放
   - 号段消耗完再去数据库取下一批
   - 优点：极大降低数据库访问次数，写 QPS 大幅提升，实现简单
2. **雪花算法**：64 位 Long（时间戳+机器ID+序列号），趋势递增，无需中心节点
3. **[[Leaf]]（百度）**：分布式 ID 组件，集成号段与雪花两种模式

### 为什么不用单机数据库自增 ID
- 存在单点故障
- 写入性能瓶颈
- 分布式环境下无法保证全局唯一

### 在短链接系统中的应用
1. 发号器生成全局唯一递增十进制 ID
2. ID 转 [[Base62编码]] 得到短码
3. 数学保证：ID 唯一则短码唯一，从根源消除 [[哈希碰撞]]

> 注意：直接递增 ID 作为短码会被爬虫批量遍历，对外输出使用 Base62 混淆，避免 ID 直接暴露。
