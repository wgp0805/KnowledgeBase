## 定义
任务级成本是 GPT-6 Astra 时代成本管理的方向：成本指标从单次 Token 调用变为完整任务。长任务可能经历多轮推理、多次工具调用和失败重试，只看单次 Token 数已经很难解释成本。

## 关键信息

### 为什么从 Token 转向任务
- GPT-6 Astra API 价格：每百万输入 $10、缓存输入 $1、输出 $50
- 输入超过 272,000 token 后，输入按 2 倍计费，输出按 1.5 倍计费
- Batch 和 Flex 模式可获得 50% 折扣
- 长任务多轮推理+多次工具调用+失败重试，单次 Token 数难解释成本

### 企业需要计算
- 完成一张工单花多少钱
- 每次代码修复节省多少人工时间
- 哪类任务经常重试

### 对架构设计的影响
- 简单分类/抽取/格式转换交给更便宜的模型
- 复杂判断与长任务交给 Astra
- 稳定结果进入缓存
- 超过预算的任务自动降级或转人工
- 模型路由逐渐像数据库读写分离一样成为常见工程配置
