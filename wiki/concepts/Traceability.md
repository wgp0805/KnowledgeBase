# Traceability（可追溯性）

## 核心定义
Agent 执行过程的可追溯能力。记录任务当时发生的事件（工具参数、返回结果、拒绝步骤、子任务上下文注入），使团队能在事后判断故障来源。

## 追加式会话日志
DeepSeek Harness 采用追加式会话日志，旧事件不会为迎合后续结果被直接改写。继续会话、搜索和重放都基于同一条事件流。

## 失败类型区分
- **命令返回非零状态**：程序运行了，结果不符合预期 → Agent 读取输出并修改代码
- **沙箱拒绝**：动作触碰当前范围 → Agent 请求范围更明确的授权
- **审批被拒**：命令根本没有开始 → 重新发起任务或修改设置
- **沙箱运行器不可用**：执行环境在命令开始前出了问题 → 平台维护者处理
- **任务超时**：独立情况
- **用户主动取消**：独立情况

不能统一归为"执行失败"，否则恢复动作会变得混乱。

## 回放的边界
- 重放可帮助复现问题，但外部环境可能已变化
- 文件更新、依赖版本改变、网页内容消失，完全相同的工具调用不一定得到相同结果
- 产品应区分"事件重放"和"环境复现"，避免对审计能力作出过大承诺

## 分叉会话的权限继承
新分支从旧事件开始，应继承哪些权限事实、是否继续使用原工作区，都要在创建时说明。
