## 定义

跨窗口接力是 Codex 在 [[GPT-6.1-Terra]] 中实现的**基于编号寻址的跨窗口无损记忆接力机制**：当工作窗口剩余空间不足时，不做全文摘要压缩（避免信息损失），而是把任务进度与关键记录写成结构化数据，开启干净的新窗口，再按编号把旧窗口原始内容**一字不差**地调取出来。

## 关键信息

### 触发条件

- 剩余可用空间低于 **6144 个 Token**

### 接力流程

```
剩余 <6144 Token
   │
   ▼
① notes 工具：任务进度 + 关键记录（window ID / item ID）写成结构化数据
   │
   ▼
② new_context：开启一个干净的新窗口
   │
   ▼
③ history 工具：按编号把旧窗口里的原始内容一字不差调取出来
```

### 与摘要压缩的本质区别

| 维度 | 全文摘要压缩 | 跨窗口接力 |
|------|------------|-----------|
| 信息保真度 | 有损（压缩丢细节） | **无损**（按编号原样调取） |
| 代价 | 单窗口内省 Token | 占用新窗口空间 |
| 前提 | 无需编号体系 | 需要 window ID / item ID 编号寻址 |
| 适用 | 通用上下文管理 | 长周期多模态任务（高清原图 + 长记忆并存） |

### 设计价值

- 既能读取**高清原图**（`supports_image_detail_original` 不缩略裁剪），又能**跨窗口无损调取记忆**——两者兼得
- 支撑长周期多模态评测（Agents' Last Exam v1）中 Terra 60 分反超 Sol 58.6 分的表现
