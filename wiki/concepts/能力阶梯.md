## 定义

一条**先试最便宜、最可靠的办法，再一级一级往上爬**的能力使用阶梯。核心原则：每一步都问自己，有没有更便宜的办法。

## 关键信息

### 阶梯的五级

| 级别 | 手段 | 说明 |
|---|---|---|
| 1 | 对话历史里已经知道的东西 | 零成本，最优先 |
| 2 | 插件 / MCP 服务器 / API | 例如从 Plaid 拉银行信息 |
| 3 | 网上搜 | 例如昨晚小熊队的比分 |
| 4 | 到那台电脑上开浏览器搜 | 需要启动虚拟机，成本更高 |
| 5 | 动用整个桌面 | 在 Linux 机器上写脚本、造东西 |
| 兜底 | 打扰用户 | **所有办法都失败了**才让用户输入或批准 |

### 在电脑上读取信息的子阶梯
- 截图最直接，但最费 token
- 更省的是读页面 HTML
- 更省的是读 **accessibility tree（无障碍树）**——能大幅减少 token，帮模型找到按钮和链接
- 实在不行才去点像素（比如网站弹出一个必须点的对话框）
- 碰到两步验证码、CAPTCHA，就回头找用户

### 为什么这条阶梯比任何具体技术都值得学
- 它是一个好同事的素质——**不是什么都交给上级，而是先自己排除可能**
- agent 要让人愿意长期用，就要让用户觉得「**它很少烦我，而一旦来找我，就是真的需要我**」
- 与打扰启发式配套：同事每有一点进展就来找你说「快看，我有进展了」，你肯定烦，大多数任务一天一次状态更新就够了
