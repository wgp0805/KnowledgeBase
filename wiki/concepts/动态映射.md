## 定义
动态映射（Dynamic Mapping）是 Elasticsearch 在未显式定义 Mapping 时，自动推断并添加字段类型的功能。

## 关键信息
- **推断规则**：
  - JSON 整数 → `long`（不是 `integer`）
  - JSON 浮点数 → `float`（不是 `double`）
  - `true` / `false` → `boolean`
  - 字符串 → `text` + `keyword` 子字段
  - 符合日期格式的字符串 → `date`（默认开启日期检测）
- **陷阱**：符合日期格式的字符串会被误判为 `date`，导致后续非日期字符串写入失败
- **生产建议**：显式定义 Mapping，关掉自动检测（`date_detection: false`），避免类型推断错误
- **与 MySQL 对比**：MySQL 需要显式定义列类型，ES 的动态映射更灵活但风险更高
