## 定义
浏览器录制回放（「浏览器录制与回放」Skill）：用户在网页上亲手示范一次查找与采集流程，Agent 识别其中的步骤并把它固化为可复用的方法，后续换一个查询对象（如换一个景点、换一批酒店）时沿用同一套方法继续执行。本质是"编程式示范"（Programming by Demonstration）在 Agent Skill 体系中的落地——把用户查资料的方法本身变成后续任务可以直接复用的条件。

## 关键信息
- **工作流**：示范一次 → Agent 识别步骤 → 确认查询条件（日期、范围、预算等）→ 对新对象复用方法 → 结果统一导入结构化表格（如飞书多维表格）供比较
- **实测案例（北京旅行）**：景点查询录成 Skill 后，五个景点的名称/简介/开放时间/门票/链接按同一格式入库；酒店查询（每晚 400–800 元、评分 8.5+、按景点距离）录一次后换景点继续沿用，最终保留 18 条候选记录
- **产品价值**：解决"选择太多却缺少比较依据"的问题——人只决定预算与位置偏好，工具接手重复进页面、提取字段、整理表格的工作；信息有了共同格式和可回查来源，下一步选择不必从收藏链接堆开始
- **与传统 RPA 的差异**：由 Agent 识别步骤而非录制选择器脚本，条件（日期、范围、数量）可在执行前被 Agent 向用户确认，换对象不需重录
- **与多 Agent 并行的关系**：录制回放处理"同一方法反复执行"的重复劳动，多 Agent 并行处理"不同方向同时搜集"的研究任务，二者构成个人 Agent 接住整段任务的两条执行路径
