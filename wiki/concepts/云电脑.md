## 定义
云电脑指 Personal Agent 架构中分配给每个用户的、24 小时在云端独立运行的完整 Linux 机器，自带浏览器与文件系统，是 Agent "你不在也在跑"的物理载体。它把 Agent 的执行环境从用户本地设备搬到持久在线的云端，是 2026 年 Personal Agent 赛道爆发的共同底层架构（Meta Muse 的 Secure VM、OpenAI Dots、纳米Work 均属此路线）。

## 关键信息
- **蚂蚁灵光新版架构**：给每个用户分配独立 Linux 云电脑，24 小时云端运行，有自己的浏览器；可在上面装必要工具——作为 Personal Agent 的能力边界远比"电脑上运行的普通 Agent"更强
- **开放连接**：用户可让 Agent 接入自己的 MCP、CLI、各种 Skill，支持第三方工具的 Harness 能力；云电脑里的 Agent 甚至可被再当子代理用（实测：在云电脑里装 Claude Code 当执行子代理，顺手写个计算器小程序）
- **实测价值**：作者过去把日程/排版/知识库等封装成独立 Agent，但分散各处管理成本高；通过"自己的服务做页面+后端 → Claude Code 访问 → 灵光云电脑浏览器发指令连接自己电脑"，实现一句话把电脑文件发手机、一句话调用电脑上的各种 Agent，且是三分钟跑完任务、比桌面 Work Agent 快
- **其他同路线产品**：[[MetaMuse]]（Secure VM）、[[Dots]]（OpenAI 云电脑）、[[纳米Work]]（360，7×28 上线早于 Muse）、[[GrokBot]]（多角色共用一台云端电脑）
