# Anaconda

## 定义
预装 conda 与数百个数据科学库的 Python 发行版，定位"数据科学全家桶"。

## 关键信息
- 预装 conda（包与环境管理器）、Jupyter Notebook 及 NumPy/Pandas/Matplotlib/scikit-learn 等几百个数据科学常用库，适合数据分析、机器学习方向（本课程第三阶段起大量用到）
- 官网 anaconda.com，体积较大约 1GB，可选精简版 miniconda
- **课程立场**：主线直接用官网 Python + `pip install`，Anaconda 作为"懒人全家桶"备选、不强制
- 自带的 Jupyter Notebook 是"网页版交互式编程"工具，量化部分（Day53 起）会用到，届时再展开
- 工具分工定位：初学用 [[IDLE]]、专业开发用 [[PyCharm]]、数据科学用 Anaconda
