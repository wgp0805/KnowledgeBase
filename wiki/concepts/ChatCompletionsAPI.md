# Chat Completions API

Chat Completions API 是 OpenAI 传统单轮对话接口，与新一代 Responses API 相比不支持内置工具和多轮编排。简单调用场景仍适用。

## GPT-6 Astra 时代
- **GPT-6 Astra 不再支持 Chat Completions API**，只支持 [[ResponsesApi]]
- Chat Completions 的核心体验接近"发消息，等回复"，无法承载异步工具调用和长任务状态延续
