## 定义
运行在桌面端、以"交付可继续使用的成果"为核心目标的 AI Agent 形态。与以对话为中心的传统助手不同，桌面 Agent 的评分标准是能否把活干完，而不仅是答得对不对。

## 关键信息

### 四个特征（以 MiMo Desktop 为代表）
1. **混合素材直投**：表格、图片、视频、PDF、录音乃至未解压压缩包可直接作为上下文，不用先整理或转格式
2. **成果可编辑**：输出是文档、表格、PPT、网页、图片、音视频乃至 3D 模型、App 与工程源码，且支持[[局部编辑]]与版本回退
3. **预览是真页面**：包含组件结构、交互逻辑、状态变化与数据可视化，在会话里可直接点击体验，而非静态截图
4. **浏览器即执行环境**：既能作为信息入口（打开网页、检索、填表、提取素材），也能在同一工作流里检查生成成果的关键交互、自动验证——相当于给交付物加一轮自动化验收

### 竞争格局的信号
- 桌面 Agent 赛道已有 [[Codex]]（OpenAI）、Claude Code（Anthropic）、[[MiMoDesktop]]（Xiaomi）等参与者
- 2026-09 时段 Xiaomi 入场后，作者称腾讯、阿里、字节"又多了一个对手"
- 关键观察：厂商话术从跑分转向"交付"，说明竞争维度正在切换

### 与编程 Agent 的关系
桌面 Agent 是编程 Agent 的能力外延：编程 Agent 交付代码，桌面 Agent 交付任意办公与创作成果。共享的底座是 [[MCP]]（接第三方工具）、[[HarnessAgent]]（能力被当作工程组件）、多模型路由与上下文缓存。
