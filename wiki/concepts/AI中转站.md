## 定义
AI 中转站（API 中转站）是介于用户与 AI 模型服务（如 GPT、Gemini、Claude）之间的中间代理层，本质是 API 网关 + 聚合转发服务。

## 关键信息
- **运行原理**：用户请求 → 中转站用官方 API Key 调用模型 → 模型返回结果 → 中转站转发给用户
- **解决的问题**：
  1. 绕过国外 AI 模型的访问壁垒
  2. 聚合多家模型 API，提供统一入口
  3. 提供标准化接口，简化多模型适配
- **盈利模式**：
  - 汇率与支付溢价（人民币收款）
  - 批零差价（批量低价账号拆分零售）
- **风险**：
  - 跑路坏账（预充值模式）
  - 数据隐私泄露（明文传输）
  - 服务不稳定（多层代理延迟）
  - 模型以次充好
  - 虚报 Token 计费
