## 定义
面向办公场景的 Agent 形态：文档生成、数据清洗、会议总结、日程协作；豆包工作、千问办公、WorkBuddy 为代表。共同特征是以本地文件夹/工作区为中心，让 AI 直接碰用户的文件与工作环境，而不只是聊天。

## 关键信息
- **代表产品**：[[豆包工作]]、千问办公、[[WorkBuddy]]
- **新玩家（2026-09-25）**：[[DeepSeek]] 推出官方桌面客户端 [[DeepSeekHarness]]（nightly），支持本地工作区读写、联网搜索、终端操作与多 Agent 协作——DeepSeek 从"模型、网页、App、API"扩展进 AI 办公赛道，凭模型品牌与用户基础成为重量级玩家（详见 [[摘要-deepseek-harness桌面客户端]]）
- **与 [[桌面Agent]] 的关系**：办公 Agent 是桌面 Agent 的主流场景切面，共享工作区、工具调用与多智能体协作底座
