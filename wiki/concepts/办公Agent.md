## 定义
面向办公场景的 Agent 形态：文档生成、数据清洗、会议总结、日程协作；豆包工作、千问办公、WorkBuddy 为代表。共同特征是以本地文件夹/工作区为中心，让 AI 直接碰用户的文件与工作环境，而不只是聊天。

## 关键信息
- **代表产品**：[[豆包工作]]、千问办公、[[WorkBuddy]]
- **新玩家（2026-09-25）**：[[DeepSeek]] 推出官方桌面客户端 [[DeepSeekHarness]]（nightly），支持本地工作区读写、联网搜索、终端操作与多 Agent 协作——DeepSeek 从"模型、网页、App、API"扩展进 AI 办公赛道，凭模型品牌与用户基础成为重量级玩家（详见 [[摘要-deepseek-harness桌面客户端]]）
- **与 [[桌面Agent]] 的关系**：办公 Agent 是桌面 Agent 的主流场景切面，共享工作区、工具调用与多智能体协作底座
- **选型十维度（2026-10-03，程序员小灰，详见 [[摘要-workbuddy-vs-豆包工作-10维对比]]）**：定位 / 上手门槛 / 复杂任务执行 / 执行环境（本地 vs 云电脑）/ 办公交付能力 / 权限安全机制 / 生态连接器 / 远程控制 / 定时任务 / 计费模式（积分制 vs 额度制）。核心判断：不存在"谁绝对更好"，取决于 **资料在哪、团队在哪、用得多不多**——WorkBuddy 胜在腾讯系连接器与本地执行+积分制，豆包工作胜在云电脑+飞书交付+额度制
- **形态共性**：派活→干活→交付闭环、工作空间/云电脑双执行环境、技能与连接器扩展、远程通道与定时任务
- **行业垂直落地模式（2026-10-05，详见 [[摘要-workbuddy-汽车业四场景]]）**：汽车流通行业（4S 店半年亏 55.7%、利润压到售后/续保/置换）给出四场景范式——销售跟进/售后回访/车源文案/跟进台账，套路统一为"提示词模板 + 行业 Skill + 人工红线"（价格当天核实、回访频率上限、持牌业务人工讲解、隐私字段不进台账）；与此前[[摘要-workbuddy-美业四场景]]、[[摘要-workbuddy-建筑业四场景]]共同构成"行业场景包"打法：一个行业抽 4 个动嘴动笔的高频场景，每个场景=痛点+解决思路+可复制提示词+推荐 Skill+合规红线
