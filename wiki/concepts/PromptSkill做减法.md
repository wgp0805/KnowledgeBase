# PromptSkill做减法

## 核心定义
模型越聪明，Prompt 和 Skill 越需要精简的趋势。强模型理解能力强，过度约束反而限制能力发挥。

## 关键要点
- 核心逻辑：强模型理解能力强，过度约束反而限制能力发挥
- 模型能力提升 → Prompt 复杂度下降 → Skill 规则精简
- 做减法不是不做，而是去掉冗余约束，保留核心意图

## 详细说明

### 核心逻辑
随着大模型能力持续提升：
- **理解能力增强**：模型能从简短指令中准确推断意图
- **推理能力提升**：复杂任务可由模型自主分解，无需 Prompt 逐步引导
- **遵循能力改善**：模型更可靠地遵循核心规则，减少需要强化的细节约束

### 做减法的表现
1. **Prompt 精简**：从冗长的 Few-shot 示例简化为核心指令
2. **Skill 规则减少**：去掉过度细化的边界条件，保留核心原则
3. **约束放松**：给予模型更多自主决策空间

### 注意事项
- 做减法不等于不写 Prompt，核心意图和边界仍需明确
- 安全相关约束不可精简，宁可冗余不可遗漏
- 需根据具体模型能力水平动态调整，弱模型仍需详细引导
