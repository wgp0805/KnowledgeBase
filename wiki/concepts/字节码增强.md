## 定义

字节码增强指在**类加载前或运行期**修改 Java 类文件的二进制字节流，向方法中插入额外逻辑（埋点、耗时统计、日志、异常处理、监控）而不改动源码。它是 Java Agent、APM 探针、AOP 框架（CGLIB）、热更新等能力的底层实现手段。

## 关键信息

### 工具演进

| 工具 | 层次 | 特点 |
|------|------|------|
| **ASM** | 底层 | 直接操作 ClassNode/MethodNode，性能最高、学习曲线最陡 |
| **bytekit** | 简化层（阿里） | 基于 ASM 提供注解式 API：`@AtEnter`/`@AtExit`/`@AtExceptionExit` + `@Binding` 参数绑定，大幅降低编写难度 |
| Javassist | 高层 | 源码字符串式增强，易写但性能与灵活性弱于 ASM |
| ByteBuddy | 高层 | 链式 API，现代主流选择之一 |

### bytekit 注解模型

- `@AtEnter(inline=false)`：方法进入时插入，`inline=false` 表示"调用增强方法"，`inline=true` 表示"代码直接内联到原方法"
- `@AtExit(inline=true)`：方法退出时插入，`@Binding.Return Object returnObject` 绑定返回值
- `@AtExceptionExit(onException=RuntimeException.class)`：异常退出时插入，可绑定异常对象与字段
- `suppress`/`suppressHandler`：声明插入代码被 try/catch 包围
- 验证方式：`Decompiler.decompile(bytes)` 反编译查看增强后代码——可见代码量剧增，但语义正确

### ASM 使用要点（以计时案例为例）

```java
ClassReader cr = new ClassReader(classfileBuffer);
ClassWriter cw = new ClassWriter(cr, ClassWriter.COMPUTE_FRAMES);
ClassVisitor cv = new TimeStatisticsVisitor(Opcodes.ASM7, cw);
cr.accept(cv, ClassReader.SKIP_FRAMES | ClassReader.SKIP_DEBUG);
return cw.toByteArray();
```

- 自定义 `ClassVisitor#visitMethod` 返回 `AdviceAdapter`（ASM 提供的简化适配器）
- `onMethodEnter()` / `onMethodExit(opcode)` 里用 `visitMethodInsn(INVOKESTATIC, ...)` 插入静态方法调用
- 注意：**构造方法 `<init>` 通常要跳过**

### 与相关技术的关系

- **AOP**（Spring）：基于动态代理（JDK Proxy/CGLIB），只能增强被代理的 Spring Bean 方法，存在自调用失效等边界；字节码增强可作用于任意类、任意方法，更底层
- **Java Agent**：提供"何时增强"的挂载机制（premain/agentmain），字节码库提供"如何增强"
- **热更新**：Arthas 的 `mc`（内存编译）+ `redefine`（重定义）本质也是字节码替换（注意只能改方法体，不能增删字段方法）
