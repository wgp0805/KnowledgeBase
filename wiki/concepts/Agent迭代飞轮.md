## 定义

Agent 迭代飞轮（Agent Self-Iteration Flywheel）是《Your Game Is A Harness》提出的终极形态：把确定性输入、结构化且免编译的状态修改途径、完全隔离的毫秒级验证环境、以及文本化的性能与视觉评估全部串联起来，让一个原本在传统引擎里需要**数分钟甚至数十分钟**的 Agent 迭代轮次被压缩到**数秒之内**——这就是专为游戏量身定制的终极 Harness。

## 关键信息

### 飞轮的组成部分（对应八条原则）
| 环节 | 支撑机制 |
| --- | --- |
| 确定性输入 | 全局单一随机种子源（[[确定性]]） |
| 可寻址状态 | [[FatStruct]] 单一结构体 + [[命令模式]] 命令流 |
| 免编译修改 | [[外部化数据管理]] + JSON 命令注入 |
| 隔离验证 | [[无头模拟内核]] 纯内存秒级测试 |
| 视觉验收 | 引擎渲染开关 + [[图像差分]] 相似度数值 |
| 性能评估 | [[纯文本性能分析]]（samply 输出到终端） |
| 上下文健康 | 避免[[上下文污染]]，让模型始终只看到高质量信息 |

### 为什么"快"是决定性的
因为它从根本上消除了让大模型步履维艰的两大障碍——**上下文盲区**（游戏内部对模型不透明）与**编译等待**。正因为闭环运行得如此迅捷、精准，这套流程才可以无差别地覆盖到开发过程中的**每一次微小改动**，而不再是等到积重难返时才做一次昂贵的集成测试。

### 核心原则
**确保每一次改动都是达成目标所需的最小改动，并能被毫秒级验证。** 这要求一个极其稳定、近乎"乏味"的代码基线，可以在近乎完全隔离的真空环境中执行推演，杜绝技术债务与面条代码的蔓延。

### 与通用 Agent 飞轮的关系
仓库中其他来源描述的 Agent 自主循环（[[ReAct_Agent]]、[[LoopEngineering]]、[[AgentHarness]]）解决的是"Agent 怎么想、怎么调工具"；本概念补充的是**运行环境侧**的前提——让被改造的对象本身变成 AI 可读、可操作、可验证的形态。二者是同一枚硬币的两面。
