## 定义
Personal AI Agent（个人 AI Agent）：长期围绕单个用户工作的 AI 助理形态。与 ChatGPT/Gemini 式一问一答不同，用户交给它的不是单个提示词而是一个项目或长期目标——记住偏好、连接邮件日历与社交账号、在云端虚拟机中全天候推进任务，退出 App 后后台任务继续。与之相邻的两个特征是 Personal（长期围绕一个人）与 Proactive（主动推进事情），二者并不冲突。

## 关键信息
- **能力栈**：云端/安全虚拟机（持续行动）、长期记忆（夜间写入反思、可迁移）、Connector 接入外部服务、定时任务与子 Agent、权限与凭据系统、目标拆解与追踪
- **设计门槛**：扎克伯格主张这类能力必须从预训练开始设计——理解个人长期目标、判断信息可否披露，不能靠通用模型后训练加界面补出来
- **体验门槛**：能力太多反而让用户不知道拿它干嘛，需要 Ideas/推荐任务降低首次使用空白感；能力拆开都见过，价值在于不让普通用户意识到自己在调用多少 Agent 能力
- **赛道玩家**：Meta Muse、OpenClaw（极客侧鼻祖，长期在线 + 自有电脑 + 工具调用）、Instinct、Town 等；国内支付宝鱼来/阿宝切入生活消费侧
- **竞争判断**：具备个人 Agent 最先进水平的公司可能不超过十二家；平台间可通过 Agent 匿名化经验学习形成网络效应
- **阶段判断（2026-09-29）**：个人 Agent 已从"概念"进入"产品"阶段——Muse 几百万下载证明普通人愿意排队下载一个替自己干活的 AI，需求真实存在
- **共同底层架构**：形态各不相同（独立 App、常驻云电脑、住进微信），底层几乎一样——常驻云端的独立计算环境，连接用户的账号，长时间自主执行，关键节点找用户确认（详见 [[摘要-豆包Spell对标Muse]]）
- **国内战局（2026-09-29）**：阿里千问 9-22 云栖大会宣布加速打造 Personal Agent（依托 3 亿用户，健康/理财等方向已接入个人数据，开放平台申请入驻伙伴超 1000 家）；腾讯 [[LightVela]] 已在微信里跑起来、被视为"中国版 Muse"头号受益者；[[Manus]] 国内版产品与团队在筹备；字节 [[Spell]] 箭在弦上；OpenAI 据 The Information 报道正基于开源框架 [[OpenClaw]] 做内部代号 "Codex Bot" 的产品，直接对标 Grok Bot 和 Muse
- **围城判断**：国内不会出现"中国版 Muse"，会出现"几座围城里的 Agent"——阿里最懂淘宝支付宝、腾讯住在微信、字节离不开抖音本地生活，短期难有跨平台畅通办事的 Agent；没有自家围城的独立玩家反而敢做真正的"连接者"
- **生死指标**：不是下载量（分发能堆出来），而是任务完成率、复用率、用户愿意授权多深、每完成一个任务要花多少钱
- **无界面路线（Instinct，2026-09-30）**：与 Muse 的"AI 原生 App"相对的另一极——不做独立 App，给 Agent 配电话号码、邮箱和云端电脑，像联系真人助理一样发短信/打电话交互；为支撑免费必须自研混合推理+批处理+蒸馏剪枝管线（吞吐提升 3-8 倍），商业模式从交易网络收 Take rate（对标 Apple Pay/美运通），拒绝广告变现；用户绑定至少一项敏感资产后留存约 80%（详见 [[Instinct]]、[[摘要-instinct创始人对话个人agent]]）
- **大厂集体冲锋时间线（2026-09）**：9-08 Meta Muse → 9-22 阿里千问加速变 Personal Agent（核心词 Context 与"时间感"）→ 9-26 腾讯 LightVela 集中报道 → 9-29 字节 Spell 曝光 + OpenAI 发布 [[Dots]] → 9-30 腾讯 Handy Bot 浮出；腾讯三线并行（小微守微信、LightVela 卖云、Handy Bot 冲 C 端），办公线与个人线几乎每家大厂都在同时做
- **产品形态分野**：办公 Agent 是"帮你干活的同事"（授权都在自己手里的文件/公司系统，已跑出规模），Personal Agent 是"替你过日子的管家"（要的权限很多不在自己手里——淘宝账号是你的但"店"不是你的）；技术底座趋同但面对的"墙"高度完全不同，详见 [[围墙花园]]
- **a16z 产品哲学（2026-09）**：消费者不在乎"提升 10% 效率"而在乎省钱（free money 场景最易建立信任）；[[Agent主动性]]（Proactivity）是真护城河但有红线——不可逆动作必须先问；理想形态是 Invisible Agent（骑车 30 分钟语音指挥，到办公室 inbox zero）；雄心勃勃的 personal agent 每用户每天约 20 美元成本，主导产品免费靠大厂烧钱；assistant（辅助）与 agent（受托决策）的心理差异决定信任建立方式（详见 [[摘要-a16z-personal-agent对话]]）
- **六条海外路线与五维度评估框架（2026-10-01）**：胜负手不是功能数量而是 [[默认委托权]]——五维度为入口/上下文/权限/执行/信任，六条路线：[[Dots]] 第二身份（always-on、Custom Rules 分级授权、后台主动研究只读）、[[MetaMuse]] 生活交易（Muse Secure VM、Stripe Link 一次性卡、邮件只读/代发分级）、Gemini Spark 数据调度（借 Gmail/Docs/Calendar，云端 24/7）、[[Instinct]] 无新界面（成为联系人本身，接邮件/屏幕/音频/位置，可主动来电）、[[GrokBot]] 数字员工队伍（多角色分工、共用一台云端电脑、含在付费 Cursor 计划）、[[OpenClaw]] 所有权（local-first、模型无关、自托管，代价是把责任从厂商转移给使用者）；另 Siri AI（系统级入口）与 Alexa+（家庭声音入口）随时可能改写竞争；终局判断：一个总入口 + 多个专业 Agent，竞争也发生在 Agent 与 Agent 之间（详见 [[摘要-personal-agent六条海外路线]]）
- **国内三家的切入方式与产品特点（2026-10-03，详见 [[摘要-豆包千问元宝转向personal-agent]]）**：国内前四通用 AI 助理除 [[DeepSeek]] 外集体转向——豆包做对标 [[MetaMuse]] 的产品（代号 [[Spell]]、名或叫 [[小豆]]，工期 6 天，实为既有项目整合）；千问是"把自己定位为 Personal Agent"，郑嗣寿 9-22 云栖提出第一步构建**全域终生 Context**（通用 Context 按身份、领域级 Context 按场景、多终端 Context 按眼镜/穿戴数据），未来几个月推统一 Personal Agent；[[Yuanbao]] 据权威媒体正在筹备、加模块还是独立产品仍在评估。**六条产品特点**：围绕个人自主办事关键节点人确认 / 独立云端虚拟机 24h 运行 / 链接日常服务 / 长期记忆与长周期任务 / 多入口多终端 / 安全可控用户愿授权——纯消费级 C 端、围绕生活状态而非任务，比拼服务能力与生态链接而非模型能力（三分靠模型七分靠应用）
- **大厂组织能力之战（2026-10-02，详见 [[摘要-小豆个人agent卡位]]）**：字节独立个人助理应用内部可能定名 [[小豆]]（李福祥 Chat 与搜索线主导、[[Spell]] 供端侧能力，另起炉灶不并入豆包——两套数据飞轮与评测指标难以共存）；腾讯三路各有限制（小微受微信克制哲学束缚、[[LightVela]] 门槛偏高、Handy Bot 最接近 Muse）；技术路线分化——Meta 全栈重做底座 vs Instinct 死磕推理管线（Agent 单次复杂任务 Token 消耗可达普通对话数十倍，不控推理成本会陷入"用户越活跃账面越亏"死循环）；国内超级 App 高墙下个人 Agent 可能异化为"平台 Agent"，浮现"代表用户还是代表平台"的信任悖论；要建立深度信任与全天候响应，终局必然走向随身硬件与终端操作系统
- **2026 年 Agent 战场三段论（2026-10-04，详见 [[摘要-腾讯四款muse产品盘点]]）**：上半场"龙虾狂热期"（所有公司入局虾场、全民养虾，已退场，没有赢家或者说所有人都成了赢家——龙虾为 Agent 的到来铺路）→ 中场"办公 AI Agent 战争"（[[WorkBuddy]] 暂时性胜出但战争远未结束）→ 下半场"个人 AI Agent"（被 Muse 验证有巨大用户需求、盈利早期阶段尚未跑通）；中秋国庆之际腾讯、字节、阿里都在大力压局
- **四条判定标准与发展三要素（2026-10-05，小普，详见 [[摘要-grok-bot-六助理ai团队]]）**：算不算 Personal AI Agent 看四件事——**能替你动手**（用工具登账号办事）、**记得你**（偏好规矩存长期记忆）、**你不在也在跑**（定时+触发）、**该你拍板时回来找你**；想法很老（1987 Apple Knowledge Navigator、90 年代 MIT Pattie Maes software agents、2011 Siri、2023 AutoGPT 常绕圈出不来、2024 Rabbit R1/Humane AI Pin 硬件失败、2025 Operator/Manus 又慢又贵）但 2026 才火，凑齐三样：模型真能连续干活（Claude Code/Codex 在程序员处先证明）、Agent 有了自己的云端电脑、入口变成聊天（OpenClaw 几个月 30 多万 star 证明需求、Muse 九月登顶美区 App Store 挤下 ChatGPT 出圈）；多助理群场景新增一层问题：谁先说/说多长/几点能说/吵起来谁拍板，需要自己写群规（第一指令）——单 Agent 一份 system prompt 就够，一群 Bot 则要额外的交互协议
- **术语被重新占据（2026-10-04，详见 [[摘要-tencent-handybot官方回应]]）**：Personal AI Agent 本不是新事物（以前的 AI 管家/AI 助理、云端 [[HermesAgent]] 及各种智能体都属此类），但 Muse 爆火后被媒体反复代指，借维特根斯坦"词语的意义在于它的使用方式"——不是新事物发明了旧名称，而是**旧名称被新现象重新占据**：以后说 Personal AI Agent 默认指 Muse 这类有长期记忆、云端 24 小时主动办事的形态

- **"活儿它来干，主意我来拿"：授权边界成为信任分水岭（2026-10-06，详见 [[摘要-nanowork-personal-agent省200刀]]）**：Muse 靠省钱出圈（砍宽带费省 1920 刀/年省车险 3500 刀/追回遗忘订阅 200 刀）但授权翻车——「始终允许」后未经确认 10 刀贱卖键盘并泄露地址致陌生人上门，另有记者称拒绝授权仍被读到 18 万多条私信（Meta 否认）；国内 [[纳米Work]]（360，云电脑 7-28 上线早于 Muse）用"敏感操作停下等确认 + 交付物截图留底 + 手机端 7×24 可见"做安全可控，实测从 Vercel 账单激增查到项目被刷量省下 200 多刀、GitHub 体检查出 5 处密钥泄露，获 IDC 2026 安全可控维度唯一 Top 产品——Personal Agent 的信任不只在"能干什么活"，更在"干的时候你心里有没有底"

- **委托经济学与信任架构（2026-10-08，详见 [[摘要-agent信任与决策权100条]]）**：从 Answer→Action 的转变看赛道，商业模式争的是早已存在的分发费（旅行分发费只是冰山一角），免费→信任→委托→交易抽成；衡量指标从日活换成**权限深度、委托钱包份额、委托 GMV**；信任三重结构（能力/立场/程序）+ 代理人宪法（最小权限、额度隔离、双确认、审计）；授权按最大损失/可逆性/外部性三轴分档；美国难在服务集成、中国难在调用权限（超级生态已存在，争的是通行证，可能走交易原生路线）；终局判断：两三个委托入口 + 大量执行层，成熟产品需个人上下文、判断与信任、服务图谱、交易经济**四种资产相乘**

- **技术三支柱与医疗试金石（2026-10-08，详见 [[摘要-personal-agent-技术内核与医疗落地]]）**：支撑该品类的三根技术支柱——**分层记忆**（工作/长期/技能记忆，须记忆隔离、删除即清除）、**MCP 协议**（Agent 世界的 USB，按场景动态加载而非堆插件）、**权限分级**（只读默认允许/低风险可自动/高风险必须确认 + Auto-review）；医疗场景加一条"谁签字谁负责"（AI 只写草稿不诊断不开处方）；四款对比：[[Dots]] 云端全能但无 HIPAA、[[GeminiSpark]] 谷歌生态生活调度、[[ClaudeCowork]] 本地虚拟机文档专家、[[DAXCopilot]] 垂直临床（每次接诊省 5 分钟）；演进四阶段：对话式助手→单点执行→后台常驻→多 Agent 数字共生，本质让渡的不是决策权而是注意力

- **开源平替与旅行高频场景（2026-10-09/10，详见 [[摘要-personal-agent-open-source-alternatives]]、[[摘要-doubao-work-travel-ppt]]）**：三款爆火 Personal Agent 出现 GitHub 开源平替——[[Rakazo]]（对 Grok Bot，多 Bot 分工、模型与电脑环境自选、可本地/服务器常驻）、[[OpenMuse]]（对 Muse，CopilotKit 出品，持久浏览器+定期监控页面价格阈值提醒）、[[OpenDots]]（对 Dots，多专业助手+Space/Page 草稿审核工作流），共同点是自托管、后台常驻、执行环境可配置；旅行被实测验证为高频场景——klook 调查超七成规划者规划一次旅行花 10 小时以上，Meta 把预订旅行列为 Muse 代表用途，[[Instinct]] 创始人 [[NoahShinn]] 称旅行约占平台交易额一半，「豆包工作」用 Skill 录制 + 三 Agent 并行把几十小时攻略浓缩成 20 页行程 PPT
