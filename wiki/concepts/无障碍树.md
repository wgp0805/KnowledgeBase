## 定义
无障碍树（Accessibility Tree）是浏览器为屏幕阅读器等辅助功能维护的页面结构化描述树：它记录页面上有哪些按钮、输入框、链接及其文本语义，而不依赖 CSS 样式与 class 名称。

## 关键信息
- **为什么是 Web Agent 的关键**：传统自动化（Selenium/Playwright 选择器页面一改就整片失效）与截图视觉方案（每轮都要处理图像，token 高、响应慢）之间有三条路线，无障碍树是中间路线——模型拿到的是一份结构化页面说明，结合任务目标自行决定操作顺序，"元素定位"从代码里转移到模型推理里
- [[BrowserUse]] 即以此为核心：把无障碍树交给大模型，Agent 用自然语言完成任务链路
- **局限**：结构复杂、动态渲染很强的页面上模型仍可能判断失误，结果取决于推理质量，可结合 `use_vision=True` 视觉辅助兜底
- **适用判断**：页面常改、任务偏一次性、希望非技术同学参与 → 无障碍树路线合适；高频、稳定、接口级测试 → 传统硬编码仍占优
