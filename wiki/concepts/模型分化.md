## 定义
模型分化：模型厂商不再只把旗舰模型做得尽量全能，而是按任务的复杂度、调用频率、响应速度和成本重新切分能力档位，让不同模型承担不同工作——从"一个最强通用模型打天下"走向"按任务结构给具体环节做取舍"的多档位供给。

## 关键信息
- **分化信号（2026 年）**：Google 5 月推 Gemini 3.5 Flash；DeepSeek 7-31 发布 V4 Flash（后更新 V4.1 Flash，并把 V4 Pro 的 API 请求路由到 V4.1 Flash 按 Flash 价格计费）；8 月下旬 Qwen3.8-Flash-Next 和 GLM-5.3-Flash 接连亮相——flash 模型扎堆
- **不是阉割版**：这些模型未必追求所有 benchmark 最高，也非简单砍能力的降级版，而是为高频、简单任务专门优化出的新档位，价格更划算
- **极端样本 Jev**：把一类能力（判断）从通用模型中彻底分离单独成模型——输出 Choice/Score/Boolean + 概率，不解释、不写自然语言，为 Agent 提供可直接往下走的明确信号；背后是对 RLHF 让模型"没把握也给笃定回答"的反思，试图把不确定性写进输出
- **分化的推动力**：Agent 从代码场景向办公场景扩散（OpenAI 数据：2 月到 6 月企业周活 Codex 用户在法律、销售招聘、市场营销增长 108 倍、41 倍、26 倍），模型成为持续执行任务的基础设施，调用频率与 Token 消耗激增
- **衍生格局**：任务本身成为 Agent 的核心，按任务调用不同模型（复杂推理给强模型、简单判断给快便宜模型）在同一 Agent 里协作——一个能按任务路由多模型的 Agent 入口因此更加重要
- **与"模型分化"相邻的判断**：模型之间的关系从"谁更强、强了就替换"变成"各司其职、同框协作"
