## 定义
规则引擎是一种组件，可以嵌入到应用程序中，将复杂的条件判断规则从业务代码中剥离出来，使得业务系统只需关注核心业务逻辑。它接受一组输入数据，通过预配置的规则进行计算，最终输出一组结果。

## 核心架构
规则引擎的通用构成包含三个部分：
1. **如果（If）**：配置规则的条件判断
2. **那么（Then）**：满足条件后执行的动作
3. **否则（Else）**：不满足条件时执行的动作

## 常见规则引擎
- **URule** — 纯浏览器可视化编辑，Java 平台
- **Drools** — 功能强大的企业级规则引擎
- **Aviator** — 轻量级 Java 表达式引擎
- **EasyRules** — 基于注解的轻量规则引擎

## URule 核心概念
URule 的规则配置围绕四种库文件和三种规则集组织：

**四种库文件：**
- **变量库** — 映射 Java POJO/DTO 等数据载体对象到规则配置中
- **常量库** — 管理枚举和常量，与 Java 枚举类型相互映射
- **参数库** — 规则的临时变量，结构类似 Map，key-value 形式存储
- **动作库** — 映射 Spring Bean 方法到规则中可直接调用的动作

**三种规则集类型：**
- **向导式规则集** — 鼠标可视化配置，门槛最低，是 URule 的最大亮点
- **脚本式规则集** — 需要编写脚本配置规则，适合有开发经验的人员
- **决策表** — 表格形式展示规则，直观易理解，非技术人员也能看懂

## 典型应用场景
- 复杂条件判断场景（多层 if-else 分支）
- 用户等级晋升规则
- 风控审批规则
- 价格计算与折扣策略
- 需要业务人员参与配置的场景
