## 定义
Agent 时代的分发法则：当分发由 agent 决定，而 agent 又是看留存来选择推荐对象时，质量本身就成了分发。产品无法再靠包装、关键词或活动换来长期位置，因为 agent 是一种会"用脚投票"的新用户。

## 关键信息
- **出处**：Tibo 被问及插件如何被 ChatGPT 推荐时只答"做好插件"——系统看留存、使用质量，据此在对话里推荐，不好的插件会被停止推荐；他同意这不同于 AEO（针对 AI 的搜索优化）靠写对关键词
- **与传统分发的区别**：AEO/SEO 时代靠关键词与包装，agent 时代用户（agent）持续使用才算数
- **对产品团队的推论**：会被 agent 调用的产品要为 agent 规模的流量做好准备（Notion 做好 MCP 后流量涌入的教训），并提前算清这笔账
- **姊妹判断（脚手架贬值）**：为模型搭的循环、流程图、harness 有一部分只是弥补模型今天的不足，下一代模型一来就该拆；长期投入的应是对目标和好坏标准的描述
- **人的稀缺项**：打字快贬值，升值的是品味、对用户的思考、对目标受众的连接——实现变便宜后，稀缺的是判断什么是好的、该往哪走的能力
