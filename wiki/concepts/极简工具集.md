## 定义
极简工具集是指 AI Agent 仅提供最少的原语工具（如 read/write/edit/bash），通过组合这些原语完成所有任务的设计哲学。核心论点：50+ 工具本质上是 4 个原语的语法糖，更多工具 = 更长 System Prompt = LLM 注意力分散 = 更多幻觉。

## 核心原理
1. **图灵完备**：read + write + edit + bash 在计算理论意义上是图灵完备的——有 bash 就能执行任意程序，有 read/write 就能读写任意文件
2. **减少选择负担**：LLM 不需要在 50+ 工具中选择，只需在 4 个原语中做选择，减少决策复杂度和幻觉概率
3. **语法糖的代价**：专用工具（如 git_commit、npm_install）虽然方便，但增加了 System Prompt 长度和工具选择负担
4. **bash 作为万能钥匙**：所有 CLI 工具都可通过 bash 调用——`bash("git commit -m 'fix'")` 替代 `git_commit(message="fix")`

## 与 Flask 哲学的传承
[[ArminRonacher]] 将 Flask 的极简主义（5000 行核心 + 扩展系统）带入了 AI Agent 领域——Pi Agent 仅 4 个工具 + TypeScript 扩展系统，与 Flask 的"核心极简 + 扩展丰富"一脉相承。
