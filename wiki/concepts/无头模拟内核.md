## 定义

无头模拟内核（Headless Simulation Kernel）指把游戏的「模拟」逻辑**完全剥离于图形引擎之外**，做成一个独立的、无头的纯代码动态链接库。引擎本身并不"拥有"游戏模拟内核，它仅仅是一个消费模拟计算结果的**哑客户端**。

## 关键信息

### 要解决什么问题
传统游戏开发中，核心逻辑常与视觉渲染、UI 回调、音效播放紧紧缠绕：角色发起攻击，脚本在同一帧内扣减血量、播放受击动画、更新血条 UI 并触发声效。恶果是**为了测试任何细微的逻辑分支，必须把整个庞大的游戏完整跑起来**——所有 3D 模型必须加载、材质必须编译、关卡场景必须初始化。出 Bug 时无法快速断言究竟是模拟逻辑出错、模型网格损坏，还是 UI 绑定的空指针异常。

### 通讯模式（与现代 Web 同构）
- 引擎将玩家输入转化为 [[命令模式]] 的 Command 发送给独立模拟内核；
- 模拟内核处理状态演算，把更新后的状态对象（或与上一帧的 State Diff 差异包）返回给引擎；
- 引擎只负责执行无脑的视觉渲染与动画播放，**绝不掺杂任何核心裁决逻辑**。

具体例子：角色从 A 点移动到 B 点，表现层包含行走动画、骨骼转向、脚步声、视野迷雾更新；但在模拟内核眼中，位移**仅仅是坐标从 A 到 B 的数值变更**。引擎提交位移指令 → 内核判断路径合法性 → 更新坐标并返回最新状态 → 引擎平滑插值移动模型。**模拟内核是绝对的唯一真理源。**

### 三大红利
1. **任何来源都能发送指令**：网络模块（多人联机开发变得极其简单）、单元测试脚本、**以及 LLM/AI Agent 都能直接向纯逻辑内核注入指令**。
2. **秒级无头测试**：可以完全抛弃庞重的游戏引擎，使用最纯粹的标准 C#/C++ 命令行工具链，以极高的并发度在纯内存里秒级跑完数千轮自动化单元测试——这正是 AI 最擅长、最喜欢的运行环境。
3. **真空环境验证**：把游戏当成纯粹的技术推演对象，彻底脱离沉重的视听资源开销，在真空环境中运行仿真、假设检验与自动化测试。
