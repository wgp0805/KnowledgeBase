## 定义
用一个共享 `Meta/` 目录作为单一事实来源，统一维护同一产品多平台实现的一致性资产（图标、i18n 文案、链接正则、范围约束），实现"改一处、多端齐发"。

## 关键信息
（以 Agent YOLO 的 IntelliJ / VS / VSC 三端为例）
- **图标**：三端保持图标一致；VSC 端因为技术限制只支持 `.png` 格式图标。
- **i18n 文案**：以 IntelliJ 的 properties 文件为基准，IntelliJ 端的 i18n 改动**必须同步到 `Meta/`**。
- **链接正则**：各端对 Link 的正则处理要大体一致（个别语言差异除外），在 `Meta/` 下维护一份共享 RegExp。
- **范围约束**：YOLO-IntelliJ / YOLO-VS / YOLO-VSC 分别对应三端。
- **效果**：用户侧——不管用哪个 IDE 面对的都是同一套操作，换 IDE 不用重学；维护侧——新增一个 Agent 或图标，改一处三端齐发，修一个共同 bug 三端一起好。
- **适用面**：任何"一套心智模型、多平台实现"的插件 / 工具维护场景。
