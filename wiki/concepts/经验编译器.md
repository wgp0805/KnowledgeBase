## 定义
Experience Compiler（经验编译器）是作者提出的一种 Agent 基础设施产品构想：输入 Agent 每天产生的执行轨迹、真实结果与人类纠正，输出"这条经验应该以什么形式留下来"的决策——写进 Memory、修改 Skill、更新 Policy、调整 Threshold、加入 Evaluation，还是进入训练集沉淀为专业 Judgment Model。

## 关键信息
- **核心职责**：不是保存所有经验，而是决定经验应该以什么形式留下来
- **输入**：执行轨迹、真实结果（Outcome）、人类纠正
- **输出去向**：Memory / Skill / Policy / Threshold / Evaluation / 后训练数据集
- **所处层级**：属于 Agent Learning Infrastructure（智能体学习基础设施），与现有"把 Agent 跑起来且跑得稳定"的基础设施（模型网关、Memory、可观测性、工具调用、评估、护栏、Harness）互补
- **回答的问题**：现有 Agent 产品解决"怎么让 Agent 记住过去"，经验编译器面向"怎么让 Agent 从过去变得更强"
- **对应能力资产分层**：Knowledge（RAG）→ Know-how（Skill/SOP）→ Experience（执行轨迹），见 [[决策数据]]
- **现状**：产业未验证的推演概念，与 [[智能压缩]]、Experience Scaling 共同构成对 Agent 学习闭环的设想
