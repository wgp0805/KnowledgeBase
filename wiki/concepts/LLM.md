## 定义

LLM（Large Language Model，大语言模型）是基于 Transformer 架构、按概率逐个预测下一个 Token 的神经网络。既不是数据库也不是搜索引擎——它把海量语料压缩进固定大小的参数里，靠"词语接龙"（自回归）生成文本。

## 关键信息

### 核心机制

1. **Token 化**：分词器把文本切成模型能处理的最小单位 Token（词元）并转数字编号。估算：1 中文字符≈0.6 Token、1 英文字符≈0.3 Token（DeepSeek 官方）
2. **自回归生成**：逐 Token 预测——输入"床前明月"后给词表十几万个候选 Token 各算概率，"光"95% 最高就输出"光"，拼回输入继续预测下一个；"打字机效果"是底层本来就逐 Token 输出
3. **参数规模（Scaling Law）**：7B/70B/671B 的 B=Billion（十亿）指参数数量（权重）。缩放定律：参数、训练数据、算力一起往上加，效果稳定变好；语料达十几万亿 Token、参数跨百亿/千亿时出现**涌现能力**

### 两阶段训练

- **预训练**：读遍互联网书籍/网页/代码，把通用知识压缩进参数（决定"肚子里有多少墨水"）
- **后训练**：SFT 监督微调（问题+标准答案示范，学问答格式）→ RL 强化学习（对齐人类偏好、数学/代码任务反复试错练出思维链）（决定"能不能用对地方"）

### 温度采样与幻觉

- **温度（Temperature）**：控制采样随机性——写代码调低（0.1）尽量选最高概率 Token，写文案调高（0.8）给次选机会更灵活
- **幻觉根源**：① 生成靠概率采样；② 参数是海量语料的有损压缩（记的是统计规律不是原文），遇训练截止后新闻或没记准的细节不会主动说"不知道"，而挑通顺路径接完
- 模型权重固定不会自学新知识、不记上次对话、不能自己查资料执行命令 → 工程上需 [[RAG]] 补真实资料、[[Harness]] 管记忆与工具调用

### 一句话总结

LLM 本质上是一个基于 Transformer 的神经网络：根据前文按概率一个 Token 一个 Token 地预测；参数和语料规模大到一定程度就能应付很多种任务；靠预训练装知识、靠后训练学指令推理；会幻觉，所以要配 Prompt、RAG、Harness。
