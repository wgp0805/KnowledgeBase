## 定义
分布式对象存储是一种将非结构化数据（图片、视频、文档）以对象形式存储在分布式集群中的存储架构，兼容 S3 API 标准，具备高可用、可扩展、低成本等特性。

## 关键信息
- **代表产品**：MinIO、RustFS、Amazon S3、Ceph
- **核心优势**：高可用、水平扩展、兼容 S3 生态、成本可控
- **常见场景**：AI 数据湖、私有云存储、备份归档、媒体存储
