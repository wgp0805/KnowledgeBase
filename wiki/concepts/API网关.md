API 网关是系统对外暴露 API 的统一接入层，负责路由转发、鉴权、限流等横切职责，让内部服务只关注业务本身（通用概念详见 [[网关]]）。在 [[OpenSystem]] 这类微服务开放平台中，它是统一服务接入的入口（见 [[摘要-手写企业级微服务开放平台]]）。
