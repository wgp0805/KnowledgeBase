## 定义
语义化版本（Semantic Versioning）是大厂版本发布的标准规范：版本号遵循 `主版本号.次版本号.修订号` 三段式格式，各段含义明确，使版本演进可预测、可自动化。

## 关键信息

### 三段式规则
| 段 | 何时递增 | 示例 |
| --- | --- | --- |
| 主版本号 | 不兼容的 API 变更 | 3.0.0 |
| 次版本号 | 向下兼容的功能性新增 | 2.1.0 |
| 修订号 | 向下兼容的问题修复 | 2.1.5 |

### Git Tag 管理
- Tag 是版本发布的"里程碑"
- 创建带注释的 Tag：`git tag -a v2.1.0 -m "Release version 2.1.0"`
- 推送：`git push origin v2.1.0` 或 `git push origin --tags`
- 规范的 commit message 可自动决定版本号（利用 semantic-release 等工具）

### 与其他规范的关联
- 与 [[ConventionalCommits]] 配合：feat 对应次版本、fix 对应修订号、破坏性变更对应主版本
- 与 [[GitFlow]] 配合：release 分支携带语义化版本号
- API 演化的 MAJOR.MINOR.PATCH 划分见 [[api-compatibility]]
