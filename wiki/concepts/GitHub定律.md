## 定义
AI 时代的 GitHub 定律：今天一个叫 xxx 的产品刚刚刷屏，明天 GitHub 上很可能就会冒出一个 Openxxx 冲上热榜——商业产品与开源复刻的间隔已从"年/月"缩短到"按天计算"（Devin→OpenDevin 次日、Manus→OpenManus 同日约 3 小时、Jev→Open JEV 次日、Muse→OpenMuse 7 天）。

## 关键信息
- **成因**：拆解爆火产品技术路线 + 攒开源组件 + 把 Context 丢给 Codex 聊几轮即可产出开源复刻，做 Demo 的门槛坍塌，原本只有少数团队能做的产品现在更多人可以动手验证
- **经典对照**：ChatGPT→ChatGLM-6B/Chatbot UI、Code Interpreter→Open Interpreter、Sora→Open-Sora（5 天）、Perplexity→Perplexica、Cursor→Void（已停维护）、NotebookLM→Open Notebook、Lovable/v0/Bolt→Open Lovable、Claude Design→OpenDesign（十来天）
- **开源抢跑案例**：LangChain 的 Open Deep Research（2024-11）早于 Gemini/OpenAI 同名产品发布
- **复刻质量警示**：OpenManus 首版 3 小时做出仅是可运行早期版本；Void/Open Deep Research 停止维护——复刻容易、长期维护难
- **核心推论**：复刻变容易后，产品的物理实体（代码）不再稀缺，真正拉开差距的是三样代码之外的东西——**判断力**（发现并定义新问题，如 OpenClaw Personal AI 与 Muse Personal Agent 对需求/时机/形态的不同判断导向不同产品）、**品味与取舍**（AI 让做加法前所未有地容易，什么该做什么不该做更考验人）、**渠道与运营**（独立开发者同步经营自媒体建立个人信用、用户关系与分发渠道）
