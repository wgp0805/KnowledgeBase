## 定义
Base62 是用 62 个字符（`0-9 a-z A-Z`）表示数值的进制编码方式，常用于将十进制数字压缩为短字符串。短链接系统中把 [[分布式发号器]] 生成的 ID 转为 Base62 得到短码。

## 关键信息
- **字符集**：`0-9`（10）+ `a-z`（26）+ `A-Z`（26）= 62 字符
- **转换逻辑**：十进制 ID 不断对 62 取余，映射到字符集拼接得到短码；反向解析短码还原回十进制 ID 再查数据库
- **容量**：
  - 6 位 Base62：`62^6 ≈ 568 亿`，绝大多数业务足够
  - 7 位 Base62：`62^7 ≈ 3.5 万亿`，可支撑超大规模业务
- **数学保证**：ID 唯一则 Base62 短码唯一，从根源消除 [[哈希碰撞]]
- **防爬虫**：直接递增 ID 作短码会被批量遍历，Base62 混淆避免 ID 直接暴露
