## 定义
合并冲突是 Git 在 merge/rebase/cherry-pick 过程中，同一文件的同一位置被不同分支修改时产生的冲突标记，需要手动解决后提交。

## 关键信息
- 冲突标记：<<<<<<< 当前分支 / ======= />>>>>>> 目标分支
- 解决流程：手动编辑文件 → git add . → git commit（merge）或 git cherry-pick --continue
- 核心原则：解决完冲突立即提交，不要拖延
- 撤销合并：git merge --abort 回到合并前状态
- 切分支风险：工作区有未提交修改时切分支，冲突标记会随文件带走
