## 定义
WebSocket 是全双工双向通讯协议，客户端与服务端可彼此互推消息，功能强大；使用独立于 HTTP 的 ws/wss 协议，相对 [[SSE]] 更重、更复杂。

## 关键信息
- **最大优点**：双向通讯——客户端与服务端可以同时相互推送，这是 [[SSE]]（仅服务器→客户端单向）不具备的能力
- **协议代价**：ws/wss 是独立于 HTTP 的新协议，支持 HTTP 协议的浏览器不一定支持 ws 协议；服务端也需额外支持，不像 SSE 部署在 HTTP 之上、现有服务器软件都支持
- **重量级**：因功能更强、结构更复杂，相对较重，对客户端消耗也比较大
- **断线重连需额外部署**（SSE 默认支持断线重连）
- **浏览器兼容性总体不错**
- **适用场景**：聊天等既要服务端主动向客户端推送信息、客户端也有向服务端推送需求的业务
- **选型结论**：能用 [[SSE]] 完成的单向推送需求，没有必要使用更重更复杂的 WebSocket，避免杀鸡用牛刀
