## 定义
理解 Agent 系统中 LLM、Skill、Tool、Agent Runtime 四个组件协同位置的架构框架（源自「无花 开源圈」《为什么Skill才是未来的资产》）。类比一个公司：Runtime 是管理层，LLM 是决策者，Skill 是各业务线的专家顾问，Tool 是一线执行团队。

## 关键信息

| 层 | 职责 | 类比 |
| --- | --- | --- |
| LLM 层（大脑） | 思考、理解、决策——"想清楚" | 决策者 |
| Skill 层（专业知识） | 提供领域知识和标准，告诉大脑"该怎么做"——"做专业" | 专家顾问 |
| Tool 层（工具） | 连接外部世界（浏览器/Python/数据库），获得执行能力——"能动手" | 一线执行团队 |
| Agent Runtime 层（运行时） | 组织、调度、记忆、反思，把三层串联成有机整体——"能闭环" | 管理层 |

缺了任何一层，系统都无法跑成一个完整、专业的闭环。该框架强调：Skill 不是 Agent 的附属品，而是让 Agent 从"能用"走向"好用、敢用"的关键一层。
