## 定义

墙钟时间采样（wall-clock profiling）是相对于 CPU 时间采样的一种 profiling 方式：记录的是「从任务开始到结束的实际时间」，而非「CPU 实际在执行的时间」。Arthas 4 的 `profiler --wall` 参数即启用此模式。

## 关键信息

### 解决的问题

**CPU 不高但接口慢**：锁等待、网络 IO 阻塞、数据库连接池耗尽等场景下，线程在「等」而不消耗 CPU，传统的 CPU 火焰图看不出问题——采样只记录 CPU 时间，等待时间被忽略。

### 原理

- CPU 采样（默认）：只记录线程实际占用 CPU 的时间片段
- 墙钟采样（`--wall`）：记录线程从开始执行到完成的整个时间跨度，包括等待时间

### 典型应用场景

- 接口 P99 延迟突然升高，但 CPU / 内存 / GC 全部正常
- 怀疑线程阻塞、锁竞争、连接池耗尽
- 微服务调用链路中下游服务慢，导致上游线程长时间等待

### Arthas 中的使用

```bash
profiler start --wall
profiler stop --file /tmp/wall-flame.svg
```

生成的火焰图中，等待时间（锁、IO、Sleep）会出现在火焰图里，CPU 火焰图中这些位置是「空」的。
