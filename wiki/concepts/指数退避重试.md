## 定义
指数退避重试（Exponential Backoff with Jitter）是一种 API 调用容错策略，当请求失败时，以指数递增的间隔进行重试，并在每次等待时间中加入随机抖动，避免多个客户端同时重试导致服务端过载。

## 关键信息
- **默认策略**：最多重试 3 次，间隔 500ms → 1s → 2s，上限 30 秒
- **随机抖动**：每次等待时间加 20% 的随机偏移，避免"惊群效应"
- **Retry-After 支持**：如果服务端返回 Retry-After 头，取退避计算值和服务端指定值中的较大值

### 可重试 vs 不可重试

| 可重试 | 不可重试 |
|--------|---------|
| HTTP 408（请求超时） | SSL 证书错误（安全问题） |
| HTTP 429（限流） | JSON 解析错误（响应格式问题） |
| HTTP 500/502/503/504（服务端故障） | 线程中断（用户主动取消） |
| 网络层异常（连接超时、DNS 失败、流式传输中断） | |
