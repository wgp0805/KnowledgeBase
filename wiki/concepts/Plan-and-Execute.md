# Plan-and-Execute

Plan-and-Execute 是 Agent 模式之一：先规划完整计划再逐步执行。与 ReAct 的选型：简单任务用 ReAct（边想边做），复杂多步任务用 Plan-and-Execute（先规划再执行），避免 ReAct 在长任务中偏离目标。
