## 定义
认知劳动产品化（张佳提出）指：把脑子里需要"三年五个项目"练出来的经验与方法论，固化成 Skill（提示词 + 脚本 + 工具），直接垫给用的人——过去靠时间积累的认知劳动，变成可分发的产品。

## 关键信息
- **赋能对象画像**：短期教不会、也不愿意学的员工。一教就会的人不用赋能（自己就会找工具）；教不会的靠 Skill 照着干
- **固化内容三件**：你的流程、你的规则、你的审美——AI 会做 PPT，但默认不会按你的偏好做
- **通用做法会被模型内化**：GitHub 万 Star 上下的 AI 做 PPT 项目火过一个版本，那套审美就被训进模型了，成了**AI Slop**；个性化偏好、垂直流程里的玩法才难被复刻，也就是 Skill 的真正资产价值
- **Skill 的本质**：提示词 + 脚本 + 工具；工具一般外挂在 MCP/CLI 上，全塞进 Skill 会臃肿
- **垂直 Agent 之辨**：通用 Agent + 一套 Skill 就是垂直 Agent（不然竞对做出同款 Skill 用户立刻迁走）；真正需要单独一个 Agent 的理由只剩权限、规范、边界几类
- **写 Skill 的门槛**：要懂 Agent 和模型底层原理——不懂的人写出的 Skill 干轻松活也要二三十分钟、规则反复读、时灵时不灵
