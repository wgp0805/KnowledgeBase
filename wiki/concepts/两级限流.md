## 定义
两级限流是秒杀防刷分层体系的**第 3 层**，采用"本地粗筛 + 分布式精算"两级结构。**目标是保护系统，不是维护公平**——别指望限流能防住黄牛。

## 两级结构
- **本地粗筛**：Guava RateLimiter 或信号量，按实例数把总配额粗略切分。绝大部分超额请求在进程内就被挡掉，根本不出网
- **分布式精算**：漏下来的那一小部分走分布式限流做精确控制
- **原则**：粗筛在本地，精算在远端

## 限流维度选择
### 禁止按 IP 限流
- 黄牛代理 IP 池按天算钱，几百块拿几万个动态 IP，比你写的规则多得多
- 误伤严重：同一公司出口、同一学校 NAT、同一运营商大客户后面的正常用户对外看起来就是一个 IP 发了几百个请求

### 稳的维度
账号、设备指纹、手机号、收货地址、支付账号。但账号能批量注册，所以真正防线还要再往前移到 [[准入门槛]]。

## Redisson RRateLimiter 热点 Key 陷阱
- `RRateLimiter` 底层是 Lua 脚本，每次 acquire 走一次 Redis 往返
- **限流器自己就是一个 Redis Key**：秒杀峰值下全站请求都往同一个限流 Key 上打，该 Key 瞬间变成整个集群最热的热点 Key，把所在节点单独烤糊
- **结果**：为保护系统加的限流，成了第一个倒下的组件
- 参见 [[热点Key]]
