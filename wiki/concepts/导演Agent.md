## 定义
导演 Agent 指把内容生产类 Agent 从"执行指令的工具"升级为"统筹整部作品的导演"：它知道这是一部什么类型的剧、前面该埋什么伏笔、角色该长啥样、一场戏要怎么拍，然后把编剧、选角、场景、分镜、视频生成与后期包装这些环节接起来。LibTV 1.5 把 Agent 更名为 TV Director 是这一设计的代表。

## 关键信息
- **统筹而非执行**：只给模糊方向（如"古装言情 + 喜剧"），Agent 从爆款预测、类型融合开始自主推进到成片
- **文档级可编辑**：分集剧本像文档一样可手动改台词，也可框选片段交给 Agent 修改，改完逐条接受/撤销，人工介入不打断整体流程
- **可中断可调头**：生成到一半可打断 Agent，先出一集成片验证视觉风格，再继续后续创作
- **资产自动生成**：在画布上自动创建人物、场景、道具等资产节点，支持自动/手动两种推进模式控制积分消耗
- **专业角色外挂**：导演执导模式可挑选不同类型导演或像建 Skill 一样自建导演，优化分镜提示词后一键应用到视频节点
- **能力接口**：剧本原创及改编、角色造型室、导演执导、3D-BOX 预演、创意片头五项能力围绕"导演"角色组合
- **用户价值**：让没有编剧、分镜、导演专业背景的人"先把第一版做出来，看见它，再一点点改成想要的样子"
