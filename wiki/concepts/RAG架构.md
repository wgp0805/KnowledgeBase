## 定义
RAG（Retrieval-Augmented Generation，检索增强生成）是企业级 Agent 知识库工作流的底层技术。通过将外部知识库（产品文档、报价、案例等）接入大模型，让 Agent 在回答时引用来源、推荐可发客户材料，并在无答案时记为「知识缺口」反馈负责人补充。

## 关键信息
- **在企业 Agent 中的定位**：知识库工作流解决「知识调用」问题
- **工作流闭环**：
  1. 接入产品文档/报价/案例
  2. 提问给答案 + 引用来源
  3. 推荐可发客户材料
  4. 无答案记为「知识缺口」
  5. 提醒负责人补充
- **价值**：不是回答得像真人，而是少错、少漏、可追溯
- **与 Agent 工作流的关系**：是 [[Agent工作流]] 五大工作流之一（知识库工作流）的底层技术
