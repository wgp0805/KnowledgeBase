## 定义
国内源三件套是解决国内网络环境下 Docker + Python + Node.js 部署时拉镜像/装包超时问题的标准配置组合：**DaoCloud 镜像加速器 + 清华 pip 源 + 淘宝 npm 源**。由 [[码农刚子]] 在 Ubuntu 22.04 全栈项目部署实录中总结，基本能覆盖国内大部分镜像拉取和包安装场景。

## 关键信息

### 三件套配置

**1. [[DaoCloud加速器]]（Docker 镜像加速）**
- 配置文件：`/etc/docker/daemon.json`
- 内容：`{"registry-mirrors": ["https://docker.m.daocloud.io"]}`
- 重启：`systemctl daemon-reload && systemctl restart docker`
- **坑**：地址末尾不要加斜杠，否则可能报 403
- 踩过的坑：腾讯/163/阿里云专属加速器几个都不稳，最后 DaoCloud 公共加速器最稳

**2. 清华 pip 源（Python 包加速）**
- Dockerfile 配置：
  ```
  ARG PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
  ENV PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn
  ```

**3. 淘宝 npm 源（Node.js 包加速）**
- Dockerfile 配置：`ENV npm_config_registry=https://registry.npmmirror.com`

### 解决的问题
- 国内直接拉 `docker.io` 很容易超时 → DaoCloud 加速器
- pip install 超时 → 清华源
- npm install 超时 → 淘宝源
- 不配这三件套，国内网络环境部署基本走不通
