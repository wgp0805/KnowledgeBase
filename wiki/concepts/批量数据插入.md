# 批量数据插入

## 核心定义
大规模数据高效写入数据库的技术方案，通过批量操作、分批提交和索引优化显著提升写入吞吐量。

## 关键要点
- 核心方案：批量 INSERT、LOAD DATA INFILE、分批提交、连接池优化
- 10亿数据场景：分表分批、并行写入、禁用索引/约束后重建
- 单条 INSERT 与批量 INSERT 性能差距可达数十倍

## 详细说明

### 核心方案
1. **批量 INSERT**：单条 SQL 插入多行数据，减少网络往返和 SQL 解析开销
2. **LOAD DATA INFILE**：MySQL 原生高速导入，跳过 SQL 解析层，速度最快
3. **分批提交**：控制单批大小（通常 1000-5000 行），避免事务过大和锁表
4. **连接池优化**：调整连接池大小，支持并行写入

### 10亿数据场景
- **分表分批**：按业务维度分表，每表分批写入
- **并行写入**：多线程/多连接并行写入不同分片
- **禁用索引/约束后重建**：导入前禁用非唯一索引和外键检查，导入后重建
- **调整参数**：增大 `innodb_buffer_pool_size`、`bulk_insert_buffer_size`

### 性能对比
| 方式 | 大致吞吐量 | 适用场景 |
|------|-----------|----------|
| 单条 INSERT | ~1K rows/s | 少量数据 |
| 批量 INSERT | ~10K-50K rows/s | 中等数据量 |
| LOAD DATA INFILE | ~100K+ rows/s | 大批量导入 |
