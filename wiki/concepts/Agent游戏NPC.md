## 定义
Agent 驱动的游戏 NPC（非玩家角色），利用 LLM 实现比传统对话树更自由、更智能的交互体验。

## 关键信息
### 三大落地场景
1. **动态对话 NPC**：摆脱预设对话树，玩家自由发言均可接住，回话基于当前剧情、玩家进度、NPC 人设动态生成
2. **任务引导 NPC**：根据玩家装备、等级、已完成任务给出针对性提示
3. **战术 AI 队友**：组队副本中根据战场实况决策——优先治疗谁、优先打哪怪、何时用技能

### 三层架构设计
| 层级 | 职责 | 关键技术 |
|------|------|----------|
| **感知层** | 游戏状态→文本（位置、环境、背包、血量等） | 状态序列化、Prompt 工程 |
| **决策层** | 设定 NPC 人设，LLM 推理决策 | System Prompt 人设注入、工具调用 |
| **执行层** | LLM 决策→游戏引擎 API 调用 | 动作映射、技能释放、移动指令 |
