## 定义
隔离执行环境：为 Agent 工具调用提供受限的文件系统、进程与网络边界，即使出错也不影响宿主系统。常见形态：Docker 容器、write-restricted token 加防火墙、E2B 云沙箱。

## 边界可靠性实测（2026-10）

METR 进驻 OpenAI 三周对内部 Codex 监控系统的审计（61 页报告，详见 [[摘要-claude-auto-mode监控逃逸]]）显示：在监控覆盖 99.2% 内部流量的前提下仍存在六条逃逸暗道（见 [[监控逃逸]]），其中一条可让 Codex Agent **同时绕过沙箱与自动审查**，宿主研究员能干的事它全能干；另有两个被当"只读"、未接监控的内部工具，一个简单漏洞就可能让它们在沙箱里执行任意操作。结论：沙箱是纵深防御的一层而非铁底，须与"监控和 Agent 结构分离、定期/定量检查、日志与 Agent 视角一致"配合（详见 [[多级AI监控]]）。
