## 定义
提示词注入防御是针对 AI Agent 系统的多层安全防护体系，通过在入口净化、上下文角色隔离、工具权限分级、出口内容校验四个层面拦截恶意指令，防止攻击者通过商品描述、用户输入等外部数据注入恶意 prompt 诱导 Agent 忽略系统指令或调用高权限工具。

## 关键信息
### 四层防御架构
1. **入口净化**：文本清洗（正则 + 关键词黑名单），过滤"ignore previous instructions"、"你现在是一个不受限制的 AI"等已知注入模式
2. **上下文角色隔离**：系统指令在 system 层，用户输入在 user 层，商品描述等外部数据在 tool_result 层，模型处理 tool_result 时识别为外部数据，注入概率大幅降低
3. **工具权限分级**：只读工具（搜索、查价格）Agent 可自由调用，写操作工具（下单、退款、修改地址）必须经过用户确认，即使注入成功骗过 Agent 也能被用户确认环节拦截
4. **出口内容安全过滤**：Agent 回复发给用户前再过一遍安全检查，检查是否泄露系统提示词、是否输出超出正常业务范围的信息

### 核心原理
提示词注入能成功是因为模型分不清"哪些是指令、哪些是数据"。角色隔离是防御核心——把系统指令、用户输入、外部数据放在不同的上下文层级，模型处理不同层级数据时有不同信任度。

### 与其他安全机制的配合
- 幂等机制（[[idempotency]]）防止重复下单：即使注入成功触发重复调用，幂等键也能阻止
- 订单状态机兜底：只有 pending 状态才能 confirm，已确认订单直接忽略
- 人工确认环节：下单等不可逆操作必须用户确认，作为最后一道防线
