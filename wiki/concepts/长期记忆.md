# 长期记忆

Agent 长期记忆存储在外部文件/数据库中，每次启动时加载。Claude Code 用 CLAUDE.md 文件存储，Codex 用 SQLite 存储。记忆机制包括：形成（用户主动写/Agent 自动总结）、检索（全文注入/关键词匹配）、淘汰（过期清理）。
