# 长期记忆

Agent 长期记忆存储在外部文件/数据库中，每次启动时加载。Claude Code 用 CLAUDE.md 文件存储，Codex 用 SQLite 存储。记忆机制包括：形成（用户主动写/Agent 自动总结）、检索（全文注入/关键词匹配）、淘汰（过期清理）。

## 与工作记忆的对比（2026-09-19，详见 [[摘要-工作记忆vs长期记忆上下文工程]]）

| 维度 | 工作记忆（上下文） | 长期记忆（收口摘要） |
|------|------|------|
| 载体 | 当前对话窗口 | 外部文件/笔记/知识库/Memory Layer |
| 稳定性 | 易失（Volatile），单次会话内有效 | 持久（Persistent），跨会话 |
| 抗干扰 | 弱，易上下文腐化、注意力衰减 | 强，提炼后噪音低 |
| 典型内容 | 过程对话、草稿、多轮纠错、临时指令 | 最终决策、核心事实、用户偏好、下一步计划 |

- **Agent Memory/Long-term Memory Layer**：Mem0、Zep、LangMem 自动收口+按需检索
- 一句话概括：**工作记忆是"当下的负担"，长期记忆是打包精炼后的"未来资产"**
