## 定义
Agent 落地是将 AI Agent 从演示推向生产的关键一步，核心挑战是模型成本——Agent 干活和聊天不同，一项任务背后几十次调用，调用越多对单价越敏感。

## 关键信息
- Agent 成本敏感：一项任务触发几十次模型调用，按一次任务五十次调用算，Opus 好几美元 vs Flash 几毛钱
- 价格差影响：同样的活成本差四十倍，便宜到能当日常消耗品
- 企业付费模式：Token 成本被 Agent 打包进任务价里，企业按任务付钱
- 评测案例：杰富瑞实测八款 Agent，千问办公综合得分第一
- 模型与 Agent 绑定：Qwen3.8-Flash 已接入千问办公，日常活儿一款模型够用
