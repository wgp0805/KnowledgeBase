## 定义
自扩展（Self-Extension）是 Pi Agent 的核心理念——如果 Agent 缺某个功能，不要去下载扩展，让 Agent 自己写。这是对 LLM 代码生成能力的极致信任，也是极简工具集哲学的自然延伸。

## 工作方式
1. 把别人的扩展源码给 Agent 看
2. 告诉 Agent "照着这个思路写一个，但做这些修改"
3. Agent 读源码 → 理解逻辑 → 改写实现 → 测试验证
4. 整个过程不需要人类写一行代码

## TypeScript 扩展系统
Pi 提供 TypeScript 扩展 API，支持编写：
- 子 Agent（sub-agent）
- Plan Mode（规划模式）
- 自定义工具
- 特定 API 集成

扩展即代码，代码即扩展——不需要注册中心、插件协议、热加载机制。

## MCP 的"刻意缺席"
Pi 不内置 MCP 支持——需要时通过 bash 调用 mcporter，或写 TypeScript 扩展封装 MCP 调用。这种"可选而非内置"的设计保持了核心极简性。

## 与其他扩展机制对比
- **Claude Code**：MCP + Skills（预置扩展生态）
- **Cursor**：插件 + MCP
- **Pi Agent**：自扩展 + TypeScript（Agent 自己写扩展）
