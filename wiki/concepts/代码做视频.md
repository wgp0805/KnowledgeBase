## 定义
代码做视频（Code-to-Video，2026-10 社区随 Claude Opus 5.5 热潮将其命名为 **Vibe Video**）：不用 Seedance 类视频生成模型，而是让 [[ClaudeCode]]、[[Codex]] 等 Agent 工具**编写 HTML、Canvas、WebGL 或 [[Remotion]] 动画代码，再逐帧导出 MP4** 的视频生产路线。字幕、镜头路径、转场全部在代码里调，视频因此可编程、可复现、可精确控制每一帧。

## 关键信息
- **主流渲染管线**：单个 HTML 页面用时间参数计算每帧元素位置与形状（任意时刻画面可精确重现）→ Playwright 截取浏览器画面 → FFmpeg 合成视频
- **能力门槛**：模型代码能力过线后该路线可用性大增——产品发布片、动态图解、五分钟历史电影等场景均有成品
- **典型玩法**：Three.js 实时渲染三维场景做一镜到底（镜头从数据中心钻进芯片直到原子尺度）；Canvas 逐帧手绘短片（约 28 秒）；剪纸风科普片解释相对论；代码生成配乐与音效；JavaScript 控制文字/图形/转场做 26 秒公司介绍片
- **与视频生成模型的分工**：[[AI视频生成]]（扩散/DiT 模型）交付"生成感"画面但控制粒度粗；代码路线控制精确、可改可复算，但画面表现依赖手写样式，不适合写实场景
- **生态（2026-10 观察）**：Lemo-Opuscar 收录 39 种影片风格配样片与 Skill；Awesome-Opus5-5-Videos 301 个视频、作者花费 3000 美元、全套 Prompt 与工作流开源；opus-video-prompts 按成片找提示词；OneTake 提供一镜到底动作拆解与可复用 Skill；[[HyperFrames]] 把 HTML 动画渲染成视频；Remotion 官方 Agent Skills 教 Agent 用 React 制作、预览、导出视频
- **Vibe Video 破圈案例（2026-10，详见 [[摘要-claude-gpt-video-seedance-moat]]）**：X 博主 anabology 仅提供参考提示词 + Midjourney 调用权限 + 情绪板，12 小时输出电影质感反乌托邦短片，帖子浏览量破 2000 万，马斯克多次转发并称"真切感受到 AGI 的深远影响"；博主 vittorio 一句指令产出 2 分 16 秒西方文明史短片、两天播放破千万；有创作者基于 [[Remotion]] 写约 7400 行前端代码，一小时产出三分钟 AI 发展史视频；推理初创 Deedy 单条产品视频生成耗时约 1 分钟、API 成本约 2 美元；GitHub 案例集合站 awesome-opus5-5-videos 已收录 400 多条作品
- **场景边界**：天然擅长程序化/图形化内容（文字动效、数据图表、科普动画、抽象 3D 场景），难以胜任写实真人画面与复杂自然物理效果——后者是 [[AI视频生成]]（[[Seedance]] 等）的核心主场；渗透范围集中在轻量化商业内容、知识科普与创意实验赛道
- **国内落地与可编辑性维度（2026-10-21，详见 [[摘要-fotor-agent-mg动画视频]]）**：社区玩法原本依赖海外账号与订阅、看懂代码、配环境三道坎，[[FotorAgent]] 把这条路线搬回国内并做成可交付产品——**MG 动效走代码生成视频路线，实拍素材走生成/上传路线，两层分排在不同轨道**；交出的是"零件"而非"一整段画面"，每个字、每个色块都能点着改
- **竞争维度迁移**：AI 视频下一阶段拼的不再是画面精美，而是**信息承载、生成精准以及可编辑性**——"从能生成到能交付，中间差的其实就是这一层工程化"；"改不改得动"才是检验生产力的唯一标准
