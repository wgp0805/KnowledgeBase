# 上下文数据库

## 核心定义
火山引擎 OpenViking 提出的虚拟文件系统，统一知识库/记忆/技能，将 Agent 的上下文管理从分散存储统一为文件系统语义。

## 关键要点
- 核心价值：将 Agent 的上下文管理从分散存储统一为文件系统语义
- 统一知识库、记忆、技能三类上下文资源
- 以文件系统接口降低 Agent 上下文管理复杂度

## 详细说明

### 核心价值
传统 Agent 的上下文管理面临以下问题：
- 知识库、对话记忆、技能定义分散在不同存储中
- 各类上下文访问接口不统一，增加开发复杂度
- 上下文生命周期管理缺乏统一机制

上下文数据库通过虚拟文件系统语义解决上述问题：
- **统一接口**：以文件/目录操作统一访问各类上下文
- **语义清晰**：知识库、记忆、技能映射为不同"目录"
- **生命周期管理**：支持上下文的增删改查和过期清理

### 设计理念
- 借鉴文件系统的成熟语义，降低学习成本
- 支持挂载、权限控制等文件系统级特性
- 为 Agent 提供一致的上下文访问抽象层
