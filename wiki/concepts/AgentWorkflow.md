## 定义
Agent 工作流指 AI Agent 深度参与业务流程、连接信息/人员/业务动作、形成完整人机协同流程的产品形态。区别于单点 Agent（写文案、做总结等易被通用平台取代），Agent 工作流连接业务前后节点、系统数据、角色责任和反馈机制。

## 关键信息
### 从个人能力到团队工作流
- **个人能力是入口**：个人记忆、录音、会议纪要适合作为 AI 产品的低门槛入口
- **团队工作流是终点**：企业长期付费不是为了多一份摘要，而是希望信息在团队中流动，推动任务分配、项目跟进、风险预警、决策复盘
- 当 AI 开始连接信息、人员和业务动作，它才真正进入工作流

### 单点 Agent vs Agent 工作流
| 维度 | 单点 Agent | Agent 工作流 |
|------|-----------|--------------|
| 能力 | 写文案、做总结、分析表格 | 连接业务前后节点+系统数据+角色责任+反馈机制 |
| 壁垒 | 易被基础模型/办公平台覆盖 | 难复制，需深入业务流程 |
| 持久性 | 短期，会被通用平台洗一遍 | 持久，形成人机协同 |
| 价值 | 功能性 | 业务数据循环 |

### Anthropic 实践建议
- 根据任务特点选择简单工作流或 Agent
- 只有在复杂度确实带来可衡量价值时，才值得增加系统复杂度
