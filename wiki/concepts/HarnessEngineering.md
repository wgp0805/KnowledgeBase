# Harness Engineering

Harness Engineering 是为 LLM 搭建「外壳」的工程实践——工具注册、上下文管理、循环控制、错误恢复、安全边界。Harness 是 Agent 与 ChatBot 的分水岭：Claude Code 和 Codex 本质都是 Harness。2026 年模型能力趋同，Harness 成为差异化关键。
