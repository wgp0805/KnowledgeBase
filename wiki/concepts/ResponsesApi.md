# Responses API

Responses API 是 OpenAI 新一代接口，支持内置工具、状态管理、多轮编排。与 Chat Completions API 的区别：后者是传统单轮接口。迁移建议：需要内置工具和多轮编排用 Responses API，简单调用保留 Chat Completions。
