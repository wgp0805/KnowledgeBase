在 Agent 语境中，Memory（记忆）指智能体「记得什么」——跨轮次、跨会话保存与召回信息的能力，是 [[Molio]] 四要素（Agent / Wiki / Skill / Memory）之一；系统化的记忆机制详见 [[AgentMemory]]（见 [[摘要-agent平台两种哲学-weknora-molio]]）。
