## 定义
用多个账号组成资源池、按顺序轮询切换以规避单账号限流的机制：当一个账号被 429 限流，系统自动切换到下一个备用账号循环使用，从而不因限流卡住。

## 关键信息
- **动机**：Cline 等服务提供免费模型但存在 429 限流且官方不公开限流规则，单账号体验不可靠
- **实现要点**：本地反代项目（如 ClineFreePool）支持多账号登录 → 账号入池 → 限流自动切换 → 对外暴露统一的 Base URL + API Key，下游 Agent 无感
- **账号来源**：利用注册门槛低的账号体系（如 Microsoft 账号，Windows 用户普遍已有、国内注册无需特殊网络）批量注册，再登录成目标服务账号
- **对外接入**：反代服务对下游暴露标准 OpenAI 兼容接口，Base URL / API Key / 模型名三件套可接入任意主流 Agent 或 AI 聊天工具
- **运维注意**：后台服务使用期间不能关闭；控制台每次使用前手动刷新以获取最新免费模型列表
- **边界**：属于灰度薅福利性质，上游随时可能收紧政策或加强限流
