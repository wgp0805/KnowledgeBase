## 定义
会话树（Session Tree）是 Pi Agent 的会话管理结构——会话不是线性历史，而是树结构。Agent 可以在决策点分叉探索不同路径，然后回退到分叉点选择另一条路，无需从头开始。

## 核心特性
1. **分支探索**：在某个决策点分叉，尝试不同方案
2. **回退重试**：回到之前的分支点选择另一条路，不需要从头开始
3. **JSON 存储**：每个节点包含消息内容、工具调用、模型信息
4. **可恢复**：会话可被暂停、恢复、回放、分享

## 与其他会话结构对比
| Agent | 会话结构 | 特点 |
|-------|---------|------|
| Pi Agent | 树 | 分支探索，回退重试 |
| Claude Code | 线性 + Checkpoint | 线性推进，检查点恢复 |
| Cursor | 线性 | 单线推进 |
