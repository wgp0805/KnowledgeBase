## 定义
Agent 系统的经典三层架构：感知层负责环境状态编码，决策层负责推理规划，执行层负责动作落地。广泛应用于游戏 NPC、机器人控制、自动驾驶等具身智能场景。

## 关键信息
| 层级 | 职责 | 输入 | 输出 |
|------|------|------|------|
| **感知层** | 将原始环境状态翻译为 LLM 可理解的文本/结构化表示 | 游戏状态、传感器数据、图像帧 | 结构化 Prompt / 多模态输入 |
| **决策层** | 基于人设/目标/历史进行推理，决定下一步动作 | 感知层输出 + System Prompt + 记忆 | 结构化决策 / 工具调用参数 |
| **执行层** | 将决策翻译为具体环境 API 调用 | 决策层输出 | 引擎指令 / 硬件控制信号 |
