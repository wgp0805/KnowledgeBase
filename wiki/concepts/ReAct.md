# ReAct

ReAct（Reasoning + Acting）是 Agent 经典模式，在推理（Thought）和行动（Action）之间交替循环，每次行动后观察结果（Observation）再决定下一步。与 CoT 的区别：CoT 只推理不行动，ReAct 边想边做。与 Plan-and-Execute 的区别：ReAct 每步推理，Plan-and-Execute 先规划再执行。
