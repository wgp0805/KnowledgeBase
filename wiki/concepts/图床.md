## 定义

图床是为 Markdown 写作、博客与文档系统提供图片托管与外链访问的存储服务。评价维度：稳定性、私密性（不公开暴露仓库/桶）、成本（是否免费）、访问速度（是否走 CDN/反代）、上传便捷性（是否可与编辑器集成）。

## 关键信息

### 免费私有图床方案（GitHub + Cloudflare + PicGo）
来自 [[摘要-github-cloudflare-picgo图床]]：

1. **存储层**：GitHub 私有仓库提供免费空间；必须用令牌上传与访问
   - Fine-grained token（推荐）：Repository access 限定图床仓库；Contents: Read and write + Metadata: Read-only；`github_pat_` 只显示一次
   - Classic token（不推荐）：scope 需 `repo` + `write:packages`，权限过宽
2. **反代加速层**：Cloudflare Workers 把请求拼接为 `raw.githubusercontent.com` 路径并附加 `Authorization: token`，解决 raw 直连慢与私有仓库鉴权问题
   - 环境变量：`GH_TOKEN`、`GH_NAME`、`GH_REPO`、`GH_BRANCH`（可加 `URL`/`URL302` 处理根路径跳转）
   - token 可经 URL `?token=` 传入；缺失时返回 400，失败返回自定义错误页；可接自有域名（Cloudflare DNS 代理）
3. **上传层**：[[PicGo]] 配置 GitHub 图床（owner/repo/branch/token/存储路径），`rename-file` 插件按 `{y}/{m}/{d}{h}{i}-{rand:3}` 自动重命名防冲突；Typora 可内置集成 PicGo 一键上传

### 关键安全点
- 令牌只授必要权限并离线保存（刷新页面后不可再查看，丢失/泄露即 Delete 重建）
- 仓库设为私有 + 反代持有 token，避免图片直链暴露仓库内容
