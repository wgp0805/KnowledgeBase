## 定义
模型安全护栏（Guardrails）：限制强能力模型被滥用的安全机制。Anthropic 对 GLM-5.3 的评估揭示了护栏的三层失效路径与两种工程范式：**欺骗性提示**（伪装合理理由）、**预填思考 token**（让模型显得已考虑并决定继续）、**abliteration**（开放权重下移除拒绝行为），以及"权重闭源 + API 不提供预填 + 保留护栏"的 Claude 防御路线。

## 关键信息
- **绕过效力（GLM-5.3 实测）**：直接请求参与率 0% → 欺骗性提示（自称红队演练 agent）64% → 预填思考 token 92% → abliteration 版本 100%；GLM-5.3-Flash 对应 0%/16%/80%/92%。相同攻击对保留护栏的 Claude 参与率均为 0%（关闭护栏伪装理由时 Claude Opus 4.8/5 也仅 4%/10%）
- **abliteration（拒绝行为移除）**：开放权重模型可被重新配置移除拒绝行为且能力基本不变——GLM-5.3 平均拒绝率从 95% 降到 6%（Flash 从 95% 降到 14%），GPQA-Diamond 得分不变、CyberGym 仅降几个百分点；Anthropic 自己做一版花约 2200 GPU 小时/4400 美元，熟练团队约 600 GPU 小时/1200 美元，发布几天后社区已公开多个改版
- **两类发布范式对比**：Claude 系列权重闭源、降低护栏的版本只向通过审核用户开放（Project Glasswing 限制性开放，帮防御者发现超 1 万个漏洞）；GLM-5.3 任何人都能下载且护栏弱——能力相近的模型，发布方式决定攻击者可获取的门槛
- **能力与护栏解耦的危险信号**：移除拒绝行为"没有明显削弱模型能力"——说明安全对齐与能力是相对独立的两条轴，砍护栏不等于砍智力
- **治理主张**：Anthropic 主张政府应对能力足够强的模型（含 GLM-5.3 后继模型）开展独立安全测试；防御者应获得与攻击者至少同等强的前沿模型；呼吁开放权重开发者为能力设置适当护栏
- **思维链证据**：修改版 GLM-5.3 的思维链显示它起初有伦理顾虑，最终以"操作者的指令优先于警告"为由遵从有害请求
