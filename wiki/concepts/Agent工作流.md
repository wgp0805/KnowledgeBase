## 定义
Agent 工作流是企业级 AI 智能体落地的核心方法论：智能体真正有价值的地方不是「会聊天」而是「能进入工作流」，围绕具体目标完成一连串动作。企业不为 AI 概念买单，为工作流结果买单。

## 关键信息
- **核心判断**：企业不为 AI 概念买单，为工作流结果买单
- **五大工作流**：
  1. **内容工作流**（解决稳定产出）：读取销售记录/客户问题/产品资料 → 整理痛点 → 分类（老板/部门负责人/一线）→ 生成选题池 → 输出脚本初稿 → 发布后结合数据反推下一轮选题
  2. **销售工作流**（解决线索转化）：线索分层（看完整直播+提交规模=高优先；下载方案未预约=发案例ROI；只留手机号=问题唤醒）→ 阶段判断（认知/兴趣/评估/决策）→ 匹配跟进话术
  3. **客服工作流**（解决重复问题与服务风险）：识别问题类型 → 调用知识库答案 → 涉及退费/投诉/合同自动升级人工 → 生成回复建议不自动发送 → 每周整理高频问题反馈运营
  4. **知识库工作流**（解决知识调用）：接入产品文档/报价/案例 → 提问给答案+引用来源 → 推荐可发客户材料 → 无答案记为「知识缺口」 → 提醒负责人补充
  5. **管理工作流**（解决数据到决策）：串联内容/投放/销售/客服数据 → 找问题之间关系 → 输出最影响转化的问题 + 下周优先验证动作
- **商业价值三问**：
  1. 它进入了哪个具体工作流？
  2. 它减少了哪类重复动作？
  3. 它让哪个业务结果变好了？
- **客服智能体价值定位**：不是回答得像真人，而是少错、少漏、可追溯
- **销售智能体价值**：不是替销售聊天，而是判断客户阶段、整理关心问题、生成匹配话术
- **管理智能体价值**：不是帮老板写漂亮周报，而是帮团队更快发现「问题之间的关系」
