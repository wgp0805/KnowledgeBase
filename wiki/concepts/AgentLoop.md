## 定义
Agent Loop 是 AI Agent 的核心执行循环：模型提出计划 → 调用工具 → 读取结果 → 决定下一步，赋予系统连续行动能力，但循环不会自动带来更好的判断。

## 关键信息
- 循环流程：计划 → 工具调用 → 结果读取 → 下一步决策
- 硬限制需求：步数上限、预算上限、超时、重复检测、终止条件
- 外部写入：需考虑幂等，避免重试造成重复操作
- 日志要求：保存模型看到了什么、选了哪个工具、传了哪些参数、系统返回了什么
- 监控指标：越权调用率、错误动作拦截率、人工确认后取消率、单任务平均步骤数、失败恢复时间
- **取消信号主动检查点（2026-10-05，详见 [[摘要-agent任务取消机制]]）**：ReAct 循环"调模型→执行工具→再调模型"不能只靠信号传递，必须在**流式输出过程中、每个工具执行之前、重试等待的间隙**主动检查取消信号，取消了就不再发起新的一步——类比 Java `Future.cancel(true)` 只打中断标记，任务自己不检查标记线程就停不下来；Claude Code（AbortController）与 Codex（CancellationToken）均如此实现，详见 [[Agent任务取消]]
