## 定义
Agent 基础设施指支撑 Agent 真正干活的各类环境与连接件——浏览器、电脑（云电脑）、邮箱、飞书/钉钉等通讯工具、MCP/CLI/Skill 等连接协议。在 Personal Agent 公式 **Personal Agent = Agent Harness 框架 + Agent 基础设施 + 垂直领域专业工具** 中居中间层：只有基础设施成熟，Agent 才能从"能聊天"变成"能办事"。

## 关键信息
- **历史教训**：龙虾（[[OpenClaw]]）时代只有驱动 Agent 运行的框架，各种基础设施和专业工具都在萌芽期，与人们"无所不能 AI 管家"的野心不匹配，所以热度消散；该阶段最大价值是教育市场、培养核心开发团队和工具生态
- **2026 年成熟标志**：AI 浏览器让 AI 能访问 Web 应用 → 视觉能力提升后 AI 可调用各种工具 → 各家推出 MCP/Skill/CLI，Agent 开始连接过去只有人能操作的桌面工具与企业 SaaS
- **反向压力**：传统 SaaS 厂商最近开始主动适配 Agent——"如果你不主动适配，Agent 可以直接逆向你的 SaaS 一键复刻"
- **个人侧配套**：与 [[云电脑]] 共同构成"Agent 有了自己的云端电脑"这一发展三要素之一
