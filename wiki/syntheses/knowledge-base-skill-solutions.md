# 用 Skill 实现知识库优先检索的四种方案

## 背景
用户想在工作知识库中记录代码问题解决方案，当 AI 写代码遇到难题时，先检索知识库找现成方案，有则用，无则自行解决并可选记录。

## 四种方案对比

### 方案一：Skill（推荐 ⭐）
创建 `.claude/skills/knowledge-first/SKILL.md`，定义知识库位置和检索规则。遇到问题时手动触发 `/knowledge-first` 或自动生效。
- **复杂度**：低
- **优点**：灵活可控，不占上下文，渐进式披露
- **适用**：大多数场景

### 方案二：CLAUDE.md 写规则
在项目级 CLAUDE.md 中写入"先查知识库"的规则，每次对话自动生效。
- **复杂度**：最低
- **优点**：无需手动触发
- **缺点**：规则膨胀会占上下文

### 方案三：AutoMemory 自动积累
结合 CLAUDE.md 规则 + AutoMemory 自动记忆，让 AI 自动记录经验，下次自动注入。
- **复杂度**：最低
- **优点**：完全自动，无需维护
- **缺点**：记忆不如文件系统可控

### 方案四：RAG 系统
用向量数据库（如 Chroma）把知识库做成向量索引，通过 MCP 或 Tool 连接。
- **复杂度**：高
- **适用**：知识库很大（几百+文件），需要语义搜索

## 推荐 Skill 模板
```markdown
---
name: knowledge-first
description: 遇到问题时优先检索知识库，有现成方案就用，没有再想其他办法。
---

# 知识库优先策略

## 知识库位置
我的工作知识库在：`/path/to/your/knowledge-base/`

## 执行规则
当你遇到我无法解决的问题，或我明确说"查一下知识库"时：
1. 用 Grep/Glob/Read 工具搜索知识库
2. 如果找到匹配方案，严格执行
3. 如果没找到，自行解决，并询问是否记录到知识库
```
