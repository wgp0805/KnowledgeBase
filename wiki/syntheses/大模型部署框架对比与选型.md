# 大模型部署框架对比与选型

将本地知识库中收录的大模型部署框架按 **推理引擎层**、**应用编排层**、**微调层** 三类梳理，并给出企业与个人的选型建议。

## 一、推理引擎层（让模型跑起来）

| 框架 | 侧重点 | 适用场景 |
|------|--------|----------|
| [[Ollama]] | **易用性优先**，封装模型管理 + CLI 体验，一行命令拉模型即用 | 个人本地尝鲜、开发联调、Spring AI 集成 |
| [[LlamaCpp]] | **性能与可控性**，C++ 底层，暴露 TensorSplit / KV cache 量化 / 投机解码等调优参数 | 本地 Agent 工作站、多卡部署、追求极致吞吐 |
| [[LM_Studio]] | **桌面 GUI**，图形化管理本地模型 | 不爱命令行的用户、作为 Dyad 等工具的本地后端 |
| vLLM | **服务端高吞吐**（PagedAttention），偏生产部署 | 企业级 API 服务、多用户并发 |

### 关键区别
- [[Ollama]] 底层即 [[LlamaCpp]]，但封装了模型管理和 CLI 体验；llama.cpp 直接暴露更底层的参数控制，适合调优。
- vLLM 偏服务端高吞吐，llama.cpp 偏本地端灵活配置（见 [[LlamaCpp]]）。
- 协议层已统一为 OpenAI 兼容端点，上层框架不挑推理引擎（见 [[本地Agent工作站]]）。

## 二、应用编排层（让模型干活）

| 框架 | 侧重点 | 适用人群 |
|------|--------|----------|
| [[Dify]] | **LLMOps + RAG 知识库**，可视化搭知识库和 Agent，开源 | 企业知识库、产品/运营零代码搭建 |
| [[Coze]] | **零代码 Agent + 工作流**，字节出品，Text-to-Workflow | 非技术人员快速搭建场景化 Bot |
| [[CherryStudio]] | **桌面端个人知识库**，接入多 LLM API | 个人知识管理 |
| [[Dyad]] | **本地全栈应用构建器**，对话式开发，21k Star | 开发者本地构建 AI 应用 |

### 关键区别
- [[Dify]] 更偏 RAG/知识库场景，[[Coze]] 更偏 Agent 工作流编排，二者同为入门级工具（见 [[Dify]]、[[Coze]]）。
- [[Dyad]] 面向开发者，可接入 [[Ollama]] / [[LM_Studio]] 作为本地模型后端（见 [[Dyad]]）。

## 三、微调层（让模型变专属）

| 框架 | 侧重点 |
|------|--------|
| [[LlamaFactory]] | **一站式微调**，降低门槛，初学者几小时完成专属模型微调，代表"开源基座 + 行业数据微调"标准范式 |

## 四、推荐选型

### 个人开发者
- **入门**：[[Ollama]] + DeepSeek/Qwen（一行命令，零门槛，见 [[摘要-Ollama+DeepSeek本地部署]]）
- **进阶 Agent 工作站**：2× RTX 5090 + [[LlamaCpp]] + Qwen3.8-27B + DSH，完全本地、完全私有、零 API 费（见 [[本地Agent工作站]]、[[摘要-人类智力基线与2张显卡]]）
- **知识库**：[[CherryStudio]] 或 [[Dify]] 本地部署

### 企业
- **内部知识库/客服**：[[Dify]]（可视化、RAG、多模型接入）
- **生产级 API 服务**：vLLM（高并发）+ [[LlamaFactory]] 微调行业模型
- **数据敏感场景**：[[本地Agent工作站]] 方案（数据不出内网）

### 成本对比（来自 [[本地Agent工作站]]）
| 方案 | 一次性投入 | 月费 | 数据隐私 |
|------|------------|------|----------|
| 云端 API（DeepSeek/GPT） | ¥0 | 数百-数千元 | 数据在云端 |
| Claude Code 订阅 | ¥0 | $20+ | 数据在云端 |
| **本地双卡工作站** | ¥30,000-40,000 | ¥0（仅电费） | **数据不出本机** |

## 五、核心权衡维度
1. **易用 vs 性能**：Ollama 易用，llama.cpp 性能
2. **本地 vs 云端**：本地隐私好但一次性投入高；云端零投入但月费持续且数据出域
3. **零代码 vs 代码**：Dify/Coze 零代码，DSH/llama.cpp 需技术能力
4. **框架不挑模型**：OpenAI 兼容端点统一了接入层，模型升级硬件不用换（见 [[本地Agent工作站]]）
