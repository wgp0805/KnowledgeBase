什么是Hermes Agent

Hermes Agent，是以自进化的能力出圈的龙虾类Agent～

比起OpenClaw，它不仅多了自进化技能，还更容易上手，Bug更少，运行更安全稳定，更省token，所以口碑持续飙升。

同时，它又比编程类Agent更适合连接飞书、微信等IM工具，方便我们远程使用。再加上长期记忆能力，它很适合作为一个7×24小时运行的日常助手，尤其适合需要长周期的学习！

![图片](assets/0%E5%9F%BA%E7%A1%80%E5%B8%A6%E4%BD%A0%E4%B8%8A%E6%89%8B%20Hermes%20Agent%EF%BC%81%E3%80%90%E6%96%B0%E6%89%8B%E6%95%99%E7%A8%8B%E3%80%91/4ce2de1a8eeed2c1a73111b0a596081b_MD5.webp)

2.2 添加本地模型的好处

本地模型主要有三大优点：

更节省 Token：一些网页提取、上下文压缩等基础任务，可以交给本地小模型处理，减少主模型的消耗。

隐私性更高：敏感资料可以直接留在自己的电脑上处理，不需要上传到云端。

离线也能使用：即使断网，本地模型依然可以运行。后续还可以根据自己的需求进行微调。

![图片](assets/0%E5%9F%BA%E7%A1%80%E5%B8%A6%E4%BD%A0%E4%B8%8A%E6%89%8B%20Hermes%20Agent%EF%BC%81%E3%80%90%E6%96%B0%E6%89%8B%E6%95%99%E7%A8%8B%E3%80%91/fc8f515b5520a66998a1dfd21cbfd120_MD5.png)

多 Agent 与多模型配置

3.1 多个 Agent 的好处

Hermes可以有不同的Agent，配不同的身份、记忆和用途，完全隔离，比如一个生活助理、一个工作助理、一个学习导师。而且它最大的好处是，一个挂了，你还能让另一个去修它。

另外，多个模型也是有必要的！Hermes可以设置辅助模型，把杂活都给小模型，尤其是免费的本地模型干，更省token！
