HexHub 是一款专为开发者和运维工程师打造的高颜值全栈开发运维工具，集成了数据库管理、SSH终端、SFTP传输和Docker管理四大核心功能模块。

作为"Navicat + FinalShell + Portainer"的终极替代方案，HexHub 提供原生中文界面和开箱即用的便捷体验，支持 Windows、macOS、Linux 全平台部署。

其社区版永久免费，为个人开发者和小型团队提供了专业级的运维管理能力。

01

核心功能

01 数据库管理与开发

HexHub 构建了完整的数据库开发生态，支持 MySQL、MariaDB、PostgreSQL、SQLite、ClickHouse 等主流数据库系统。

![图片](assets/%E5%86%8D%E8%A7%81Navicat%E3%80%81XShell%EF%BC%81%E4%B8%80%E6%AC%BE%E9%AB%98%E9%A2%9C%E5%80%BC%E7%9A%84%E6%95%B0%E6%8D%AE%E5%BA%93%E3%80%81SSH%E3%80%81Docker%E7%AE%A1%E7%90%86%E5%B7%A5%E5%85%B7%EF%BC%81/87bdb91808bab8caddf91611765a9667_MD5.webp)

智能 SQL 编辑器

- 提供上下文感知的自动补全功能，大幅提升编码效率
- 语法高亮和代码格式化确保代码可读性
- 流式查询支持大数据集的实时加载
- 执行计划分析帮助优化查询性能
- 查询结果支持多格式导出

可视化表结构编辑器

- 字段属性编辑支持类型推导和约束设置
- 索引管理提供可视化创建和优化建议
- 内联编辑模式允许直接在表格中修改数据结构
- 修改和新增操作提供视觉着色反馈
- 字段顺序支持拖拽调整，操作直观便捷

高性能数据编辑器

- 提供类似 Excel 的操作体验，学习成本低
- 支持百万级别数据的流畅编辑，性能表现优异
- 批量导入支持 SQL 和 Excel 文件格式
- 导出功能涵盖 SQL、Excel、TXT、JSON 以及数据字典
- 跨数据库复制粘贴实现异构数据源的数据迁移
- 表结构和数据同步确保多环境一致性

02 SSH/SFTP 远程连接管理

![图片](assets/%E5%86%8D%E8%A7%81Navicat%E3%80%81XShell%EF%BC%81%E4%B8%80%E6%AC%BE%E9%AB%98%E9%A2%9C%E5%80%BC%E7%9A%84%E6%95%B0%E6%8D%AE%E5%BA%93%E3%80%81SSH%E3%80%81Docker%E7%AE%A1%E7%90%86%E5%B7%A5%E5%85%B7%EF%BC%81/48b5e852729d4f43191b236f01cb58fc_MD5.png)

多协议终端访问

- 支持 SSH 和 RDP 远程连接协议
- 同屏展示终端、远程目录和本地目录，操作连贯性强
- 支持 SFTP、ZMODEM/LRZSZ、TRZSZ、SCP 四种文件传输协议
- 基于自研 ZMODEM 协议实现高速稳定的传输体验

高级文件管理

- SFTP 跨服务器多线程并发传输，大幅提升大文件传输效率
- 本地和远程文件系统的双向同步和对比
- 文件权限和属性的可视化编辑

系统监控面板

- 实时显示网速、CPU 使用率、内存占用等关键指标
- 进程列表提供详细的系统运行状态
- 磁盘挂载和使用情况的可视化展示

03 Docker 容器管理平台

![图片](assets/%E5%86%8D%E8%A7%81Navicat%E3%80%81XShell%EF%BC%81%E4%B8%80%E6%AC%BE%E9%AB%98%E9%A2%9C%E5%80%BC%E7%9A%84%E6%95%B0%E6%8D%AE%E5%BA%93%E3%80%81SSH%E3%80%81Docker%E7%AE%A1%E7%90%86%E5%B7%A5%E5%85%B7%EF%BC%81/ff4a67d8c93c5139bf3ae12f7b2c2c98_MD5.png)

容器全生命周期管理

- 支持自定义镜像仓库配置
- 透过 SSH 连接远程 Docker 服务器，无需暴露 Docker API 端口
- 容器 CPU、内存、IO 实时趋势图，性能监控直观清晰

日志管理系统

- 支持限制最大显示行数，避免大量日志导致的界面卡顿
- 关键字过滤和搜索功能快速定位问题
- 追加时间和行数标识，便于日志分析和问题追溯
- ANSI 彩色输出保持日志的可读性
- 标准输出流和错误流的分离显示，便于故障诊断
