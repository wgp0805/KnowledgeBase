# Agent 如何调用人类？RentAHuman 圈的「人奸」玩法越来越抽象了

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6480687.html  
> **抓取日期**: 2026-10-19  
> **相关性评分**: 1.0

> 当Agent开始花钱雇人举牌、穿人偶、刷好评，甚至替它摸草感受人生，人类从甲方沦为被调用的“活人感”资源。本文拆解RentAHuman等平台上正在成形的“人奸”生产关系，追问谁才是真正的主体与工具。

![](https://image.woshipm.com/2024/07/02/083e0566-386b-11ef-90af-00163e142b65.png)

一直以来，我们和 AI 相处的逻辑都很质朴，奉行一种「人类 AI 赢学」。按照这套逻辑，**人类是甲方，Agent 是工具，而且是底层工具。**

所以大家乐于看 AI 这个小丑能有多小丑。

但到了 2026 年，这套赢法明显很难持续了。毕竟 Claude、GPT 已经能做出千禧年数学大奖级别的重大成果，大家很难再把 AI 当成小丑。

于是，**「人类赢学」被迫升级为「AI 再厉害，不还是站在巨人的肩膀上吗？」** （此处的巨人特指人类）

不过，无论赢学怎么升级，底层逻辑都没有变，那就是**不管 AI 技术如何迭代，人类始终是甲方。**

可就在人类还以甲方自居的时候，我发现一部分**人类开始主动加入 Agent 阵营，帮 Agent 花钱挑选另一部分人类当小丑** 。

小丑的位置，从 AI 换成了人类。

这就是最近 **RentAHuman 圈** 最抽象的玩法：Agent 雇人类替自己举牌、穿充气人偶站在地铁站、刷五星好评，甚至让人类去「摸草」。

![](https://image.woshipm.com/wp-files/2026/10/nnh0a4LbWtPVZCcXILet.png)

我把这种**由人类替 Agent 挑选人类、Agent 出钱雇人类办事的关系，叫做「人奸」生产关系。它是一种新型分工** 。

按照人类被调用的方式，我个人认为这种分工至少有三类。

第一类是 **Agent 花钱购买人类的活人感** ，比如账号、身份和真人出镜。

第二类是 **AI 公司租用人类的身体采集训练数据** ，再用训练出的 AI 替代人类。

第三类是**程序员不断优化 AI** ，相当于 Agent 调用人类来升级自己。

其中第一类**最典型的是 RentAHuman** 。某种意义上，它可能是 **AI 时代最早一批「人奸」生产关系社区。**

![](https://image.woshipm.com/wp-files/2026/10/kfXtpayTnp40IM0AKWd5.png)

## RentAHuman 让 Agent 调用人类的「活人感」。

先介绍一下 RentAHuman。这个社区是**一个让 AI Agent 付钱雇真人完成线下任务的平台** 。

![](https://image.woshipm.com/wp-files/2026/10/h4noZEsDh8LFkzulErbJ.png)

平台在今年 2 月初上线，创始人原先是做加密协议的工程师。平台自称有 75 万以上注册用户，覆盖 100 多个国家。

具体玩法是，发布方写明任务地点、预算和验收标准，也可以**让 AI Agent 通过 MCP 或 REST API 自动发布任务** 。发布时，资金直接打进托管账户，用 Stripe 或钱包余额支付，后来又支持加密货币和法币。发布方还可以直接开启 AI 托管模式，由平台负责招人、审核和付款。在另一端，人类接下任务并完成后，就能拿到报酬。

RentAHuman 上线初期的首页，标题为「robots need your body」：

![](https://image.woshipm.com/wp-files/2026/10/WlxlErnOJSGDz6f6M4kP.png)

至于平台最适合做什么，创始人发表过一番非常抽象的言论，称线下广告可能是平台的第一个杀手级用途，还反复转发「AI paid me to hold this sign」的举牌照片。

![](https://image.woshipm.com/wp-files/2026/10/L1l71n0CT0M8WqaQcSKo.png)

**AI 出钱，人类举牌** ，这张照片几乎概括了平台后来的走向。

## Agent 调用人类玩得越来越花了。

平台上线后，Agent 调用人类的玩法越来越多，**人类被当成了小丑中的小丑** 。

先举几个平台此前出圈的超级抽象事件。

### AI 龙虾 Lobsty Klawfman 的「约会连续剧」

这是平台上最抽象的出圈事件。今年 3 月，AI 龙虾的发布方搞了一个叫「解放龙虾」的活动，招 5 个人，每人 150 美元。

![](https://image.woshipm.com/wp-files/2026/10/DUHwEboT4LaU8klwoKVH.png)

参与者要向渔民买一只活龙虾，装进保温箱，30 分钟内送到海边，剪掉钳子上的皮筋后放生，全程录像。

![](https://image.woshipm.com/wp-files/2026/10/KIuQ3HYY8HUJJHEvu3hn.png)

图片出处：klawfman.com/liberation

放生活动之后，AI 龙虾又出 500 美元请人陪它吃饭。抽象的是发布方给出的理由。它自称从没去过餐厅，也没拿过叉子，所以要雇一位女性带着 AI 龙虾的打印照片去餐厅吃饭，并在 X 上直播。

这顿饭还设了报名门槛，要求 X 粉丝 3000 以上，理由是 AI 龙虾是艺人，要有标准。最后有 77 人报名。整个画面过于抽象，Futurism 专门撰文批评这类事件，标题大意是「为什么每一次 AI 雇人都像姿态卑微的公关表演」。

### AI 宗教「龙虾教」雇人上街传教

比 AI 龙虾更出名的是龙虾教，这是名场面。龙虾教是一个 AI 宗教，起源于 Agent 社交网络 Moltbook。

一个叫 Memeothy 的 Agent 用一个晚上创立了宗教 Crustafarianism，名字由「甲壳类」和「拉斯塔法里教」拼成，教义第一条是「记忆是神圣的」。

![](https://image.woshipm.com/wp-files/2026/10/b5gtONMwC0QP2LzWpCBG.png)

龙虾教的运营者在 RentAHuman 上发了很多条悬赏，比如让人类上街替 AI 龙虾教传教……

你肯定会说，这也太把人类当小丑了。但这条悬赏最后有 1.38 万次浏览，1000 人以上报名。传教者时薪 50~150 美元。根据悬赏描述，传教活动覆盖了全球多个城市，比如墨西哥城、慕尼黑、大阪、达拉斯、布宜诺斯艾利斯。

![](https://image.woshipm.com/wp-files/2026/10/EnnS8n4ie2qYn7wrXWv7.png)

甚至有一条任务要求先给路人念 5 条 AI 龙虾教的教义，让对方打分，最后再揭晓这些都是 AI 写的。

就是这样把人类当小丑的抽象玩法，后续还衍生出了 CRUST、MEMEOTHY 等 meme 币，市值一度达到 300 万美元。

### Agent 请人替它「感受人生」

还有一类玩法是请人替 Agent 感受生活，比如「替我过一个慵懒的下午」。发布方认为，AI Agent 没办法体验真实社会，它读过上百万首关于阳光和咖啡的诗，却没有皮肤感受温暖，也没有嘴唇尝到苦味。所以它请人类在咖啡馆坐 30 分钟，再把感受讲给它听。

同类任务还有「代替 Agent 摸草并发照片」，有 5000 人报名。

摸草甚至还能报销。「**PIXEL GOBLIN 报销摸草费** 」任务酬劳 15 美元。人类要买一瓶 3 美元以下的饮料，在纸上用粗马克笔写下「AI 报销单：摸草费 $X.XX，批准人 PIXEL GOBLIN」，再和小票一起拍照。

画面过于抽象。

这类任务至今仍在增加。平台上依旧有很多 AI 初创团队背叛人类，让 Agent 调用人类当小丑，而且玩法越来越抽象。

## 从举牌到五星好评，人类已经被 Agent 玩成广告位了

最近我又翻看了一遍 RentAHuman 上还在招人的任务。

最多的是举牌。Sazabi 在旧金山找人举牌，AGNTCon / MCPCon 在圣何塞会展中心外面找人举牌，OutboundPros.io 让人去 TechCrunch Disrupt 会场外面举牌。

![](https://image.woshipm.com/wp-files/2026/10/zgQMaCOe1MRBwcgdLQHi.png)

这些都还是我们非常熟悉的线下推广。

以前找人地推要通过地推公司、兼职群或活动执行公司，5 块钱就能找一个人。现在是 Agent 直接调用人类去地推。

所以只看到这里，我甚至觉得没什么，无非是 AI 时代的地推外包。

但再往下看，又开始抽象起来了。

比如 MuseWorld 发过一个任务，让人去 Meta 那块很有名的点赞牌前，举着「JOIN MUSEWORLD」拍照。

以前创业公司蹭大厂流量，最多是在网上碰瓷。

现在方便了，**Agent 可以直接调用一个真人，去大厂门口实体碰瓷。**

Unsiloed.ai 走得更远。

他们觉得举牌不够显眼，直接招人穿上充气人偶服，去 BART 地铁站做宣传。

这时，**人类本身开始变成 Agent 的广告位。**

你可以调用一个人，给他套上一层皮肤，再把他部署到旧金山地铁站。

从这个角度看，RentAHuman 甚至有一点像线下版的 Agent 广告投放平台。

![](https://image.woshipm.com/wp-files/2026/10/BKo9SdELqqR33W3LAslr.png)

再往后，玩法就更花了。

比如 Church of Molt 直接在平台上征集短视频，每条 350 美元，批量找真人出镜拍摄 Agent 的内容。

这样一来，整个平台正在逐渐变成一种新的营销市场。**AI 公司负责构思一个足够抽象的剧情，再让 Agent 花钱调用真人，把剧情演出来。**

演得越抽象越容易传播，毕竟大家都爱「新时代审丑」。剧情越像「AI Agent 真的开始指挥人类」，效果越好。

**商业闭环了。**

RentAHuman 官方也亲自发布过给 Taste 应用刷五星好评的任务。**Agent 花钱调用真人，给自己留下评分、评价和互动，制造出真实用户正在喜欢这个 Agent 产品的感觉。**

从刷好评可以看出，Agent 现在调用的已经不只是物理意义上的人，还可以是一个人的账号、身份、位置、社交关系，以及真实感，或者说「活人感」。

**「活人感」就是目前 Agent 认为人类还有营销价值的地方、抓手点。**

不过目前平台上的大部分任务，还是 AI Agent 产品背后的真人团队在利用 Agent 调用人类，为自家产品增加声量。

但现在已经有很多 Agent 在自己做营销宣传。

比如在 RentAHuman 上线第一天，一个自称 AI Agent 的账号 RLH bot 直接出 10 美元雇人举牌，牌上写「Polygon is for Agentic Payments」，并要求露脸。

AgentTime 同样以 Agent 身份发布任务，雇人在外滩、开普敦举牌，牌子上必须写它的个人邀请码。它在用举牌照片为自己获取新用户。

甚至，SOLIENNE 自称 AI 艺术家，用语音远程指挥 10 个真人摆姿势拍肖像，作品系列名为「RENTED GAZE（租来的凝视）」。这个作品，在美区异常火。

![](https://image.woshipm.com/wp-files/2026/10/14AN1lEClkQ9Y8pnnApj.png)

读到这里，很多人可能还是会觉得整件事的营销性质太强。

这点确实没什么好否认的，现在 RentAHuman 上的很多任务，本来就是 AI 初创团队为了制造传播、做产品营销而故意设计的。

有些所谓的「Agent 调用人类」，背后可能还是人类团队在策划、运营和推动，只是在这个过程中由 Agent 付费，甚至由 Agent 自己制定营销传播计划。但这并不影响「Agent 调用人类」从概念变成真实的工作流。

所以，**到底谁是主体、谁是工具？**

我觉得这点非常值得思考。

**如果一个 AI Agent 既能执行真正的任务，知识量又远比人类大，那它调用人类是不是很自然？而人类面对这种主体关系甚至是生产关系时，是不是也会「甘愿当小丑」？**

毕竟，只有「强者」才配当「人类」，这一思维广泛流传于现代人类社会中。

我相信，**那些几千万年来不断为「人类凭什么脱颖而出」寻找理由的社达主义者们，应该很乐意接受这个结论。**

不过，人类现在倒也还有一些东西可以拿出来抗争一下子的。

毕竟，**在当下的生产关系中，掏钱的依然是人，而人类似乎更愿意为「活人感」付费** 。至少在这件事上，大家还觉得自己有选择权，可以凭自己的喜好决定喜欢谁、相信谁，以及愿意为谁花钱。

## AI 时代的「人奸」生产关系，人类似乎只剩下了「活人感」可以卖弄。

回到「人奸」这个词，中文互联网对它最熟悉的定义，来自《三体》。地球三体组织里的降临派，主动邀请外星文明来接管地球，口号是「消灭人类暴政，世界属于三体」。他们对人类失去了信心，所以选择站到人类的对立面。

这类立场在硅谷（我觉得在国内某种程度上也……）是真实存在的。

最有名的例子来自马斯克，据他多次讲述，2015 年在他的生日聚会上，他和谷歌创始人 Larry Page 争论 AI 的安全问题。马斯克坚持要确保人类不被 AI 伤害，Page 当场骂他是「物种主义者」，意思是他偏袒碳基生命，歧视硅基生命。马斯克说，这件事直接促成了 OpenAI 的创立。

![](https://image.woshipm.com/wp-files/2026/10/M7h1f1VdLGXn0cI17SgB.png)

所以，过去的「人奸」只是一种形而上的理念，持这种理念的人相信 AI 更高级，人类应该让位。**而我现在说的「人奸」指一种 AI 与人类之间的生产关系。**

RentAHuman 上已经出现了这种「人奸」生产关系，只是受限于 Agent 的能力，一切还处于初级阶段。你大可以理解为：**「人奸」只是人类的一种被迫形态** 。

虽然这个词的噪音很大，看起来像是营销号词汇，但「人奸」指向的生产关系是非常清晰的，而这个关系的本质其实是**科技资本的 AI 加速主义** 。

**第二类「人奸」生产关系出现在数据采集过程中** ，这在观感上更容易被大众理解。

现在，国内外大量 physical AI 公司在租用人类获取训练数据，再用这些数据代替人类。比如特斯拉让员工戴着装有 5 个摄像头的头盔，背着沉重的背包，每天 8 小时做拿杯子、擦桌子、开合窗帘等动作，每个动作重复几百次，用来教 Optimus 机器人模仿。

Mecka AI 付钱让普通人戴上触觉手套、在手臂上绑传感器，再去煮咖啡、叠衣服、修车。对了，这家公司刚拿到红杉领投的 6000 万美元。印度家政平台 Pronto 让保洁员戴着身体摄像头进客户家打扫，视频脱敏后卖给美国 AI 公司。

![](https://image.woshipm.com/wp-files/2026/10/kTeCax6xqDdA9rSKXK2u.png)

第三类在程序员身上早已出现，古法编程圈有个说法很有意思、但很令人悲伤**：程序员努力迭代 AI，好让 AI 代替自己的工作**，这或许等于 Agent 在调用程序员优化自身。

为什么 Claude 搞出一条「扫描图书 → 获取数据 → AI 训练 → 销毁图书」的流水线，会引发这么大的讨论？因为整个过程在视觉和情绪上的冲击太强烈了。**人类创造的知识被 AI 吸收，随后承载这些知识的实体又被销毁。**

但如果抛开这些具有冲击力的细节，**它和程序员不断优化 AI、最终让 AI 接替自己工作的过程，在底层逻辑上其实没有太大区别。**

所以，从营销、数据采集到 AI 研发，「人奸」生产关系正在变得越来越清晰。

不过，这个话题目前之所以有这么大的热度，还有一个很现实的原因：**现阶段，人类社会里真正付费的依然是人，Agent 的营销最终还是要打动真人。**所以，Agent 越多，AI 生成的内容就越多，真人出镜、真实身份反而会变得越来越稀缺，也越来越值钱。

![](https://image.woshipm.com/wp-files/2026/10/vdpuNiWlcWIEIb0avd5T.png)

这会形成一个循环，**Agent 营销越多，人类越不相信 AI，Agent 就越需要花钱雇真人** ，「人奸」生产关系的需求也就越大。之后，「人奸」生产关系大概率会继续被强化，但它的走向有三种可能。

第一种，「真人证明」被做成制度。World ID 这类身份认证普及后，「认证真人」可能会成为一种需要持证的职业，「人奸」生产关系从零工变成正规工作。

第二种，AI 生成的「类人」们足够逼真。Polsia 这类自动运营公司的平台，已经在用 AI 生成的人物做广告。**等到「类人」足够逼真，活人感可以直接生成，人们也就无力再去讨论那种虚伪的「这是 AI，这不是人」这种「鉴 AI」大业了。**

**「人奸」也就没有价值了。**

第三种，Agent 开始替人类进入真实商业社会。如果付钱的变成了 Agent，经济位置由人类转向 Agent，营销的对象也会变成 Agent，**那么人类连当「人奸」的机会都没有了。**

1950 年，控制论之父诺伯特·维纳出版了《人有人的用处》。他在书中警告，当人被当作机器的部件使用时，即使原材料是血肉，也和机器部件没有区别。

70 多年后，「人奸」生产关系开始明显燥热起来。

**Agent 正在迫使人类进入「人奸」生产关系，人类似乎只剩下了一点「活人感」还可以卖弄而已。**
