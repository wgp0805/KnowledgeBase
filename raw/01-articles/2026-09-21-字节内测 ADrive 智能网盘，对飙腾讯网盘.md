# 字节内测 ADrive 智能网盘，对飙腾讯网盘

> 字节正在内测面向企业的 ADrive 智能网盘，让用户与 AI Agent 共用同一套文件存储与协作空间，豆包、TRAE 以及 Codex、DeepSeek 生成的文件都能沉淀进来。它带企业、团队、个人三级空间与自然语言检索，对标的腾讯网盘也在内测。

网盘作为办公的基础性储存服务，在 AI 时代，不再是仅仅作为文档存储的空间。

而是成为知识资产沉淀、共享协作、多应用连接、Agent 调用的基础设施。

**AI 办公 Agent 的竞争，进入了深耕期。**

**大家要开始发力AI 智能网盘了。**

## 1 字节内测 ADrive 智能网盘

当前，**字节正在内测一个叫 ADrive 智能网盘产品。**

![](https://image.woshipm.com/wp-files/sha256/a0/2d/a02d21c467a0226e027295d84ad3dfee776df5d30f758ccd716450354a9f3649.png)

**这是一个 Agentic AI 智能网盘，目前主要面向企业用户。**

可供用户和 AI Agent 协同使用，为用户、为 AI Agent 提供统一的文件存储与协作能力。

![](https://image.woshipm.com/wp-files/sha256/bd/1b/bd1b85e3900f44d14dd87285ebea88740ea33bb66db4fee657d8dc7674e4ecf2.png)

ADrive 的slogan：

**链接你的AI应用，让文件与产物持续可用。**

在 ADrive 产品介绍页上，可以了解到。

字节系的 AI Agent ，如豆包、豆包工作、TRAE、Aime 等，在使用过程中生成的文件，可存储在 ADrive 里。

同样，Codex、DeepSeek等外部 AI Agent 生成的文件，也可以存储在 ADrive 里。

**不用再切换多个 AI 应用找文件。**

![](https://image.woshipm.com/wp-files/sha256/7f/0f/7f0f8e7af57027288c408a5643ae13cd8ba7972d6f1b2611d1272927058fa247.png)

**这些文档和产物， 可团队复用和被 Agent 引用。**

**实现人和 Agent 在同一个工作空间办公。**

![](https://image.woshipm.com/wp-files/sha256/66/56/6656dbfcaf9d3fbd7e636557661b5f6765841dcd55bac3a14ca8ec6ca719d023.png)

**ADrive 也支持挂载本地同步盘。**

下载安装客户端后，打开应用。能实现云上、本地信息的同步。

![](https://image.woshipm.com/wp-files/sha256/6a/08/6a08b9bb5284fbd06c7c4c858d63d4b17a926dbbbbbdd0229ea4d4bcdd4dd252.png)

这是云端个人空间文件信息。

![](https://image.woshipm.com/wp-files/sha256/3c/cf/3ccf85b9b9b77a1a11fd14d010d5bc4cf59afdfb3ce6837547b9148aa7f0d388.png)

这是本地 ADrive 虚拟盘。

![](https://image.woshipm.com/wp-files/sha256/42/63/4263d6b645d4f16f59a64b68be49217f3c08359c8226ae55b5ab0063e7e3a646.png)

**可以看到本地 Drive 虚拟盘中的文件结构，与云端网盘保持完全一致。**

**在 ADrive 中，有集成 AI 智能助手，可提供智能化的文件处理能力。**

支持文档润色、文档改写扩写、文档翻译等文档总结归纳。

支持PDF 转 Word、图片转 Word、图片转 PDF 等各类文档格式间的转换。

支持图片添加水印、尺寸调整、美化、OCR 等图片编辑。

**还能把存储的文档内容，当成知识库，可基于知识库进行推理和问答。**

![](https://image.woshipm.com/wp-files/sha256/02/51/02511b00688d2b128c6d31fe805228b0bca491bf7488ed118336428a2199e050.png)

作为企业文件管理 AI 智能网盘。

**ADrive 提供三级空间管理体系** ，企业空间、团队空间、个人空间，支持灵活的容量配额管理。

![](https://image.woshipm.com/wp-files/sha256/34/d1/34d17050ac7b0c15f6c21bbb975884ed1138e62b6fdd91310bbc0c13bffdf90d.png)

同时，ADrive有很强的智能检索能力

不需要你知道文件名，支持在全局或指定范围内，使用自然语言，一句话快速搜索文件。

ADrive AI 能通过语义的理解，精确匹配文件内容。

还支持以图搜图的能力，上传图片，快速定位相似图片。

## 2 腾讯内测腾讯网盘

**腾讯网盘，一直在为 WorkBuddy 提供储存支持。**

WorkBuddy 资料库的存储空间，就是腾讯网盘提供的服务。

![](https://image.woshipm.com/wp-files/sha256/83/52/8352be53a410c2f683cd89d2bcc2b071329f650808509423802cdc783918de62.png)

前阵子， 腾讯网盘上线了官网。

准备作为一个独立产品推出，为用户提供 AI 智能网盘服务。

![](https://image.woshipm.com/wp-files/sha256/08/32/083209a45daa418dda0b17b47c2163f49feca15f6a2ddeb8aac2607900a0b99b.png)

从官网介绍可以看到。

**腾讯网盘，可连接多个 AI 应用，共享存储空间，聚合上下文。**

![](https://image.woshipm.com/wp-files/sha256/f2/70/f2703b25a01713e0f2a6c6d0903a30c63db62de66468e32d9a366a6595b5cd8f.png)

腾讯生态内的所有 AI 应用的数据，比如 WorkBuddy、腾讯文档、CodeBuddy、IMA、元宝、腾讯会议等。

**不管是人上传的、新建的，或者 AI Agent 生产的，或者人机协作完成，都可以沉淀在腾讯网盘。**

在腾讯网盘，形成企业、团队或个人的长期记忆资产。

这些文档，可作为上下文，随时被 AI Agent 引用。

**腾讯网盘的内容，支持 Agent 调用。**

通过 CLI、MCP 调用数据，让 AI 真正用上数字资产。

## 4 当 AI 遇上网盘

**以前的网盘产品** ，主要作用是存放资料的云空间，支持跨设备随时随地获取网盘数据。

**主要是存资料和看资料的地方。**

现在，随着 AI Agent 作为企业、团队或个人配置的数字员工。

需要作为一个员工，加入到工作流中来。

这样，文档的来源、文档的使用、文档的检索识别、文档的共享协作等。

**都需要有 Agent 的加入。**

**这和以前传统的网盘的逻辑，完全不一样。**

网盘需要支持 人和 Agent 共同协作。

网盘中的资料，也需要被 Agent 随时作为上下文使用。

也正是有 Agent 的加入，网盘中的数据资料，才不止于躺在那里吃灰，会被彻底激活。

资料变成真正的资产。

这也需要从新的角度，AI Agent 的角度，重构网盘产品。

随着字节、腾讯的 AI 智能网盘推出。

**传统网盘业务，将迎来 AI 化。**

**AI 智能网盘，将作为AI 办公 Agent 产品的重要基础设施。**

**参与到激烈的市场竞争中去。**
