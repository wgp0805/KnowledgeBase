# 从卖工具到收”过路费”：SAP、Salesforce 殊途同归的 Agent 生意

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6466441.html  
> **抓取日期**: 2026-09-18  
> **相关性评分**: 1.0

> SAP 今年 4 月收紧 API 政策，外部 AI 智能体不能直连接口，必须走自家助手 Joule，集成网关也开始按调用次数计费，圈里管这叫「代理税」。Salesforce 走的是相反的路，把整个平台的能力拆成 60 多个工具、30 多项技能。

![](assets/2026-09-18-%E4%BB%8E%E5%8D%96%E5%B7%A5%E5%85%B7%E5%88%B0%E6%94%B6%E2%80%9D%E8%BF%87%E8%B7%AF%E8%B4%B9%E2%80%9D%EF%BC%9ASAP%E3%80%81Salesforce%20%E6%AE%8A%E9%80%94%E5%90%8C%E5%BD%92%E7%9A%84%20Agent%20%E7%94%9F%E6%84%8F/8b956e28e93e8918cd5f1fdafa1d1841_MD5.jpg)

**我要先分享一个数：**

平均每家企业眼下大概跑着12个以上AI智能体。其中有一半呢？是在单干的；也就是说，他们谁不挨着谁，那这批员工很多公司连智能体的名字都没有，乱不乱？

**肯定很乱的，但是老牌厂商们把它分成了两排。**

第一排，SAP。

今年 4 月，SAP 改了 API 政策。一句话，外部 AI 智能体不许直接调 SAP接口，自己规划、自己执行，都不行；想进来干活，走它自家助手 Joule 这条道。

6 月 9 日，安全补丁跟上，不合规的调用，技术层面直接封掉；代理服务器、网关、定制代码、冒充身份，这些绕道的路子，也一并堵上。

**同时，它的集成网关开始按调用次数计费，圈里有人管这个叫「代理税」，另外，Joule Studio 的免费期只到今年年底，明年怎么收，还没公布。**

它这么干，底气是手里真有别人没有的东西，50 年的财务、供应链、采购数据，全在客户的系统里，想换一家，成本按年算。

自家 Sapphire 大会上，它一口气发了 200 多个 agent、50 多个助手。

可它也有自己的难处，2 月，德语区用户组 DSAG 做了个调查，生产环境里用 SAP 自家 AI 的客户，只有 3%。

跑起 AI 的企业里，77% 用的是微软 Copilot 这类别家工具，SAP 对样本量提过异议，可 4 月的政策收紧，比调查发布只晚了两个月。

**这份政策的另一头，是迁移。**

SAP 老系统 ECC 的支持到 2027 年底到头，还有一万多家没迁的客户，眼下要同时面对系统迁移和 AI 迁移，两件事在同一个时间表上，日子还是 SAP 定的。

**第二排，Salesforce。**

它的干法正相反，前两年做了个决定，官方说法是「为智能体重建 Salesforce」。今年 4 月兑现：整个 Salesforce 上的能力，全部变成了 API、MCP 工具和命令行，算下来 60 多个工具、30 多项技能。

高管放的话很冲，你们以后何必再登录 Salesforce？

**后果是，一个销售可以全程不打开 CRM。在 Slack 里说一句，查客户、改商机、看管线，全在对话里完成，CRM 退到后面干活。**

官方数据，自定义的智能体挂在 Slack 上，从 1 月起，涨了三倍。

做 IT 服务台的 ServiceNow，同样把攒了二十年的流程、审批、目录，全开给了外部智能体，任何一家的 agent 都能来替客户执行这批动作。

它敢开，因为自家客服台八成九的问题，已经交给 AI 自己处理了。

**Google 更彻底，A2A 协议就是它牵头发起的，它家的企业 AI 产品，干脆把自己叫作「职场 AI 的新前门」** ，客户里跑得最快的是毕马威，员工九成在用，头一个月就搭了 100 多个智能体。

Jira 的东家 Atlassian，也把自家知识图谱的接口开出来，命令行和 MCP 都有。

做 HR 软件的 Workday，站在两排中间，一边把客户的人力数据管得严严实实，一边掏 11 亿美金，收了一家做 AI 界面的公司 Sana，给员工当每天第一个打开的界面。

**微软另算，它两头都占，既是入口，又是老牌本身，光 Copilot 的付费席位，就超过 3000 万。**

两家胆子，都长在客户身上，SAP 敢收紧，仗着客户跑不掉；Salesforce 敢全开，仗着换一家 CRM 的成本，远没有换 ERP 那么吓人。

**所以，客户跑不掉的收租，客户能跑的开门。**

……

两边干法是一松一紧，可我翻了他们半年的动作，发现最后去的是一个方向，什么方向呢？**先把答案放这儿：同一门生意，帮企业把 agent 管住。**

Agent 已经进厂干活了，管它们的家伙什还没备齐。

有组数字，我翻时多看了两眼：

**全球企业里，觉得自己把 AI 管得明明白白的，有 72%。可真问一句「你的 agent 这周花了多少钱」，答得上来的没几个。**

敢说自己治理到位的，只有 13%。另一份调查里，六成的企业，搭 AI 工具和流程不经过 IT。还有一家公司，一年没到，跑了 900多个 agent，才想起来该建个委员会。

管不住，就得有人来管，生意就从这儿开头。

**第一个把这门生意做响的是微软。它给 agent 发了套管理服务，叫 Agent 365，一个人一个月 15 美金。**

管什么：这个 agent 是谁，谁的活它能碰，干过什么，出没出格。

这套服务上线两个月，各家登记进来的 agent，接近 4000 万个，微软自己家里，也跑着 50 万多个。

**有人把这笔生意总结得很清楚，治理即产品，你付的不是软件钱，是「知道你的 agent 在干什么」的钱。**

ServiceNow 的收法更细，按动作来。

任何外部的 agent 来替客户办事，每一步都得过它的「控制塔」，过塔就算一次，叫 assist。**这座塔原来是管自家的，现在扩到管「任何系统里的任何 AI」。**

它家自己的说法挺狂：

别人让 agent 读数据、写数据，我们让 agent 执行被管着的动作。有观察者翻了它最新季度的账，一半的新订单，已经不按人头算了。它家现在 8400 个企业客户，续费率 98%。

**Workday 干脆把价目表挂了出来，计价单位叫点，查一遍工资单缺漏，5 个点；筛简历 6 个点，找一轮人才，就要 750 个点。用完加买，点多少钱一个，没公开，得找销售谈。**

第一批拿到名额的，有埃森哲、耐克、默克。它家平台上，上一个财年跑了 17 亿次 AI 动作。

![](assets/2026-09-18-%E4%BB%8E%E5%8D%96%E5%B7%A5%E5%85%B7%E5%88%B0%E6%94%B6%E2%80%9D%E8%BF%87%E8%B7%AF%E8%B4%B9%E2%80%9D%EF%BC%9ASAP%E3%80%81Salesforce%20%E6%AE%8A%E9%80%94%E5%90%8C%E5%BD%92%E7%9A%84%20Agent%20%E7%94%9F%E6%84%8F/51de75880dd4aa27ed569f4d17ad07d6_MD5.png)

Salesforce 那边，除了那份按动作算的明细表（一个动作大约一毛美金），还多做了套治理台，多家的 agent 混着来的时候，谁跟谁配合、找谁批、出了事查谁，都在这台上管。

**Google 那边更直接，今年 7 月到 9 月，它家 agent 平台的四个服务，一个接一个开始收钱：技能登记、智能体网关、记忆库、会话。**

名单里还有一项，叫「语义治理策略」，8 月 1 日起，治理本身，明码标价。

Atlassian 也是，12 月 3 日起，谁用它的上下文去喂自家的 AI，按点数记账，用超了，一个点一美分。这两家，平时嘴里讲的都是「开放」，可开放的口子上，也开始按点收钱了。

**SAP 那笔「代理税」也一样，过它的网关，按次数收费。**

看出来了吧？管 agent 的规矩，和收钱的价目表，是同一套家伙什。这些钱，名目一个比一个拗口，动作就一个，过我这关，记我一笔。

**管门的人，顺便管收费，门口归他管，谁进来了、进来了几个，他最清楚，这笔钱，自然他收。**

英文圈有家专门研究「非人类身份」的机构说：定价设计，本来就是访问治理的一部分。翻成大白话，你怎么收钱，就是你怎么管人。

**所以，别看两排人嘴上吵得凶，忙的都是同一件事，agent 的身份、权限、流水和账单，全攥在手里。**

有人算过，到 2030 年，企业软件四成的钱，会改成按用量、动作、结果来收，利润在搬家，从便宜的「聪明」，搬向稀缺的「管束」。

……

**接下来，账单开始找上企业，第一处不对劲，是数对不上。**

客服软件 Zendesk 的客户里，有人翻到账单才知道，用超的那部分，不声不响早就开始收钱了，这笔钱怎么冒出来的？

得从付法说起：

过去买一套软件，包给几个人用，一个月多少钱，签完不用再想；**现在各家的新表，跟着用量走，跟着动作走，还有的，跟着结果走，干一下活，记一笔账。**

每张表上都画着一条线，线内的事算在月费里；出了线，才开始一笔一笔算钱。进场干活的 agent 越多，表就走得越快。账本上一次这么改，是云。

**这些账怎么算，多数没写进合同，纸面上只有月费、人数，会变的那部分，全在厂商的文档里，改一版，价就换一档，不用跟你商量。**

我看到一项调查里：

78% 的 IT 负责人撞上过意外账单，61% 的人为了没计划的软件支出砍过项目；开发平台 GitHub 上，有个模型的价码，两个月里从 7.5 倍调到 27 倍，用户是从账单上先看出不对的。

**最扎人的不是涨价，涨价之前，没人通知你。**

有人把这种改法叫先圈地、后收割，头两年白送额度、给折扣，等大家用顺手了，再慢慢收紧，这话不算全冤，地圈得差不多了，接下来进的每个 agent，都带着自己的价码。

**第二处不对劲，是账单的涨法。**

做客服机器人的 Intercom，一单收九毛九美金，解决才收。它手里 76% 的问题，自己就能办完。

**它替你办完的事越多，记的笔数越多；哪天它不干活了，那天也就不挣钱。**

看起来买家占了大便宜，九毛九办一件事，怎么都比养个人划算。可账是两本，你算的是省了多少人工，它记的是又办成了多少单，它越能干，你越离不开，记的笔数也越多。

老软件卖工具，贵不贵，买之前就知道；现在这套卖的是它干出来的活，活有多少，买之前没人知道。**账单没算错，可就是比你想的多。省下来的钱，顺着账单，又收了回去。**

更大的数也有，有公司一个月冲到 5 亿美金，有开发者一周花掉 8 万多，账单吓人，通常不是哪一笔花错了，是每一笔叠出来的。

**还有近一半的公司，因为 AI 成本，把项目放缓了，再往远看，有人估到 2028 年，用 AI 写代码的钱，会超过一个开发者的工资。**

买家这边，开始还手了。最直接的一招，是换付法，干成了收钱，干不成不收。

做营销软件的 HubSpot，把这话直接撂在台面上；Intercom 靠这套收法，把营收做到了上亿美金，这个月，被 Salesforce 花 36 亿美金买下；做客服 agent 的 Sierra，按结果收，营收跑到了 2 亿美金。

**Zendesk 那边更实在，解决完先晾 72 小时，等一套独立的模型验过，才记一笔。Intercom 还放过话，新客九十天不满意，全额退。**

光换付法还不够，账还得看得见。

买家的要求很直接，贵一点不怕，账对不上不行。近三成公司说不清自己的 AI 钱花在哪。

**有人开始设上限、把账摊到部门头上，Netflix 有工程师干脆开源了个工具，专门看住这笔钱。**

中文圈，胡延平补了一刀，一样多的用量，不等于一样值钱，这话戳的是按用量收钱的软肋，量好数，值难量；买家还能换人，规矩不写明的，下一单就换一家。过半数企业，打算一年内换掉或新增 AI 供应商。

**剩下最后一个问题：这笔账，该算给谁？卖家的表还在走，买家也在装表。**

两边都没松口，也没把话说完，这场拉锯不只在账单上，也在合同里，谁先把「值不值」说清楚，下一轮的价，就归谁定。

这门生意怎么算，试的人已经不少；眼下交出来的是前半句，表装好了，账开始走了，后半句还空着，**收得顺不顺？付得服不服？得看接下来这两年。**
