# Spring Data 2025.0.13 released

> **来源**: Spring Blog  
> **链接**: https://spring.io/blog/2026/06/24/spring-data-2025-0-13-released  
> **抓取日期**: 2026-06-25  
> **相关性评分**: 1.0

On behalf of the team and everyone who contributed, I am pleased to announce the availability of Spring Data `2025.0.13`.

This service release is expected to be the final open-source release of the Spring Data 3.5.x generation and contains regression fixes only. Please consider upgrading to the latest `4.0.x` (`2025.1.x` release train) or `4.1.x` release at your earliest convenience.

Spring Boot 3.5.16 is scheduled to pick up this Spring Data release tomorrow.
