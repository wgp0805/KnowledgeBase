# 豆包，被张一鸣送上了车

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6466885.html  
> **抓取日期**: 2026-09-19  
> **相关性评分**: 1.0

就在昨天，豆包又往前走了一步。

这次不是手机，也不是电脑，而是汽车。

豆包与火山引擎正式发布了 **豆包座舱助手** 。

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/bbf3afd2e3fe45126ba35bd3e0b19aa6_MD5.gif)

它不是简单在车机里塞一个聊天框，而是想直接参与汽车的“感知—决策—执行”：实时感知数百种车辆信号，再去调用车控、导航、辅助驾驶、车载娱乐等数千个整车原子能力。

首款搭载车型是上汽荣威家越07，上汽奥迪相关车型也计划在年内亮相。

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/1aeba76047b562693966984c555b699f_MD5.png)

乍一看，这好像就是“豆包终于上车了”。

但其实不是。

**豆包早就在车里了。**

今年7月，特斯拉中国就已经通过 OTA，把豆包大模型推送到了Model 3、Model Y、Model S、Model X 等车型。

再往前看，火山引擎今年 4 月公布的数据是，搭载豆包大模型的智能汽车已经超过 **700 万辆** ，覆盖 50 多个汽车品牌、145 个车型。

所以这次真正有意思的，不是“豆包上车”。

而是：

**以前它更多藏在车机后面当模型，现在开始直接往前台走，变成一个真正能干活的 Agent。**

## 车里的 AI，终于不只是陪你聊天了

这几年“大模型上车”已经不算什么新闻。

几乎每家车企都在做。

但很多所谓的大模型上车，本质还是把原来的语音助手变聪明了一点。

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/9b7908eb0009efc44adf6269a3a2761b_MD5.png)

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/98c779e43bdd7d55c3248c4d8dfacd89_MD5.png)

以前你说：

“空调调到 23 度。”

它帮你调空调。

现在你可以说：

“我有点冷。”

大模型理解了一下，最后还是帮你调空调。

体验当然变好了，但 AI 主要负责的还是一件事：

**听懂人话。**

豆包座舱助手这次比较有意思的地方，是它想继续往后走。

不只是“听懂”，还要自己想办法完成。

比如你开车带着一家人出去玩，直接说：

“孩子准备在后排睡觉了。”

如果整车能力真的被打通，AI 理论上就可以自己判断：

是不是应该调一下后排温度；

是不是应该把音乐声音降低；

是不是该调整座椅；

是不是需要关闭部分灯光。

以前这些都是一个个独立的按钮。

以后可能变成 AI 自己组合这些按钮。

所以汽车里的 Agent 真正值得看的，从来都不是：

**它能不能陪你聊天。**

而是：

**它能不能真正控制这辆车。**

## 汽车，可能比手机更适合 Agent

这也是我看到这条新闻后觉得最有意思的一点。

豆包最近也一直在折腾手机Agent。

但手机 Agent 有一个非常现实的问题：

**模型已经会干活了，可 App 不一定让它干。**

AI想帮你点外卖、叫车、订酒店、发消息，就意味着它要进入第三方 App。

这里面马上就会碰到权限、安全、协议和商业利益。

说白了：

手机里面有几十上百个 App。

**这些App又不是豆包家的。**

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/d0e6103092b5b318451ec551e2944c10_MD5.png)

所以手机 Agent 想真正接管任务，本质上还得一家一家敲门。

汽车反而简单很多。

空调是谁的？

车企的。

座椅是谁的？

车企的。

车窗、音响、导航、灯光、驾驶模式，大量功能本来就在一套整车系统里面。

只要车企愿意把底层接口开放出来，AI 就不需要跨几十个 App 到处找权限。

更重要的是，汽车本身就是一个非常适合 Agent 的硬件。

它天然有大量传感器。

定位、摄像头、麦克风、温度、座椅状态、车辆状态……

这些都是 AI 的“眼睛”和“耳朵”。

同时它还有大量执行器。

空调、车窗、座椅、音响、导航、灯光……

这些又变成了 AI 的“手”和“脚”。

过去的汽车不缺这些东西。

**缺的是一个能把它们串起来的大脑。**

所以我反而觉得，真正能把 Agent 做出感觉的设备，未必最先是手机。

汽车可能跑得更快。

## 特斯拉用豆包，也说明了一件事

这里再说回特斯拉。

特斯拉中国现在确实已经接入了豆包大模型。

![](assets/2026-09-19-%E8%B1%86%E5%8C%85%EF%BC%8C%E8%A2%AB%E5%BC%A0%E4%B8%80%E9%B8%A3%E9%80%81%E4%B8%8A%E4%BA%86%E8%BD%A6/251bbdfe9d96a5d798119de3cda3754c_MD5.png)

不过有一点需要区分。

今年7月 OTA 上线的这版豆包，主要还是负责实时信息查询、自然对话、唱歌、讲故事这类 AI 语音助手能力。

按照当时公开的信息，**它还不能直接控制车辆。**

这反而更能说明豆包座舱助手这次的变化。

同样是“豆包进汽车”。

一种是：

**把大模型接进车机。**

另一种是：

**把整辆车的能力交给 Agent 调度。**

这两个东西看起来很像，实际差得挺远。

前者解决的是“车机会不会聊天”。

后者解决的是“AI 能不能帮我开这台机器”。

我觉得后者才是接下来智能座舱真正值得卷的方向。

否则无论接入豆包、DeepSeek，还是其他大模型，最后都只是车里多了一个聊天机器人。

## 手机和汽车，还是会慢慢连起来

当然，这次还有一个值得观察的功能：

**手车互联。**

按照官方介绍，后续豆包 App 可以远程控车、查询车况，还可以把手机里聊出来的行程直接推送到车机。

这部分我反而觉得不用吹得太大。

因为手机远程控车、同步导航，本身并不是什么新鲜功能。

真正值得看的是：

**AI 会不会成为手机和汽车之间的那个中间层。**

比如你在家里跟豆包说：

“周末想带孩子出去玩，找个两小时车程以内的地方。”

它帮你把目的地、路线、天气这些事情都聊完了。

等你真正坐进汽车，如果不需要再重新设置一次，而是直接继续刚才的任务，这才开始有点意思。

以前我们换设备，就等于换了一套软件。

以后 AI 如果真的能记住上下文和任务，设备本身反而会慢慢退到后面。

不过这件事情现在还早。

至少今天的豆包座舱助手，真正值得关注的，还不是所谓的“跨终端生态”。

而是一个更具体的问题：

**AI 开始真正拿到汽车的控制权了。**

过去几年，我们一直在讨论 Agent 怎么帮人订票、点外卖、操作电脑。

但很多时候，最大的阻力不是模型不够聪明。

而是它没有足够多的权限。

汽车可能恰恰相反。

车企手里本来就握着整辆车的权限。

现在，只差把这些权限交给一个足够聪明的 AI。

所以豆包这次从手机、电脑走进汽车，我觉得真正值得看的并不是“豆包又多了一个入口”。

而是：**Agent 终于找到了一台真正有手、有脚，而且愿意把控制权交给它的机器。**
