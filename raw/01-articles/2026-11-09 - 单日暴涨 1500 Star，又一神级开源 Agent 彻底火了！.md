# 单日暴涨 1500 Star，又一神级开源 Agent 彻底火了！

最近在 GitHub 上翻到一个叫 OpenMausBot 的项目，火得挺快，光昨天一天就涨了 1500 来个 star。

OpenMausBot 的定位是 Grok Bot 的开源替代。Grok Bot 是 xAI 搞的东西，类似的还有 Meta 的 Muse、OpenAI 的 dots、Manus 的 Cue，今年这几个月一家接一家地出。这些东西有个共同点，闭源，而且模型、电脑、你的数据，全都放在厂商自己那边。OpenMausBot 开源后这么火，主要就是把这套东西搬回你自己的电脑上，代码开源，数据尽量留在本地。

今天分享一下这个最近挺火的项目。

# 先简单介绍

OpenMausBot 是个开源的桌面软件，打开以后跟聊天软件长得差不多，左边一列联系人，右边对话框。不一样的地方在左边这一列，里面每个“联系人”都是一个真的 AI agent，会真干活的那种。你发一句话过去，它就去做事，做到关键的地方会停下来，先问你一句同不同意。

这些 agent 靠什么跑呢？靠你电脑上已经装好的命令行工具，Claude Code、Codex、Grok CLI 都可以。它自己不带模型，也不找你要 API key，不用注册什么新账号，用的就是你现有的登录和订阅。想接别的模型也有办法，README 里写了，OpenAI 兼容接口都支持，DeepSeek、OpenRouter 这些都能配进去。

![](https://mmbiz.qpic.cn/mmbiz_png/38IO1MnhnawIsYEKyoico4UKl0416XL5qVJRnZZEHjGOkiamSnzac4lSINH7AvfXop0zf28RCYic6W8j2SMLGPYB9Niav6lnwUkYxWd5csVY3rI/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=1)

# 功能详情

下面只讲它能干什么，不聊怎么实现。

### 每个 bot 自己选模型

每个 bot 都能单独选模型。打开选择器，Claude 和 Codex 的模型并排摆着，哪个是默认的有标出来，用不了的就灰掉，旁边还会写上为什么用不了。聊着聊着觉得模型不合适，中途换就行，不用重新开会话。

这样分工就方便了，写代码的 bot 用 Codex，整理资料的用 Claude，各管各的事。

![](https://mmbiz.qpic.cn/mmbiz_png/38IO1MnhnazDJWXDNX5fmkgvAJCsbs9P3rJUiaJiaFAuVNn8pficge4sYuuMeXB4f16NRIwNOfHzqR7O8zFtoZicGuAPggsdbYah9TgIsj0Aq9g/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=2)

### 每个 bot 配一台电脑

每个 bot 都能分到一台自己的电脑。可以是一个云端的 Linux 桌面，也能用隔离的本地虚拟机，或者干脆就是你正在用的这台电脑。最后这种听着有点吓人，所以它默认是不开的，macOS 和 Ubuntu Xorg 上你明确同意了才会打开，Wayland 下现在干脆是关着的。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnawpbqO8GHOjYSZ0ILxH0eUiaGycvMF9o3zsLX2r7tyAcdvzchiagPoVlvoyC7f1r5AUbEdwgcPdHq44WtfUJNnE78tuic1S7syXibU/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=3)

打开 Computer 面板，能看到它那台电脑的实时画面，它在点什么、跑什么，我们都看得见。想自己上手的话，在浏览器里打开它的桌面就能接管过来。云端电脑这块用的是 Boat 的服务，试用期过了要收费，这个先记着。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnawYRfbJ80yfse9GjUEmMqc0cAwrX9kkVDYUmK5HQ4H3crQxkTkbDwRbCBTQHibuFPDYq7tA4psZHuV43msuwDTUSXq8y1s0ekMc/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=4)

### 干活之前先问我

bot 要跑命令、改文件的时候，聊天里会先弹一张卡片出来，写清楚它打算干什么，允许还是拒绝，我们点一下就行，不点它就不动。不管是在云端电脑上还是在你自己本机上，都走这一步。说实话，有这个机制在，我才敢把真实的任务交给它跑。

![](https://mmbiz.qpic.cn/mmbiz_png/38IO1MnhnazjseN080WmCFWsomB80A2VUbYWA5H7QticWbgBY6dk73UzNfByBlTzb0n3IxlUJQXvcsguicDVNnEpBibjfvdEuptx5UzDuLb34E/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=5)

### 连外部应用

软件里内置了一个应用市场，走的是 Composio，常见的 Gmail、Slack、GitHub、Notion、Linear 都在里面，一共 500 多个应用。授权只要做一次，之后所有 bot 都能用。

比如我们可以让某个 bot 盯着邮箱，收到某类邮件就先起草个回复，等我们看过点头了再发出去。对了，Gmail 是每 15 分钟查一次，Slack、GitHub 这类是实时推过来的。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnayT2uzT2XruKyeFDIcRAJQNX8rc29FEp73m4KoTibx7ibwDq5uPs19mezA7cVyfEBo0YXRbEtaut5mayoUdFb4qtJib88jlT4fkwc/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=6)

### 定时任务和 webhook

想让 bot 定期干活，直接跟它说就行。比如来一句“每个工作日早上九点汇总一下我的收件箱”，它自己就把定时任务建好了，还会在聊天里出一张卡片，想改想暂停都从那张卡片点。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1Mnhnay907loLPklyiaPMp7UP3DV5mqO6utVutiaf428LVPfCGNricESvPIn1PT4sxFxaEib1pKtJ2Jqxo8rzuu5kSVT54JpEB4tTQC8Mick/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=7)

侧栏有个 Triggers 页面，所有定时任务和 webhook 都列在那，带日历，每次跑没跑也有记录。webhook 默认只监听本机的 127.0.0.1，想暴露到公网得自己去配反代。

这个默认我还挺认可的，起码不会一不小心把服务开到外网去。

### 让 bot 开口说话

每条回复旁边都有个小喇叭，点一下就给你念出来。也可以直接打电话，接通以后它一边干活一边口头跟你说进度，需要你批的事也直接念出来问。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnazIJnzo2P4OF9icjwf52cGGvQnlzTYDc3MsDCcojoicj8TT2JoMPjNiaUMwoeoDMEtHeedtAc7OlpX8hsdnhiaPCZAXmJ5odnLjCM8/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=8)

语音这块选择挺多，ElevenLabs、Fish Audio、Grok 的语音、Mac 自带的语音都行，也可以在本地跑一个 Chatterbox。Mac 自带的语音不用配任何云端 key，拿来就能用。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnawDwPPmAyXCQhXGAT5xvx3CPY4fibQEXvkfJQicEGEvSZev3LvLWLibiaxAGlH8E2Gkiaicfds4obcHhbpfWxWBEx1sqITZ6uibh0lk6w/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=9)

### 像管聊天一样管 bot，还能整套打包

右键点一个 bot，置顶、标未读、改资料、复制、隐藏、删除，这些都有，跟平常聊天软件里管联系人差不多。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnayTDFKj2ugV3MLyOF9DCgoY9hgOicic2vv15B9ib4Xm927mJxUbuLFicPx719nZHicJclYELLblEPZDtqHFubfCxBV6ibMMSiaPtBWvJM/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=10)

还有一个设计我挺喜欢的。你调好的一整套 bot 团队，可以整个存成一个 Markdown 文件发给别人，对方导入一下，一套现成的团队就有了。

这个文件里不带密钥、不带聊天记录、不带权限，导入之后定时任务是暂停的，应用连接也是关的，想用得自己一个个打开。这点做得挺细心。

# 快速开始

我装的时候走的是安装包路线，省事。

安装包去 GitHub 的 releases 页面下就行。Mac 下载 dmg，拖进应用程序就完事了，签名公证都做了，不会拦你。Windows 是个一键安装的 exe，不需要管理员权限，不过安装包还没做代码签名，SmartScreen 会弹个“未知发布者”，点“更多信息”再点“仍要运行”就过去了。Ubuntu 24.04 有 deb 也有 AppImage，目前还是 beta，官方说只支持 GNOME 桌面。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1MnhnazMRvBUE4Iicia3icicuDgI9GMCU4BVibBE8KUaeV9pNJgNtvwoia7Wj2WE0siaiaiblYyC0uYVVNMg4hAEwEvUNgsarpZQkmhibAK462Sus/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=11)

源码跑的话，需要 Node 24 以上和 pnpm：

```
git clone https://github.com/milind-soni/OpenMausBot && cd OpenMausBot
pnpm install

pnpm dev:server    # 后端服务，127.0.0.1:8799
pnpm dev           # 网页界面，127.0.0.1:5199
pnpm dev:desktop   # 桌面壳，上面两条要保持运行
```

要是连仓库都不想克隆，还有更懒的办法，npm install -g openmausbot 装一个，或者直接 npx openmausbot 跑起来。第一次启动会有那种方向键选择的引导，一路选下去就配置完了。

有个前提得说在前面，跑起来之前，电脑上得已经装好、登录好至少一个 agent 命令行，Claude Code 或 Codex 都可以。前面说了，OpenMausBot 自己不带模型，靠的就是这些本机的工具，装好登录好以后，它们会自动出现在模型选择器里。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/38IO1Mnhnay9AShJicAG46ibeUiaqR6Dg15yhFbqt0ZYmTknb3auS1O1cYskTCaMZ3qNz8vuVXkOT00JuemRqXo35NibUnQJvdfYe8RAwmr0Mf4/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=12)

# 我的看法

我自己用下来，最认可的是这个形态。一个输入框塞一个助手，真要多开几个 agent 一起干活，马上就乱了。它把每个 bot 做成通讯录里的联系人，各管各的会话，各记各的事，发个任务跟回消息差不多，没什么要学的。安装完成自动把本地已经配置好的AI并进去了，直接就能用，省下二次配置。

操作上也非常流畅，Codex那些已经下载好的 Skill 也是直接用的，集成的东西也比较多，邮箱、看板、数据库什么的都有。在这个应用上基本我们订阅的所有AI模型都可以用，还可以互相协作，账单也有，还有APP，可以说，任何开源项目能短期大火，那指定是有点东西的。
