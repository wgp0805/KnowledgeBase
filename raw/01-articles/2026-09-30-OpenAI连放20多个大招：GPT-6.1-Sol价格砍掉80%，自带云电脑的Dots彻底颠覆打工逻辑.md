## 01 简介：从被动对话框走向 7×24 小时自主协作生态

过去两年多，很多打工人使用 AI 的姿势其实相当受累：你得先想好一段精妙的 Prompt，复制资料投喂进去，等它吐出结果，再手动搬运到别的地方，一旦你离开电脑，AI 就立刻陷入待机

这次 OpenAI 端出的全家桶，本质上是一场体系级的升维重构

核心主线非常清晰：

  * 核心形态层面推出了 **Dots** ，拥有独立云端电脑，24/7 不眠不休主动找活干
  * 基座模型层面祭出了 **GPT-6.1 Sol** ，性能逼近顶级旗舰 GPT-6 Astra，价格直接暴降 80%，缓存输入更是低至一毛钱
  * 性能体验层面发布了 **Ultrafast 极速引擎** ，在 Codex 中实现最高 8 倍的恐怖推理提速
  * 开发者与协同层面打通了 **Codex in the Cloud** 、**Codex Security Cloud** 、**Sign in with ChatGPT** 全局身份与 16 家伙伴算力抵扣

## 02 核心杀招：Dots，自带独立云电脑的 7×24 小时“赛博打工人”

如果整场发布会只选一个最震撼的技术形态，我毫不犹豫投给 **Dots**

官方定义它为由顶级模型 GPT-6 Astra 驱动、能够承担持续职责的常驻自主智能体（Always-on Agents）

它的设计理念完全颠覆了传统 AI 助手的运行逻辑：

**1\. 自带专属独立云电脑（Cloud Computer）** 每个 Dot 都拥有一台运行在云端的独立虚拟沙箱电脑和专属浏览器，完全脱离你的本地设备限制 它在云端自己打开网页、操作应用、检索资料、处理数据，完全不需要霸占你的物理屏幕 当然，如果你授权它连接你的笔记本，它也能直接跨端协同，在你的桌面上完成本地交互

**2\. 24/7 全天候在线与全渠道渗透** 你的 Dot 不仅常驻在 ChatGPT 网页端、桌面客户端和手机 App 它还能直接进驻你们公司的 Slack 和 Microsoft Teams 遇到复杂工作，你甚至能随时通过语音通话直接给它“打电话”，就像跟一位真实的远程同事语音拉齐需求一样自然

**3\. Proactive Research（主动后台调研）** 这是最让我拍案叫绝的功能 当你没有主动给它发消息时，Dot 绝不会在那儿闲坐着，它会在后台开启“只读受限模式”，对你连接的 4000+ 款应用进行主动巡检 比如在内部测试中，一位测试者忘了给合作媒体开具业务账单，Dot 在后台巡检发现后，直接主动把发票与明细起草完毕，生成审批卡片推送到测试者的手机端，只等人类点一下确认

**4\. 严格的分级安全与审批沙箱** 后台主动工作时，Dot 严格处于只读权限，不能擅自发送公开消息、修改关键资产或接管核心权限 涉及敏感操作（例如向外付款、发送商业合同、更改密码）时，必须通过 Auto-Review 触发人工审核，确保不发生越权失控

**5\. 面向组织的 Specialist Dots 与微软深度协同** 除了个人主力 Dot，OpenAI 还推出了面向企业的专职数字员工（Specialist Dots） 企业 IT 可以为其分配独立数字身份、组织权限与凭据，直接承接采购核验、发票报销、法务合同审查和一线客服等长链路业务 同时 OpenAI 正式联手微软，将专职 Dots 深度整合进 Microsoft Agent 365 体系，直接通过企业既有的微软管理后台统一管控

性价比王炸：GPT-6.1 Sol，价格砍掉 80%，缓存输入只要一毛钱

开发 Agent 最痛苦的痛点是什么？答案一定是高昂的 token 账单

跑多步复杂工作流时，几十轮长上下文反复重传，顶级大模型分分钟能把开发者的钱包吸干

昨晚发布的 **GPT-6.1 Sol** ，正是冲着解决这个致命瓶颈来的

它在编程、复杂工具调用、多步商业流程等领域的智力水平无限逼近旗舰 GPT-6 Astra，但在价格上却狠得让人不敢相信：

  * **标准 API 价格** ：每百万输入 token 为 2 美元，每百万输出 token 为 10 美元，仅仅相当于 GPT-6 Astra 标准价格的五分之一
  * **缓存输入（Cached Input）价格** ：**每百万 token 仅需 0.10 美元（约合人民币 7 毛钱）** ，比标准输入价直降 95%，比上一代 GPT-6 Sol 的缓存价再次腰斩 50%



这意味着长上下文 Agent 在反复复用提示词与历史记录时，综合推理成本直接被打到了地板上

来看一组官方在技术报告中公布的硬核对比数据：

  * **代码基准 DeepSWE v1.1** ：在真实代码库复杂软工任务中，GPT-6.1 Sol 跑分追平了 GPT-6 Astra，成本却只有后者的约五分之一，并且以更低的思考算力超越了上一代 GPT-6 Sol 达 6.4 个百分点
  * **长文档研读 GDP.pdf** ：在覆盖金融、医疗、法律等专业领域的复杂 PDF（包含图表、表格与小字条款）深度问答测试中，GPT-6.1 Sol 表现超越了带 Fallback 的 Claude Opus 5.5，单任务成本还不到 Opus 的一半
  * **商业多步自动化 AutomationBench** ：在涵盖销售、营销、财务、人事等 47 项生产力工具的多步工作流评测中，GPT-6.1 Sol 在中等推理强度下高出 Claude Opus 5.5 达 2.2 个百分点，综合成本仅为其约三分之一
  * **电脑操作 OSWorld 2.0** ：在长时间跨度的图形界面操控测试中，GPT-6.1 Sol 较上一代大幅提升 7 个百分点，距离顶级 Astra 仅差 2.1 个百分点，成本却只有 Astra 的约七分之一
  * **科学探索 Terminal-Bench** ：在数据分析与定理证明测试中，Astra 和 Opus 5.5 单任务平均花费高达 23 美元以上，而 GPT-6.1 Sol 仅需 5.47 美元，成本暴降超过 75%
  * **抗幻觉与事实准确度（Factuality）** ：在真实用户纠错的极难提示词集评测中，低思考强度下的事实错误率直接下降了 32%，表现极度扎实



GPT-6.1 Sol 目前已正式登陆 Plus、Pro、Business、Enterprise 和 Edu 用户的 ChatGPT Work 与 Codex 环境，API 也已同步开放调用（模型代号：gpt-6.1-sol）

## 03 极速狂飙：Ultrafast 带来 8 倍提速，告别“打字机”等待

跑代码重构或者让 Agent 处理长文本，最折磨人的莫过于看大模型像蜗牛一样逐字蹦输出

这次 DevDay 官方正式推出了针对极致响应速度打造的 **Ultrafast 极速引擎** ：

  * 在 Codex 编程环境中，代码生成速度最高提升 8 倍，吞吐量飙升至约 300 tokens/s
  * 在标准 API 中，也能实现最高 6 倍的生成加速
  * 当前 GPT-6 Astra Ultrafast 已全面上线，GPT-6.1 Sol 也将在未来几天内火速跟进支持

## 06 总结：AI 时代的打工逻辑，已经发生了不可逆的剧变

看完 OpenAI DevDay 2026 这一整套让人喘不过气的连招，我有一个强烈的预感：

以往我们总把 AI 当成一个“输入提示词、输出一段字”的答题器，很多人还在比拼谁的 Prompt 写得长、谁的技巧更花哨

但这次 OpenAI 用事实证明，真正的生产力革命，必须把智能体直接丢进复杂的业务环境中：

  * 它得有自己的云电脑和浏览器，能 24/7 不知疲倦地在后台看盘、调研、起草方案
  * 它的推理成本必须降到极低（缓存输入低至一毛钱），才能支撑几十轮上百轮的持续思考与环境交互
  * 它的生态和算力必须全局打通，让你在一个账号下就能调动从代码、文档到第三方 SaaS 的全部生产力



对于开发者和普通打工人来说，留给单纯套壳问答工具的窗口期已经基本闭合；而真正懂得把垂直业务痛点拆解成长链路 Agent、善用极低缓存成本搭建自动化流水线的人，正在迎来前所未有的巨大红利
