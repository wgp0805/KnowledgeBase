# 腾讯刚入局，Manus又要融资33亿

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6466160.html  
> **抓取日期**: 2026-09-17  
> **相关性评分**: 1.0

Manus 这家公司，今年的剧情多少有点离谱。

去年底，Meta花大约20亿美元把Manus收入囊中。没想到几个月之后，这笔交易因为监管原因被叫停，双方开始拆分，Manus 又重新变回一家独立公司。

![](assets/2026-09-17-%E8%85%BE%E8%AE%AF%E5%88%9A%E5%85%A5%E5%B1%80%EF%BC%8CManus%E5%8F%88%E8%A6%81%E8%9E%8D%E8%B5%8433%E4%BA%BF/23e56aba957a0cfa6a707266d1ebd318_MD5.png)

正常创业公司的剧本走到这里，多少都会伤点元气。

Manus倒好。

刚恢复独立没多久，新一轮融资5亿美金就要来了，而且估值直接翻倍。

**据彭博社报道，AI初创企业 Manus即将完成融资。这是在其与Meta分拆之后的首轮募资，本轮融资计划将使其估值翻番，达到40亿美元（约合268亿元人民币）。**

据知情人士透露，计划中的5亿美元融资轮次很快就将完成。这笔交易落地之后，这家智能体AI初创企业将成为国内该赛道估值最高的初创公司。相关磋商仍在进行当中，交易条款仍有可能发生变动。目前新投资方的具体身份尚不明确；Manus 现有投资方包括腾讯控股、HSG 以及真格基金。如果交易最终完成，它也将成为国内估值最高的 AI Agent创业公司之一。

最有意思的是，把时间线拉长一点看。

Meta当初大约花20亿美元收购Manus；收购被叫停之后，包括腾讯、HSG、真格基金等原有投资方又参与把 Manus 买了回来。媒体此前报道，这笔回购仍然是按照大约 20 亿美元的估值进行。腾讯随后成为 Manus 重要的外部股东。

结果没过多久：

**20 亿美元买回来，40 亿美元继续融资。**

至少从账面估值来看，Manus 绕了一圈，身价反而翻倍了。

## 01 为什么资本还愿意给 Agent 这么高的估值？

这件事其实挺值得琢磨。

过去一年，大模型能力提升得太快了。

以前Manus刚火的时候，一个AI能自己打开网页、搜索资料、整理信息、操作电脑，已经足够让人惊艳。

![](assets/2026-09-17-%E8%85%BE%E8%AE%AF%E5%88%9A%E5%85%A5%E5%B1%80%EF%BC%8CManus%E5%8F%88%E8%A6%81%E8%9E%8D%E8%B5%8433%E4%BA%BF/37a28a50bd7c0505c8c15d301c765aa0_MD5.png)

现在 Kimi、Claude 等模型都在不断往 Agent、Computer Use、桌面操作这些方向走。模型厂商亲自下场之后，独立 Agent 创业公司的压力其实比一年前更大。IT之家在报道中也提到，Manus 面临的一个现实问题就是，越来越多基础模型已经开始具备类似的通用桌面任务能力。

更关键的是，Manus自己并不从零训练基础大模型。

按以前的互联网逻辑看，这种公司很容易被质疑一句：

**模型越来越强以后，还需要你吗？**

现在资本给出了一个很有意思的答案。

至少现阶段，他们依然愿意为 Agent 应用层下注。

原因也很好理解。

模型能力不等于产品能力。

ChatGPT、Claude、Gemini、Kimi 可以越来越聪明，但真正把这些能力变成一个普通用户愿意使用、能够完成复杂任务、形成稳定工作流的产品，中间还有很长一段路。

Manus赌的就是这一层。

它不一定要拥有最强的大模型，只要能把不同模型、浏览器、工具、Computer Use 和用户任务组织起来，最终把一句“帮我做这件事”，变成真正交付的结果，它就还有自己的价值。

## 02 Manus真正值钱的，可能已经不是“模型”

这也是我觉得 Manus 这轮融资最值得关注的地方。

![](assets/2026-09-17-%E8%85%BE%E8%AE%AF%E5%88%9A%E5%85%A5%E5%B1%80%EF%BC%8CManus%E5%8F%88%E8%A6%81%E8%9E%8D%E8%B5%8433%E4%BA%BF/4acbd92762c6b9f9757023831b0bb270_MD5.png)

过去AI创业公司的估值逻辑，很大程度上围绕模型展开：谁的参数更大，Benchmark 更高，训练集群更猛，融资自然也更容易。

Agent 公司正在尝试走另一条路。

**底层模型越来越像基础设施，真正面向用户的入口和工作流，也可以成为一门大生意。**

这其实有点像移动互联网早期。

操作系统属于苹果和 Google，但并不妨碍微信、抖音、美团长出巨大的商业价值。

今天的大模型也有点类似。

OpenAI、Anthropic、Google、DeepSeek 可以继续把模型能力往上推，但最终谁能占住用户每天真正工作的那个入口，可能依然会诞生一批非常大的公司。

所以 Manus 这 40 亿美元估值，某种程度上也是资本在给“独立 Agent 公司还能不能活”投票。

至少现在，答案还是肯定的。

03 不过 Manus 面前的问题也越来越现实。

以前大家竞争的是“谁先做出一个能自己干活的 Agent”。

现在的问题变成了：

**当 Claude、Kimi，甚至各大操作系统和办公软件自己都开始做 Agent，为什么用户还要单独打开 Manus？**

这才是下一阶段真正难的地方。

![](assets/2026-09-17-%E8%85%BE%E8%AE%AF%E5%88%9A%E5%85%A5%E5%B1%80%EF%BC%8CManus%E5%8F%88%E8%A6%81%E8%9E%8D%E8%B5%8433%E4%BA%BF/571ab0c2bd6c92085bd1871d0397a75d_MD5.png)

独立 Agent 必须建立模型之外的东西：用户习惯、任务数据、工作流、工具生态，甚至一个足够强的品牌和入口。

否则模型公司只要把能力继续往产品层延伸，应用公司的空间就会被不断挤压。

所以我反而觉得，Manus 今天最值得看的已经不是“融了多少钱”。

从被 Meta 收购，到交易被叫停，再到重新独立、估值翻倍，这家公司正在参加一场更大的实验：

**在大模型越来越强的时代，一家不自己训练基础模型的 AI Agent 公司，到底能不能独立长成一家巨头。**

40 亿美元，只是资本现在给出的价格。

真正的答案，还得看接下来几年用户到底把工作交给谁。
