# AI Agent 的故事：QClaw 停运观察

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6469810.html  
> **抓取日期**: 2026-09-24  
> **相关性评分**: 1.0

> 腾讯 QClaw 从爆红到停运仅半年，官方称业务调整，实为内部赛马终局。本文复盘其兴衰，揭示 AI 办公 Agent 从演示到使用的留存困境，以及大厂入口整合背后的商业逻辑。

![](https://image.woshipm.com/2024/07/03/d8c88ba2-38e8-11ef-a88c-00163e142b65.png)

2026年9月24日，腾讯 QClaw 团队发布停运公告：因业务发展调整，产品将于2026年12月24日00:00正式停止运营。自公告之日起，停止新用户注册，停止订阅服务购买与续费，已购未用的订阅与积分可申请退款。

用户可以选择备份数据，也可以通过官网入口将配置、记忆、Agent 人格和对话记录迁移至腾讯的另一款 AI 办公产品 WorkBuddy——完成迁移的用户，还会获得1000积分补贴。

![](https://image.woshipm.com/2026/09/24/34867446-b7e4-11f1-8891-00163e4b86a1.jpeg)

QClaw 即将停止运营，一个曾经站在热潮中央的产品，正在被整合进另一个入口。

## 01 一款“顶流”产品的退场

如果只看公告，QClaw 的退场方式相当体面：三个月缓冲期、退款通道、数据迁移工具开放至2027年3月24日。

但把时间线拉长，这个“体面”反而更值得琢磨。今年1月底，“小龙虾”OpenClaw 火遍全网，排着队安装的场面成为2026年第一个真正破圈的 AI 事件；腾讯3月跟进，推出以低门槛安装和微信远程指挥电脑为核心卖点的 QClaw，开放公测；7月，已有报道提及 QClaw 相关业务及部分团队调整至 WorkBuddy 所在部门；9月24日，停运公告正式落地。

半年多时间，一个站在时代热度上的产品，走完了从出生到退场的一生。官方给到的停运原因是：业务发展调整。而腾讯相关人士的补充是：为进一步整合资源，为用户提供更好的 Agent 服务。

这句话本身就是一个信号：AI 办公产品的“淘汰赛”，比很多人预想的更早开始了。

## 02 它为什么曾经那么火：不只是“能干活”

先回到今年年初那个春天。OpenClaw 的出圈方式，在今天看来几乎是个完美样本：发一句话，AI 就在你的电脑上自己操作起来。

排着队安装、Mac mini 一度卖到缺货（有调研称约23.5%的受访用户曾为“养虾”专门购买 Mac mini）、社交媒体上铺天盖地的演示视频。它把“AI 能替我干活”从一句口号，变成了一个具体的、可传播的画面。

拆开来看，那股热度里至少叠着两种需求：围观需求——“AI 已经能自己用电脑了？”，看着小龙虾替自己操控电脑是一种十分新奇的体验；尝鲜需求——“我也想拥有一个替我干活的助手”，谁不想拥有一个属于自己的打工人。

而长期使用，需要的是第三种需求：我有一件反复发生的事，交给它比自己做更省心。前两种需求足以制造出圈，第三种需求才支撑日常留存。三种需求的规模，可能相差一个数量级。

## 03 热度的另一面：七成人在两周内不再使用

热度退去之后，问题逐渐显现出来。增长黑盒与网易智企在2026年4月发布的《中国 OpenClaw 调研》（2000名个人受访者、100名企业管理者）显示：在999名实际使用或曾经使用过的人中，309人已经停用，接近三分之一；而停用者中，约三分之二的人在开始使用后的前两周内就决定不再使用。

它指向一个清晰的现象——尝鲜之后的快速放弃，是这类产品的普遍宿命。

小龙虾的出圈代表的是这种新型个人 Agent 产品的火爆，但用户是否把它长久保存在自己的电脑，还需要解决它带来的安全问题、成本问题以及是否是能真正解决个人的日常工作。

这难得多。

![](https://image.woshipm.com/2026/09/24/f536774e-b7e5-11f1-8891-00163e4b86a1.jpg)

前段时间 Openclaw 的大更新已经几乎无人在意了

## 04 停运的真正原因：一场内部赛马的终局

那么，QClaw 到底输在了哪里？公告口径是“业务发展调整”，腾讯相关人士的说法是“进一步整合资源，为用户提供更好的 Agent 服务”。

把镜头拉远，停运发生在腾讯桌面 Agent 产品布局的整合背景下：今年7月，已有报道提及 QClaw 相关业务及部分团队调整至 WorkBuddy 所在部门，也有报道称其产品经理此前已经离职；而在社区流传的版本里，腾讯内部曾让不同团队赛马。

QClaw 出自电脑管家团队，WorkBuddy 出自腾讯云团队，如今资源明显向后者倾斜。

QClaw 停运，不等于“Agent 方向失败”。它更可能是腾讯在入口之争里做出的一次取舍——把相近的产品、用户与能力收拢到一个被寄予厚望的入口上。

商业上，这并不难理解。当两个产品服务相近用户、完成相近任务，独立运营的边际价值就在下降；账号、记忆、工作流最终都会变成迁移成本。与其让两个产品互相消耗，不如集中资源赌一个。

## 05 三款产品，三个痛点

如果把腾讯桌面 Agent 的牌面摊开，其实一直在打三张牌：QClaw 卖的是“在微信里叫电脑干活”，WorkBuddy 卖的是“把 AI 放进办公任务”，Marvis 卖的是“有一个懂我电脑和文件的个人助手”。

三个产品回答的是三个不同的痛点：人不在电脑前，仍能处理电脑上的事；写材料、处理文件、开发这类反复发生的办公任务，能形成固定工作流；电脑上的文件、设置和个人资料每天都在，越熟悉用户环境越有价值。

这也能解释为什么 WorkBuddy 最近更容易持续有声量：它早已在不断地功能迭代中加上了其它两种产品的核心功能，也可以不断展示办公场景和任务成果；而 QClaw 最容易传播的“微信一句话操控电脑”，第一次看非常震撼，第二次看就要问——它到底帮我省了多少事？一个能持续展示使用价值的入口，显然更容易获得集团的资源倾斜。

## 06 更深的一层账：AI 办公到底能不能成为生意

Codex、Claude Code 的走红已经证明了一件事：用户愿意为“AI 实际完成工作”付费。

但办公 Agent 的生意，要算的是三本账。第一是产品收入：个人订阅、积分或企业采购，确实能带来现金流；第二是任务成本：Agent 会反复规划、调用工具和模型，token 消耗量更大，对产品方首先是更高的成本，只有收费、使用限制和模型调度能覆盖它，规模扩大才有利可图；第三是集团价值：办公入口可能带动云服务，并给模型改进提供过程数据。

这也解释了腾讯为什么押注 WorkBuddy：它可能是一条贯通用户任务、办公产品、模型和云服务的链路，而不只是一个能远程操作电脑的应用。QClaw 和 Marvis 也能覆盖其中一些任务，但在功能越来越重叠时，集中推广一个能承接更多办公场景的入口，是更理性的选择。

接下来最关键的验证，是“任务级经济账”：一次有用的任务，用户愿付多少钱、平均要调用多少算力、失败重试多少次、最终还能留下多少贡献。能把这笔账稳定算正的产品，才真正有能力长期承接模型训练之外的商业投入。

## 07 入口合并的故事结束了，新的故事才刚刚开始

站在今天往回看，QClaw 的经历像是一堂被压缩到一年内的产品课：它证明了 AI 入口可以一夜爆红，也证明了热度无法兑换成习惯；它证明了整合比并行更符合商业理性，也提醒所有产品人——用户投入的每一份上下文，都需要明确的数据归属和可迁移机制。

一个产品退场时，用户真正失去的，也许不是一个 App，而是“AI 能替我干活”的那份新鲜期待。热度可以被制造，习惯只能被时间证明。爆火与留存之间的距离，就是 AI Agent 行业从“演示”走向“使用”的距离。

接下来值得观察的，是三件事：迁移窗口期里，有多少 QClaw 用户真的愿意搬进 WorkBuddy；Marvis 会沿着个人电脑助手的方向走到哪里；以及，AI 办公产品们什么时候才愿意公开自己的留存率。它们将比任何一场出圈，都更能说明这个行业的真实体温。
