## 一、核心观点

> **人类智力基线站在了新的台阶上，门槛是2张显卡。**

这句话的含义是：**如今，仅凭两张消费级显卡（如 RTX 5090），就能在本地运行一个具备 Agent 能力的强大 AI 系统——这标志着"普通人可触及的 AI 智力水平"跨入了一个全新的阶段。**

过去，要跑一个能真正"干活"（读写文件、执行命令、拆分任务、持续工作）的 AI Agent，要么依赖云端 API（按 token 付费），要么需要企业级 GPU 集群。而现在，**两张 RTX 5090 + 一个开源框架 + 一个开源模型 = 一台完全本地、完全私有、完全免费的 AI 工作站**。

## 二、三大核心组件

### 2.1 Qwen3.8-27B —— 本地最强开源模型

| 属性 | 详情 |
|------|------|
| **发布方** | 阿里巴巴（通义千问团队） |
| **参数规模** | 27B（稠密模型） |
| **上下文窗口** | 262,144 tokens（256K） |
| **架构特点** | 混合注意力架构：64 层中 48 层为线性注意力（Gated DeltaNet），仅 16 层为全注意力——KV cache 大幅缩小 |
| **量化后权重大小** | Q4 GGUF 约 16.69GB（unsloth UD-Q4_K_XL 动态量化） |
| **视觉能力** | 支持多模态（附带 0.86GB 视觉投影器） |
| **许可证** | Apache 2.0 |

**为什么是 27B？**

- 单张 24GB 显卡装得下 Q4 权重，但 256K 上下文的 KV cache 会撑爆显存
- 两张 24GB 卡（如 2× RTX 5090）通过 tensor-split 平均分摊权重和 KV cache，**跑满 256K 上下文毫无压力**
- 27B 的能力在 Agent 编程、操作系统任务、网页操作、多模态理解方面表现极为出色

### 2.2 DeepSeek Harness (DSH) —— 开源 Agent 框架

| 属性 | 详情 |
|------|------|
| **发布方** | DeepSeek（深度求索） |
| **发布日期** | 2026 年 8 月 13 日 |
| **开源协议** | MIT |
| **语言** | TypeScript |
| **架构基础** | Cordis 插件内核（Koishi 同源技术，4 年 4000+ 社区插件验证） |
| **GitHub Star** | 发布 2 小时破万，12 小时超 5 万，42 小时约 10 万——**GitHub 史上涨星最快项目** |

**核心公式：**

```
Agent = Model + Harness
```

- **Model（模型）** = 大脑，负责推理和生成
- **Harness（框架）** = 手脚，负责调度工具、管理上下文、编排任务、记录状态

**设计理念：一切皆插件（Everything is a Plugin）**

模型适配器、工具注册表、会话日志、Agent 主循环、沙箱、审批策略、甚至 UI 界面——全部可以自由替换和重组，开发者无需修改源码。

**四种运行模式：**

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| 标准模式 | 完整工具集：文件编辑、Shell、搜索、Skills、子 Agent、工作流 | 日常开发 |
| PTC 模式 | 模型写 TypeScript 代码一次性组合多步工具调用，大幅省 Token | 批量自动化 |
| 极简模式 | 仅保留 bash + 文件编辑器 | 模型基准测试 |
| 创造模式 | 标准模式 + 运行时检查 + 插件实验 + 自定义预设 | 插件开发、定制 Agent |

## 三、技术方案：如何用2张显卡跑本地 Agent

### 3.1 整体架构

```
┌─────────────────────────────────────────────────┐
│              DeepSeek Harness (DSH)              │
│         Agent 框架 / 工具调度 / 任务编排          │
│                                                  │
│    通过 OpenAI 兼容端点连接，不需要 DeepSeek Key   │
└──────────────────┬──────────────────────────────┘
                   │ OpenAI 兼容 API
                   ▼
┌─────────────────────────────────────────────────┐
│            llama-server (llama.cpp)              │
│         本地推理引擎 / 提供 HTTP API 端点         │
└──────────────────┬──────────────────────────────┘
                   │ tensor-split 1,1
          ┌────────┴────────┐
          ▼                 ▼
   ┌─────────────┐   ┌─────────────┐
   │  RTX 5090   │   │  RTX 5090   │
   │  GPU 0      │   │  GPU 1      │
   │  32GB VRAM  │   │  32GB VRAM  │
   │             │   │             │
   │ 权重一半     │   │ 权重一半     │
   │ KV cache    │   │ KV cache    │
   │ 一半        │   │ 一半        │
   └─────────────┘   └─────────────┘
```

### 3.2 关键技术参数

| 维度 | 配置 |
|------|------|
| **模型** | Qwen3.8-27B UD-Q4_K_XL GGUF（16.69GB） |
| **视觉投影** | mmproj-F16.gguf（0.86GB） |
| **总权重** | 约 17.5GB |
| **上下文** | 262,144 tokens（256K 全开） |
| **KV cache 量化** | q8_0（体积减半，精度损失可接受） |
| **GPU 分配** | tensor-split 1,1（两卡对半分摊） |
| **生成速度** | 约 66 tokens/sec（日志波动 44-100） |
| **预填充速度** | 2,500-2,900 tokens/sec |
| **投机解码** | MTP（GGUF 内置头，无需草稿模型） |
| **启动时间** | 约 10 秒 |

### 3.3 llama-server 启动命令

```bash
export CUDA_VISIBLE_DEVICES=0,1
setsid nohup llama-server \
  --mmproj mmproj-F16.gguf \
  -m Qwen3.8-27B-UD-Q4_K_XL.gguf \
  --batch-size 2048 \
  --ubatch-size 512 \
  -c 262144 \
  -ngl 999 \
  --tensor-split 1,1 \
  -np 1 \
  --alias "Qwen3.8-27B" \
  --flash-attn on \
  --spec-type draft-mtp \
  --spec-draft-n-max 4 \
  --spec-draft-type-k q8_0 \
  --spec-draft-type-v q8_0 \
  --cache-type-k q8_0 \
  --cache-type-v q8_0 \
  --fit off \
  --jinja \
  --temp 0.6 \
  --cont-batching \
  --threads 32 \
  > server.log 2>&1 &
```

### 3.4 DSH 接入本地模型

DeepSeek Harness 认的是 **OpenAI 兼容端点**，不绑定 DeepSeek API。llama-server 一起，把 base URL 指过去即可：

1. 启动 `dsh web`，打开 `http://127.0.0.1:3080`
2. Settings → Models → 添加自定义模型
3. 填入本地 llama-server 的地址（如 `http://127.0.0.1:8080/v1`）
4. API 协议选择 `openai-completions`
5. 保存，立即生效，无需重启

**接入协议的统一像插座标准的统一——插头规格定了，电器是谁家的无所谓。**

## 六、为什么说"智力基线站在了新台阶"

### 6.1 过去的门槛

| 时间 | 跑一个 Agent 级 AI 需要什么 |
|------|---------------------------|
| 2023 年 | 调用 GPT-4 API，按 token 付费，月费数百到数千元 |
| 2024 年 | Claude Code 订阅制，$20/月起步，数据在云端 |
| 2025 年初 | 本地跑 7B-14B 模型，能力有限，只能做简单对话 |

### 6.2 现在的门槛

| 组件 | 需要 | 费用 |
|------|------|------|
| GPU | 2× RTX 5090（或任何两张 24GB+ 显卡） | ~¥30,000-40,000（一次性） |
| 模型 | Qwen3.8-27B（Apache 2.0 开源） | 免费 |
| 框架 | DeepSeek Harness（MIT 开源） | 免费 |
| 推理引擎 | llama.cpp / Ollama | 免费 |
| API 费用 | 无（完全本地） | ¥0/月 |
| 数据隐私 | 数据不出本机 | 无价 |

### 6.3 核心意义

1. **能力跃升**：27B 模型 + Agent 框架的组合，能力已经从"尝鲜"变成"日常可用"。实测能从零交付一个完整的 3D 体素游戏——这不是玩具，是生产力工具。

2. **门槛降低**：从"需要企业级 GPU 集群"降到"两张消费级显卡"。2× RTX 5090 的成本约 3-4 万元，一次性投入，无后续订阅费。

3. **完全私有**：数据不出本机，不经过任何云服务商。对企业 IT 来说，数据不出内网也能上 Agent 工作流；对独立开发者来说，可以拒绝任何订阅涨价。

4. **生态爆发**：DSH 上线 5 天，社区插件已超 1400 个。模型、框架、推理引擎全部开源，生态正在滚雪球。

5. **架构解耦**：框架不挑模型（OpenAI 兼容端点），模型能落本地，两者结合只需改个 base URL。这意味着未来模型升级（Qwen4、Qwen5...），框架和硬件配置都不用换。

## 十、注意事项与避坑

1. **DSH 仍是开发者预览版**：官方明确警告会有破坏性变更，不适合直接上生产环境。

2. **安全第一**：DSH Agent 有读写本地文件、执行 shell 命令的权限，工作区尽量选择空测试文件夹，**不要直接挂载系统目录或重要业务项目**。建议用 Git 做版本管理。

3. **双卡没有 NVLink**：RTX 5090 不支持 NVLink，多卡通信走 PCIe。tensor-split 摊开的是权重和 KV cache，解码每步两卡都要同步，**双卡不会让解码速度翻倍**（约 1.6-1.8x）。

4. **`--fit off` 必须开**：默认 on 时显存吃紧，llama.cpp 会悄悄调小你没显式给的参数，你要的 256K 可能被静默降级。off 就是装不下直接报错，不装糊涂。

5. **`--jinja` 必须开**：用模型内置聊天模板，工具调用全靠它，Agent 场景必开。

6. **插件安装后必须重启 dsh 进程**：仅刷新浏览器通常不够，需要 Ctrl+C 后重新 `dsh web`。

7. **Windows 用户注意**：PowerShell 可能会拦截 npx.ps1 脚本，换成 `npx.cmd @deepseek-ai/dsh web` 即可。

8. **Node.js 版本**：建议 v22.19+，v18 会直接崩溃。v24 安装社区插件可能有兼容性问题，推荐 v22。
