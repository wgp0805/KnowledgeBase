## 一、研究与信息处理

## 1、Deep Research（深度研究）

你平常有没有遇到这样的问题：想研究一个主题时，搜出来的资料特别多，网页、文章、视频和帖子混在一起，最后虽然看了很多内容，却不知道哪些信息可靠，也很难整理成一份有依据的报告？

**Deep Research** 这个 Skill 主要解决的就是这类问题。它会把一个大问题拆成多个小问题，再去查找资料、判断来源、提取事实、进行对比和核对，最后整理成一份带引用的调研报告。你不需要自己先设计完整流程，只要告诉它想研究什么就行。

比如你可以直接说：

```
深度调研 2026 年普通人最值得付费的 AI 工具有哪些，给出来源、对比表和最终结论。
```

## 2、Last 30 Days：过去 30 天发生了什么

你平常有没有遇到这样的问题：想了解一个产品、一个行业或一个热点最近的真实讨论，但普通搜索出来的内容大多是几个月甚至几年前的文章，根本看不出这个话题最近发生了什么？

**Last 30 Days** 这个 Skill 主要解决的就是“只看最近一段时间发生了什么”这个问题。它会搜索多个平台过去 30 天的内容，再结合点赞、评论、观看等互动数据，整理成一份近期简报。

比如你可以这样问：

```
/last30days 最近 30 天 AI Agent 领域最受关注的话题是什么？
```

除了行业热点，也可以用它查公司、产品、人物或某个具体事件。

### 安装方式

直接对 WorkBuddy 说：

```
帮我安装这个技能：
            https://github.com/mvanhorn/last30days-skill
```

## 3、Research-to-Diagram：把调研结果画成关系图

你平常有没有遇到这样的问题：调研本身已经花了很长时间，最后还要重新整理人物关系、事件关系或技术结构，手动画图又慢，画出来还不一定清楚？

**Research-to-Diagram** 这个 Skill 主要解决的就是“调研完成后还要手动画关系图”的问题。你只要给它一个主题，它就会先整理资料和关系，再生成关系图谱。人物关系、历史事件、知识分类和技术架构，都可以用这种方式展示。

比如：

```
深度调研《红楼梦》人物关系，生成关系图谱，并附上参考来源。
```

## 二、学习与知识管理

## 4、IMA 知识库

你平常有没有遇到这样的问题：资料已经存进笔记软件或知识库，但 AI 看不到里面的内容；想查资料时只能自己翻，想把一篇文章整理成笔记，也得重新复制粘贴一遍？

**IMA 知识库 Skill** 主要解决的就是“让 AI 读写你的 ima 笔记和知识库”这个问题。接入之后，可以让 AI 搜索资料、整理笔记、上传文件、添加链接，或者根据知识库里的内容生成新的清单和文章。

比如你可以这样说：

```
搜索一份日本关西 5 日游的旅行攻略，存到我的 ima 知识库，并整理成一篇笔记。
```

也可以这样用：

```
在我的 ima 知识库里搜索所有关于阅读书籍的资料，整理出阅读清单。
```

## 5、用 AI 管理 Obsidian 笔记和画布：Obsidian Skills

你平常有没有遇到这样的问题：让 AI 帮你写 Obsidian 笔记时，普通 Markdown 看起来没问题，但双链、Properties、Bases 或 Canvas 格式经常写错，最后还得自己修一遍？

**Obsidian Skills** 主要解决的就是“让 AI 按 Obsidian 的规则管理知识库”这个问题。它支持创建和修改笔记、建立双链、生成数据视图、绘制 Canvas 画布，还可以把网页内容整理后保存进知识库。

## 三、职场办公与求职

## 6、Ego Lite：浏览器技能

你平常有没有遇到这样的问题：很多事情必须打开浏览器才能完成，比如登录网站、点击按钮、填写表单、复制数据或截图。只让 AI 读网页不够，但每一步都自己操作又很麻烦？

**Ego Lite** 主要解决的就是“让 WorkBuddy 真正使用浏览器”的问题。它可以打开网页、点击页面元素、填写内容、提取数据和截图，也能在允许的情况下使用浏览器里的登录状态。

## 8、Kami 纸张 Skill

你平常有没有遇到这样的问题：内容已经写完了，但简历、白皮书、作品集或一页纸材料还要重新排版，自己调半天格式，导出的 PDF 还可能出现字体和版式问题？

**Kami 纸张 Skill** 主要解决的就是“把 Markdown 内容排成正式文档”的问题。它提供多套文档设计模板，可以把 Markdown 整理成适合投递、分享和打印的 PDF，也能处理中文、英文和日文材料。

比如：

```
搜索数学家王虹的公开资料，整理成一页学术简历，突出教育背景、研究方向和主要成就，输出 Kami 纸张风格的 PDF
```

这个提示词和上面 AI 简历助手的例子是一样的，你可以对比两个技能的产出效果：简历助手侧重内容组织和求职场景，Kami 侧重排版和纸张质感，看你更喜欢哪个。

## 14、用 HTML 设计杂志、演示文稿和海报：HTML Anything

## 15、女娲 Skill

你平常有没有遇到这样的问题：遇到复杂问题时，普通 AI 给出的建议都很通用，听起来什么都对，但缺少明确的判断框架。你想知道乔布斯、费曼或张雪峰会怎么分析，却不知道该怎么提问？

**女娲 Skill** 主要解决的就是“借用不同人物的思考框架分析问题”这个问题。它会把人物的心智模型、决策方法和表达特点整理成可以调用的视角。它不是简单模仿某个人的语气，而是尝试用对方的思考方式分析新的问题。

安装之后，可以这样使用：

```
蒸馏张雪峰的思考框架。用张雪峰的视角帮我分析：孩子高考报志愿，计算机和临床医学该怎么选？费曼会怎么给小学生解释下雨是怎么回事？
```
