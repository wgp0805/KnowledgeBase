# 最近逛GitHub，挖到3个给力的开源项目，第一个比较硬核。

**01**

**给你的 Agent 赋予 CAD 超能力**

![图片](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU0zDg4J3icL4e8LafTia8sHDMZsSXIggRcEW3z7eCrWEjll9PTibgRYuFj6fwY9AMkaV6tickm9zV25CjklOKNMCn3icWLXD3mqRGpg/640?wx_fmt=png&from=appmsg#imgIndex=0)

text-to-cad 给 Claude Code、Codex 等 Agent 工具**增加了 CAD 建模能力。**

CAD 就是用电脑设计工程图和三维模型，**机械专业大学生、机器人比赛团队、硬件工程师和三维打印爱好者****经常会用这个东西。**

这个开源项目就是把建模、查看和导出等流程整理成了插件与 Skill。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU1XN61CPuOTIYpWQ8GTsgh6dlUgCwictibkyFzYsCtvpmKnCS26veibDPCCylQNcgDd3zOWiak0UcAUjEH3RIcWNdmCfYTeYFw724A/640?wx_fmt=png&from=appmsg#imgIndex=1)

你可以**描述零件的形状和尺寸，让 Agent 编写本地建模脚本，再生成三维文件。**

比如要做一个带安装孔的支架，可以说明整体尺寸、厚度、孔径和孔的位置。

后面想把支架加宽或者调整安装孔的位置，就修改对应参数，再重新生成。

模型源码也会保留下来，方便继续调整。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU1UBVQt0hmPrqF7xR0icw6vmGuvicypXGribWicaAAOapya9iaag53WFlnvRjEX9sZ5bUMElcw8pQssCORRtviaS3kOxSnoM3a3CQNfI/640?wx_fmt=png&from=appmsg#imgIndex=2)

![图片](https://mmbiz.qpic.cn/mmbiz_gif/M2ibDBMdECU17eKlKZC1wlKBicqQmeAHNvrVgvLreuVI8Vs3R0trTFCAjQG9Xyyqwdv54XkSLPptH8QdCPxOicwn0NCND5YpzNmrcyvk2yG3Bo/640?wx_fmt=gif&from=appmsg#imgIndex=4)

它生成的是三维模型文件，能接着进入后续设计和打印流程。

项目支持导出 STEP、STL、3MF 和 GLB。

STEP 适合继续在 CAD 软件里处理，STL 和 3MF 常用于三维打印，GLB 则方便三维展示。

配套查看器可以打开模型，让人检查形状，再给 Agent 提修改要求。

```javascript
开源地址：https://github.com/earthtojake/text-to-cad
```

02

**开源一支音乐视频 MV 制作方式**

pdoom-video 把一支音乐视频的**画面、歌词动画和渲染过程开源了。**

它为歌曲《I'm Upping My P(doom)》制作了一套视觉作品，画面由程序绘制，歌词逐词跟着人声变化。

也就是下面这个 MV：

[📹 点击播放视频](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_4725492698185678853)

这个视频里有图表、表格、三维房间和回形针等元素。

不同场景有各自的画风，又共用一套色彩和字体规则，画面切换与音乐节拍对齐。

开源项目里还保留了**视觉构思**和**分场景制作说明**，能看到这些设计是怎样落地实现的。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M2ibDBMdECU30Guh226ERpjxZsjFusyz1yxDdK80Alpn1YWiaFibDDAavGchoBTFqShe0wGEMLicngWaYibpBpIsJeDbCiaHs4ncMgC0Vt8v9H9GA/640?wx_fmt=png&from=appmsg#imgIndex=5)

这个开源项目就是包括这个 MV 的完整制作细节。

还包含音频、逐词歌词时间和节拍分析数据。

视觉构思、歌词对齐、音频分析和场景实现，都是开发者通过与 Claude Code 对话协作完成。

对做动态设计、创意编程的人来说，这些文件能提供不少具体参考。

开源地址：https://github.com/mexicat/pdoom-video

03

**Jev 聊天助手**

![图片](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU3ibXicu7MFKwTL8lNdoCiaOJlDVGMCT7mGROGxMQh3FWD0NbG15xyfNs1p7HdAEh5Gv1dEPnWd6MxnfhUic77rzbYibmjpuqreCvUY/640?wx_fmt=png&from=appmsg#imgIndex=6)

Jev 聊天助手是一个开源的安卓应用，**能在聊天界面里分析消息，帮你想几种回复方式。**

打开 QQ、飞书，屏幕上就会**出现一张可以拖动的小卡片。**

你可以展开看看分析，再挑一条回复填进输入框，改好之后自己点发送。

它会结合当前对话，推测对方想表达什么、希望你做什么，再据此起草回复。

你可以选择生成一条、两条或三条，生成三条时还会给候选排序。

觉得这一组不合适，可以点**换一组**重新生成。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU2ochLwYNNwsHlUoU3CG8uJheTbkhgWBX1OADlSJwtX5ynDLFBIBlUpHZqXaY7CdQsl08rYU8WWhOaArdMak9Z0iblRRNsyRcNU/640?wx_fmt=png&from=appmsg#imgIndex=7)

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M2ibDBMdECU0B1hhiceHpCf46OX1STUtmtcYSYe1ic26Dw4YAY9rZzBORqtrqYFmOoI4Eyom2icIYM0ZrfawMQyqKWm5eymLvV1cYicEEfmAzibcA/640?wx_fmt=png&from=appmsg#imgIndex=8)

你还可以手动添加笔记，给联系人写上关系和备注。

匹配到对应联系人，或聊天里出现笔记的标题、标签时，这些背景就能一起参与分析。

聊天历史也可以记录在手机本地，在后续分析时作为参考，这个功能默认关闭。

安卓端目前主要适配** QQ、X 私信和飞书。**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M2ibDBMdECU2PI9icNCGuVFbXpj7SLpKxGLKzW4AEU7EWtUAd9BQpYiagbeTiaZBcfLQ8qsjd3tLaEm9lvzZGLsOgm2j2JQE05ibymt7dFUE3v5I/640?wx_fmt=png&from=appmsg#imgIndex=9)
