# 最近逛GitHub，挖到3个给力的开源项目，第一个比较硬核。

程序汪大量接私活案例：[程序汪接私活项目目录，2026年总结](https://mp.weixin.qq.com/s?__biz=MzA4NzQ0Njc4Ng==&mid=2247520080&idx=1&sn=da5201e8b5503122cfb022ea27bcd7ef&scene=21#wechat_redirect)

**01**

**给你的 Agent 赋予 CAD 超能力**

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/210aafe168de6e43486d7bb522c2ee48_MD5.png)

text-to-cad 给 Claude Code、Codex 等 Agent 工具**增加了 CAD 建模能力。**

CAD 就是用电脑设计工程图和三维模型，**机械专业大学生、机器人比赛团队、硬件工程师和三维打印爱好者****经常会用这个东西。**

这个开源项目就是把建模、查看和导出等流程整理成了插件与 Skill。

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/73708387ce26aa36c1ab427a731457cd_MD5.png)

你可以**描述零件的形状和尺寸，让 Agent 编写本地建模脚本，再生成三维文件。**

比如要做一个带安装孔的支架，可以说明整体尺寸、厚度、孔径和孔的位置。

后面想把支架加宽或者调整安装孔的位置，就修改对应参数，再重新生成。

模型源码也会保留下来，方便继续调整。

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/e71d159e0c6554a98d6bd3b5cfd5d6ef_MD5.png)

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/6978db7d96df71754b8dd0483e914bfd_MD5.gif)

它生成的是三维模型文件，能接着进入后续设计和打印流程。

项目支持导出 STEP、STL、3MF 和 GLB。

STEP 适合继续在 CAD 软件里处理，STL 和 3MF 常用于三维打印，GLB 则方便三维展示。

配套查看器可以打开模型，让人检查形状，再给 Agent 提修改要求。

```javascript
开源地址：https://github.com/earthtojake/text-to-cad
```

02

**开源一支音乐视频 MV 制作方式**

pdoom-video 把一支音乐视频的**画面、歌词动画和渲染过程开源了。**

它为歌曲《I'm Upping My P(doom)》制作了一套视觉作品，画面由程序绘制，歌词逐词跟着人声变化。

也就是下面这个 MV：

[📹 点击播放视频](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_4725492698185678853)

这个视频里有图表、表格、三维房间和回形针等元素。

不同场景有各自的画风，又共用一套色彩和字体规则，画面切换与音乐节拍对齐。

开源项目里还保留了**视觉构思**和**分场景制作说明**，能看到这些设计是怎样落地实现的。

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/52789d233d1af4c0e2e150455f05d324_MD5.png)

这个开源项目就是包括这个 MV 的完整制作细节。

还包含音频、逐词歌词时间和节拍分析数据。

视觉构思、歌词对齐、音频分析和场景实现，都是开发者通过与 Claude Code 对话协作完成。

对做动态设计、创意编程的人来说，这些文件能提供不少具体参考。

03

**Jev 聊天助手**

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/6a965d71b9d0f28728aa4a3cfc0c5d6b_MD5.png)

Jev 聊天助手是一个开源的安卓应用，**能在聊天界面里分析消息，帮你想几种回复方式。**

打开 QQ、飞书，屏幕上就会**出现一张可以拖动的小卡片。**

你可以展开看看分析，再挑一条回复填进输入框，改好之后自己点发送。

它会结合当前对话，推测对方想表达什么、希望你做什么，再据此起草回复。

你可以选择生成一条、两条或三条，生成三条时还会给候选排序。

觉得这一组不合适，可以点**换一组**重新生成。

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/05af588c7cbfad7df36a1a22f82398d9_MD5.png)

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/e90a50c6378651fadaea6a75da5d0959_MD5.png)

你还可以手动添加笔记，给联系人写上关系和备注。

匹配到对应联系人，或聊天里出现笔记的标题、标签时，这些背景就能一起参与分析。

聊天历史也可以记录在手机本地，在后续分析时作为参考，这个功能默认关闭。

安卓端目前主要适配** QQ、X 私信和飞书。**

![图片](assets/2026-10-16%20-%20%E6%9C%80%E8%BF%91%E9%80%9BGitHub%EF%BC%8C%E6%8C%96%E5%88%B03%E4%B8%AA%E7%BB%99%E5%8A%9B%E7%9A%84%E5%BC%80%E6%BA%90%E9%A1%B9%E7%9B%AE%EF%BC%8C%E7%AC%AC%E4%B8%80%E4%B8%AA%E6%AF%94%E8%BE%83%E7%A1%AC%E6%A0%B8%E3%80%82/06d748918e2eae89be78970c84f927e6_MD5.png)
