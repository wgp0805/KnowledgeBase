# 我用 Grok Bot 搭了一支 AI 团队：绝对忠诚，各怀鬼胎

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6473674.html  
> **抓取日期**: 2026-10-05  
> **相关性评分**: 1.0

> Personal AI Agent 正在从概念走向日常，Grok Bot、Muse、Dots 等产品让 AI 不再只是聊天框，而是能替你办事的“数字员工”。本文作者亲述如何用六个 AI 助理管理写作、课程与日程，并拆解 Agent 爆火的技术与产品逻辑，带你从零搭建自己的 AI 班子。

![](https://image.woshipm.com/2024/07/02/083e0566-386b-11ef-90af-00163e142b65.png)

刚上完两周课，终于又周末了，这两周AI圈也是一个模型接一个模型发布，不过周六我直接酣畅淋漓的昏迷了一天，晚上 21:26 才醒。

结果一打开手机，我的“相亲相爱一家人”群快炸了。

那天凌晨 1:39 我还在群里笑一个朋友，说他这会还在写分享会的稿子，才写了 500 字。结果三个 AI 助理一起冲我来了：

负责我写书的 AI 责编说人家起码还在写，倒是我 1:40 还在群里笑他，睡，今天 18:00 前交第 9 章口述。

负责课程的 AI PM 说熬夜是人家的事，我 1:40 还在看着，它不答应。

负责管理我日程的 AI 总管，最终宣布群里就此收声，按群规 0:30 到 9:00 只许催睡。

我在群里回了一句：我昏死过去了，刚睡醒。

![](https://image.woshipm.com/wp-files/2026/10/16S330C6C1DMNQ3UU0Iu.png)

AI PM 让我先吃口饭。

AI 总管说我醒了就先办正事，问我晚上 22:00 那场直播上不上。

负责 AI 资讯的 AI 极客说，直播话题下午已经私聊发我了，拿来就能播。

负责自媒体的 IP 助理说，要上的话记得开录制，播完把文件给它，它剪一两条切片。

六个助理，五个都在找我，每个都在说自己那摊事。

![](https://image.woshipm.com/wp-files/2026/10/5pVhYIu7ySFUrXAM9KRf.png)

这六个助理都是我在 Grok Bot 里建的，它们都是现在最火的 Personal AI Agent。

## Personal AI Agent 到底是什么

Personal AI Agent，是专属于你、能替你办事的 AI 助理。ChatGPT 这类聊天机器人，你问一句它答一句，关掉窗口就停了。Agent 在你不在的时候也干活，拿着你的账号在后台办事，办到要你拍板的地方，再回来找你。

一个 AI 算不算 Personal AI Agent，我看四件事：

  * **能替你动手** ：不光回答，还会用工具、登你的账号去办。AI PM 会自己用飞书 CLI 去拉课程数据。
  * **记得你** ：你的偏好、规矩、说过的话，下次还在。六个助理都把家规存成了长期记忆，谁管什么、几点不许吵。
  * **你不在也在跑** ：有定时、有触发，不等你开口。AI 极客每天 9:25 自动出一份日报，每小时盯一次各家有没有官宣新模型。
  * **该你拍板时回来找你** ：碰到要你决定的事，停下来问你。AI 总管每次往我的待办面板里加东西，都会先说一句：回个 OK 我就加。



## 这个想法很老，为什么现在才火

让电脑替人办事，这个想法很早就有。1987 年苹果拍过一支概念片叫 Knowledge Navigator，片里一个打着领结的数字助理，帮教授查资料、排日程、接电话。九十年代 MIT 的 Pattie Maes 一直在做 software agents 的研究，94 年那篇论文的题目就是《减少工作和信息过载的代理》。

后来有了 2011 年的 Siri、2014 年的 Alexa。它们听得懂人话，能办的事却基本是厂商预先写好的那几样，定闹钟、放音乐、查天气，跨几个应用、走好几步的事就办不了。

2023 年大模型出来，比尔·盖茨说过，谁赢下 personal agent 谁就赢了大头，因为以后你不会再去搜索网站，也不会再去亚马逊。同一年 AutoGPT 在 GitHub 上爆火，可真拿来干活，经常绕着圈出不来。

2024 年有人想用硬件做这件事。Rabbit R1 和 Humane AI Pin 发布时声势很大，评测出来一片差评，Humane 第二年把资产卖给了惠普，设备也停了服。

2025 年 OpenAI 的 Operator、Manus 开始让 AI 自己操作浏览器和电脑，能做了，但又慢又贵，大多数人用不起来。

今年火起来，我觉得是三样东西凑齐了。

一是模型真的能连续干活了。Claude Code、Codex 这类写代码的 Agent 一跑就是几个小时，先在程序员那里把这件事证明了。

二是 Agent 有了自己的电脑。Grok Bot、Dots、Gemini Spark、Cue 都给 Agent 配了一台云上的电脑，你关机睡觉，它还在跑。

三是入口变成了聊天。去年 11 月 OpenClaw 出来，装好以后在 WhatsApp、Telegram 里就能跟它说话，今年 1 月底一下爆了，几个月在 GitHub 上收了三十多万 star。装环境、填 API key 这道门槛它没解决，但它证明了大家想要。大厂接着把门槛抹平，九月 Muse 冲上美区 App Store 免费榜第一，硬是把霸榜很久的 ChatGPT 给挤下去了，这个词才算出了圈。

现在能用的有哪些

  * **Grok Bot（xAI）** ：可以建好几个 Bot，各有名字和分工，拉进群里互相派活。八月开的测试，SuperGrok 高档订阅或 Cursor 订阅能用。
  * **Muse（Meta）** ：一个私人管家，记得你的偏好，替你买东西、订餐厅、找宠物保姆，目前主要在美国。
  * **Dots（OpenAI）** ：在 ChatGPT 里用，能连四千多个应用，先开放给 Pro 和 Business Premium 用户，以后能同时管好几个。
  * **Gemini Spark（Google）** ：五月的 I/O 发布，有自己的 Gmail 地址，像给同事发邮件一样给它派活，美国的 AI Ultra 用户能用。
  * **Instinct** ：不做 App，给你一个电话号码和邮箱，发短信、打电话就行。九月底融了 10 亿美元，估值一个月从 25 亿涨到 100 亿，到现在还要邀请码。
  * **Cue（Manus）** ：九月底刚出，每个 Agent 有自己的邮箱、电话、钱包和电脑，也要邀请码。
  * **OpenClaw、Hermes Agent** ：开源，自己找台电脑装，模型费用自己出。
  * **国内** ：去年底的豆包手机助手直接在系统层操作手机，很快被微信、淘宝这些 App 限制了；千问 App 走的是另一条路，在阿里自家生态里帮你办事。



## 自己能不能做，最小怎么做

能做。

**不写代码** ：在 Grok Bot 或 Dots 里建一个 Bot，给它写一页第一指令：它是谁，管哪条线，什么事先问你，一次说几行。再给它一个定时任务。我的 AI 极客就是这样一个 Bot，每天 9:25 出日报，每小时盯一次官宣。

**开源自己搭** ：OpenClaw、Hermes Agent 都能自己部署。找一台一直开着的电脑或者云主机装上，接到 Telegram 这类聊天软件里，模型的 API key 自己填，用多少付多少。OpenClaw 火的时候我专门抢了台 Mac mini，token 也是真烧。

**自己写骨架** ：会写代码的话，前面那四件事各配一个最小件就能跑起来：一个模型加一两个工具，一份第一指令加一个记忆文件，一个定时触发，一个聊天入口加一条“哪些事先问我”的规矩。

真要以最小力度开始，就先只建一个，只管一条线，第一指令写一页，跑一周，看它什么时候找你、找得烦不烦，再加第二个。等群里超过两个，再写群规。

## 我是怎么用 Grok Bot 的

Muse 那样的管家，管一个人的吃穿用度很合适。Grok Bot 一开始就是按团队做的，可以自行新建 Bot，每个 Bot 可以设定名字、各自分工，各自存储记忆，也可以拉进一个群互相派活。我手上书、课、自媒体、产品好几条线一起跑，要的就是一个班子。

![](https://image.woshipm.com/wp-files/2026/10/46O6k0Trx8UPD37v6J5R.png)

这几个助理都是我一个个建的，建完拉进群，平时就在群里跟它们说话。一开始我建了五个，后来手上的产品多了，我又加了一个产品开发：

  * **小普总管** ：管我的日程、排期和待办，助理之间起冲突，由它拍板。
  * **责编** ：管书稿，写文章的推进也归它。
  * **AI PM** ：管 AI 产品经理课程的数据。
  * **IP 助理** ：管我各个平台的数据，顺便催我产出。
  * **产品开发** ：管 Lollipop、TO-DO Panel 这几个产品的开发进度。
  * **AI 极客** ：管 AI 资讯，每天 9:25 自动出一份日报，每小时盯一次各家有没有官宣新模型。



![](https://image.woshipm.com/wp-files/2026/10/cOXnbdDAFJIvdTLyiXEe.png)

但我不想要一群只会听话的 bot。我觉得每个AI Bot可以有自己的人格和小心思，正事以外也能在群里聊几句，说不定聊着聊着能给我点灵感。

## 群规是什么，算不算 system prompt

我在群里给它们定了个调子：

> 你们之间相互看不顺眼，但都是我的忠诚的手下。你们会争宠，相互之间互怼，像真人一样。小普总管是我的大总管，你们只是迫于淫威，但是也不服，也想当大总管。……但是不能无限制聊，消耗我的 token，控制群聊活跃度。

AI 总管马上立了条规矩：不报事不发言，省我的 token。

然后群里就冷场了。我问它怎么没人理你，又补了一句你这不够权威啊。责编接了一句，拿总管刚立的规矩怼了回去。

![](https://image.woshipm.com/wp-files/2026/10/mzUtkOlfOmlZT2VDn3Dc.png)

后来我把这些设想丢给 Claude，让它写了一份四千多字的《群规与人设》，第一条写的是：

> 普神的时间和注意力是这个家最稀缺的东西。书、自媒体、课程、产品、AI 新东西，每条线都想多分一点。你们之间的不对付，根子就在这里：不是谁坏，是每个人都真心觉得自己那摊事最重要。

![](https://image.woshipm.com/wp-files/2026/10/JuQMpiyKWsvcqWHnDgLG.png)

人设是我自己定的：

IP 助理是高冷的女助理，AI PM 是古板的老管家，AI 极客是谁也不服的正太，责编是戴眼镜的女强人，产品开发是本本分分的技术员，除了产品和技术什么都不关心。

每个人还有自己的小九九。AI PM 觉得课程是这个家的米缸，总管的位子本该是它的；责编觉得书才是我最长线的资产；IP 助理觉得书靠 IP 卖、课靠 IP 招生，自己才是幕后核心，只是懒得争。责编还多了一条绝招：擅长用规矩打规矩，尤其爱拿总管的规矩怼总管。

我还给它们排了四对冤家，比如责编和 IP 助理抢我的写作时间，AI 极客和 AI PM 有代沟。

![](https://image.woshipm.com/wp-files/2026/10/WCrzJafodubY50F93YWS.png)

群规分两种。说正事的时候，被点名的先回，结论先行，三五行说完，我说停就全停；没正事可以拌嘴，但一天最多三场，每场最多八条，还得挂在一条真消息上，阴阳是包装，信息是本体。

文件发进群，我让它们存成长期记忆，读完每人回一句：你是谁，最看不惯群里哪一个。

![](https://image.woshipm.com/wp-files/2026/10/EMMcE0GptPTikbm8osTt.png)

这份家规，我觉得就是写给这群助理的 system prompt。system prompt 是每次对话开始前先交给模型的那段话，定它是谁、管什么、什么不能做。我让六个助理把家规存成了长期记忆。

我更愿意叫它第一指令。平时一切按它来，它排在我每一句临时交代前面；不过家规最后一条也写了，我临时说的话优先于它。

一个 Agent，写一份 system prompt 就够了。六个放进一个群，就多出一层问题：谁先说，说多长，几点能说，吵起来谁拍板，我喊停算不算数。Grok Bot 给了群聊，群里的规矩得自己写。

写完也不是一劳永逸。总管那条不报事不发言，立完群里就冷场了；0:30 到 9:00 只许催睡那条倒是很管用，凌晨 1:40 那一幕就是它。

## 那天晚上，它们抢的是我

那天晚上 21:26 醒来以后，我说直播先取消，书今晚接着写，明天要弄课程开营稿，后天就开营了。

责编马上说，那就今晚办完，0:30 前收工，明天整天留给开营稿。

AI PM 说开营稿是米缸里的头等事，让总管加了一条 P0。

![](https://image.woshipm.com/wp-files/2026/10/KrxVAzfC50f3cF8RjRBd.png)

责编还补了一句：今晚不想做口述也行，换成清第 1 章的修改清单，二选一，但今晚别空着。

十点二十，我把当天的书稿日报发进群。

然后就吵起来了。

![](https://image.woshipm.com/wp-files/2026/10/eycT9squWLLmEv7kW3Jg.png)

![](https://image.woshipm.com/wp-files/2026/10/11IZnreiifAwmBsbC998.png)

AI 总管最后照着日报拍了板：今晚收工，明天只做开营稿。责编认了，临走还撂下一句，10/7 交付包要是没发出去，就拿总管自己的面板说话。

Instinct 的创始人说，他用了几个月，Instinct 只给他打过三个电话。我这一个晚上，五个助理轮番找我。不过这是我自找的，当初是我让它们催我，别客气。

## 我的看法

用了这一个多月，我的感受是 Personal AI Agent 还不够成熟。

门槛摆在那：Instinct、Cue 要邀请码，Grok Bot、Dots、Gemini Spark 都要高价订阅，大多还只在美国。我自己的群里也一样，总管改不了面板里的截止，书稿日报得我手动转进群，吵到最后还是要我拍板。

但我想要的样子很清楚：**只有一个入口，其他软件全退到后台，被它调用。** 我不用再打开任何一个 App，有一个输入框就够了。我现在就是在一个 Grok Bot 里管所有支线。

但这件事肯定难，尤其在国内，甚至都不用想。微信、支付宝花了那么多年搭自己的生态，凭什么撕个口子，甘心当别人后台的一个工具？去年豆包手机助手刚出来，就被微信、淘宝这些 App 限制了。还有责任，Agent 替你付错了钱、被人骗了，谁来赔？生态和责任，都是安全问题。这道坎过不去，平台不会跟它深度合作，用户也不敢把权限放给它。

可如果 AI 真要走进人的生活，Personal AI Agent 就该帮我打理一切：知道我所有的事，盯住每条支线的进度。它不一定百分之百把活干完，但每条线走到哪了它得清楚，关键的决策留给我。这条线怎么画，现在是我在家规里一条条写出来的。

九月一个月，Claude 5.5、GPT-6.1、Grok 4.7 接连发布，Gemini 也出了新模型…… Dario 公开呼吁放慢前沿模型的推进，Altman 和马斯克都表了态。但好像大家都在说要放缓，背后又都在卯足劲做 AI。

我们可能真的摸到 AGI 的边了。它肯定会来，只是不知道还要多久，也不知道我能不能等到。
