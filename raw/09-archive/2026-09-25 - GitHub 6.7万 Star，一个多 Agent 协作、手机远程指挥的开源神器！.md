# GitHub 6.7万 Star，一个多 Agent 协作、手机远程指挥的开源神器！

最近在 GitHub 上有个挺火的项目叫 Orca，一个管理 AI 编程 Agent 的开源工具，现在已经 6.7 万 Star 了，还在涨。看了一圈，社区反馈普遍不错，我自己也装来用了一段时间。今天这篇分享给大家，说说它具体能干什么。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/5cf172847c68b3f84e28fc42c30de36c_MD5.jpg)

Orca 桌面端

# 简介

Orca 是 Stably AI 开源的项目，这家公司是 YC 孵化出来的。官方给它的定位叫 ADE，Agent Development Environment，智能体开发环境。意思是传统 IDE 里 AI 只是个插件，而在 Orca 里干活的主力就是 Agent，人主要管派任务和看进度，跑完了挑结果。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/5b718697c9ed420317a1802ceaaf74af_MD5.png)

有一点我觉得很关键：Orca 自己不含任何模型，也不用注册什么 Orca 账号，你本地已经登录好的那些命令行 Agent，它直接接着用。

官方列表里具名的 Agent 已经排了将近三十种，Claude Code、Codex、OpenCode、Grok、Cursor CLI、GitHub Copilot CLI 都在里面，国产的 Kimi、Qwen Code、MiMo Code 也支持。官方的说法是，**只要这个 Agent 能在终端里跑，就能放进 Orca 里跑。**

# 看看它能干什么

### 并行 Worktree，多个 Agent 同时干活

这是 Orca 最核心的功能。

实际用法是这样的：同一个需求，我们可以同时派给好几个 Agent。每个 Agent 分到一个独立的  `git worktree` ，也就是独立的目录加独立的分支，谁改文件都碰不到别人的东西。跑完以后在一个界面里并排看 diff，挑一份最满意的合并，剩下的直接丢掉。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/cf61d7da584bfe7e652afd10231f4d62_MD5.gif)

并行 worktree以前想这么干，得手动开五六个终端，自己建 worktree，自己记哪个窗口对应哪个任务，切来切去头都大。现在用 Orca，这些杂事不用手动干了。

### 终端分屏，一个窗口看所有任务

内置终端是 WebGL 渲染的，可以无限分屏，而且回滚记录在重启之后还在。同时跑五六个 Agent 的时候，所有输出平铺在一个窗口里，扫一眼就知道谁干完了、谁卡住了。哪个 Agent 干完了会有通知，不用人一直盯着屏幕。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/f7426c3f27f4a287b9ed27cc67f995b3_MD5.gif)

终端分屏

### Design Mode，页面上点元素提需求

前端活最烦的就是描述样式问题，“那个按钮往左挪一点”这种话，AI 经常理解偏。Orca 内置了一个 Chromium 浏览器，打开 Design Mode 以后，直接点页面上的元素，这个元素的 HTML、CSS 和截图会一起发给 Agent。这样改样式省事很多，不用费劲描述是哪个元素。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/156df7bc641d90e750cf5ccb6a9ded32_MD5.gif)

Design Mode

### Diff 批注，像 review 代码一样提意见

Agent 写完的代码，我们在 diff 视图里可以直接在某一行上写评论，写完一起发回去让 Agent 接着改。这个流程和给人 review 代码差不多，哪行有问题就在哪行写，不用再单独描述一遍位置。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/2b757a2b421c58c34459663543f3378f_MD5.gif)

Diff 批注

### GitHub 和 Linear 集成

PR、Issue、项目看板可以在 Orca 里面直接看。看到哪个任务要做，一键就能从这条任务开出新的 worktree，不用在浏览器和编辑器之间来回切。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/066c8fe2ce5e934bbfb19c7bb29354c1_MD5.gif)

GitHub 和 Linear 集成

### SSH 远程 Worktree

本地机器跑不动的重活，可以把 Agent 放到远程服务器上跑。文件编辑、git、终端这些能力都是完整的，断线了自动重连，还带端口转发，本地只留一个控制端就行了。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/a7ca548b906bd3b278b4f4235b927e5c_MD5.gif)

SSH 远程 Worktree

### 手机端 App，随时看进度

iOS 和 Android 都有配套 App，跟桌面端配对以后，Agent 跑完了手机会收到通知，人不在电脑前也能发后续指令。长任务挂在那里，出门吃个饭回来接着看进度就行。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/f33b5840c434d6fa80ffde8e2318dec0_MD5.gif)

手机端

### 账号和用量管理

同时用多个 Agent 的人，应该都被限流搞过。Orca 的状态栏直接显示 Claude 和 Codex 的用量和限流重置时间，多个账号之间一键切换，不用重新登录。多账号轮着用的时候，这个功能省事不少。

### Orca CLI

Orca 自己还带一条命令行，建 worktree、打快照、点界面这些操作都能脚本化。也就是说 Agent 反过来也能驱动 Orca，想把整个流程接进自动化的话，靠这个 CLI 就能串起来。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/8de4c02adf8c9cbcbc16302cc22b5c60_MD5.gif)

# 快速开始

我自己是 Mac，装的时候就一行命令：

```
brew install --cask stablyai/orca/orca
```

Windows 和 Linux 的话，去官网  `onorca.dev`  或者 GitHub 的 Releases 页面下安装包，Windows 是 exe，Linux 是 AppImage，平时怎么装软件就怎么装。

![](assets/2026-09-25%20-%20GitHub%206.7%E4%B8%87%20Star%EF%BC%8C%E4%B8%80%E4%B8%AA%E5%A4%9A%20Agent%20%E5%8D%8F%E4%BD%9C%E3%80%81%E6%89%8B%E6%9C%BA%E8%BF%9C%E7%A8%8B%E6%8C%87%E6%8C%A5%E7%9A%84%E5%BC%80%E6%BA%90%E7%A5%9E%E5%99%A8%EF%BC%81/f6c8e715d39d0d798d42a0c0b6ca72ea_MD5.png)

装完打开，把本地的代码仓库添加进去，新建一个 worktree，在终端那里选我们想用的 Agent，说一句要做什么，它就开工了。想对比方案的话，同一个需求多开几个 worktree，一个 worktree 派一个 Agent，跑完挑结果。

有一件事要说清楚，Orca 自己不卖模型，也不收费，它用的是你已有的 Agent 订阅，各个 Agent 的额度该怎么算还怎么算。同时派五个 Agent 出去，token 消耗也是五份，到时 token 消耗可能飞起。

手机端想一起玩的话，iOS 走 App Store 或者 TestFlight，Android 在官网下 APK，装好后跟桌面端配对就能用。

# 最后聊聊

Orca 这类工具能火，原因不复杂。现在单个 Agent 写代码已经够用了，真正耗人的是同时开几个之后多出来的那些杂事，比如哪个任务跑到哪一步了，这份改动是哪个需求来的，合错了还要回滚。Orca 做的就是把这些杂事管起来，功能都不花哨，但日常都在用。

如果你平时只用一个 Agent，一次只干一件事，那它对你来说有点重，可以先观望。如果已经在同时用两三个 AI 编程工具，经常被窗口和分支搞得头疼，那可以装一个试试，绝对适合你。
