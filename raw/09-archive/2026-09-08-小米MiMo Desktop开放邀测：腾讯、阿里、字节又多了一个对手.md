# 小米MiMo Desktop开放邀测：腾讯、阿里、字节又多了一个对手

> 刚刚，小米 MiMo 团队把 Xiaomi MiMo Desktop（下称 MiMo Desktop）的邀测闸门打开了，同时甩出两款新一代模型的预览版：MiMo-X-Pro-Preview 和 MiMo-X-Flash-Preview。我最大的感受是——这次小米几乎没谈跑分，所有话术都压在”交付”两个字上。这其实是个信号：桌面 Agent 的竞争，正在从”答得对不对”转向”能不能把活干完”。

## 真实工作，从来不是从一个干净的 Prompt 开始的

官方这句话我挺认同。现实里的任务是脏的：表格、图片、视频、PDF、录音，甚至一个没解压的压缩包，同时构成上下文。MiMo Desktop 允许这些素材直接扔进去，不用先整理、不用转格式。

输出也不再是一段文字，而是可以继续编辑的成果：文档、表格、PPT、网页、图片、音频、视频，甚至 3D 模型、App 和软件工程项目。官方给的 PPT 工作流长这样：

混合素材输入 → 事实与数据梳理 → 叙事结构设计 → 图表与版式生成 → 交付可继续修改的 PPT

![MiMo Desktop PPT 工作流演示](https://tu.aixq.cc/wp-content/uploads/2026/09/mimo-desktop-01.gif!ys)

另一条链路更值得留意——设计：自然语言输入 → 理解任务 → 规划工作流 → 调用 MCP 控制 Figma → 实时生成设计元素 → 交付成果。MCP 正在成为桌面 Agent 接第三方工具的通用插头，小米这次直接把它写进了官方工作流。

![MiMo Desktop 调用 MCP 控制 Figma](https://tu.aixq.cc/wp-content/uploads/2026/09/mimo-desktop-02.gif!ys)

## 预览不是截图，是能点、能玩、能改的真页面

这是我认为本次最实在的一条：成果预览”并非静态截图”，而是包含组件结构、交互逻辑、状态变化和数据可视化的完整页面，直接在会话里展示。

官方放了几个 demo：一个塞进单 HTML 的 3D 场景（城堡、摩天轮、旋转木马、极光，城堡还能变灯光秀）、一个用 three.js 做的 SnowRunner 风格足球游戏（越野卡车在泥地里踢球，带跳跃和加速）、一份意大利主题 PPT、以及一份徽派建筑深度调研报告。做游戏原型、数据网页、Office 文件和交互 Demo 时，成果可以立刻预览、提问、继续迭代，不用自己先搭本地前端环境。

## 改一页 PPT，不用重做整份

交付不是会话的终点。你可以直接选中会话或产物里的任意元素、文本段落、图表、表格区域，用自然语言描述下一步要改什么。选区会限定作用范围，只处理你想改的那部分，不用重新生成整份成果，也不用把任务背景再交代一遍。

每次修改都留版本记录，可以横向比方案，也可以随时回退。

![PPT 局部修改](https://tu.aixq.cc/wp-content/uploads/2026/09/mimo-desktop-07.gif!ys)

这个能力听起来朴素，但它是”玩票”和”真能用”之间的分水岭。生成一次很惊艳不难，难的是第九次微调还愿意用它。

## Smart 调度：把”该选哪个模型”从用户手里拿走

MiMo Desktop 内置「Smart」调度模式，自动评估任务类型、复杂程度、交付要求和执行成本，再匹配执行路径。拆开看是三层：

  1. **任务评估** ：识别属于办公、编程、研究、设计还是混合场景，判断需要多深的推理、多大的工具范围、什么交付标准。
  2. **模型路由** ：在标准模型和旗舰模型之间动态选。日常任务走标准模型，快、便宜；复杂推理、长链路执行和高质量交付走旗舰模型。
  3. **Harness / Agent / Skill 路由** ：按任务类型选办公、代码或研究 Harness/Agent；大任务可以拆给多个 Agent，分别负责调研、规划、执行、复核，过程中自动调用不同 Skill 扩展能力。

![Smart 调度架构](https://tu.aixq.cc/wp-content/uploads/2026/09/mimo-desktop-08.png!ys)

此外还支持多会话协同：按需组成多角色会话团队，多会话之间自动通信协作，每个会话有独立的记忆、工作区和任务状态。

说句我的看法：模型路由本身不算新鲜事，但小米把它下沉到 Harness / Agent / Skill 三层，说明内部是把能力当工程组件拆的——这一点比口号更值得关注。

## 浏览器既是信息入口，也是执行环境

MiMo Desktop 可以自主控制电脑浏览器：打开网页、检索信息、填写表单、提取素材。从浏览器里拿到的信息能直接进当前任务，省掉你自己检索和跨应用搬运的时间。

更有意思的是后半句：生成网页类成果时，它可以在同一条工作流里用浏览器检查关键交互，自动验证成果。相当于给交付物加了一轮自动化验收。

顺带补一个中文通稿没写的细节：小米英文官网上还列了”电脑操控”能力——读屏、跨应用操作键鼠，以及 Record & Replay 一键复用工作流，目前标注为海外版专属。

## 长任务的账：缓存命中率 99%，省在哪

长任务不仅要做得好，还要算得过来。MiMo Desktop 给出三条降本路径：模型路由（不拿旗舰模型干杂活）、局部编辑（改一页不重做整份）、上下文缓存（重复上下文不重复算）。

官方实测数据：同会话缓存命中率最高可达 99%，跨会话最高可达 95%。

## 我的三点判断

第一，桌面 Agent 的评分标准变了。过去比谁答得漂亮，现在比谁能交出可编辑、可局部修改、可回退的成果。小米这次把话挑明了。

第二，这次邀测本质是”用真实任务换反馈”。官方原话是”用真实任务告诉我们：它已经能够完成什么，还有哪些地方需要改进”。限时限量免费、优先开放给 MiMo 开放平台老用户，都是这个逻辑。

第三，真正该盯的是没公布的那些：定价、Mac/Windows 支持范围、长任务的失败率和稳定性。MiMo-X 系列还处在预览测试阶段，能力会随版本变化，现阶段别急着把它压进核心生产流程。
