## 01 Hypit 简单介绍

给你的 AI Agent 装完这个 SKill 。

你可以把一条参考视频交给 Codex 或 Claude Code，再告诉它想怎么改。

比如让它保留原视频的排行榜形式，**把原来盘点的内容换成足球明星、或 AI 科技公司创始人。**

或者把视频中的主要人物替换掉。

再看这个。

基于如下这个参考视频生成新的对话的视频。

生成下面这种新视频，可以沿用播客的双人对话版式，把推广内容换成自己的 App。

也可以把一条中文视频重新制作成其他语言的版本。

AI 会围绕**参考视频重新组织素材。**

不仅仅知识能处理文案，还包括人物画面、配音、逐词字幕、插入素材和动效。

完成之后，用户会得到**一套可以继续修改、再次运行的视频工程。**

下次想换产品或人物，可以沿用已经做好的镜头结构和字幕样式，只修改发生变化的部分。

生成结束以后，这个视频项目仍然可以继续编辑。

> 项目地址：https://github.com/hypit-ai/hypit

Hypit Skill 本身不是视频模型。**它工作原理分为五步。**

Skill 提供制作知识与导演方法，Agent 工具负责理解和编写方案，Hypit 把方案变成可以执行、修改和复用的视频工程。

![](assets/2026-09-23-%E5%BC%80%E6%BA%90AI%E8%A7%86%E9%A2%91%E5%A4%8D%E5%88%BB%E7%A5%9E%E5%99%A8Hypit%E7%88%86%E7%81%AB%EF%BC%9A%E9%97%B2%E9%B1%BC%E5%B7%B2%E6%9C%89%E4%BA%BA%E9%9D%A0%E5%AE%83%E6%9C%88%E5%85%A5%E8%BF%87%E4%B8%87%EF%BC%9F/0546387fb025397a386126f62a60a8ff_MD5.png)

**① 输入素材**

用户提供参考视频、创作要求，以及人物、商品、Logo 等素材。

**② 理解参考视频**

Codex、Claude Code 等 Agent 工具读取 Hypit Skill，分析原片的文案、镜头、字幕、节奏和动效，判断这条视频为什么成立。

**③ 写成视频工作流**

Agent 把分析结果写成可编辑的视频工程。

比较特别的是，字幕、图片和动效可以绑定到台词中的词。以后修改台词，相关画面也能跟着重新调整时间。

**④ 调用服务执行**

Hypit Runtime 根据工作流调用图片生成、视频生成、配音、语音转写和本地渲染等服务。

Skill负责告诉 Agent 怎么制作，Runtime负责真正执行。

这里调用的服务就有说头了，你运行 Skill 的时候**可以托管给Hypit执行或直接用本地工具实现。**

这个是要 Money 的，毕竟 Seedance 这些模型都挺贵的。

但是效果会好很多。

最后同时得到成片和视频工程。下一次可以保留结构，只换人物、产品、台词或语言，继续生成多个版本

## 02 怎么使用

用下面这个命令，丢给 Agent 就能安装 Hypit 了。

> npx skills add hypit-ai/hypit -g

或者直接把开源项目链接丢给AI，让它装就行了。

安装完成后输入 /hypit，然后提供参考视频和修改要求。

AI 会检查电脑里的运行环境，并根据这条视频询问需要使用哪些模型和账户。

如果要生成新的人物、配音或视频片段，还得准备相应的模型服务。

你可以使用项目推荐的托管服务，也可以接入自己的 API 或本地模型。

开始付费生成前，AI 会列出准备使用的服务和预计费用。
