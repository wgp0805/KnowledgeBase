# WorkBuddy大更新，上线浏览器操控能力

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6478181.html  
> **抓取日期**: 2026-10-14  
> **相关性评分**: 1.0

> WorkBuddy 上线浏览器操控能力，Beta 公测，支持 Chrome、Edge 与 QQ 浏览器。它能自己开标签页组执行搜索、下载、去水印，遇到安全验证滑块这类敏感操作则交回给你确认。作者认为这意味着人和浏览器的交互被换成了人与 Agent 的交互。

![](https://image.woshipm.com/2023/04/14/a1ab4bea-da9e-11ed-af94-00163e0b5ff3.png)

WorkBuddy 更新，最新版中上线了一个实用的大功能：

**让 WorkBuddy 控制浏览器。**

![](https://image.woshipm.com/wp-files/sha256/aa/ae/aaae51d2604aa591c76688c1d6ef26599d74972d401b2ae20eeb5dd11fc577b5.png)

目前该功能，**处于 Beta 公测版。**

**支持 Chrome、Edge 和 QQ 3 个浏览器。**

我常用 Chrome。

**点击前往安装，打开 Chrome 插件市场，进行添加。**

![](https://image.woshipm.com/wp-files/sha256/47/f5/47f5aebf6ae617fff3aa10f34d2066ffef3c9a36d268521211c413b7f1e9d6d1.png)

在添加确认弹窗上，可以看到该 WorkBuddy 插件的功能。主要是自动操作浏览器。

![](https://image.woshipm.com/wp-files/sha256/ef/f4/eff425f3d3341140be5c156eeb46933f04a715301d5ed8d88a6e004c7b5019a7.png)

添加成功后，**Chrome 扩展程序中，多了一个 WorkBuddy。**

点击可查看 WorkBuddy **插件的连接状态和活跃会话。**

![](https://image.woshipm.com/wp-files/sha256/92/2b/922b275c6b65a2e1e440e6029e1cd473a95a042fd6350c89c4b23c5d10617ccc.png)

WorkBuddy 客户端中，也显示扩展程序已安装。

![](https://image.woshipm.com/wp-files/sha256/ae/e8/aee80da008394a8ef027c738a998147826e19e0774e2abdad44ab5f34ba8df06.png)

**既然是执行控制浏览器的任务，我先让它：**

> 帮我打开小红书，下载 3 张治愈系的绿色壁纸。

![](https://image.woshipm.com/wp-files/sha256/23/2a/232a55f5d1a1c0fda6c5ae585454e89e6b57303f39f53b51eaa5018aab773e57.png)

**它确实调用了 Browser 工具** ，打开了小红书，输入关键词，进行搜索、查看操作。

![](https://image.woshipm.com/wp-files/sha256/01/12/0112594da7183e1f2f6a7eacd83a7212f87accebd59a85665d6f91b0c5307258.png)

**它新建了一个 WorkBuddy 的标签页组** ，里面自主执行浏览器操作任务，不打扰你当前的浏览器操作。

![](https://image.woshipm.com/wp-files/sha256/4f/af/4faf40a68b5fec1b989fdb6946119251f978ec67dee9e526cd3e83c51714e8c8.png)

页面上，还有一个**小猫抱着一个鼠标箭头的图标** ，在移动，很是可爱。

![](https://image.woshipm.com/wp-files/sha256/0a/bf/0abf39499bf7748cd701e4651aa60dee3e5feca83f02da054c407c85873bcc6f.png)

一会儿后，它完成了任务，自己关闭了 WorkBuddy 标签页组。

**下载的是最高清的版本，并且非常贴心地，帮我把水印去掉了。**

![](https://image.woshipm.com/wp-files/sha256/c7/6a/c76a938ba37987b7bc0c33701d74f2fe5d10d63df8214e9a330646db19b7ecd5.png)

整个操作过程，几分钟完成，完成质量很高。

**可以看到，这种相对简单，没有什么人工验证的网页操作任务。**

**WorkBuddy 会非常轻松地完成。**

接下来，想让它帮我做个复杂的操作。

**让它帮我注册微信小程序。**

![](https://image.woshipm.com/wp-files/sha256/4f/6f/4f6f46abbcb945b493e2e3806138946e868d1c864010a25793476fd493029091.png)

很熟练地打开了微信和小程序页面。

![](https://image.woshipm.com/wp-files/sha256/3a/5e/3a5ee6c8a16da5c7a155d19fbb9163b9c8dfabf570051811d9ddf26638406fec.png)

因为涉及到各种需要我做决定的地方，它会问我。

![](https://image.woshipm.com/wp-files/sha256/8d/49/8d4974b864772189bd3eee1cd0e09ae8c4188a190dd16522333d10a354bcd885.png)  
![](https://image.woshipm.com/wp-files/sha256/f7/06/f706f0598af1f433fd1ed24dd8ead2b24416155dd08c027a1da49b9dae3b52cc.png)

我确定后，它继续执行。

因为注册小程序，涉及复杂的验证过程，**WorkBuddy 会尽可能多地自动完成它能完成的工作。**

**需要我确认的，还给了我一个清单。**

它自己能做、需要我做的，整理得明明白白的。

![](https://image.woshipm.com/wp-files/sha256/b4/a8/b4a8223a2308d3aa0b4631d583824f9440509af0358959987bf4dfe746d38470.png)

比如这个安全验证滑块，就是防脚本、防机器人的，它做不了。提示：等我拖。

![](https://image.woshipm.com/wp-files/sha256/7c/d9/7cd93e0dbd4111b6a4940b8a0877f27f3d4d8949c62c36f1e4626508e9c9de21.png)

我们看到，这种涉及比较多信息提供、安全验证的操作。

需要人和 Agent 共同来完成，会来回进行信息确认。

**整个操作过程比较费劲，感觉还不如自己来操作。**

这也正常，做决策和敏感操作，本就需要留给人来执行。

**但是，我们在这里，看到了 WorkBuddy 的新能力。**

**自主去通过浏览器执行一些繁琐的任务。**

比如信息搜索，软件下载，截图，填写表单等。

就算是一些复杂的操作，WorkBuddy 通过浏览器没法自动去完成所有操作。

但是，你不需要去浏览器做各个操作，不需要查看和连接浏览器中的各种信息。

只需要在 WorkBuddy 中确认和提供信息即可。

**把你和浏览器的交互，变成了 WorkBuddy 这种 Agent 的交互。**

并且，随着 Agent 模拟人操作网页的能力越来越强。

越来越多的任务，都可由 Agent 来代劳。

这次 WorkBuddy 上线浏览器操控能力。

**不是让 Agent 多了一个工具。**

**而是让你的工作、生活少了一道门槛。**
