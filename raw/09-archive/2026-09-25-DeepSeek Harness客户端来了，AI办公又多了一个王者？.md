# DeepSeek Harness客户端来了，AI办公又多了一个王者？

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6470242.html  
> **抓取日期**: 2026-09-25  
> **相关性评分**: 1.0

DeepSeek 终于有自己的官方客户端了。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-01-888f6e2c8a.png!ys)

而且这次做得还挺大。

Windows、Mac 都可以直接下载安装，能读本地文件、联网搜索、跑终端，还能让多个 Agent 一起干活。

如果非要给它找一个普通用户容易理解的名字，我觉得可以叫：

**DeepSeek 的“AI 办公版”。**

它的正式名字叫 **DeepSeek Harness** 。

目前 DeepSeek 官方还没有正式官宣，但安装包已经开始在社区流传。我第一时间下载安装，又把整个流程跑了一遍。

先说结论：

**确实能用，而且已经不是一个简单的“DeepSeek桌面壳子”了。**

比如今天正好是中秋节，我随手让它写了一段祝福：

> 海上生明月，天涯共此时。无论相隔多远，愿这一轮圆月捎去我最真挚的祝福：中秋安康，万事顺遂，所求皆如愿。

这段就是刚刚用 **DeepSeek Harness** 生成的。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-02-92a38ae3a3.png!ys)

嗯，熟悉的 AI 味儿已经扑面而来了。

不过写祝福当然不是重点。

真正有意思的是，打开 Harness 以后，你可以直接指定一个电脑里的文件夹作为工作区，然后把任务交给它。

读写本地文件、网页搜索、终端操作、多智能体协作，这些能力都被塞进了一个桌面客户端里。

DeepSeek 这次明显是想把自己从“聊天框”里放出来。

下面直接带大家跑一遍。

## 01.DeepSeek终于有桌面客户端了

01.DeepSeek终于有桌面客户端了

目前 Harness 已经有 **Windows 和 macOS** 版本，Linux 暂时还没有。

整个安装包不算大，下载安装过程也比较顺畅。

以前用 DeepSeek，大部分人的习惯还是打开网页或者 App，然后问一句、答一句。

Harness 的逻辑明显不一样。

它启动后第一件事，就是让你选择一个本地文件夹作为工作区。

这就已经有点像最近很火的 WorkBuddy、豆包工作这类桌面 AI 产品了：AI 不光跟你聊天，还要开始碰你的文件和工作环境。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-03-4370470374.png!ys)

### 02 登录账号，然后把文件夹交给它

第一次打开 Harness，可以直接登录自己的 DeepSeek 账号，也可以填写 API Key。

我用的是最简单的方式：

**直接登录 DeepSeek 账号。**

登录之后，它会让你选择本地工作目录。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-04-3f449cddca.png!ys)

比如你有一个项目资料文件夹，里面放着 Word、Excel、代码、图片和各种资料，就可以直接把这个目录交给 Harness。

后续你给它下任务，它就可以围绕这个工作区处理文件。

这也是我觉得它更像“AI 办公版”的地方。

以前你用 DeepSeek，经常得把文件一份份上传。

现在它开始直接进入你的电脑工作目录了。

这个变化看起来不大，但产品形态其实已经完全不同。

### 03 第一次启动，还会问你拿它干什么

第一次进入 Harness，它还会先做一轮初始化配置。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-05-a421882579.png!ys)

其中一个问题是：

**你希望 DeepSeek Harness 帮你做什么？**

目前可以选择类似：

  * 办公与创作
  * 代码与开发



后面还会继续让你选择，希望看到多少工作过程。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-06-6bbeea7f5d.png!ys)

比如只看最终结果、查看关键步骤，或者把整个执行过程都展示出来。

这套初始化流程做得已经挺像一款成熟的桌面 AI 软件了。

开发者可以把过程全部打开，方便调试；普通用户则可以尽量少看 AI 在背后折腾什么。

这其实也是 Agent 产品现在普遍会遇到的一个问题：

**AI 干活的时候，到底该给用户看多少？**

看少了，用户不知道它到底干了什么；看多了，又像盯着程序员终端刷日志。

Harness 干脆把选择权交给用户。

### 04 一上来就准备了四种模式

目前 Harness 里面一共有四种工作模式：

**标准模式、PTC 模式、极简模式、创造模式。**

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-07-f3393d0af8.png!ys)

**普通用户第一次用，直接选择****标准模式** 就够了。

PTC 更适合批量任务；极简模式会更接近命令行体验；创造模式则可以自己编写插件、组合各种能力。

Harness 里面一直在强调一句话：

**Everything is a Plugin。**

翻译成人话就是：

**它希望几乎所有能力都可以继续往里装。**

这也决定了 Harness 后面会不会好用，很大程度上要看它的插件生态能长成什么样。

## 05.DeepSeek已经往里面塞了不少东西

05.DeepSeek已经往里面塞了不少东西

我看了一下，目前 Harness 里面已经可以看到不少插件：

智能体团队、语音输入、终端、Agent Loop、Subagent、网页搜索……

其中我比较感兴趣的是 **智能体团队** 。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-08-c7cbd74018.png!ys)

它允许你同时创建多个 Agent，然后让它们一起完成任务，还可以进行一些简单的角色配置。

这已经非常接近现在桌面 Agent 的主流玩法了。

比如一个 Agent 查资料，一个 Agent 整理数据，一个 Agent 写文档，最后再让主 Agent 汇总。

过去这些东西更多出现在开发者框架里。

现在 DeepSeek 直接把它做成了桌面客户端里的一个功能。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-09-cd7beb2b32.png!ys)

所以从产品定位来看，Harness 显然不只是为了让大家在电脑上“更方便地聊 DeepSeek”。

**它想接管一部分真正的电脑工作。**

### 06 实测时，我还踩了一个坑

配置完成以后，我直接给 Harness 下了一个任务。

结果出现了一个挺尴尬的情况：

**任务怎么都不执行。**

一开始我还以为自己遇到了新版 Bug，折腾了一圈才发现，问题出在账号模式。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/DeepSeekAI-10-20e25ecab5.png!ys)

Harness 这里有两种使用方式：

登录 DeepSeek 账号，就选 **账号模式** ；

使用自己的 API Key，就选 **API 模式** 。

我前面是直接登录 DeepSeek 账号，所以这里也必须切到账号模式。

改完之后重新执行，任务马上就正常跑起来了。

所以如果大家安装以后遇到一种情况：

**能输入任务，但就是不干活。**

先别急着卸载。

看看这里是不是选错了。

毕竟现在还是 nightly 版本，很多细节明显还在打磨。

## 07.DeepSeek这次，终于开始碰“办公”了

07.DeepSeek这次，终于开始碰“办公”了

最后再提醒一句：

**DeepSeek 目前还没有正式官宣 Harness。**

社区目前已经对相关安装包做过核验，macOS 版本带有 DeepSeek 公司主体的开发者签名，也通过了 Apple 公证，下载源和版本信息同样指向官方体系。

再加上目前已经可以正常登录 DeepSeek 账号、调用相关能力，基本可以确认这就是 DeepSeek 自己的东西。

不过它现在走的仍然是 **nightly 通道** 。

也就是说，版本更新很快，Bug 大概率也不会少。

但比 Bug 更值得关注的，是 DeepSeek 产品方向终于出现了一个很明显的变化。

过去大家提起 DeepSeek，第一反应还是：

**模型、网页、App、API。**

现在它开始进入电脑本地文件夹，开始读文件、操作终端、搜索网页、组织多个 Agent 协作。

这个路线就和 WorkBuddy、豆包工作、千问办公这些产品碰上了。

区别在于，DeepSeek 手里本来就有一个巨大的模型品牌和用户基础。

所以 Harness 一旦正式推向普通用户，AI 办公这个赛道又要多一个重量级玩家。

至于现在这个版本嘛……

也挺符合 DeepSeek 一贯的节奏。

官方还没开发布会，用户已经下载了；

教程已经有人写了；

Bug 也有人踩完了；

甚至连“DeepSeek 办公版”这个名字，我们都先替它想好了。
