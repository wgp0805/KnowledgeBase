**项目开发用到的SKILL**

**1. 后端架构 Skill** `ai-drama-backend-architect` 用于设计服务拆分、目录结构、模块边界、接口规范。 覆盖：用户、项目、剧本、分镜、生成任务、素材库、计费、审核。

**2. 数据库建模 Skill** `ai-drama-db-modeler` 用于设计 PostgreSQL 表、索引、迁移、关系。 重点表：users、projects、episodes、scenes、characters、assets、generation_jobs、job_events、credits、exports。

**3. 任务队列 Skill** `ai-generation-job-queue` 这是最关键的开发 Skill。AI 漫剧平台不是普通 CRUD，核心是异步任务：图片生成、视频生成、配音、字幕、转码、失败重试、回调处理。

**4. 第三方模型接入 Skill** `ai-provider-integration` 用于封装 OpenArt、Runway、HeyGen、OpenAI、Replicate 等接口。 重点统一：请求参数、回调、状态查询、错误处理、费用记录、超时重试。

**5. API 测试 Skill** `backend-api-test-suite` 用于自动生成接口测试、集成测试、mock provider、任务状态流测试。 特别要测：任务创建、回调幂等、扣费回滚、失败重试。

**6. 安全权限 Skill** `saas-auth-rbac-security` 用于登录、团队空间、权限、素材隔离、管理员审核、API Token。 这个平台会涉及用户私有素材，权限不能乱。

**7. 前端设计 Skill  ** `frontend-design  用于从零生成有明确视觉风格的生产级前端界面，覆盖视觉风格、布局排版、配色、动效交互与设计细节。`

# AI 漫剧创作平台 · 技术方案

面向短剧编剧 / MCN / 个人创作者的 AI 漫剧生产工具 · 九阶段生成 + 无限画布 + 多模型网关 + 代理分销

前端：Vue 3 + Vite + TypeScript后端：Python FastAPI数据库：PostgreSQL + Redis

## 一、项目概述

AI 漫剧创作平台定位"**编剧的 AI 制片助手**"。用户输入一个故事主题，系统通过**九阶段流水线**自动生成从意图、大纲、小说、剧本、资产、分镜到视频的完整漫剧内容；同时提供无限画布做节点式编排、资产库管理素材、模型市场统一接入多家 AI 服务，并以代理分销和充值计费作为商业闭环。

## 三、技术栈选型与项目创新点

### 3.1 项目技术栈

### 3.2 项目创新点

- 九阶段漫剧生成流水线： 从故事主题到视频分镜分 9 个阶段，每阶段独立可编辑、可重生成，草稿自动保存。用户不用从零写剧本，填一个主题就能拿到完整分镜脚本。
- 多模型统一网关： 文本模型（通义/DeepSeek）、生图模型（即梦/通义万相）、生视频模型（可灵）统一封装在一个网关里，按类别路由、失败自动重试、统一计量 token 成本，业务层不直连任何模型 SDK。
- 无限画布节点编排： 基于 Vue Flow 实现节点连线、拖拽、缩放、框选，角色/场景/道具/剧情四类节点，整段 JSON 存库，支持保存恢复，编剧可以像画脑图一样编排漫剧结构。
- 原子扣费 + 异步任务： 生成任务先原子扣减余额（数据库行锁防超扣），再丢 Celery 队列异步执行，失败自动退款。前端轮询任务状态，不阻塞用户操作。
- 代理分销体系： 用户可申请成为代理，审核通过后获得专属邀请码，邀请新用户消费后按比例分润，形成自增长的分销网络。
- PostgreSQL JSONB 混合存储： 九阶段草稿和画布节点都是半结构化数据，用 JSONB 字段存，不用改表结构，还能建索引。单机 2C4G 即可跑通 MVP。

## 六、数据库设计（核心表）

## 九、安全与合规

### 9.1 技术安全

| 维度 | 措施 |
| --- | --- |
| 通信 | 全站 HTTPS；JWT 2 小时过期+刷新；接口限流（Redis 令牌桶，60 次/分） |
| 数据 | 手机号加密存储；日志脱敏；PG 每日全量备份到 OSS |
| 越权 | 用户只能访问自己的 projects/assets/jobs；管理后台接口加 require_admin 依赖 |
| 资金 | 余额原子扣减；支付回调验签+order_no 幂等；日终对账；失败自动退款 |
| 模型安全 | API 密钥存后端配置，绝不暴露前端；调用日志审计；模型可远程启停 |

### 9.2 合规硬性要求

**必须做：**

- 域名 ICP 备案
- 上线用户协议、隐私政策、免责声明
- AI 生成内容标注"AI 生成"
- 漫剧内容需符合广电总局短剧审核要求
- 禁止生成违法违规内容

**待决项：**

- AI 生成内容版权归属：需在用户协议中明确
- 充值定价是建议价，上线后 A/B 测试调优
- 代理分润比例：需法务审核
