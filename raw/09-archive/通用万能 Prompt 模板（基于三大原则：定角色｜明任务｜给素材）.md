# 使用最佳实践（避坑要点）

1. 【】占位符号一定要替换，不要保留括号直接发送；
2. **参考上下文素材是重中之重**：素材尽可能完整，素材缺失极易出现 AI 幻觉；
3. 如果模型第一次输出不符合预期：优先完善「约束条件」，而不是反复重复需求；
4. 复杂任务可以拆分，不要把几十条需求全部塞进一条 Prompt；
5. 使用 pi-agent 这类 Agent 框架时，可以直接将整套模板作为系统提示词注入框架。
