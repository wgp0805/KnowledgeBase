# 把 DeepSeek Harness 做成一个正经的安卓 App，在本机直接跑，练 Root 都不用！

现在在安卓手机上跑 AI agent 的路子其实挺多了，Termux 里自己搭环境的，各种包装出来的客户端，我前前后后都见过一些。

这几天刷到一个新项目，DSH Go，10 月 25 号才建的仓库，五天之后就冲上了 Trendshift 全语言日榜第一。它干的事是把 DeepSeek Harness 做成一个正经的安卓 App，手机上本机能跑，还能遥控电脑，现在已经8千多 Star 了。

也算是背靠 DeepSeek Harness 生态，用户量大，比其他的手机端 Agent 更火一些。当然，这个开源项目做的也确实挺优秀，今天给大家分享一下这个项目。

# 先简单介绍

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/8c4b0c3d5ca1a364ac294dcaaf6b0b2f_MD5.jpg)

先说下 DSH Go 是个什么东西。它就是一个安卓 App，作用是把 agent 装进手机里，在本机直接跑，不用 Root，也不用你自己折腾环境。除了本机跑，它还能连上你电脑里跑着的任务，人在外面也能用手机接着聊。

UI界面是拿 Flutter 写的，代码完全开源。要说明一下，这不是 DeepSeek 官方出的，两边没有关联。模型走的是你自己配置的提供方，所以别误会，本机运行不代表模型离线，网还是得连的。

# 有哪些能力

### 所有环境全搞定，APP开箱即用

这个 App 里面直接内置了 Ubuntu、Node.js 还有 DSH 的运行环境。安装好，打开就能用，不用 Root，也不用再装个 Termux 之类的。官方建议留 1GB 左右的空间，启动默认走的是 PRoot 兼容模式，开发者选项里还有个直接启动的开关，默认关着，一般人不用管。

### README 里放了个演示，让它把这个月的花销整理成表格和图。它就自己去读 CSV 账单，跑 python3 脚本，最后交回来一个 xlsx 表格加一张趋势图。截图上有记录，整个花了 23 秒，跑了 4 步，用了 3.4 万 tokens。

账单汇总这个活本身不算重，但读文件、跑脚本、再把做好的表格交回来，这一整套都是在手机里干完的，中间压根不用碰电脑。以前想在安卓上做同样的事，还得自己一点点折腾环境，这一点挺好的。

### 遥控电脑

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/c994998901b810abe7a8a7251c7c3da7_MD5.jpg)

写代码这种活，大部分时候还是在电脑上干的。所以 DSH Go 还有另一个用法，给电脑上的 DSH 当遥控器。点一下对话顶部的「切换主机」，App 里显示的就变成你电脑上那份 DSH 了，会话和工作区全都是远端那边的。

连接方式有两种：在同一个局域网里的话，走 SSH 直连，电脑上装好 DSH 就行。不在一个网络，就用 DSHarness Remote，这是一个远程插件，不用自己配网络，连接是端到端加密的。第一次连的时候会让你核对身份指纹，跟主机上显示的对得上再点信任。

### 远程模式现在还有一些限制，比如只能发图片附件，App 里面打不开网页版，插件只能开关不能细管，DS Bot 和对话日志导出也用不了。

这样电脑上跑着的任务，人不在电脑跟前也能管了，看一眼进度，或者补一句要求让它改个方向，手机上都能办。不过话说回来，真想拿手机从零写一个项目，我还是劝你用电脑。

### 生成到一半，能插话

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/fcf97ab4d795532976cc0eaa4e5d2e09_MD5.jpg)

用 agent 的时候经常碰到这种情况，它跑到一半，你突然想起来还有个要求没说。在 DSH Go 里，生成过程中直接发消息就算插话，它手上的活不停，下一步就会把你这条考虑进去。长按发送键还有别的选择，可以「中断并发送」，也可以先「排队」，排队的消息随时可以点「立即发送」提前发出去。

任务做完以后，中间的思考过程和工具调用会自动折成一行，屏幕上只留下结果，想看过程展开就行。这样不用干等它跑完再补话，也不用把跑了一半的任务推翻重来，这个设计省时间，也省得任务重跑。

界面这块，原生界面和网页版可以一键切换，切过去还是同一段对话。回复可以一键做成分享卡，整段对话也能生成一个回放链接，这个链接是端到端加密的，密钥就在链接里，服务器那边看不到内容。不过分享之前记得自己先看一眼预览，拿到完整链接的人是能读能存的。

### 手机操控的权限和规矩

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/d037a117af7e411217ddc00776ee1f6c_MD5.jpg)

因为 DSH 就跑在手机里，所以它还能直接操作你这台手机。打开「手机操控」以后，它能读屏幕、帮你点按、输入文字，像建日程、定闹钟这种事，你说一句它就去了，实现上用的是安卓的无障碍权限。

确认方式分了三档：

- 默认是「每次都询问」，进新 App、发送、删除、付款这些动作之前都会先问你。
- 松一点可以选「本任务免确认」，每轮问一次。
- 最松的是「始终免确认」，基本就放手了。

应用也分了层，支付、银行、券商这类 App 默认是不碰的，微信默认每一步都要确认。另外还有个「解除限制」，里面列着系统设置、密码和验证码、DSH Go 自身这三项，默认全关，想开任何一项都得长按确认。

建议使用的时候，支付、银行、微信这类就别去解除限制了，AI 有可能被网页、消息或者文件里的内容误导。开了手机操控之后，屏幕上的文字会发给你选的模型，如果你的模型能看图，还可能收到截图。

### 官方的原话是，不建议在存有支付或银行信息的设备上解除限制。

我自己的话，会把默认档位留着，不会图省事切到「始终免确认」。能读屏的 agent，提示注入就是个实实在在的威胁，网页上藏一句恶意指令，对它一样有效。

另外还有个「不打扰模式」，Android 14 以上配合 Shizuku 或者自连 ADB 用，它会在一块你看不见的屏幕上操作，不占你正在用的屏幕，这个门槛高一点，适合重度用户折腾。

### 外观和吉祥物这些边角

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/363eef5f097bf4b80d9f3ba556e9e077_MD5.png)

还有几个小地方我觉得挺加分的。横屏和平板专门重新排了版，侧栏一直常驻，主题色有六套，桌面图标四款，功能图标还有三种风格可以挑。界面中英文都有，默认跟着系统走。

吉祥物是两只像素风的，小鲸鱼 Deepy 和鲸娘，干活的时候在那敲代码，做完了给你翻个空翻，等你确认的时候会举手，打开「App 外显示」它们还会跟到桌面上。桌宠这东西我觉得没啥用，但是很多软件做说明还是有市场的，所以也说一嘴。这玩意可以关掉的，觉得没用设置里面关掉就好。

# 快速开始

想省事的话直接安装包，去 GitHub Releases 拿 APK，一般手机选 arm64 那个包，装完配一下模型和凭据，就能开始聊了。系统是 Android 8.0 以上就行，安装包接近 200MB，个头不小，因为里面塞了一整套运行环境。

![](assets/2026-11-06%20-%20%E6%8A%8A%20DeepSeek%20Harness%20%E5%81%9A%E6%88%90%E4%B8%80%E4%B8%AA%E6%AD%A3%E7%BB%8F%E7%9A%84%E5%AE%89%E5%8D%93%20App%EF%BC%8C%E5%9C%A8%E6%9C%AC%E6%9C%BA%E7%9B%B4%E6%8E%A5%E8%B7%91%EF%BC%8C%E7%BB%83%20Root%20%E9%83%BD%E4%B8%8D%E7%94%A8%EF%BC%81/f9819667d35b91921f43e220094ca346_MD5.png)

装完用起来之后，国产 ROM 的省电策略会拦后台，DSH Go 发现被拦会提醒你，还能直接跳到对应的放行设置，vivo、小米、华为、荣耀、OPPO 这些都有。项目评论区里已经有人踩过坑了，切出去回个微信，回来发现任务断在那儿。

### 还有个小提醒，「发送匿名使用统计」默认是开着的，官方说不包含账号、API Key、对话内容和主机地址，介意的话去设置里的「隐私与分享」关掉就行。

不过话说回来，这是个跑在手机上的 agent，能读文件、跑命令，开了手机操控还能替你点屏幕，有人对安全性不放心，这很正常。反正代码都在 GitHub 上放着，不放心的可以把仓库拉下来，丢给 AI 帮你审一遍，有风险的地方让AI帮重构一下，然后直接源码部署重新打包也可以。

仓库里有现成的工具链脚本，找一台 Linux x86_64 的机器，跑几条命令就行：

```
git clone https://github.com/ccch1mneyyy/dsh-go.git
cd dsh-go

bash tooling/setup-toolchain.sh
source tooling/env.sh

bash runtime/build-runtime.sh arm64-v8a
DSH_BETA_TOKEN_FILE= bash tooling/build-apk.sh -f arm64
```

工具链脚本会帮你把 JDK 17、Flutter 和 Android SDK 都装好，编出来的包在  `app/build/app/outputs/flutter-apk/`  下面。

有一点要注意，自己编的包默认是 debug 签名，跟官方包的签名不一样，不能直接覆盖安装，想保留数据的话装到测试设备上。更细的说明在仓库 README 的「从源码构建」那节，模拟器用的 x86_64 包怎么编也写了。

# 我的看法

**先说生态这块。**

DSH 开源之后，周边的项目冒得特别快，而且比较容易出爆款开源项目。终端里有 dsh-TUI，跟 DSH Go 是同一个作者，像素鲸鱼最早就是从那儿来的，还被 DSH 官方公众号收录过。远程连接有 DSHarness Remote。

插件都有专门的导航站了，然后吉祥物清一色全是鲸鱼，Deepy、鲸娘，打开哪个项目都能看到鱼。玩笑归玩笑，DeepSeek Harness 确实有成长起来的势头了。

**再说说 DSH Go 带来的方便。**

我觉得最大的一点是，任务不用一直绑在电脑前了。电脑上跑着的活，人出门了拿手机看一眼进度，顺手补一句新要求，都行了。轻一点的活，理个账单、处理个文件什么的，手机上直接就办了，不用等回到电脑前。现在安卓上能跑 agent 的软件也不少了，DSH Go 不一样的地方在于，它把本机运行和遥控电脑放进了同一个 App，还接上了现成的 DeepSeek Harness 周边生态。

它的限制也挺清楚的，手机的性能、散热、后台这些都摆在那儿，本机跑适合轻任务和应急，正经开发还是得靠电脑。远程模式目前的限制也不少，光是附件只能发图片这一条，就劝退一部分重度用法了。
