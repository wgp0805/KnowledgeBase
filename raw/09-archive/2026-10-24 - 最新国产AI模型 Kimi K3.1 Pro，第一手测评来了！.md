# 一、Kimi K3.1 Pro 是什么？

## 1、出身：3 万亿参数的开源旗舰

先说块头。这里要写清口径：K3.1 Pro 的 **3 万亿是总参数**（MoE 混合专家架构），是目前全球最大的开源权重模型。注意，不是每次干活都动用全部参数。

3 万亿听着唬人，但 MoE 架构的特点是每次只激活其中一小部分参数，所以实际运行成本远低于同等规模的传统模型——这也是它敢卖低价的原因。

配套的硬参数：

- 上下文长度 100 万 token ——一口气读完几十万行代码的仓库没问题
- 原生多模态 ，支持图像理解
- 开源权重 ，有卡的大佬可以自己部署

官方这次主打的方向很明确：**编程、3D 创作、金融研究**。小灰后面的两个实测案例（3D 游戏 + 复杂 2D 游戏），正好就撞在「编程 + 游戏开发」这条主线上。

参数和定位聊完，接下来是大家最关心的两件事：**怎么用、多少钱**。

## 2、价格和用法

价格方面，API 定价是输入每百万 token 2 美元、输出每百万 token 10 美元。

作为对比，GPT-6 Astra 的 API 输出是每百万 token 50 美元——整整五倍。也就是说同样跑一个编程任务，Kimi 的账单大约是 Astra 的五分之一。

普通用户最简单的用法：Kimi Code 有专门的客户端，直接去下一个装上（Mac、Windows 都有），打开后在模型下拉里选择「K3.1 Pro」即可。下面这张图可以更直观地看到，下拉里 K3.1 Pro 已经上线，还能选思考强度（Low / High / Max）：

![](assets/2026-10-24%20-%20%E6%9C%80%E6%96%B0%E5%9B%BD%E4%BA%A7AI%E6%A8%A1%E5%9E%8B%20Kimi%20K3.1%20Pro%EF%BC%8C%E7%AC%AC%E4%B8%80%E6%89%8B%E6%B5%8B%E8%AF%84%E6%9D%A5%E4%BA%86%EF%BC%81/d0710b6cdfd90e1e92d80baacdb84517_MD5.png)

小灰后面的实测，用的就是图里这套配置：**K3.1 Pro + 思考强度 High**。

开发者可以走官方 API，或者把开源权重部署在自己的机器上。

基本情况就这些。接下来的问题是：它到底有多强？先看官方自己交的成绩单，再看第三方机构买不买账。

# 二、跑分成绩：两个「全场第二」，含金量都不低

## 1、官方跑分：编程和幻觉，都只差一步登顶

发布当天的技术博客里，月之暗面放出了几张跑分表。小灰挑两张最硬的说。

第一张是编程。官方内部的 xdev-bench-hard（模拟真实开发场景的困难任务，pass@3 口径——就是每个任务给 3 次机会，解出就算过）：K3.1 Pro 平均成功率 **64.5%**，全场第二，仅次于 GPT-5.6 Sol（77.8%，还是第三方评测口径）；超过 DeepSeek V4.1 Flash 的 57.1% 和 GLM 5.3 的 34.9%；最夸张的是对比上一代——K3 只有 15.9%，这次直接翻了好几倍：

![](assets/2026-10-24%20-%20%E6%9C%80%E6%96%B0%E5%9B%BD%E4%BA%A7AI%E6%A8%A1%E5%9E%8B%20Kimi%20K3.1%20Pro%EF%BC%8C%E7%AC%AC%E4%B8%80%E6%89%8B%E6%B5%8B%E8%AF%84%E6%9D%A5%E4%BA%86%EF%BC%81/6417c4e50fb0a880aa085e0c65856e2e_MD5.png)

表里还有个有意思的细节：那个「没做网络安全风险削减的内部版本」能跑到 71.4%，公开版为了安全砍掉了一截分数——不是做不到，是主动收着。

第二张是幻觉测试（Hallu Bench，数值越低越好，衡量「瞎编率」）：不带工具时 K3.1 Pro 是 5.4，带工具的困难集是 8.3，**两项都排第二，仅输 GPT-6 Astra，比 Claude Opus 5.5 低了一大截**（Opus 在带工具困难集上是 15.0）：

![](assets/2026-10-24%20-%20%E6%9C%80%E6%96%B0%E5%9B%BD%E4%BA%A7AI%E6%A8%A1%E5%9E%8B%20Kimi%20K3.1%20Pro%EF%BC%8C%E7%AC%AC%E4%B8%80%E6%89%8B%E6%B5%8B%E8%AF%84%E6%9D%A5%E4%BA%86%EF%BC%81/94cbe4154065fc91e12ac0505bc61fd3_MD5.png)

当然，官方跑分大家都懂，自家人评自家人，先看看就好。那第三方机构怎么说？

## 2、第三方实测：智能指数第四，开源第一

第三方机构 Artificial Analysis 的独立测试更有参考价值：K3.1 Pro 的综合智能指数排到了**全场第四**，在所有开源权重模型里排第一——也就是说，排它前面的只剩闭源旗舰了。

一句话概括第三方的结论：**开源模型第一次摸到了闭源旗舰的边。**

分数是别人的，体验是自己的。接下来小灰用两个真实案例，让 K3.1 Pro 和 GPT-6 Astra 同题硬刚，看看这个「开源第一」在日常使用里到底是什么成色。

# 三、实测案例一：做一个 3D 版「跳一跳」

第一个案例，小灰选的是国民级小游戏「跳一跳」——按住蓄力、松开起跳，跳到下一个方块上得分。选它的原因很简单：所有人都玩过，蓄力手感对不对、跳跃判定准不准、3D 画面好不好看，一试便知，不用懂代码也能当考官。

提示词如下：

```
请用一个单独的 HTML 文件，为我开发一个「3D 跳一跳」网页小游戏。要求：1）按住鼠标（或空格键）蓄力、松开起跳，跳到下一个方块上得分，没跳上去就掉下去游戏结束；2）蓄力时角色有下蹲压缩动画，跳跃是平滑的抛物线，落地有轻微弹跳感；3）连续跳到方块正中心有连击加分，得分实时显示，游戏结束有结算界面和最高分记录；4）用 Three.js 实现 3D 场景，有柔和的光影、干净的配色，方块随机生成不同距离和形状；5）镜头跟随角色平滑移动；6）所有 CSS 和 JS 都写在这一个 HTML 文件里，可以直接在浏览器打开玩；7）不用过多解释，直接做出来让我玩。
```

两边的设置：Kimi 侧走 Kimi Code，选 K3.1 Pro、思考强度 High；Astra 侧走 ChatGPT 的 Codex 入口，选 GPT-6 Astra、推理强度「高」——两边都是各自官方 Agent 工具的默认高档位，口径对等。

设置就绪，同一条提示词两边同时开跑。先看 Kimi 的表现。

## Kimi K3.1 Pro 的跳一跳

小灰把 prompt 发到 Kimi Code 后，这一等就是**大约 10 分钟**——比 Astra 慢了不少，不过看完它的工作过程，你就知道这时间花哪了。

从任务记录里能看到它的工作过程相当讲究：先思考了 16 秒做规划——「固定方向蓄力跳、中心判定连击，加入柔和阴影、落地回弹和本地最高分」，想清楚才开始写文件。

写完它没直接交卷，而是**用本地预览实际跑了几局**，检查中心连击、掉落结算和重新开始。更有意思的是，首轮画面检查后它自己觉得「光照偏亮」，**主动压低曝光、让地面阴影更轻**，再继续验证——会自我审美修正的模型可不多见。下面这张任务记录里能看到它的完整工作过程：

## 案例一小结

|  | Kimi K3.1 Pro | GPT-6 Astra |
| --- | --- | --- |
| 耗时 | 约 10 分钟 | 2 分 3 秒 |

这一轮两边都一次成型、打开即玩，成品质量在一个水准线上，风格各有所爱。真正的差距在**速度**：Astra 快了近 5 倍；但 Kimi 的 10 分钟也没闲着——自己跑局、修光照、适配手机，慢归慢，交付的东西是仔细验过的。

跳一跳只能算热身——毕竟玩法规则一句话就说完了。第二个案例上点难度，看看模型做「系统工程」的能力。

# 四、实测案例二：做一版「植物大战僵尸」

让两个模型各做一版**植物大战僵尸**。

为什么选它？因为它的复杂度够硬：阳光经济、三种植物各司其职、僵尸分波次进攻、种植冷却、输赢判定——这是一个「小型系统工程」，模型逻辑不行直接崩盘。而且这游戏国民度拉满，读者光看画面就知道做对了没有：僵尸走到头算输、向日葵不产阳光就是 bug，零门槛当考官。

提示词如下：

```
请用一个单独的 HTML 文件，为我开发一个简化版「植物大战僵尸」网页游戏。要求：1）5 行草坪网格，僵尸从右侧分波次向左进攻，走到最左则游戏失败；2）至少三种植物：向日葵（定期产出阳光）、豌豆射手（向所在行发射豌豆攻击僵尸）、坚果墙（高血量阻挡僵尸），种植消耗阳光，有冷却时间；3）天上会定时掉落阳光，点击收集；4）僵尸有不同血量，被豌豆击中扣血、倒下消失，消灭所有波次则胜利；5）顶部有阳光数量、当前波次显示，游戏结束有结算界面，可重新开始；6）画面精致可爱，植物和僵尸有攻击、受击、倒下等动画；7）所有 CSS 和 JS 都写在这一个 HTML 文件里，图形全部用代码绘制，不引用外部图片，可以直接在浏览器打开玩；8）不用过多解释，直接做出来让我玩。
```

提示词发出，还是先看 Kimi。

# 五、总结

测完两个案例，小灰对 Kimi K3.1 Pro 的印象可以浓缩成三句话：

- 「直逼闭源旗舰」这话，在游戏开发场景下基本接住了。 一句话要一个 3D 跳一跳、一句话要一版植物大战僵尸，它都一次成型地交了出来——蓄力连击、阳光经济、波次进攻、输赢判定全部正常，全程没有需要返工的 bug。官方跑分编程第二、幻觉第二，第三方智能指数全场第四、开源第一，和小灰的实测体感是对得上的。
- 它比旗舰慢，但慢得有交代。 同样的任务 Astra 两三分钟交卷，Kimi 要约 10 分钟；但这 10 分钟里它在本地预览里真跑了几局、嫌光照偏亮主动调、端口被占用自己换端口，最后还记得适配手机。一个是「快刀斩乱麻」，一个是「慢工出细活」——着急出活选 Astra，让它自己慢慢磨选 Kimi。
- 价格是真正的杀手锏。 API 输出每百万 token 10 美元，只有 Astra 的五分之一，还开源可自部署。能力摸到旗舰的边、账单只有零头——对重度 Agent 用户来说，这就是「随便跑不心疼」的自由。

对号入座的话，小灰的建议是：

| 你的场景 | 推荐 | 理由 |
| --- | --- | --- |
| 游戏 Demo、日常开发、批量 Agent 任务 | Kimi K3.1 Pro | 两个案例一次成型零返工，价格只有旗舰 1/5，开源可自部署 |
| 追求极速交付、任务赶着要 | GPT-6 Astra | 快 3~5 倍，细节丰富，但 API 贵、订阅额度有限 |
| 预算敏感的个人开发者 | Kimi K3.1 Pro | 五分之一的价格，能力同档，客户端选 Highspeed 还能再提速 |
| 企业私有化部署 | Kimi K3.1 Pro | 目前能摸到的最强开源权重，数据不出内网 |

作为国产开源模型，K3.1 Pro 这一代算是把「开源等于二线」的旧印象撕掉了：**旗舰级的编程能力，五分之一的价格，还开放权重。**
