# 豆包连夜”抄作业”，字节版Muse要来了？

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6472100.html  
> **抓取日期**: 2026-09-29  
> **相关性评分**: 1.0

据说豆包的同学们在”抄作业”。

今天上午，新浪科技发了一条独家消息：**豆包从今年4月起就在内部测试一款个人助理方向的探索产品，代号 ”Spell”。** 项目原本由豆包手机助手团队主导，因为豆包手机要发布，一直没对外公开。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-01-22f93f718b.jpg!ys)

最近 Muse 这类海外个人助理产品火了，字节开始着急，计划把 Spell 和豆包产品深度整合，由 Spell 项目组和豆包对话团队一起负责，**“ 预期较快会对外推出”**。

还有一条更有戏剧性的小道消息。据某平台博主susu爆料，中秋期间豆包产品线接到一个加急任务：**快速重构一款对标 Muse 的应用** ，9月27日前完成联调，9月30日前拿出体验版进入内部评审，前后大约6天。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-02-13eebc6d93.jpg!ys)

注：网传爆料，别当成定论

那么问题来了：让字节整个中秋都在赶工的 Muse，到底是什么？它身边又有哪些同类？

## 一、字节在追的，是一个”会干活”的品类

先把这一波”个人 Agent”的几个主角理一遍。它们看上去很像，走的路子却不一样。

**1\. Meta Muse：把 Agent 做成大众消费品**

9月8日，Meta 发布 Muse。定位非常直接：**不陪你聊天，替你办事。**

  * 你给它一个目标，它自己开浏览器、填表、比价、下单、回邮件；
  * 每个用户分到一台专属的云端虚拟机，Meta 叫它 Muse Secure VM。**你关掉 App，它还在后台继续干活** ；
  * 发邮件、付钱这类敏感操作，它会先停下来问你；
  * 入口有独立 App、网页 muse.ai，还有 WhatsApp，跟它说话就像给朋友发消息；
  * 9月17日又出了 Mac 版，能直接在你电脑的邮件、日历、备忘录里操作。



数据非常猛。Sensor Tower 的统计显示，Muse 上线6天下载量就超过90万，到9月21日累计超过250万；另有报道说截至9月24日已超过340万次，一度登顶美国 App Store。从9月8日到现在，Meta 股价涨了两成多，市值多了三千多亿美元。

也有不顺的地方：**亚马逊直接封了 Muse** ，理由是未经授权的 AI 代理访问违反使用条款。同一天，Shopify 宣布和 Meta 合作，让 Agent 可以直接在商家店铺里结账。

一家封，一家迎，这就是 Agent 时代的第一场”入口战”。

**2\. xAI Grok Bot：给每个 AI 同事配一台电脑**

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-03-9aea63d9c8.jpg!ys)

8月12日，比 Muse 早了将近一个月，马斯克的 xAI 上线了 Grok Bot。

它的思路更接近”数字员工”：

  * 每个 Bot 有一台自己常驻云端的电脑，带浏览器、文件和登录状态，7×24 小时在线；
  * 你可以建一群 Bot，让它们在群聊里互相派活、交接；
  * 最有意思的是”教一次就会”：你录屏演示一遍流程，它就把这个流程变成自己的技能，以后自动执行。



Grok Bot 走订阅路线，面向 SuperGrok 和 Cursor 的付费用户，偏工作场景。马斯克说它的增速超过了他们见过的任何产品。但彭博智库的数据很扎心：**Muse 的下载量是 Grok Bot 独立 App 的四倍。**

对消费级 Agent 来说，分发能力才是护城河。

**3\. Manus 2.0 + Cue：给 Agent 发 ”身份证”**

就在昨晚，Manus发布了 2.0 版本。这是它9月1日恢复独立运营后的第一个大版本，距离独立只过了27天。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-04-19acbca817.jpg!ys)

这里有个很戏剧性的背景：Meta 去年年底宣布收购 Manus，后来交易没有完成，Manus 又独立出来。现在它转身就推出了一款个人 Agent 应用，跟 Muse 正面竞争。

这次发布有两个重点：

  * **Manus 2.0 本体** 底层换成了自研 Agent 框架 Cascade。官方给的单项测试数据是 Token 消耗减少23.2%、任务耗时缩短28.2%、运行成本降低32%。桌面端升级为 Manus Studio，定位是”人和 AI 共享的工作空间”，能剪视频、做游戏，人随时可以接手修改。另外还新增了可以长期运行的云电脑，以及由邮件、日历、Slack 消息等事件触发的自动化流程。
  * **Cue** 一个独立的个人 Agent App。它最狠的设计是**给每个 Agent 配上独立的邮箱、电话号码、钱包和电脑** 。Agent 可以在你设定的预算内付款，几个 Agent 还能拉进一个群里分工协作，比如一个查场地、一个做清单、一个写方案。Cue 目前是邀请制抢先体验。



更值得注意的是，Manus 透露**面向国内市场的产品也在筹备，团队正在组建** 。

Muse 的思路是”给你一个管家”，Cue 的思路是”给你一支有身份的小团队”。

**4\. 腾讯LightVela：住在你微信里的Agent**

国内这边，腾讯没开发布会，悄悄上线了 LightVela。

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-05-eaf0e96f10.jpg!ys)

它是腾讯云轻量云团队做的云端 Agent 托管平台，思路非常”腾讯”：

  * 背后跑的是开源智能体 Hermes Agent。你不用自己部署服务器，登录、实名、点创建，十几秒就能拥有一个 7×24 小时在线的 Agent；
  * **扫码就能接入微信、QQ、企业微信、飞书、钉钉，** 它就像通讯录里的一个联系人，不需要另外打开一个 App；
  * 模型可以自己选，DeepSeek、Kimi、千问、MiniMax，甚至豆包都能接；
  * 带长期记忆、定时任务和可安装的技能。



时间线上，LightVela 4月作为独立产品上线，5月限免内测，8月18日转入公测。

说实话，LightVela 目前更像一个”极客友好的托管服务”，离 Muse 那种大众消费品还有距离。但它指明了一个方向：**在国内，Agent 最自然的家可能不是一个新 App，而是微信对话框。**

### 做个对比吧，方便大家直观理解：

![](https://tu.aixq.cc/wp-content/uploads/2026/09/Muse-06-b88d9523d1.jpg!ys)

形态各不相同，底层架构却几乎一样：**常驻云端的独立计算环境，连接你的各种账号，长时间自主执行，在关键节点找你确认。**

这就是字节要追的东西。

## 二、字节的底牌：Spell 不是临时起意

很多人第一反应是”字节又在跟风”。但我觉得这次字节手里其实有牌。

**Spell 的技术底子，来自豆包手机助手。**

时间线是这样的：

  * 2025年12月：豆包手机助手技术预览版首次亮相，搭载在和中兴合作的努比亚工程样机上；
  * 2026年4月：Spell 项目开始内测；
  * 2026年8月底：面向企业办公的”豆包工作”发布；
  * 2026年9月14日：豆包手机助手消费者版本发布，落地努比亚 NaviX Ultra，9月16日开卖；
  * 2026年9月29日：Spell 曝光，确认要做独立的个人助理 App。



看出来了吗？**在 ”让 AI 替你操作手机”这件事上，字节已经练了快一年。** 只是这个能力之前绑定在一台特定的手机上。

Spell 要做的，就是把这套 personal agent 能力从单一机型里解放出来，变成人人都能下载的独立应用。企业端有”豆包工作”，消费端有 Spell，字节的 Agent 产品矩阵到这里基本补齐了。

生态伙伴也在排队了：多点数智的创始人在飞书大会上透露，”多点闪购”即将在豆包上线，已经完成内测。

## 三、但字节的难处，比 Meta 大得多

说完底牌，再说难处。我觉得至少有三道坎。

**坎一：国内的互联网，是一座座 ”围城”**

Muse 能跑起来，很大程度上靠的是美国相对开放的网页生态：Gmail、Google 日历和各种网站都能在浏览器里操作，很多服务也提供连接器。

国内呢？核心服务几乎都在 App 里，彼此之间筑着高墙。你让字节的 Agent 去淘宝下单、在微信里回消息、在美团上订餐，每一步都可能被挡在门外。

亚马逊封 Muse 只是开始。在国内，”你的 Agent 别进我家门”这种戏码只会更常见。

这也是为什么腾讯选择”住进微信”，而不是另开一个门。

**坎二：Agent 会不会革自己的命？**

我认为这是最本质的问题。

虎嗅有篇分析讲得很透：Meta 没有自己的电商交易生态，Muse 帮它从谷歌、亚马逊手里截流用户意图，**对 Meta 来说，增量远大于蚕食** 。

字节不一样。抖音的推荐流、抖音电商、巨量引擎的广告，都是靠”让你多刷、多看”赚钱。一个好的 Agent 恰恰是帮你**省时间** ，直接给你结果。

一个真正好用的个人 Agent，会不会让用户少刷抖音、少看广告？这笔账，字节内部一定算过很多遍。

**坎三：信任，是最贵的门票**

个人 Agent 要干活，就得拿到你的邮箱、账号，甚至支付权限。Muse 在这方面下了很大功夫：独立虚拟机、看不到密码和支付信息、敏感操作前必须确认，还承诺年底推出只有用户自己持有密钥的加密虚拟机。

Manus 的 Cue 走得更远，直接给 Agent 配了钱包，只能在你设定的预算内花钱。**权限给得越多，信任门槛就越高。**

国内用户对”把账号交给 AI”这件事，只会更谨慎。Spell 怎么讲安全这个故事，是我最想看的部分。

## 四、国内战局：大厂、创业公司都下场了

字节不是唯一坐不住的：

  * **阿里千问** 9月22日在云栖大会上宣布加速打造 Personal Agent，依托3亿用户，已经在健康、理财等方向接入个人数据，开放平台申请入驻的伙伴超过1000家。
  * **腾讯** LightVela 已经在微信里跑起来了。资本市场更是直接把腾讯当成”中国版 Muse”的头号受益者，毕竟微信有小程序、有支付，天然是一个闭环。
  * **Manus** 国内版产品和团队正在筹备，和国产模型厂商的合作也在推进。一个从国内走出去、在海外打磨了一年多的 Agent 团队，如果杀回来，不容小觑。
  * **字节** Spell 箭在弦上。



海外那边，OpenAI 也在准备大动作。据 The Information 报道，OpenAI 正在基于开源框架 OpenClaw 做一个内部代号”Codex Bot”的产品，直接对标 Grok Bot 和 Muse。今天正好是 OpenAI 的 DevDay，会不会有新东西，今晚见分晓。

## 五、来自怪哥的几个判断

**1\. 个人 Agent 已经从 ”概念”进入”产品”阶段。**去年大家还在讨论 Agent 能不能用。今年 Muse 用几百万的下载量证明了一件事：普通人愿意排队下载一个替自己干活的 AI。这个需求是真实存在的。

**2\. 国内不会出现 ”中国版 Muse”，会出现”几座围城里的 Agent”。**阿里的 Agent 最懂淘宝和支付宝，腾讯的 Agent 住在微信里，字节的 Agent 大概率离不开抖音和本地生活。短期内，我不太相信会有哪个 Agent 能在国内跨平台畅通无阻地办事。倒是 Manus 这样没有自家”围城”的独立玩家，处境跟当年的 Meta 有点像：没有存量业务要保护，反而敢做真正的”连接者”。

**3\. 字节最大的优势是 ”快”，最大的风险也是”快”。**6天重构一个对标产品，这种执行力很字节。但个人 Agent 这种东西，只要翻一次车，比如替用户下错单、发错消息，伤的就是整个品牌的信任。快是能力，稳才是门槛。

**4\. 真正该关注的指标，不是下载量。** 下载量靠分发就能堆出来。决定个人 Agent 生死的是这几个数：任务完成率、复用率、用户愿意授权多深，以及每完成一个任务要花多少钱。Manus 这次把”成本降低32%”放在发布会最显眼的位置，不是没有原因的。谁先把这几个数跑正，谁才是真正的赢家。

豆包的 Spell 什么时候上线？目前还没有官方时间表。但按这个节奏，我猜不会太久。

等它出来，我会第一时间上手测，到时候再跟大家好好聊聊：**它到底是 Muse 的平替，还是字节自己的新答案。怪哥还是蛮期待的，毕竟是豆姐的铁粉。**
