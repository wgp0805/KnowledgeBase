# 蚂蚁灵光内测新版 Personal Agent：接管钉钉、遥控电脑，一手体验！

> **来源**: 人人都是产品经理  
> **链接**: https://www.woshipm.com/ai/6477455.html  
> **抓取日期**: 2026-10-13  
> **相关性评分**: 1.0

> 新版灵光从生成个人应用转向带长期记忆、能主动推进长程任务的 AI 管家，给每个用户一台 24 小时运行的 Linux 云电脑。作者实测让它接管散落各处的自家 Agent，一句话把电脑上的文件发回来、一句话调用电脑上的 Agent。

![](https://image.woshipm.com/wp-files/sha256/e9/8e/e98e3e4b77149738ac58c8aa485a6383f65b02f4fb02e34d496da61a7d9e4877.png)

九月份，Personal Agent 突然“又”火了。

这个赛道半年前已经热过一次：**当时龙虾刚出来，所有人都在养龙虾，朋友圈、公众号每天都是各种养龙虾。** 但后来许多人部署过龙虾后，没有找到真实的使用场景，龙虾的关注度和使用热度都消散了。

前段时间，几个大厂纷纷宣布停止运营龙虾，也标志着“龙虾”时代正式结束。

但过去一个月，以云端电脑为核心架构的 Personal Agent 开始席卷国内外市场，大厂也纷纷推出自己的 Personal Agent：

国庆前 Meta 的 Muse 拉了一波期待值，紧跟着**蚂蚁旗下的灵光，也开启了新版本内测！**

![](https://image.woshipm.com/wp-files/sha256/ad/4f/ad4fc97b1620984c052ecd7e2c882b3d5552561115867c3fa7c13ac65ad6a3d1.png)

新版灵光 Tab 底下多了一个“我的生活”入口

据悉蚂蚁灵光团队在内部打磨了好几个月：**新版灵光正式从以生成个人应用为主的 Personal Agent，正式升级为带长期记忆、可主动推进任务的全新 Personal Agent。**

前两天，钉钉的 CEO 陈宇森，也在朋友圈里肯定了蚂蚁灵光的效果和方向。我们也第一时间申请了内测体验。

![](https://image.woshipm.com/wp-files/sha256/54/75/5475d5c91a73400f9f3fcec8020b3e6e6f81cc42a86f271f107dadbd69551890.png)

这一篇主要聊聊这个产品，也聊聊我们最近对 Personal Agent 赛道的一些观察（目前灵光并没有对这次新版本做正式发布声明，本篇内容更多是从我们自己的内测体验和观察所做的理解与推测）。

## 01 新版灵光的转向

灵光这次的更新，和之前一代的版本有什么区别呢？

**从目前实测的感受是，灵光新版本开始向真正具备“长期记忆”和“主动推进长程任务”的个人 AI 管家进化。**

以前的 AI 是“你问一句，它答一句”，或者点一下帮你生成一个独立卡片或小应用。但生活里最让人心力交瘁的，往往是那些周期长、变量多、普通人根本盯不住的长程琐事，比如孩子的家校群沟通、全家生活琐碎、跨越数月的长期规划……

新版灵光的核心，正是**把这些长程任务主动托管起来：**

它自带长期的上下文记忆，不用你每次重新交代背景；更会在关键节点到来时，先你一步主动发起提醒、随变化调整，替你省下盯任务的心智负担。

与此同时，**它给 Agent 提供了一套可以在云端运行的 Personal Agent 框架，支持用户自主接入常用的外部 AI 工具，拓宽了执行边界。**

具体来说，它给每个用户分配了一台独立的 Linux 云电脑，24 小时在云端运行，有自己的浏览器。你可以让灵光接入自己常用的 MCP、CLI、各种 Skill，灵光也支持接入第三方工具的 Harness 能力。

这就打开了无穷无尽的“民间野生玩法”：

比如你可以让灵光接入钉钉 CLI，然后帮你接管钉钉里的长任务。

你甚至可以直接让灵光帮你长期自动运行任务，比如处理回复不紧急的消息，自动抓取数据写周报，自动处理家校群里各种消息、打卡、待办，这对打工人和家长来说，简直是救星级别的功能。

**除此之外，它还可以帮你操作你的手机、你的电脑、你的智能家居。** 你甚至还可以让灵光通过 CLI、MCP 连接你的特斯拉、Mac Mini、3D 打印机，甚至可以让灵光直接接管你已有的 Agent。

**新版灵光，更像是一个你所有生活场景的 AI 智能中枢。**

## 02 灵光实测：让它接管我的 Agent

Agent 时代，如果想把 AI 用好，其实有一个核心逻辑：

**你应该把自己的一切数据变成 Agent 的上下文，把自己的一切能力变成 Agent 可以调用的 Skill。**

过去几个月，我也逐渐把自己常用的数据、工具都封装了独立的知识库服务和 Agent：日程安排有专门的 Web 工具，排版有专门负责排版 Agent，把知识库封装成 CLI 工具，各种效率工具也都全面桌面 App 了。

但这些 Agent 一直分散在各处，整体的管理成本非常高：

![](https://image.woshipm.com/wp-files/sha256/2d/f3/2df39acb19f575ac1e1bddc4d3bbe81132b65e05568488a17ed251262ab5d5a0.png)

所以这次，想测试一件事：**让灵光直接来接管我做的这些 Agent。**

怎么接入呢？过程其实比想象的要顺畅。

使用前，我先咨询了它怎么弄，然后按照它给的建议操作了下：

先给自己的服务做了一个页面，起了一个后端，做了一个网页输入框。这部分如果你不太会写代码，可以直接把这段话丢给电脑上的千问办公帮你实现。

然后通过 Claude Code 访问这些服务，灵光再用自己云电脑上的浏览器打开网页，通过发送指令，就可以连接自己的电脑了：

![](https://image.woshipm.com/wp-files/sha256/b6/26/b6266d5aaa2498607bbfed16fac3fab0511c7e26530ff4be3f94ebd81588f6cf.png)

最近深度体验了许多 Personal Agent，说实话，灵光作为一个个人助理的速度体验是最快的：

手机上的各种远程控制助手，由于强依赖图形界面，实际用的时候交互体验上并不丝滑，所以一直没有办法真正摆脱电脑。

但是我的需求其实只是在手机上，想要丝滑的使用电脑的各种 Agent，我发现通过灵光这套方案可以完美的解决问题。

可以一句话把电脑上的文件发我：

![](https://image.woshipm.com/wp-files/sha256/2f/2c/2f2ceb1be58226ad7bed1e57eb267d16e5b12edcc251c5b55f2226f96f8e6e48.jpg)

一句话调用各种电脑上的 Agent：

![](https://image.woshipm.com/wp-files/sha256/93/dd/93dd2c1d2e4597385e0fd7c5c47d532e98c4f9727947a01d634b76b61fc0bd72.png)

说实话，我一直很喜欢灵光这款产品，它背后的产品交互很有说法：

比如 Agent 在执行的时候，你可以清楚的看到当前它在做什么操作；然后刚刚这个任务，只跑了三分钟，任务就执行完了，比桌面上的 Work Agent 跑的都快。

然后整个链路跑通之后，我发现了一个更有意思的玩法：

**除了自己的电脑，你甚至也可以让灵光操作自己的云电脑，比如我也尝试了让它在云电脑里下载了一个 Claude Code，让它作为执行任务的子代理。**

![](https://image.woshipm.com/wp-files/sha256/bf/ef/bfef7f78ea0127189f017afb16b87059259b7845818dfef0ee3b3124ef43f8c9.png)

说实话，当时尝试这个的时候愣了一下：我让它还顺手写了个计算器小程序，打开就能直接用。

![](https://image.woshipm.com/wp-files/sha256/e4/89/e489c370d79bb4443f130fc0d25c8d820e0d3d9de94d2cc1820ebddd8ab9bbbe.png)

**整个过程没有遇到什么卡点，体验一如既往的很好。**

过去的灵光更像一个创意助手，现在的它，更像是一台永远在线的、能自己操作软件和服务的 AI 管家。

**而灵光的云电脑本质上就是一台完整的 Linux 机器，你可以在上面装一些必要的工具。** 这也意味着，它作为一个 Personal Agent 的能力边界，远比一个电脑上运行的普通 Agent 更强。

## 03 Personal Agent 新阶段来了

体验完新版的蚂蚁灵光，我开始意识到：Personal Agent，正在进入一个全新的阶段。

国庆假期，社群里有人过提出了一个尖锐的观点：**Personal Agent 会不会像龙虾一样，火几个月后就销声匿迹？**

这个问题我们内部讨论了下，然后跟观猹上的几位创业者以及几位大厂产品经理交流之后，得出了一个截然相反的判断：并不会，因为阶段不同，在这次新的阶段，Agent 的核心框架、基础设施和专业工具都全了。

我们之前提出过一个关于 Personal Agent 的定义：

Personal Agent = 龙虾（或者任意 Agent Harness 框架） + 各种全新的 Agent 基础设施（浏览器、电脑、邮箱、飞书等） + 各种垂直领域的专业工具（Blender…) .

如果你把 Personal Agent 的发展对应到 Gaterner 曲线，龙虾这个产品对应的阶段，可能正在处于 Personal Agent 的萌芽期和期望膨胀期：**人们都希望自己能有一个无所不能的 AI 管家，帮自己管理好一切。**

![](https://image.woshipm.com/wp-files/sha256/59/29/59294a4e8b5675009dcd01f82a823b3baf201f1d71afa71eecc08f507796c8f1.png)

但显然这个阶段的生态和工具发展，还不能匹配人们的野心：龙虾时代，只有一个驱动 Agent 运行的框架，各种基础设施和专业工具都还在萌芽期。

**这个阶段最大的价值是什么？其实是教育市场，培养核心的开发团队和工具生态。**

而通过使用龙虾，许多人开始第一次尝试使用 Agent。此外，由于龙虾的开源，相当于给开发者提供了早期的用和一个共同的 Harness 环境，人们可以围绕它的生态去造更多的 Skill、MCP、Saas 工具。

**所以等到这些基础生态成熟的时候，Personal Agent 就会开始真正进入新一轮的增长。**

还记得龙虾刚出现的时候，我们编辑部用 Opus 4.6 控制龙虾排版，折合人民币一次就要花几十块钱。普通人部署 Agent 的门槛、配套工具的生态，那时候都远不成熟。

但过去半年，整个行业的底层模型和工具能力开始发生巨大变化：

**首先，是模型能力方面开始溢出，可以完成大部分 Personal Agent 的任务。**

各家大模型的 Coding、视觉理解、浏览器控制、3D 生成这些能力都在持续普遍增强，Kimi 和 Qwen 3.8 跻身全球第一梯队后，大模型可以接管日常 99% 的生活和工作任务。

**其次，最关键的是 Flash 模型的极致性价比，让 Personal Agent 的日常使用成为可能。**

最近各个大模型厂商都推出了自己的 Flash 系列模型， Flash 系列把国产大模型的性价比真正拉满了，整体能力上比半年前强了两个数量级，但整体成本却比半年前降了两个数量级，刚刚提到的排版任务，现在用 Flash 模型不仅完成的更好，而且成本只要几毛钱。

**更重要的是，整个 Agent 生态的土壤已经变了：Personal Agent 开始进入物理世界。**

过去半年，最先开始火的是 AI 浏览器，有了这样的工具，AI 开始访问各种 WEB 应用。随着视觉能力的提升，AI 开始可以调用各种各样的工具。

随后各家厂商纷纷推出了自己的 MCP、Skill、CLI 工具，Agent 开始连接过去只有人可以操作的桌面工具、企业 Sass 服务。

甚至连各种传统的 SaaS 厂商，最近都开始主动适配 Agent 了，因为如果你不主动适配：Agent 可以直接逆向你的 SaaS 一键复刻。

![](https://image.woshipm.com/wp-files/sha256/2e/f5/2ef550a5271f20488598b633b721b691a71fb2aad776430be795c69b9b3ebf04.png)

随着这三个要素同步走向成熟，Personal Agent 正式迈入一个全新的阶段：稳步爬升期。

而新版灵光在这个阶段要做的，是让 Agent 真正进入用户的日常生活：

它强调对长程任务的主动托管，全天候云端在线、带着长期记忆，替你主动盯紧那些时间长、变量多、容易遗漏的日常琐事；

它同时具备一定的开放连接能力，用户可以按需接入 CLI、API 等外部 工具，把任务执行自由延伸到更多工作与生活场景，逐步串联起个人上下文、其他 Agent 以及部分智能设备能力。

## 04 为什么是灵光？

最后聊一个关于 Personal Agent 的判断：

**从过往龙虾时代的经验看，Personal Agent 这个赛道，大概率还是一个大厂才能跑通的赛道。**

原因是，Personal Agent 需要的东西太多了：底层模型能力、云端算力、工具生态、用户数据的安全保障、与主流办公软件和通讯工具的深度整合。这些要素叠在一起，创业公司很难同时具备。

过去大半年里，灵光团队积累了非常浓厚的实战经验：

灵光最初切入的是个人 Coding Agent 和生活 Personal Agent 赛道，上线后增长非常猛，甚至击败了 ChatGPT 和 Sora 达到百万下载的速度纪录：灵光的头 4 天达到 100 万下载，6 天超过 200 万。

正是有了这样的经验，他们才知道用户真正要的是什么，当你去体验灵光的时候，你会发现它的运行速度，交互体验都非常的不错。

所以从这个角度看，灵光团队对 Agent 产品的理解，可能已经早早地跑在了行业前面：在 Muse 爆火前，灵光团队就已经意识到并针对性的打磨这个阶段的 Personal Agent 产品。

**这些积累叠加在一起，可能会让蚂蚁灵光在这轮 Personal Agent 的热潮中迎来一轮新的增长。**

写完这篇文章，我回头看了看自己在灵光的云电脑上跑着的那些 Agent，它们还在安静地运行着、处理着交给它们的各种定时任务。

半年前，我们还在讨论 Agent 到底能不能真正帮人干活，在过去的这半年里，Work Agent 的爆火和真实的市场付费率给出了答案。

**半年后的今天，Personal Agent 拿回了接力棒。属于它的新阶段，也已经正式开始了：**

也许未来这半年，每个人都会逐渐接入自己专属的 24 小时在线的生活管家。

当每个人都可以通过任意方式，和一个可以调用无数真实的 Saas 工具、App、还能记住你所有偏好的 Personal Agent 交互时，我们的生活方式会发生怎样的变化？

新版灵光还在小范围内测，请大家耐心等待，估计最快本月可能就会发布了～
